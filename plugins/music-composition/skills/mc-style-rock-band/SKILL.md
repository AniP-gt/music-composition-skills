# バンド編成のスタイル層（Rock / Band）

**このスキルは、ロックの響きそのものよりも、次の問いを軸に構成している。**

> **同じ部屋にいる5人が同時に演奏する必要があるとき、この音楽はどう変わるか？**

この制約は「ロック」というスタイル名よりも編曲の判断に役立ち、パンク、インディー、ファンク、カントリー・ロック、ブルースにも当てはまる。**コーパスで `Alt-Rock---Blues---Country-Rock---Indie---Funk---Reggae` がひとまとめになっているのも、この考え方による。**

## 2. ★ 転用表

| 手法 | 他のスタイルに転用できるか | 説明 |
|---|---|---|
| **編成を制約にする**（先に編成を決めてから書く） | ✅ ★ **転用でき、取り入れるべき** | 音源を際限なく使えることの最大の弊害は、何を残して何を外すかを決めずに済むこと |
| **ごく少ない音で始める** | ✅ ★ **転用可**（§4） | 実測ではロックが最も少なく、手本にできる |
| **riff を hook にする** | ✅ 転用可 | `arrangement_hook`（lint #8）の実現方法の一つ |
| **Power chord（平行5度）** | ⚠️ **条件付きで転用可** | 独立した声部を書く技法とは区別し、**音色を作る手段**として扱う。本格的な声部書法を使う編成に持ち込むと、そのルールに抵触する（§5.1） |
| **全員のユニゾンで決める** | ⚠️ 条件付きで転用可 | ポップスでも効果的。多用するとボーカルを覆う |
| **歪んだギターの帯域の使い方** | ❌ 転用不可 | 中域のほぼ全体を占めるため、他のスタイルでは持て余す |
| **「実際に演奏できる」という基準** | ✅ ★ **転用可** | §7 |

★ **判断基準**：
> **バンドの規律（編成の制約、音数を絞った冒頭、実際に演奏できること）は転用できる。
> 帯域を占有する方法（歪んだギター + 全員のユニゾン）は持ち込まない。**

## 3. 編成は演奏上の制約

### 3.1 先に編成を決める

**バンド音楽と制作主体の音楽の根本的な違い**：
制作主体の音楽では「もう1レイヤー足す」ことに追加の負担はない。バンド音楽で**1レイヤー足すには、奏者を1人増やすか、オーバーダビングを1回増やす必要がある**。

★ **この制約が役に立つ**。
`mc-texture-layering` の冒頭にある「音楽の空間には限りがあり、限度を超えて足すと既存の音を覆う」という言葉は、
バンド編成では注意事項にとどまらず、**物理的な事実**になる。

### 3.2 オーバーダビングをめぐる2つの基準

| | 説明 |
|---|---|
| **ライブで演奏できる** | 編成 = 人数。**この基準で組むと最もすっきりした編曲になる** |
| **オーバーダビングできる** | ギターのダブルトラック、キーボードのレイヤー、コーラスを加える。★ **その場合、この曲をライブでどう演奏するかを考える** |

**実務上の折衷案**：**核となる4パート（ドラム/ベース/ギター/ボーカル）はライブで成立させる**。
オーバーダビングしたレイヤーは**彩り**とし、抜いても曲が成立するようにする。

### 3.3 編成が riff の書き方を決める

| 編成 | riff の書き方 | ページ |
|---|---|---|
| **Power trio／ボーカルを含む4人編成**（和音を担う楽器は1つだけ） | 2音以上の riff に寄せる。コードを使った riff はより魅力を出しやすい。単音 riff では一部の音に3度を加えてコードをほのめかす。2音ともルート以外が望ましく、**ルートはベースに任せる** | Rooksby《Riffs》p0140、p0048 |
| **2本目のギターがある** | riff にハーモニーをつけられ、単音 riff を重ねることもできる | Riffs p0140 |
| **キーボード奏者がいる** | 歯切れのよい単音 riff を試し、キーボードで和声を補う。★ **riff が引き立つようキーボードの音数を絞る**（Deep Purple の方法） | Riffs p0140 |
| **ベースなし**（White Stripes のような編成） | マイナー・ペンタトニックの各音の上にメジャー・トライアドを作り、6つのメジャーコードを使えるようにする（reference §7） | Riffs p0123 |

★ §3.1から言えること。**編成を確定すれば、riff を何音にするか、誰がルートを弾くかは半ば決まる。**

### 3.4 ツインギターの分担

| 分担 | 説明 | ページ |
|---|---|---|
| **1本は riff、もう1本はコード** | サビでは riff を弾くギターがボーカルのメロディに沿い、もう1本はストレートな8分音符でコードを弾く。2本目のギターやベースで riff を重ねず、編曲に余白を作る | Riffs p0056 |
| **1本は riff、もう1本は shuffle** | コードが C、D に移ったとき、もう1本は riff を移調せず、標準的な shuffle を弾く。ソロ後に riff が戻ってきたとき、新鮮に聞こえる | Riffs p0038 |
| **2本で似たパートを少し変えて弾く** | 2本のギターで似ているが完全には同じでない part を弾く（All Right Now）。同じスケールの riff で一部の音を変える方法もある（Helicopter） | Riffs p0111、p0139 |
| **音を分担する** | 速い5度を1人できれいに弾くのが難しい → 2本で単音を1音ずつ弾く。3度のハーモニーも2本で1音ずつ分担する | Riffs p0139、p0178 |
| **ツインリード（twin lead）** | 2本のギターで主に3度の平行ラインを弾く（Wishbone Ash、Thin Lizzy、Queen）。3度は1–2弦または3–4弦が最適で、低音弦では濁る | Riffs p0043 |
| **1本は持続音、もう1本は riff** | 1本目はペダル音を担わず、ステレオの反対側に置いた2本目が最後に入り、D5 で支える | Riffs p0091 |
| **左右に分ける** | intro では riff が中央で1回だけ鳴り、バンドが入ると riff が左右のギター2本に分かれる | Riffs p0038 |
| **6弦に12弦を重ねる** | オーバードライブをかけた6弦ギターに、エレキ12弦を小さめの音量で重ねる。高いオクターブの弦で倍音感を加える | Riffs p0139 |

★ §5.1との関係。**ツインギターで1本ずつ独立したラインを弾くと、平行5度が再び問題になる。ツインリードの平行3度は定番の語法として使える。**

### 3.5 チューニングが編曲に与える影響

（全表は [reference.md](reference.md) §6–§7を参照。）作曲段階で押さえておく5点。

- **キーが響きを決める**：同じ I–bVII–IV でも移調すると、使える開放弦の数や最低音が変わり、ギターの響きに大きく影響する（Riffs p0122）。ハードロックの第一候補は E、A。F#、B も人気がある。主音の全音下にある開放弦がちょうど bVII になるため（Riffs p0122）。
- **チューニングを下げて重さを出す**：全弦を半音下げると、運指はそのままで半音低くなる。半音下げるごとに弦のゲージを1段階太くする。そのままでは弦が緩み、ピッチが不安定になって、強いピッキングに耐えにくい（Riffs p0124）。Dropped D ではギターが E より D に寄り、低音側の3弦を指1本でセーハできる（Riffs p0126）。
- **オープン・チューニングで書ける riff が変わる**：open G では「セーハしたメジャー・トライアドに sus4/6/9 を加える」on/off のパターンが、標準チューニングより効果的に響く（Riffs p0125）。DADGAD はバロック風フォークと北アフリカ音楽の持続音の模倣に由来する（Riffs p0125）。
- ★ **チューニングを変えたら歪みを減らす**：オープン／変則チューニングでは共鳴、サステイン、倍音が強くなるため、歪みを抑えるとよい。隣り合う弦で全音／半音差の音を密集させる場合は、よりクリーンな音色が必要（Riffs p0127）。`mc-sound-design` の音色の判断も同じ方針にそろえる。
- **移調すると開放弦が使えなくなる**：元の riff に開放弦を使っていると、移調先の多くではその開放弦を使えない。特にペダル音／持続音／転回形／コードを使う riff は影響を受けやすい（Riffs p0122）。対処法は§6.6。変則チューニングで書いた riff は必ず運指を記録し（Riffs p0127）、**`roster[].note` に書く**。

## 4. ★ 実測：ロックは冒頭の楽器が最も少ない

Cambridge-MT のマルチトラック音源の実測（各スタイル10曲）。各スタイルの「冒頭から鳴る楽器が roster 全体に占める割合」。

| スタイル | 冒頭から鳴る楽器の割合 |
|---|---|
| ★ **rock** | ★ **8%** |
| jazz-acoustic | 16% |
| Alt-Rock パック | 20% |
| pop | 21% |
| edm | 21% |
| hiphop-rnb | 24% |

**読み取り方**：★ **ロックは全スタイルの中で、冒頭の楽器を最も絞っている。**

**理由**：後で**全員でユニゾンする**ため。
**冒頭から全員が鳴っていれば、全員で演奏する箇所の落差がなくなる。**

> **実測は、このリポジトリの強いルールも裏づけている**。「冒頭で一度にすべての楽器を鳴らさない」は **54/59 件で該当**。
> ★ ロックはこのルールを満たすだけでなく、最も徹底している。

**自己チェック**：★ **冒頭で鳴る楽器を数える。roster 全体の20%を超えたら、多すぎる。**

### 4.1 その他の実測値

| 指標 | rock | Alt-Rock パック | pop |
|---|---|---|---|
| roster の規模（中央値） | 30 | **38** | 36 |
| 途中から入る楽器数 | 26 | 28 | 29 |
| 終わりまでに抜ける楽器数 | 18 | 16 | 16 |

⚠ **BPM は引用しない**（歪んだギターに対する beat tracking の信頼性は未検証）。

## 5. ハーモニー：ここではどの一般則が通用しないか

### 5.1 ★ Power chord と平行五度

`mc-counterpoint` reference §1 のルール 2 では、**平行五度と平行八度を厳禁**としている。

★ **ここではそのルールを適用しない**。ただし、**理由を明確にする**。

> **Power chord は音色として扱う。**
> 第 3 音がなく、機能和声に関与しない。平行移動では、**同じ音色を別の音高に移しており**、
> **独立した 2 つの声部を動かしているわけではない**。

★ **判断基準**。**この 2 つの「声部」がそれぞれ独立した旋律かを確認する。**
独立していない → 1 つの音色なので、自由に平行移動できる。
独立している → 平行五度が再び問題になる（たとえば 2 本のギターがそれぞれ別の旋律を弾く場合）。

Rooksby は音色の観点から同じ結論を出している。五度には第 3 音がなく、長短の区別もないため、**強く歪ませてもロックで有効な響きを保てる**。これは歪みによって倍音が強まることと関係する（Rooksby《Riffs》p0030）。三度は長短調の情感を担い、低音弦では濁る（Riffs p0030、p0096）。そのためロックの riff では三度より五度を多く使う（Riffs p0043）。

### 5.2 弱進行（D→S）

`C–G–F–C` のような「ドミナントからサブドミナントへの進行」は、古典和声では誤りとされる
（`mc-harmony` reference §5 の対照表）。

> ★ **ロックやフォークでは標準的な語法。**
> 3 つのコードすべてに短七度を加える（C7/F7/G7）と、ブルーノートを含むブルースの響きになる。

### 5.3 引き続き有効なルール

- **機能和声の進行の骨格**は引き続き有効（T–S–D–T）
- **調外のコード**は引き続き響きに彩りを添える（lint #9 も引き続き適用）
- ★ **ベースラインの設計**は引き続き有効。**スポソービンと日本の実務の両方が認める唯一のルール**

### 5.4 riff から導くハーモニーのルール

| ルール | 説明 | ページ |
|---|---|---|
| **半音離れた 2 つの長三和音は同じ長調に収まらない** | 五度や長三和音を半音ずらすと必ず調外音が出る。それが「反抗的」に聞こえる理由。パンクでは、12 小節の各コードの前に半音下の長三和音を入れる | Rooksby《Riffs》p0018–p0019 |
| **bVII は一般的** | 全音の移動で導音がなくなり、旋法が Mixolydian になる。I–bVII–IV はロックの中核となるコード進行。「長調の I–IV–V riff 1 つに対して、Mixolydian の I–bVII–IV riff が 2、3 個あるかもしれない」 | Riffs p0022–p0023、p0097、p0100 |
| **マイナーペンタトニックの各音に長三和音を作る** | A マイナーペンタトニック → A、C、D、E、G の長三和音。F も追加できる。別の言い方をすると、長調から減三和音と 3 つの短三和音を外し、第 3／6／7 音を半音下げて長三和音にする | Riffs p0123 |
| **マイナーコードは少ない** | ロックでは五度が好まれ、マイナーコードの「感情の強すぎる響き」は敬遠される。最も一般的なマイナーコードの riff は I–VII–VI（Am–G–F） | Riffs p0104 |
| **riff の旋法は下で鳴るコードで決まる** | 第 3 音のない riff がどの旋法に聞こえるかは、リズムギターやベースで決まる。旋法を使う riff には、その特徴を弱めないハーモニーが必要 | Riffs p0071、p0078 |
| **旋法で響きに彩りを添える** | ロックで旋法を「純粋」な形で使うことは少なく、メロディもコードも一貫して旋法の音だけで組む例はさらに少ない | Riffs p0077 |
| **暗示されるコード** | ギターが同じ音を保ち、その下でベースが動くと、コードが変わったように聞こえる。同じ五度でもベース音が変われば別のコードに聞こえる | Riffs p0037、p0033 |
| **ヘヴィな曲でのメジャーセブンスコード** | 甘すぎるためヘヴィロックでは使用例が少ないが、ヘヴィロックの力強さとうまく組み合わさると効果は大きい | Riffs p0137 |

これらは §5.2 と同じ考え方に基づく。**ロックのハーモニーの骨格はブルースと Mixolydian にある。** `mc-harmony` にある長調の機能和声のルールは骨格として残り（§5.3）、響きの彩りは riff の音程で決まる（§6.2）。

## 6. hook としての Riff

**バンド音楽では、`arrangement_hook`（lint #8）は通常 1 つの riff である。**

| 要点 | 説明 |
|---|---|
| **耳に残る聴かせどころにする** | ★ `example-01` の「シンセリードは hook だけ弾き、伴奏の下支えには使わない」と同じ考え方 |
| **聴こえる余地を作る** | riff が鳴る間、ボーカルは通常歌わない（**交互に出す**。`mc-texture-layering` §4.2 の方法③） |
| **再登場させる** | `hooks.arrangement_hook.recurs_at` に、どのセクションで再登場するかを明記する |
| **リズムでも作れる** | 特定の休止やシンコペーションも riff として使える |

詳細（分類表、反復パターン、変形の手法、譜例索引、用語）は [reference.md](reference.md) を参照。以下は riff を書くときに確認する 7 項目。

### 6.1 riff の条件は短さ、反復、覚えやすさ、低さ

Rooksby の実用上の定義は、**「短く、繰り返され、耳に残るフレーズ。通常はギターの低音域で弾かれ、ロック曲のエネルギーと高揚感の大半がそこに集中する」**（Rooksby《Riffs》p0007）。4 つの特徴には、それぞれ次の条件がある。

- **短さ**。1–4 小節。それより長いとメロディやソロに聞こえる（Riffs p0007）。
- **反復**。耳に残す手段であると同時に、曲を前に進める力にもなる。「蒸気機関車の火室に石炭をくべる」ようなもの（Riffs p0007）。
- **覚えやすさ**。固有のリズム、ハーモニー、メロディの特徴で耳に残す（Riffs p0007）。確認には **RHM の公式**を使い、リズム／ハーモニー／メロディの 3 面をチェックする（Riffs p0008）。
- **低さ**。ギターの riff は多くが低いほうの 3 本の弦で弾かれる。「力強さと威厳」があり、低音がその上のハーモニーを決めるため（Riffs p0007）。高音域の riff は例外で、エコーで厚みを出してベースと組み合わせる（The Edge、Riffs p0008）。

★ **riff の 4 つの役割**は、リズムで体を動かす、ボーカルがないセクションを埋める、強弱の対比を作る（A メロでは抑え、器楽セクションで riff を一気に鳴らす）、一時的にコード進行の代わりを務める、の 4 つ（Riffs p0008）。**書く前に、その曲でどの役割を担うかを言葉にする。**

**判断基準**。十分に頻繁に繰り返され、輪郭が明確で力強いリズム型があれば、コード進行も riff になる（Riffs p0013–p0014）。逆に、同じコードでも intro／verse では明確なリズムによって riff になり、chorus では単なる伴奏になることがある（American Idiot、Riffs p0100）。**riff と伴奏の区別はリズム型で決まる。**

### 6.2 分類：素材を選ぶとハーモニーの条件も決まる

Rooksby は 3 グループ、計 30 種類に分類する（Riffs p0013。全表は reference §1）。
**① 2 つの単音間の音程**。半音／全音／オクターブ／五度／四度／三全音／三度／六度／混合。
**② 音階**。マイナーペンタトニック／ブルース／メジャーペンタトニック／長音階／Mixolydian／自然短音階／Dorian／Phrygian／Lydian／Locrian／半音階。
**③ コード**。ペダル音／持続音／アルペジオ／長調のコード／Mixolydian のコード／短調のコード／掛留／三和音／転回形／定型外。

作曲時は、好みの響きとともに**種類ごとに生じるハーモニー上の条件**を確認する。

| 選ぶ素材 | 生じる条件 | ページ |
|---|---|---|
| 五度や長三和音を半音ずらす | 必ず調外音が出る。それが「反抗的」に聞こえる理由で、どの長調にも収まらないことを意味する | Riffs p0018–p0019 |
| 全音移動 bVII→I | 導音がなくなり、旋法は Mixolydian になる。bVII のコードが伴う | Riffs p0022–p0023 |
| 五度、四度、オクターブ | 長短の区別がなく、上にはどんなコードも合わせられる。**ハーモニーは他のパート（ベース／リズムギター）が決める** | Riffs p0027、p0030、p0034 |
| 三度、六度 | 長短がはっきりする。甘く、攻撃性に乏しい。低音弦では濁る | Riffs p0043、p0048、p0096 |
| マイナーペンタトニック／ブルーススケール | メジャーコードの上では「硬く」、マイナーコードの上ではなじんで主張が弱まる | Riffs p0053 |
| メジャーペンタトニック | マイナーコードの上に置くと「かなり響きが悪い」 | Riffs p0063 |
| Dorian／Phrygian／Lydian／Locrian | 旋法の特徴を弱めないハーモニーが必須。さもなければ別の旋法に聞こえる（譜例 5.15 は Dorian ではなく Mixolydian に聞こえる）。旋法は曲全体を厳密に統一するよりも、響きに「彩り」を添えるために使うことが多い | Riffs p0077–p0078 |
| 半音階 | 安定感を保つには、安定したドラムのビートとルート音の明示が必要 | Riffs p0085 |
| ペダル音／持続音／転回形／開放弦を含むコード riff | 移調すると開放弦が使えなくなるので、作曲の段階で解決しておく | Riffs p0122 |
| 定型外のコード | 使いすぎない。「普通がなければ、何が変わっているか分からない」 | Riffs p0116 |

**riff 単体で旋法が決まらない条件**。第 3 音がない場合（大半の五度／四度／オクターブ／ペンタトニックの riff が該当）は、**下で鳴るコード**が旋法を決める。Taxman、Paperback Writer がペンタトニックよりも Mixolydian に聞こえるのは、リズムギターの長三和音による（Riffs p0071）。**riff に加えて、その下で鳴るコードまで書いて完成とする。**

非対称な riff（変わった音階、変則的なアクセント、予測しにくい跳躍、拍子の変化）は演奏者には面白いが、幅広い聴き手の共感は得にくい（Riffs p0013）。Smoke On The Water のような riff を狙うなら、こうした要素を重ねすぎない。

### 6.3 長さと反復

- **長さ**。1、2、4 小節が一般的。3 小節は珍しい（繰り返すと 6 小節になり、「4」のまとまりから外れるが、4 回なら 12 小節になる）。4 小節を超えると 1 つのまとまりに聞こえにくい（Riffs p0129）。4 小節は通常、応答関係にある 2 つのフレーズに分かれ、分かれない例は少ない（Riffs p0072）。
- **反復パターン**。1 小節を a1 とすると、基本形は **3+1** の `a1 a1 a1 a2`。8 小節は `a1 a1 a1 a2 / a1 a1 a1 a3`、16 小節は末尾に a4 を加える。問いと答えの形は `a1 a2 a1 a3`（Riffs p0129–p0130。全表は reference §2.2）。
- ★ **変形ごとの和声的な完結度**。a4 が全体の終わりなので、a2、a3 は a4 より強い終止感を持たせない。A を主音とする調なら、a2、a3 は D、E または bIII、bVII をほのめかす音で終えるとよい（Riffs p0130）。
- **反復回数**。intro で riff を 4 回弾くところを 3 回だけ弾いて A メロに入る（Tush、Riffs p0038）。4 小節の反復を 3 回または 5 回に変えると、聴き手は変化を早く感じ取る（Peter Buck、Riffs p0132）。1 小節の riff を 4 回（約 10 秒）弾いただけで歌に入る形も成立する（Riffs p0056）。
- **上限の判断基準**。聴き手が「riff は最高だけど、曲が終わるのが早すぎる」と感じて再生し直すのが狙い（Riffs p0118）。全編で 1 つの riff を貫くと力強さが出るが、飽きさせずに続けるのは難しい（Riffs p0047）。

**自己チェック**。ボーカルが入るまでに riff が何回鳴ったかを数える。4 回以上鳴り、アクセント、ベース音、楽器の追加といった変化が何もなければ、すでに riff の新鮮さが薄れている。

### 6.4 リフとボーカル：場所を譲るか、鳴らし続けるか

どちらの関係も成立する。意図して選ぶ。

| 関係 | やり方 | ページ |
|---|---|---|
| **交互に出す**（リフが鳴る間は歌わない） | ボーカルのない部分をリフで埋める。ヴァースでは抑え、インストのセクションで一気に解放する | Riffs p0008 |
| **リフを句末に置く** | 歌詞への注意をそらさないよう、各フレーズの末尾にリフを入れる（Queen Bitch）。歌詞と同時に鳴らさず、歌詞を「念押し」するように鳴らす（The Thunderthief、Money） | Riffs p0099、p0145 |
| **リフを鳴らし続け、その上で歌う** | ハードロック／メタルでは intro からヴァースまでリフを続け、その上でボーカルが歌う | Riffs p0130 |
| **ボーカルがリフの上を走る** | メロディーがリフに追従せず、その上を「乗り越える」ように動き、対位的なリズムを作る（Howlin' Wolf） | Riffs p0046 |
| **ヴァースで素材を変える** | 変化しない単一のコードの上で歌い、そのあとで動きの多いリフにつなぐ。静的なコードならボーカルへの注意がそれない | Riffs p0047 |

★ **リフとボーカルを両立させる3つの条件**（Riffs p0131）。複雑なリフはメロディーから注意をそらし、コードのように和声面で下支えする働きもない。リフにメロディーを重ねるなら、**①メロディーのリズムをリフに合わせる。②リフの音と和声的に調和する音をメロディーに選ぶ。③リフに隙間があれば、そこにメロディーを置く**。

**音域での解決**。低音域のリフは、高音域のギターリフほど主旋律のボーカルとぶつからない（Ball Of Confusion、Riffs p0056）。高いギターリフと低いベースを組み合わせると、編曲の中音域をボーカルのために空けられる（U2、Riffs p0037）。ヴァースでリフを弾くギターをミックスから外し、ベースだけにリフを弾かせる方法もある（Smells Like Teen Spirit、Riffs p0131）。

**うまくいかない場合**。歌詞とぶつかる音がリフにあれば、ボーカルが入るところで削る。Are You Gonna Go My Way では、歌が入るとリフの4度音が消える（Riffs p0062）。リフの上行フレーズは歌のフレーズ間の隙間に置くと、伴奏と hook を兼ねられる（Street Life、Riffs p0065）。

### 6.5 曲の構成におけるリフの位置

Rooksby が挙げる位置は、**intro、ヴァースを通して、ヴァースとサビのつなぎ、ソロの下や導入、coda での再現**（Riffs p0131）。それぞれに使い方がある。

| 位置 | 使い方 | ページ |
|---|---|---|
| **intro riff** | まず短縮版（5音で、解決しない音で止まる）を出し、次に完全版を出す。「リフを1本書き、完全版の登場を遅らせるために短縮版を作る」 | Riffs p0095 |
| | intro が12小節の第9小節から始まったように聞かせ、リフが入るときのインパクトを強める | Riffs p0025 |
| | リフの入りを遅らせる。シーケンスで鳴るシンセ→ピアノ→ドラムと進み、最初のヴァースのあとでようやくギターリフが入る | Riffs p0099 |
| | 最初の5秒で耳を引く。ベースの E のオクターブとギターの Bb のオクターブで三全音を作る | Riffs p0041 |
| **verse riff** | ヴァースでは簡略化し、サビやつなぎでは完全形を残す | Riffs p0131 |
| | ヴァースではベースだけでルートを弾き、コードは暗示する。または、ベースが単独でルートを弾いて第3ヴァースを支え、そのあと左右のギター2本が重ねる | Riffs p0098、p0102 |
| | ベースリフが最初のヴァースを支え（シンバルとボーカルのみを添える）、他の楽器が入ってもサビまで続く。「リフを続け、その上で別のことが起きる」ことでテンションを作る | Riffs p0070 |
| | ヴァースのリフにはベースを入れず、サビで入れる | Riffs p0111 |
| **つなぎのリフ** | アルペジオのリフでサビとヴァースをつなぐ。最初のサビのあとの2本目のリフを、第2ヴァースへのつなぎにする | Riffs p0094、p0070 |
| **ソロのセクション** | ソロでは簡略形を使い、全音上に移調することが多い | Riffs p0064、p0121 |
| **coda** | 終わりで移調し、何度も聞いたリフを新鮮に聞かせる。リフを E に移してギターとベースの最低音を使うと、最も力強い | Riffs p0120、p0082 |
| **1本のリフで全曲を支える** | 2小節のリフを、時折アクセントを変えるだけで全曲に使う（Louie Louie、Riffs p0100）。3種類の変形で全曲を支える例もある（Ain't Talkin' Bout Love、Riffs p0096）。変形に段階を設けることが前提（§6.3） | |

**ベースを入れるタイミング**（Riffs p0139）。最初の1分で手を使い切らない。①最初はギターの1オクターブ下を重ね、あとでもう1オクターブ下げる。②最初はペダル音を弾き、あとでユニゾンに入る。③ベースが先にリフを弾き、あとからギターを重ねる。

**セルフチェック**。`hooks.arrangement_hook.recurs_at` に書いたすべての登場箇所で、「前回と何が違うか」を説明できるようにする（簡略化／完全版／移調／低音変更／楽器変更）。まったく同じ形が3回以上出るなら、§6.6 の手法を使えていない。

### 6.6 変形の手法

RHM の3つの側面から変化をつける。リフは完成品と決めつけず、「一面だけを見せている物体」と考える（Riffs p0118。全表は reference §3）。

| 側面 | 手法 | 要点 | ページ |
|---|---|---|---|
| リズム | テンポを試す | 演奏可能な上限より、**リフらしさを保てる最速のテンポ**を目指す。デモは遅めになりがち | Riffs p0118 |
| リズム | 長さを詰める | 終わりで4小節のリフを2小節に縮める。テンポは変えずに加速したように聞かせる | Riffs p0134 |
| リズム | アクセント移動／音価の順序を反転／1拍ずらす | 反復時に元はなかったアクセントを足す。付点8分音符＋16分音符の順序を逆にする。一部の音を1拍または半拍、前後にずらす | Riffs p0134、p0060 |
| リズム | 拍子を変える | 4/4 を 5/4 に入れ、余った1拍の休符でドラムに fill を入れる。3/4 を1小節挟み、次のセクションを1拍早く始める | Riffs p0135、p0132 |
| ハーモニー | リハーモナイズする | 長調→平行短調。5度／4度だけのリフに、曲のセクションに応じてメジャーコードとマイナーコードを付ける | Riffs p0119 |
| ハーモニー | ベース音を変える | ユニゾンのリフのベース音を変えて転回形を暗示する。第1転回形はルートのユニゾンより「安定感」が薄く、ルートのユニゾンの登場を遅らせられる | Riffs p0119 |
| ハーモニー | 音を保ち、文脈を変える | リフはそのまま、コードを Em→G→C→F と動かす（Androgyny）。「音符を変えず、それが聞こえる文脈を変える」 | Riffs p0119–p0120、p0184 |
| ハーモニー | 一部にハーモニーを付ける | 最終小節の上にだけ数音足す。3度／6度は長調・短調の色を付け、4度／5度／8度は空虚な響きを保つ。オクターブを選ぶならボーカルラインの音高も見る | Riffs p0140 |
| 音高 | 移調（構成に沿う） | 12小節の中で、まず4度上、次に5度上に移し、1小節のリフ1本で12小節を支える | Riffs p0120–p0121 |
| 音高 | 移調（構成に縛られない） | 最も一般的なのは長2度上（第2サビ後のソロ）。短3度に移すか、ペンタトニックに沿って順に移す方法もある。不穏さが欲しければ半音か三全音を使う | Riffs p0121–p0122 |
| 音高 | オクターブで重ねる | 同じ音高では2–3トラックを超えて重ねても音量は増さない。異なるオクターブで重ねる | Riffs p0139 |
| 形式 | 繰り返すたびに発展させる | A5 のリズム→短3度を足す→短3度を bIII のコードにする→走句で厚みを足す。「発展はロックでほとんど使われない」ので、たまに使うと意外な効果がある | Riffs p0177、p0175 |

**うまくいかない場合**
- 移調すると開放弦が使えなくなる。ペダル音／持続音／転回形／コードを使うリフは特に影響を受ける。スタジオではカポタストやチューニング変更で移調版だけを重ねられるが、**ライブでどう弾くかも考える**。変形を書く機会と捉え、「作曲で解決する」とよい（Riffs p0122）。§3.2 と同じ出典に基づく。
- 音を足すなら理由を持つ。「どの音もハーモニーかリズムの役に立つように選ぶ。理由がなければ弾かない」（John Paul Jones、Riffs p0146）。

### 6.7 リフとベース、ドラムの対位

★ リフが「実際に演奏したように」聞こえるかを決める要点で、§7 に直結する。

**ドラムとの関係**（Riffs p0135）
- 基本は**リフの音をドラムの隙間にはめ込む（dovetail）**か、**ドラムと同時に鳴らす**かの2つ。特にキックとスネアに注意し、どちらかを基準に書くか、片方の音が抜ける隙間を作る。
- 定番は、**スネアの打点を空け、その前後で弾く**こと（Riffs p0135）。You Really Got Me の力強さは、リフの隙間に強く入るスネアから生まれる（Riffs p0024）。Last Resort のインパクトは、音と音の間で拍の間隔が明瞭なことから生まれる（Riffs p0076）。
- 最も効果的なオクターブリフはドラムとかみ合っている。各音をリズムのどこに置くかよく考える（Riffs p0027）。
- 優れたリフの多くは、ドラムマシン／ドラムループ／ドラマーに合わせた即興から生まれる。リズムの伴奏がないと、ハーモニーやメロディーの面白さを追いがちだが、ロックの中心はリズムにある（Riffs p0135）。
- John Paul Jones 流では、リズムセクションの視点でリフを考える。スネア（またはキック）を際立たせたいならリフの中に隙間を作る。複雑なリフでは、リフを止めてドラムのダイナミクスを出したほうがよい箇所もある。**「全員が同時に演奏すると、重くなるどころか弱くなる」**。テンションは細部に置き、リフの各部分を互いに押し引きさせる（Riffs p0145–p0146）。

**ベースとの関係**
- リズム面で優れたギターリフには、ベースが同じ音型を重ね、そのリズムがドラムと一致するものが多い（Riffs p0135）。
- **ベースがリフの和声的な性格を決める**。同じ A–C–G でも、低音が A なら A マイナー・ペンタトニックに聞こえ、F や C ならまったく違う響きになる（Riffs p0129）。ベースが落ち着いてヴァースに入ると、リフの音色も変わる（Riffs p0037）。ギターが同じ音を保ち、その下でベースが動くと「暗示されたコード」が生まれる（Riffs p0037）。
- ギターが転回形を使うリフでは、ベースも転回形の最低音を追う必要があり、ルートだけでは効果が弱まる（Riffs p0174）。転回形を試すなら、**ギターのコードを変えるよりベース奏者に音を変えてもらうほうが簡単**（Riffs p0115）。AC/DC は聴き慣れたペンタトニックのコードリフで、ベースの転回形やペダル音によって「和声のねじれ」を作る（Riffs p0100）。
- アルペジオのリフの下では、ベースはルートだけを弾いてコードの変化を際立たせられる（Riffs p0094）。速すぎてベースで模倣できないリフでは、自由に別のラインを弾く（Riffs p0158）。長三和音の下に短音階のベースラインを置くとテンションが生まれる（The Rocker、Riffs p0103）。
- ベースが1音を保ち、上でギターが音程を変える（Radar Love、ZZ Top 風、Riffs p0051、p0090）。これは `bass_kick_relation` の結合型をリフに応用した形。

**セルフチェック**（リフを書いたら必ず行う）
1. スネアの打点とリフの音の関係を説明する。隙間にはめ込むか、スネアのために空けるか、同時に鳴らすか。
2. ベースが同じ音型を重ねるか、ルートを弾くか、ペダル音を弾くか、別のラインを弾くかを説明し、その理由も述べる。
3. 全員が同時に強く鳴らす小節を数える。リフの長さの半分を超えたら、「重くなるどころか弱くなる」という言葉に立ち返る。

## 7. ★ 「貼り合わせたように聞こえる」

**バンドスタイルで最も多い失敗には、具体的な原因がある。**

| 原因 | 対処 |
|---|---|
| **全楽器がグリッドにぴったりそろっている** | → `mc-rhythm-section` §2.2。**楽器ごとにクオンタイズし**、1パートはクオンタイズしない |
| **全員が最初から最後まで鳴っている** | → 少なくとも1パートは先に抜ける（**59/59 の強いルール**） |
| **誰も他の演奏に応えていない** | ★ バンド音楽の本質は**相互作用**。ギターは歌のフレーズ間を埋め、ドラムはギターリフの打点を強調し、ベースはキックに合わせたり意図的に外したりする（→ `mc-rhythm-section` §7.1） |
| **全編でダイナミクスが一定** | 実際のバンドはヴァースでは自然に抑え、サビでは自然に解放する。→ `energy_curve` |
| **fill が 4 の倍数の位置に来る** | → lint #10 |
| **リフとドラムが同時に鳴り詰めている** | → §6.7。「全員が同時に演奏すると、重くなるどころか弱くなる」（Rooksby《Riffs》p0146）。スネアの打点でリフに隙間を作る |
| **リフが毎回まったく同じ** | → §6.3、§6.6。3+1 の変形、ベース音の変更、音は保って文脈を変更する方法を使う |

★ **いちばん直接的なセルフチェック**
> **この5人が同じ部屋にいると想像する。互いの音を聴いているだろうか？**
> どの層も「誰の演奏に応えているか」を説明できれば、実際に演奏した曲のように聞こえる。

## 9. 書き上げたら必ず確認すること

- [ ] **編成を先に確定し**、以後はその範囲内で編曲する
- [ ] この曲を**ライブでどう演奏するか**を説明できる（どのレイヤーがオーバーダブによる彩りか）
- [ ] ★ **冒頭で鳴る楽器数 ≤ roster全体の20%**
- [ ] 少なくとも1つの楽器が**曲の終わりより先に演奏を終える**
- [ ] `arrangement_hook` に**リフ**が1つあり、再登場する曲のセクションを記載している
- [ ] リフが鳴るときに**リフのための余地を確保している**（ボーカルと競合しない）
- [ ] ★ **各レイヤーが「どのパートに応えているか」を説明できる**
- [ ] 少なくとも1つの楽器にはグリッドからのずれが残っている
- [ ] パワーコードを使うときは、**ひとまとまりの音色として扱う**（§5.1）
- [ ] 別のスタイルへ応用するときは§2を確認した
- [ ] リフの**タイプ**（reference §1）、**長さ**、**下で鳴るコード**を記載した（§6.2）
- [ ] リフの反復に変化の段階がある。3+1とし、a2／a3がa4より完全な形にならないようにする（§6.3）
- [ ] リフとボーカルの**関係を選んだ**。交互／フレーズ末尾／継続（継続の場合は§6.4の3条件を満たす）
- [ ] **スネアの打点とリフの関係**、**ベースが何を弾くか**を説明できる（§6.7）
- [ ] 移調で開放弦が使えなくなる問題を、スタジオでの処理に頼らず「作曲で解決」した（§6.6）
- [ ] チューニングを変えた場合は歪みを抑えた（§3.5）
