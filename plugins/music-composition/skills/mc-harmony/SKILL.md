**このスキルは二部構成。作業に応じて使い分ける。**

| 区分 | 作業 | 節 |
|---|---|---|

## 2. 三つの機能

| 機能 | 性格 | コード |
|---|---|---|
| **T（Tonic）** | 安定 | **I、VIm**（VImはIの代理） |
| **S（Subdominant）** | やや不安定で、Dに向かう | **IIm、IV** |
| **D（Dominant）** | 不安定で、Tに戻ろうとする | **V、VIIm(♭5)**（Vが圧倒的によく使われる） |

**Dの不安定さがTへの解決を求める。その心理的な欲求が音楽を先へ進める。**

★ **IIImは表から外してある。** TにもDにもなり得る。§6を参照。

## 3. 三つの終止形

| # | 型 | 聴感 | 例 |
|---|---|---|---|
| 1 | **T → D → T** | 「起立、礼、着席」のように簡潔で力強い | C→G→C（I→V→I）、Am→G→C（VIm→V→I） |
| 2 | **T → S → D → T** | 緊張が段階的に高まり、一気にTへ解決する。**最も満足感が強い** | C→F→G→C、Am→Dm→G→C |
| 3 | **T → S → T** | Dを経由せずにTへ戻る。S→Tは通常IV→Iで、**アーメン終止（変格終止）**と呼ぶ | C→F→C |

**同じ機能を続ける**。同じ機能のコードは連ねて使える。
例 C→Am→F→Dm→G→C（I→VIm→IV→IIm→V→I）
I+VImでT、IV+IImでSを作り、全体としてT→S→D→Tになる。

### 3.1 ★ 終止形と感情（Kachulis）

このライブラリの和声に関する他の3つの出典は、歌詞の内容まで扱っていない。ここではKachulis『The Songwriter's Workshop: Harmony』（p0163–0174）を参照する。

| 終止 | 感情 |
|---|---|
| 完全終止 V → I | 確信 |
| 半終止（Vで止まる） | 不確かさ、緊張 |
| **偽終止** | 意外性があり、着地点によって印象が変わる。**V → VIminは悲しみ、V → IVは驚き、V → VI（長三和音）は明るく弾むような驚き**（p0169） |
| 変格終止 IV → I | 宗教的、精神的な響き |
| 混合終止（長調で短調から借用する ♭VI – ♭VII – I） | 喜びと悲しみが混じる。特にロック・ブルースで効果的 |

完全終止の形は旋法によって異なる（p0163–0165）。長調はV–I、短調は♭VII–IminまたはV–Imin、ブルースはV7–IV7–I7、ミクソリディアンは♭VII–I。★ **ドリアンには完全終止がない**。

### 3.2 主和音からの出発と帰着（p0176–0193）

| セクション | 形 |
|---|---|
| ヴァースとサビ | **主和音 – 離れる – 主和音に戻る** |
| ヴァース | **主和音 – 離れる**。Vで止めてサビへ進む |
| ブリッジ | **主和音から離れた状態 – 離れた状態**。I以外で始めてVで終わる。緊張は最大 |

サビの作り方は二つある。一つの終止形を繰り返すか、テーマとなる歌詞の一節だけを終止させる。★ **テーマの一節が現れるまで主和音を避ける**（p0182–0187）。
ヴァースをVで止めてサビをIから始めると、完全終止でつながる。サビをVIminから始めると、偽終止でつながり、意外性が出る（p0191–0193）。

★ **セクション間の対比を作る四つの和声上の基準**（p0195）。セクションごとに開始コードを変える。各セクションに少なくとも一つ新しいコードを入れる。**完全終止はサビだけに置く**。セクションごとにフレーズの長さを変える。
書き終えたら四つとも確認する。どれも満たさない二つのセクションは、同じセクションのように聴こえる。

### 3.3 コードの色彩で歌詞の意味合いを変える（Kachulis p0149–0160）

同じ音で歌う同じ言葉でも、コードを変えると意味合いが変わる。**長三和音は希望に満ち、パワーコードは力強く自信にあふれ、短三和音は悲しく内省的で、七の和音は憂いと色気を帯びる**（p0149–0150）。
このライブラリでは、コードが歌詞の意味に与える影響をこれまで扱っていなかった。

**フレーズの響きを磨く手順**（p0152–0160）。フレーズの中から重要な音を二つか三つ選び、**小節ごとに一列を割り当てたコード候補表**を作って、組み合わせを試す。1小節に二つコードを置くと、少し推進力が生まれる。
用途別の分類（p0082）では、IImin–IIImin–IV–V、IV–V、IImin–V、VImin–VはいずれもVへ向かう進行で、緊張を作ってサビにつなぐのに使う。

## 4. 小節ごとに和声を付ける手順

1. **土台を確認する**。その調のI、IIm、IV、V、VImと各機能を書き出し、三つの終止形も書き出す
2. **小節ごとに候補を挙げる**。小節内の旋律音を取り出し、**それらを構成音に含む**ダイアトニックコードを探す
   - 旋律音がコードの構成音と一致する → そのまま候補にする（例 A·F·C → F）
   - 複数のコードに含まれる → すべて候補にする（例 B♭·D → B♭またはGm。どちらもS）
3. **終止形で選ぶ**。最初の3小節がすでにT→S→Dなら、第4小節はTに戻る。Tの候補から選ぶ
4. **曲の終わりを決める**。曲全体は最も安定する **I** で終えるのがよい
5. **Tは終点でも起点でもある**。T S D T S T D Tのような機能の並びでは、**一つのTが前後二つの終止形を兼ねる**ことが多い

### 4.1 8小節の実例（ヘ長調、3/4、8小節）

候補一覧はF(I,T)、Gm(IIm,S)、B♭(IV,S)、C(V,D)、Dm(VIm,T)。

| 小節 | 旋律音 | 候補 | 選択 |
|---|---|---|---|
| 1 | A·F·C | F（構成音が完全に一致） | F（T） |
| 2 | B♭·D | B♭またはGm（どちらもS） | どちらでもよい |
| 3 | E·G·C | C | C（D） |
| 4 | A | FまたはDm（どちらもT） | 最初の3小節がT→S→Dなので、ここでTに戻る |
| 5–8 | 同様 | B♭ → F → C → F | S→T→D→TでIに着地する |

**結果**　F → B♭（またはGm） → C → F（またはDm） ／ B♭ → F → C → F

> **まず終止形に当てはめてみると、上達が早い。**
>
> ★ **適用の限界**。実際の楽曲には理論から外れる例がいくらでもある。
> 終止形を必ず成立させようとすると、かえって不自然な進行になる。**例外も認め、柔軟に判断する。**

### 4.2 初心者向けの二つの代理ルールと適用範囲

**IImとIVの交換（S機能内）**は最も使いやすい。任达敏『流行与爵士和声学』では、ii、IV、viを同じサブドミナント機能群に分類し、この群のコード同士の代理が最も一般的だとしている（p0134）。I-IV-V7-IをI-ii7-V7-IやI-vi-V7-Iに変えると、各声部の順次進行がさらに滑らかになる（p0135）。ジャズではこの交換がさらに一般的で、実際にはIVの代理であるii7のほうが元のIVよりよく使われる（p0280）。

**IをIIImで置き換えるときは、二つの判断基準を使い分ける**

- §2・§6のようにIIImの機能を文脈で判断する場合、IをIIImで置き換えるとVImより暗く、Dに向かう途中のコードとして聴こえやすい。
- 任达敏のクラシック／ジャズの機能分類では、iiiはV、vii°7と同じ**ドミナント**機能群に属する（p0134）。iiiからIへの解決力はVより弱く、iii-Iは和声の力が弱いと明記し、終止形のIをiiiで置き換えることは勧めていない（p0135）。長調でのIの標準的な代理はVImで、Iの構成音の大半がVIのコードに含まれるため。これは**長調でのみ成立**し、置き換えた後は通常、Iに続いていたVもii-Vに書き換える（p0279）。
- 副三和音の連用にも代償がある。ある旋律の主要三和音をほぼすべてiii、vi、iiなどの副三和音に置き換え、さらにVImで終えると、全体が関係短調に傾き、元の長調の響きが失われる（p0118、p0120 例1-20）。

## 5. 短調（和声的短音階を基礎とする）

短調の機能表と三つの終止形は長調と同じ構造を持つ。**Vには長三和音または属七の和音を使う**（和声的短音階の第7音を半音上げることで得られる）。
これでD→Tの解決力が得られる。自然的・和声的・旋律的短音階の詳しい比較は[reference.md](reference.md)を参照。

## 6. 目的別の色彩技法早見表

| 求める効果 | まず試す技法 |
|---|---|
| **推進力を強める／輪郭をはっきりさせる** | セカンダリー・ドミナント、ツーファイブ |
| **ジャズらしく／洗練された響きにする** | テンションノート、連続ツーファイブ、裏コード |
| **切なさやかすかな陰りを出す** | **サブドミナント・マイナー（S.M）**、IIIm7 |
| **ベースを半音で下げる** | 分数コード、裏コード、パッシング・ディミニッシュ、クリシェ |
| **長く続くコードの内側に動きを付ける** | **クリシェ**、sus4、保続音 |
| **定型的な属七の響きを避ける** | ドミナント・マイナー、裏コード、解決させないV7sus4 |
| **憂い／クールさ／即興感を出す** | ブルースとブルーノート |
| **セクション全体の雰囲気を変える** | 転調の導入（→ `mc-modulation`） |
| **セクション全体をリハーモナイズする** | §7の9ステップ |

### 6.1 各技法の概要

| 技法 | 効果 |
|---|---|
| **分数コード** | ベース音を指定し、滑らかに、あるいは半音で動くベースラインを作る |
| **IIIm7** | ★ 文脈に応じて、T（Iの代理）にもD（Vの代理）にもなる |
| **セカンダリー・ドミナント（Sec.D）** | 一時的にTとして扱うコードの前に、そのコードに対するV7を置く |
| **ツーファイブ（ii–V）** | 一つのドミナントをIIm7→V7に展開し、推進力を倍増させる |
| **裏コード（三全音による代理）** | V7 → ♭II7。ベースが半音で動き、響きの刺激が強まる。合わなければ♭5を加える |
| **サブドミナント・マイナー（S.M）** | IV→IVm(6)、または♭VI△7／♭VII7で置き換える。**切なさを出す代表的な技法** |
| **モードの響き（ドリアンのIV／ドミナント・マイナー）** | モードの色彩を借り、機能和声の直截な響きを和らげる |
| **sus4** | 解決を遅らせる。**V7sus4を解決させずに使う**と、定型的な属七の響きを完全に避けられる |
| **テンションノート（9/11/13）** | 機能を保ったまま色彩を加える |
| **クリシェ（半音ライン）** | 同じコードを保ち、内声を半音で動かして変化を付ける |
| **パッシング・ディミニッシュ** | 長2度の隙間を埋める |
| **保続音（Pedal）** | ベースを保ちながら上のコードを変える |
| **ブルース／ブルーノート** | ♭3、♭5、♭7で音の摩擦を出す |

（各技法の詳しい使い方、使用可能なテンションの一覧、避ける組み合わせは[reference.md](reference.md)を参照。）

## 7. ★ リハーモナイズの9ステップ

**単調な進行に順番に試す。各段階で最終的には耳で判断する。**

| # | 作業 |
|---|---|
| 1 | **七の和音にする**（三和音 → 七の和音）。**付ける箇所を選び**、全体のバランスを見る |
| 2 | **代理コードに置き換える**。I ⇄ IIIm7/VIm7、IV ⇄ IIm7、V7 ⇄ VIIm7(♭5)/IIIm7 |
| 3 | **セカンダリー・ドミナントを挿入する**。一時的にTとして扱う各コードの前に、そのコードに対するV7を置いてみる |
| 4 | **ドミナントをツーファイブにする**。各属七をIIm7→V7に展開できるか確認する |
| 5 | **ドミナントを裏コードで代理する**。ベースを半音で動かす場合や、刺激の強い響きが欲しい場合はV7 → ♭II7 |
| 6 | **サブドミナント・マイナーを借りる**。IV→IVm(6)または♭VI△7／♭VII7で切なさを出す |
| 7 | **長2度の隙間にdim7を挿入する**。**分数コードでベースを滑らかにする**。**sus4で解決を遅らせる** |
| 8 | **テンションノートを加える**。referenceの表に従い9/11/13を配する |
| 9 | ★ **最後に、やりすぎていないか確認する** |

### 7.1 ★ 最も大切なのは第9ステップ

> **「コードを細かく刻みすぎないこと。」**
> ストレートなロックやポップスでは特に、くどくならないように気を付ける。**シンプルな方がうまくいくことも多い。**

**確認方法**。手を加えた版と元の版を交互に再生する。
**どこがよくなったか説明できなければ、元に戻す。**
和声を複雑にするのは、狙った響きを出すための**手段**。

### 7.2 段階ごとの実例

共通の骨格は `C → Am → Dm → G`（I → VIm → IIm → V、循環進行）。

| 段階 | 進行 | 適用ステップ |
|---|---|---|
| 元の進行 | `C → Am → Dm → G` | ダイアトニック三和音 |
| 七の和音にする | `C△7 → Am7 → Dm7 → G7` | 1 |
| セカンダリー・ドミナントを挿入 | `C E7 Am C7 F D7 G`（I III7 VIm I7 IV II7 V） | 3 |
| ツーファイブにする | `C → Bm7(♭5) → E7 → Am → Em7(♭5) → A7 → Dm7 → G7` | 4 |
| 裏コード＋テンション | `Em7 → E♭7 → Dm7 → D♭7 → C△7(9)`（ベースを半音で下げて締めくくる） | 5+8 |
| 切なさを加える | `C → Am → Fm6 → G7sus4 → G7` | 6+7 |

> ★ 6行それぞれで得られる効果が違う。
> 技法の難しさではなく、§1の必須項目③で決めた色彩に合わせて選ぶ。

## 8. よく使う三つの骨格（詳細は `mc-progressions`）

| 名称 | 進行 | 機能 |
|---|---|---|
| **循環進行** | I → VIm → IIm → V | T→T→S→D。**何度でも繰り返せる**、基本の骨格 |
| **逆循環** | IIm → V → I → VIm | S→D→T→T。Sから始まる循環進行で、長調では循環進行よりもよく使われる |
| **カノン型** | I → V → VIm → IIIm → IV → I → IIm → V | ★ **各コードの構成音を拾うと順次下行する旋律線ができ、最後のコードで上向きに転じる**。ふと一筋の希望が見えるような効果がある |

**逆循環の最も一般的な展開**。2回繰り返し、2回目はIに着地する。または、繰り返したときの末尾のVImを **VIの長三和音**に変える。
`Dm→G→Em→Am ／ Dm→G→C→A`

## 10. 書き上げた後の必須チェック

- [ ] **機能で骨格を作ってから色彩を加えた**
- [ ] セクションごとの和声を**機能の並び**（T S D T…）で説明できる
- [ ] 曲全体が **I** に着地する（余韻のために別のコードで終える場合は、理由も明記する）
