# 曲式とセクション（Form）

**このスキルでは、曲を構成するセクションと、それぞれの長さ、並べる順序を扱う。**

`mc-arrangement-arch`とは扱う範囲が近く、混同しやすい。

> **`mc-form`は曲式の理論と慣例を扱う。
> `mc-arrangement-arch`は個々の曲で区切りを決める理由や非対称な設計を扱う。**

たとえば、**「サビは通常8小節」は form、「この曲の2番のAメロは定型を崩すため14小節にする」は arrangement-arch の範囲。**

## 1. セクション用語の対応

**J-POPと英米の用語は一対一では対応しない**。分析や打ち合わせの前に対応を確認する。

| 日本式 | 中国語／英米の用語に相当する呼称 | 機能 |
|---|---|---|
| **A メロ** | ヴァース（Verse、平歌） | 導入。音域は狭く、音価は短めで、語るように歌う。歌詞で具体的な物語を語り、場面を描く |
| **B メロ** | プリコーラス（Pre-chorus） | ★ 日本独自の「第2の平歌」。Aメロとサビの間にあり、前後とは性格が異なる。音域を徐々に上げ、期待を高める |
| **サビ** | コーラス（Chorus） | 曲のクライマックスとなる楽節。音域が最も高く、密度が最も高く、最も覚えやすい。中心となるメッセージを担う |
| **C メロ / D メロ** | 第3の展開部（ブリッジの位置） | 2番の後に新しい旋律・和声・リズムが現れ、意外な展開を作る |
| **大サビ** | ≈ 英米の bridge / middle eight | ★★ 単にサビを大きくしたものとは異なる。性格は「2つ目のBメロ」に近く、内省的で抑制が効き、ハーフタイムに感じられることが多い。**直後には必ずサビが続く** |
| **頭サビ** | サビから始める構成 | 曲の出だしからサビを聞かせ、すぐに印象づける |
| **落ちサビ** | 編成を落としたサビ | 同じサビの旋律のまま**急に編成を薄くし**（例はピアノと歌だけ）、落差で聞かせる |
| **キメ** | ユニゾンのアクセント／締めのフレーズ | サビの末尾に付く約2小節の印象的なフレーズ。伴奏を急に止めるか特徴的なリズムを打ち、曲のキーワードを歌う |
| **イントロ** | 前奏 | |
| **間奏** | 間奏 | 英語では Second Introduction と呼ぶ。2回目のヴァースとコーラスに向けた前奏 |
| **アウトロ／後奏** | 後奏 | 楽器による締めくくり |
| **ヴァンプ** | グルーヴを提示する部分 | 旋律を演奏せず、リズムパターンを提示するセクション（打楽器だけでも、ベースやギターを加えてもよい） |
| **コーダ** | 終結部 | 最後の番の後に加える**歌のセクション** |
| **1 番 / 2 番** | 1回目／2回目 | Aメロからサビまでの一巡が1つの「番」。旋律を保ち、歌詞と編成に変化をつける、**長く受け継がれてきた飽きさせない工夫** |
| **ブレイク** | Break | 伴奏が完全に止まり、歌だけが残る瞬間 |
| **フィル** | Fill | セクションのつなぎに置くドラムのフィルイン。次の展開への期待を高める |

★★ **訳を誤りやすい2つの用語**
1. **大サビ**に対応する英語は **bridge**
2. 日本語の**平行調**は主音が異なる関係長短調を指す。英語の parallel key に対応する日本語は「同主調」。`mc-modulation` §2を参照

**旋律法の階層**は、部分動機 → 動機 → 小楽節 → 楽節 → 番 → 全曲の順。
> **旋律法でのサビの定義は、「番」という大きな単位の中でクライマックスを担う楽節。**
> **各階層でクライマックスの規模は、その階層のまとまりの大きさに比例する。**

## 2. 標準テンプレート

### 2.1 サビの位置で2つに分ける

| 類型 | 形 | 説明 |
|---|---|---|
| **末広がり型**（後半に向けて広がる） | `[A→B→サビ]` または `[A→サビ]` | サビ以外のセクションはサビを準備する。**現代のJ-POPの大半はこの型** |
| **循環解決型** | `[A→サビ→A]` または `[サビ→B→サビ]` | 末尾で冒頭の旋律に戻る（三部性、**再現の原理**）。1960年代の曲や演歌、歌謡曲、ジャズのスタンダードに多く、現在は減っている |

### 2.2 王道の全曲テンプレート（末広がり型）

```
Intro → 1A → 1B → 1サビ → (間奏1)
     → 2A → 2B → 2サビ → 間奏2
     → Cメロ(大サビ) → 3サビ(転調可) → (3サビ2) → 後奏
```

**要点**

- **A−B−サビの三段構成は日本のポップスで最も一般的**（旋律法では a−b−c の純粋な三段構成。提示 − 視点の変化 − 総合と解決）
- **2番を置く理由**は、同じ旋律のまま響きを少し変え、**歌詞を一新**して飽きさせないため
- 2番の後にCメロやブリッジを挟み（旋律・和声・リズムは一新してもよい）、変化を保ちながら盛り上げ、もう一度サビを聞かせる
- ★ **反復の省略**。1番の `A−A'−B−C` → 2番の `A−B−C` → **3番はサビから直接始めてもよい**
- 全曲で通常 **2–3番、3–5分**。遅い曲では番を減らし、速い曲では増やす（BPMに3倍以上の差がある場合は番の数で釣り合いを取る）
- > **最終的な基準は、聞き手が長さに飽きも物足りなさも感じず、聞き終えて満足できること。**

### 2.3 三部曲式のテンプレート（サビが中央）

```
A(melo) → B(サビ) → A'(melo)    ×2–3 番
```

- 支柱は**再現の原理**。BではAの内容をより感情豊かに展開する（または広い視点から語り直す）。
  Aに戻ることで、深い納得や名残惜しさが生まれる
- AとBの連続性は通常、Verse=Chorus型より強い
- 拡張形 **A−A'−B−A'' は典型的な起承転結の構成**
- まれな変形 A−B−C では、末尾を「何度も同じ音に着地しながら静かに収まる」旋律にし、Aの再現がなくても**冒頭へ帰着したように聞かせる**

### 2.4 その他の形式の早見表

| 形式 | 構造 |
|---|---|
| **二部曲式** | A（ヴァース）− B（コーラス）。欧米のポップスやロックの基本形 |
| **短いブリッジを挟む形** | A −（短いブリッジ）− サビ。独立した第2の平歌を設けず、短いつなぎで音域を上げて盛り上げる |
| **複合三部形式** | `[A−B−A]−[C−D−C]−[A−B−A]` |
| **混合形** | `A−B−サビ−A`（Verse=Chorusの後にヴァースを再現） |
| **単一セクション構成** | サビだけ、またはヴァースだけ。数え歌、物語を語る民謡、ループ型のダンス曲 |
| **CM曲** | A/B/サビを15/30秒に収める。展開を明快にし、**変拍子で長さを調整する** |

### 2.5 EDM／クラブミュージックの変形

**一般的な歌ものよりも長い時間をかけて強度を積み上げる。**

```
four-on-the-floor のキックで開始
 → hi-hat を加える
 → ピアノなどの持続的な伴奏を加える（8小節以上の単位で反復）
 → 本来のイントロ → A メロ → サビ
 → ドラムだけのセクションに戻る → 繰り返す……
```

- 特徴。**旋律はなくてもよい**。構成は長く、規模が大きい。ドラムだけ、あるいはpadだけのセクションがあるため、
  **編成の厚みの落差が大きい**。ドラムを中心に編曲する
- この構成が成立する理由は2つ。(1) ゆっくり音を重ねるほうが踊りやすい。(2) ドラムだけの部分があるとDJが次の曲につなぎやすい
- ★ **自宅では冗長に聞こえる構成でも、ダンスフロアでは効果的。目的に応じて形式が決まる**
- ダンス曲の番は **A−A−A−…−A'−B** となることが多い。ヴァースで一つの動機を何度も反復し、短いサビを加える
- 極端な例では、番の中に動機が一つしかない（a a a a）。**反復が無意識に浸透し、思わず身体が反応する。
  大きなクライマックスがなくても、反復自体が高まりを作る**

## 3. 曲の入り方

歌の本編に先立って導入の楽節を置く。2つの類型のどちらでも使える。

| 方式 | 作り方 |
|---|---|
| **朗読風の前段**（静かな導入） | 中音域で音高をほとんど動かさず、単純なリズムに、和声の変わらない伴奏を合わせる。テンポを自由にしてもよい。朗読と歌の中間から始め、聞き手を自然に作品の世界へ導く（オペラやミュージカルでよく使われる）。構成は `D(序奏) − [A−B−サビ] − [A−B−サビ]` |
| **高揚型の導入**（静かな導入と逆のアプローチ） | 高揚感のある楽節（跳躍と高音域）で始め、日常との大きな落差で一気に聞き手を引き込む |
| **頭サビ** | 導入にサビをそのまま使う**最も一般的な選択肢**。`C−[A−B−C]−[A−B−C]`（Verse=Chorus）、`B−[A−B−A]`（三部）。★ **演奏の仕方は2つ**。元のサビと同じ演奏で華やかに始めるか、薄い伴奏で遅くテンポを自由に取り、語りかけるように導入する |

## 4. セクション間の対比を作る

**セクションの境目が聞き分けられないのは、隣り合う2つのセクションに共通点が多すぎるため。**
具体的な対比の手法は [reference.md](reference.md) §1を参照。ここでは判定基準を示す。

> **確認方法**。隣り合う2つのセクションを次の6項目で比べ、違いがあるものに印をつける。
> **音域／リズムの密度／和声リズム／編成の厚み／歌い方／楽句の長さ**。
> **違いが2項目未満なら、同じセクションが続いているように聞こえる。**

## 5. ★ サビから逆算して設計する

**どの構成でもサビを中心に逆算する。**

| 構成 | 設計方法 |
|---|---|
| **A構成**（単一楽節） | 性格を変えず、簡素にまとめる。同じリフを繰り返すダンス曲では、番全体に動機が一つだけのこともある（a a a a） |
| **A−B構成**（Verse=Chorusの基本形） | 二段構成。欧米のロックやR&Bに多く、耳を引きやすい。**サビがすでにあれば、そこへ導くAを逆算する**。Aがあれば、どんなサビが続くか考える。★ **サビは出だしのインパクトに加え、後半にも十分なクライマックスを作る** |
| **A−B−C構成**（日本の王道） | ★ **サビ(C)と導入のAから考え、中間部の方針を決めて、Bは最後に書く** |
| **A−B−A構成**（三部） | 楽節の末尾に深い名残惜しさや、解決による開放感を作る。★ **再現の効果を十分に出すには、Bの性格を大きく変えるのが定石** |

**Bの2つの書き方**（A−B−C構成の場合）
- **Bをつなぎにする**。抑えたA → リズムを強調する短い動機の反復と段階的な音域の上昇を使ったB → グルーヴのあるC
- **Bを第2の平歌にする**。軽いA → 内省的で静かなB → 落差で高揚感を倍増させるC
  （Bの後半にあたる小楽節では、音を積み上げてCへ導く短いつなぎを作ってもよい）

### 5.1 ★ 構成を拡張するときの注意

> **`A−B−C → A−B−C−D` のように要素を加える前に、楽節を繰り返して拡張できるか考える。**
> 要素が多すぎると、サビまでの流れが入り組み、焦点がぼやける。

まず表にある手法（A構成のリフ全体の反復、A−B−C構成のB末尾に組み込む短いつなぎなど）で必要な長さを確保できるか確認する。それでも長さや対比が足りなければ、新しい要素を加える。最終的には§8の時間枠に従う。要素を一つ増やせば通常は数小節長くなるため、3–5分を超えるなら理由を説明できるようにする。

### 5.2 キメを加える

どの構成でも、楽節の末尾やサビの途中に約2小節のキメを加えられる。
★ **曲にメリハリが足りないと感じたら、セクションを増やす前にキメを検討する。**

メリハリをつける手段はこのほかに、§5.1の楽節反復による拡張がある。どちらもセクションを新設するより小さな変更なので、先に試す。キメをユニゾン、休止、装飾のどれで作るかは、位置やジャンルに強く左右されるため、編曲の工程で決める。

## 6. ポップスの用語で足りないときに使う古典曲式の概念

映像音楽や器楽曲、より細かな構造分析では、ポップスのA/B/サビという呼び方だけでは足りない。
中国・ロシアの理論体系では、次のように細かく区分できる。

| 概念 | 用途 |
|---|---|
| **楽段（Period）** | セクションより厳密に定義された単位。**1楽句**、**2楽句**、**3楽句以上**からなる構造に分ける |
| **複楽段** | 2つの楽段で構成する、より大きな単位 |
| **開放楽段** | 主和音以外で終わる楽段。★ `mc-melody` reference §5の**終止の開放度5–8段階**に対応 |
| **楽段前後の序奏と補足** | 構造の外に付加する部分。★ 定型の16小節に1小節加わって17小節になる理由を説明できる |
| **単純二部形式** | 再現のあるものと、再現のないものに分かれる |
| **単純三部形式、複合三部形式、ロンド、変奏曲、ソナタ形式** | [reference.md](reference.md) §3を参照 |

★ **独立した曲式をなす楽段と、曲式の一部をなす楽段では特性が異なる**。
一つのセクションなのか、それだけで曲として成り立つのかを見極めるときに使う。

> **このライブラリでの使い方**。ポップスの作曲には§1–§5の用語を使う。
> `mc-style-cinematic` を使う場合や、構造分析（`mc-case-studies`）が必要な場合は、古典曲式の用語を使う。
> **引き継ぎで混乱しないよう、2つの体系の用語は混用しない。**

### 6.1 ★ セクションの働き。5つの提示様式と6つの構造的機能（李吉提）

§1から§5ではセクションの**名称**を扱った。ここで扱うのは**セクションの働き**で、名称と機能の関係を補う（李吉提《曲式与作品分析》p0022–0024）。

| 提示様式 | 特徴 | 短く言えば |
|---|---|---|
| **提示的** | 調性が安定し、素材が統一され、楽句の構造が完結している | 素材を示す |
| **展開的** | 素材の提示も和声・調性も不安定で、次第に揺れが増す。構造は分断され、転調が多く、完結した楽句を作らない | 素材を分解する |
| **経過的** | 前の楽想を補足し、転調して新しい楽想へ導くか、**先を予期させる和音**にとどまる | つなぐ |
| **終結的** | 旋律は断片的で調性は安定し、終止形や主音の持続を強調する | **答えだけを示す** |
| **導入的** | 後に続く調性、テンポ、テクスチャ、旋律の概要を示唆する | **問いだけを示す** |

構造的機能は6つ。序奏（導入的。《国际歌》のように「結論型の序奏」もある）、開始（提示的）、中間（★ **新しい主題を提示的に扱っても、機能は対比**）、
接続（経過的。大規模な作品では前に出た楽想をさらに展開することもある）、再現（提示的な性格を取り戻し、主要な楽想の強調と均衡の回復を担う。展開の要素を取り込むと**力動的再現**になる）、
終結（終結的。大規模な作品では終結部の冒頭で補足的な再展開を行う場合がある）。

**使い方**。仕様書の各セクションに、どの提示様式を使うかを書く。サビが展開的でブリッジが提示的なら、担当する機能と書法が合っていない。名前を変えるだけでは解決しない。

### 6.2 再現部の5つの形態（李吉提 p0066、p0070）

| 形態 | 作り方 |
|---|---|
| 完全（静的）再現 | 原形のまま再現する |
| 変化再現 | テクスチャや楽器編成を変え、素材を保つ |
| **力動的再現** | 動機の再加工、不安定なリズム、和声による変化、テクスチャの充実、強弱の増大。構造の拡張につながり、全曲のクライマックスになることもある |
| **総合再現** | 中間部や序奏の素材も同時に再現する |
| 縮小再現 | 一部分だけを再現する |

最後のサビの変化はこの表から選べる。歌詞で最後だけ1〜3文字を変えたり、末尾に1フレーズ足したりするのも、同じ発想による（コーパスの数値と曲側の対応は `mc-development` §7.4）。
★ 再現は主調に限らない。バッハでは属調や下属調で再現する例も多く、セクションの各部分が提示部と対応していれば再現と呼ぶ（赵晓生 p0232）。

### 6.3 楽想の展開と曲式の組み立て（李吉提）

楽想の展開（加工、展衍、対比の3つの方向と10の手法との対応）は **`mc-development`** §5.1を参照。曲式の組み立てはこのスキルの§2と reference §4を参照。

## 7. ARR-SPECのフィールドとの対応

| フィールド | このスキルの該当箇所 |
|---|---|
| `form[].id` | §1の用語体系（I/A1/B1/C1/D/O） |
| `form[].name` | ★ **英米の用語を使う**（Intro/Verse/Pre-Chorus/Chorus/Bridge/Instrumental/Outro）。バックエンドのセクションラベルに直接対応するため。**日本式の用語はメモと打ち合わせで使う** |
| `form[].bars` | §2のテンプレートが既定値を示す。**既定値から外すときは `mc-arrangement-arch`** |
| `form[].start_bar` | セクション同士を隙間なくつなぐ（lint #2） |
| セクション数 | §2.2の2–3番 |

★ **対応を間違えやすい例**。**大サビには `Bridge` を割り当てる。**
`Chorus` を指定すると、内省的なセクションを置く位置に、バックエンドが勢いのあるサビを生成してしまう。
