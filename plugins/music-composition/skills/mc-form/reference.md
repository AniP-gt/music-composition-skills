## 1. ★ セクションを対比させる6つの要素

> **セクションの違いは、名前をつけるだけでは伝わらない。音楽の動きの性格を変えることで伝わる。**
>
> **同じ素材でも、前後の文脈で性格が変わる**。
> 直前が静かな楽句なら小さなクライマックスに聞こえ、直前が高揚した楽句なら穏やかな応答に聞こえる。

**典型的なAメロ → サビの展開。どの項目も性格を反転させれば対比が生まれる。
複数の項目を一度に反転させると強い対比になり（サビへの移行向き）、一項目なら弱い対比になる（セクション内の小さな変化向き）。**

| # | 要素 | A メロ（導入） | サビ（クライマックス） |
|---|---|---|---|
| 1 | **音域** | 低く、狭い | 高く、広い（**広い音域を使って一気に盛り上げる**） |
| 2 | **音価／密度** | 短い音符を詰めた語り口、または長く伸ばす白玉音符 | ★ **Aとは逆にする**。Aが細かければサビは長い音価で広がりを出し、Aの音数が少なければサビの音数を増やす |
| 3 | **音程の動き** | 同音反復、順次進行 | **大きな跳躍**。特に冒頭の上行跳躍 |
| 4 | **楽句の入りの位置** | 裏拍／弱起 | 強拍から入る |
| 5 | **リズムの性格** | 素直で拍に沿う | シンコペーション、または逆に、拍にぴたりと合う力強いリズム |
| 6 | **和声リズム** | コードを短く保ち、頻繁に変える | コードを長く保つ（またはその逆）。旋律の広がりに合わせる |

### 1.1 ★ 対比させる素材の選び方

> **直前のセクションの出だしで最も特徴的な要素を見つけ、その性格を反転させる。**

たとえばAが「弱起＋同音反復＋低く狭い音域」で特徴づけられるなら、
サビを「強拍から入る＋大きな跳躍＋高く広い音域」にして対比させる。

**各楽節の出だしの性格を優先して設計すると、構造が伝わりやすい。**

### 1.2 動きの違いが対比として聞こえる条件

> 動きが違っても、**性格が共通**していれば（どちらも八分音符、狭い音域、順次進行）、同じものが続いているように聞こえる。
> ★ **静かなセクションでは、これが適度な統一感になる。**

**はっきり対比させるには、動きの性格を大きく変える**。
順次進行 ↔ 跳躍、短い音価 ↔ 長い音価、拍に沿うリズム ↔ シンコペーションなど、**複数の項目を一度に反転させる**。

### 1.3 例

Aは弱起で、シンコペーションの多い細かな八分音符。
Bは全音符の白玉をまばらに置く。
サビは音域を上げ、密度を中程度にして、動機を反復する。
→ **音の密度と音域でセクションを対比させる。**

これは、一項目だけを反転させた場合と、複数を反転させた場合が、6要素の表のどこに当たるかを示す模式例。実曲の分析例は `mc-case-studies` §2.4を参照（桑田佳祐、Hey Jude、Sunday Morningの3例を、この表に照らして確かめられる）。

## 2. セクション別の編成の厚み

典型的なポップスの編成（ドラム、ベース、アコースティックギター、エレクトリックギター、ピアノ）を例にする。

★ **`mc-arrangement-arch` との関係**
この表は**慣例上の既定値**を示す。既定値を外す判断（この曲でなぜ2Aのほうが厚いのか）は arrangement-arch で扱う。

| セクション | 厚みの目安 | 編曲の要点 |
|---|---|---|
| **イントロ** | 薄い編成 | 長くしすぎず、Aメロへ滑らかにつなぐ。弦楽四重奏で主題を提示してもよい。**サビを予告するフレーズを一つ入れる** |
| **1 A メロ** | **隙間を作る** | ピアノかアコースティックギターにベースとドラムを加えるだけで足りる。**ベースとドラムを抜いてもよい**。声に混じる息や息継ぎまで聞こえる、広々とした音場を作る |
| **1 B メロ** | やや厚め | ストリングスの持続音を薄く重ね、フルートで厚みを足す。マンドリン、シタール、ハープ、柔らかい音色のコルネットで動機にアクセントを置く。エレクトリックギターのハーモニクスも使える。★ **一斉に入れず**、「休止 → 短いフレーズで埋める」と進める |
| **セクションのつなぎ** | 橋渡しの音 | ストリングスの駆け上がり（速い上行音階）、シンバルロール、ハープのグリッサンドで盛り上げる。★ **歌が弱起で入るところは、思い切って伴奏を止める** |
| **1 サビ** | 全部入り | 全パートでクライマックスへ押し上げ、弦で**対旋律**を奏でる。金管を足し、コーラスや字ハモを重ねる |
| **2 A メロ** | **1Aと違う印象** | ★ **編曲者の腕の見せどころ**。1Aのピアノを2Aではアコースティックギターに替える。ドラムとベースを抜く。歌のダブルトラックを1本にする（息遣いが聞こえる） |
| **2 B メロ** | — | 1Bと同じでもよい。ストリングスなどの細部を微調整するところに腕が出る |
| **2 サビ** | — | 通常は1サビと同じ編成。**歌の隙間に対旋律を織り込み**、印象を深める |
| **間奏** | **あえてさりげなく** | サビの余韻を残し、耳を休ませる。その間に楽器を一つずつ加え、転調のための和音を置いて次のセクションに備える |
| **C/D メロ** | **意外な展開** | ★ **コード進行が最も重要**。それまでに現れていない響きを作る |
| **3 サビ 1**（大サビの位置） | クライマックスの頂点 | 転調してもよい。弦を前のサビより高く舞い上がらせ、コーラスを厚くする |
| **3 サビ 2** | — | ストリングスのダイナミクスをさらに大きくし、頂点に達する |
| **後奏** | **美しい余韻を残す** | 長くしすぎない。フェードアウトするか、ピアノだけを残すか。**印象を残す工夫をする** |

## 3. ★ 歌い手と編曲の抑揚を補い合わせる

**見落とされがちだが、音が詰まって聞こえるか、息づかいが感じられるかを左右する。**

| 歌い手 | 編曲 |
|---|---|
| **抑揚が少ない**（平坦に歌う） | **抑揚のある編曲**（音数は多いが隙間も十分に残す）でダイナミクスを補い、聞き手が無理なく歌を追えるようにする |
| **抑揚が豊か**（表現力の強い歌） | **抑揚を控えた編曲**で歌を前に出す（たとえばアコースティックギター1本だけで伴奏する） |

> ★ **歌と編曲が一緒に盛り上がるのはポップスの王道だが、定型どおりに進めすぎると新鮮さが薄れ、
> 演奏の派手さを競う形になりやすい。両者の抑揚を意図的にずらして補い合うことで、曲に個性を出せる。**

**このライブラリでの扱い**。`mc-vocal-direction` §1②のセクション別の delivery と、
`mc-arrangement-arch` §2のエネルギー曲線と**併せて決める**。
生成モデルは、歌と編曲の抑揚を**同時に最大まで上げがち**。

**このライブラリで特に使う3項目**

1. **開放楽段**（主和音以外で終わる）。
   `mc-melody` reference §5の**終止の開放度の第5–8段階**に直接対応する。
   2冊は同じ現象を異なる角度から説明している。
2. **楽段前後の序奏と補足**。
   ★ 16小節の定型に収まらず17小節になる場合、**増えた1小節が楽段の構造外に付く補足**と考えられる。
   `mc-arrangement-arch` §4の非対称設計では、楽段の内部で定型を崩す。ここでいう補足は構造の外に付ける。
3. **独立した曲式をなす楽段と、曲式の一部をなす楽段**。
   一つのセクションなのか、単独で曲として成り立つのかを判断する基準。`mc-case-studies` でセクションごとに分析するときに用いる。

### 4.2 ソナタ形式。ポップスにも使える考え方（第9章、p0266–0292）

単純二部形式、単純三部形式、複合三部形式、ロンド、変奏、組曲は原書の各章を参照。ここでは2つの主題が対立し、やがて折り合うモデルとしてソナタ形式を扱う。ポップスのverseとchorus、AとBの関係を考える際にも使える。

**主題の関係**（p0266–0268）。複合三部形式とロンドでは対比主題を**並置**する。ソナタ形式の対比主題には**内的なつながり**があり、直接対立しながら統一へ向かう。関係は、相互補完、相互対立、その両方の3種類。副主題は主主題から**派生**することが多い。
**調性**。主部は主調、副部は従属調。長調作品の副部は属調が最も典型的で、短調作品では平行長調がよく使われる（p0267）。

**全曲を貫く展開**（p0268–0269）。主主題は6つの段階をたどる。序奏で準備され、提示部で初めて提示され、副部の「転換」と結尾部に断片が現れ、展開部で十分に展開され、再現部で新たな段階に入り、コーダでは締めくくりの素材となる。**主題を全曲にわたって展開することは、全曲のクライマックスを作るうえで重要**。ポップスでは、フックの動機をverse、pre、bridgeに一度ずつのぞかせる方法に相当する。

| 部分 | 作り方 | ページ |
|---|---|---|
| **提示部** | 主部、推移部、副部、結尾部からなる。主な対比は主部と副部の間にある。推移部は両者をつなぐため、対比は目立たない | p0270 |
| **推移部** | 独立した構造を持つものと、主部に付属するもの（主部の後楽句、または単純三部形式で書かれた主部の再現部）の2種類。典型的には開始部（主部の終わり）、主要部（対比の強くない新しい旋律の展開と転調）、準備句（副部の属和音にとどまる）の3部分。すべてを備えるとは限らない。調性の扱いでは、**転調後に副部の属和音を出す**方法が最も典型的 | p0275–0277 |
| **副部** | 単一素材による歌謡的で叙情的な主題が多い。★ 副部が静かで内部に対比が乏しいとき、古典派の作曲家は**後半に「転換」を入れ**、活発な素材で急な対比を作った。副部の拡張につながることが多い。通常は副部の調の完全終止で閉じるが、開放したまま展開部に入ることもある。ロマン派以降はテンポを変えて対比を強める例もある | p0277–0279 |
| **結尾部** | 提示部を締めくくり、ひとまず総括する。副部末尾の調を用い、典型的には**副部末尾の主和音への終止を反復し、拡張した大きな終止形にする**。主音の持続を伴うことが多い。構造は楽段に補足を加えたもの、または複数の補足を組み合わせただけのもの | p0279–0280 |
| **展開部** | 最も規則化しにくく、3つの面から捉える。**素材**（原形の引用より主題の分割が中心。別の調で主部または結尾部の素材から始めることが多い。活発な主部の素材が最もよく使われる。ポリフォニーやフーガ風の一節を用いることが多く、派生した新主題も導入できる）。**調性**（長く不安定で、主調はほとんど現れない。近親調か3度関係調から始まり、後半は下属方向の調を多く使い、主調と属調を強調した提示部と対比させる。完全終止は少ない。末尾では主調の属和音に戻り、「属和音による準備」または「属音の持続による準備」を作る）。**構造**（導入部は短いか省略し、主要部で全曲のクライマックスを作り、再現への準備部を置く。偽再現が現れる場合があり、挿入部は少ない） | p0280–0287 |
| **再現部** | **どの場合も変化を伴う再現**。最小限の変化では副部が主調に戻り、結尾部もそれに従い、推移部の構造も変わる。楽想が激しく発展すると力動的再現となり、強弱・テクスチャ・楽器編成にとどまらず、構造、調性配置、主題の性格まで変化する | p0287–0288 |
| **序奏** | 主題と対比する素材も、主題から派生した素材も使える。独立して完結した構造でも、数小節の準備でもよい。末尾で主部の入りを準備する必要があり、従属調から主調の属和音へ導く「属和音による準備」が多いため、序奏自体では閉じないことが多い。独立した意義を持つ序奏は、全曲を貫く主導動機にもなりうる | p0290–0291 |
| **コーダ** | 全体を総合して結論を示す。既出の主題を再現するか、変化させて展開することが多い。全主題を用いても、一つだけを強調してもよい。新主題はまれ。主調での完全終止が必要。規模の大きな展開を行う場合は下属方向に傾く。完全終止の後からも、偽終止の後からも始められる。展開部に似た構造を取り、互いに呼応させて全体の均衡を取ることもある | p0291–0292 |

**ポップスに直接使える4項目**
1. 副部の「転換」は、chorusの後半でもう一段盛り上げる考え方に通じる（p0278）。
2. 結尾部で「終止形を反復して大きな終止形を作る」手法は、outroでフックの末尾を反復する方法に通じる（p0280）。
3. 展開部の後半もコーダも下属方向へ進みやすい。bridgeを下属調へ進める根拠になり、主調に戻る際は属和音による準備を経る（p0284–0285、p0292）。
4. 再現には必ず変化がある（p0288）。最後のchorusには少なくとも1か所に変化をつける。`mc-arrangement-arch` の最終セクションでの小さな変化と同じ考え方。

## 5. 中国音楽の構成原理

> 底本は李吉提《曲式与作品分析》の各所にある中国音楽の構造についての考察。**同書は西洋曲式の教科書で、板腔体や曲牌体のレベルまでは扱っていない**。
> このパッケージでも板腔体と曲牌体の構造規則は扱わない。

### 5.1 ★★ 新たな段階へ進む過程を重視する

「中国では音楽を一つの過程と捉える。新たな出発点に達したら、そこから一段高い水準で展開すればよく、再現や調性の回帰を強調する必要はない」（p0071–0072）。
瞿维《花鼓》にあるのは主題の総合再現とテンポの再現で、調の再現はなく、調性配置は実質的に二部性を持つ。
**中国風の曲では、最終セクションで主調に戻ることは必須ではない**。素材とテンポが戻れば足りる。

### 5.2 ★★ セクションを区切る基準

「民間音楽や大衆歌謡では、**主題素材、テンポ、板式やジャンルの対比と再現のほうが、曲式上の段階を区切る重要な指標になる場合があり**、
西洋の専門的な古典曲式理論をそのまま当てはめることはできない」（p0072）。中国の楽曲の単純三部形式は「和声の変化や転調を強調せず、主題素材、テンポやジャンルの変更、旋法の切り替えをより重視する場合がある」（p0065）。
**中国風のセクション間の対比は、素材、テンポ、ジャンル、旋法で作る**。`mc-melody` reference §3.0の同宮犯調と同じ考え方で、調を保ちながら響きの色を変える。

### 5.3 素材を育てる展衍と起承転結

- **展衍**。短い旋律の断片から出発し、素材を段階的に更新する（《二泉映月》）。「中国の伝統音楽でとりわけ多く見られる」（p0016、p0020）。中国音楽で素材を展開する原理で、再現の原理と並ぶ
- **起承転結**の4句構造は「中国の伝統音楽ではより普遍的な意味を持つ」（p0022、p0035）。楽想を示す過程（提示 → 確立 → 展開と対比 → 総括と終結）自体が起承転結に合致する
- **句句双**（各句を二度ずつ奏する形式、p0035、p0153）。もとは2句で、それぞれを1回ずつ反復して4句にする。中国と国外の民間音楽に見られ、手を加える量が少なくても飽きにくい
- **合尾式**（p0032）。句末に呼応がなくても、**句頭で対比**させれば楽段を作れる。`mc-melody` §7.3では句末での呼応を既定とするが、ここでは句頭に着目する
- **垛句**（句を積み重ねる技法）は楽想の展開を促し、展開的な対比楽句を作る（《猜调》、p0031）

### 5.4 民間音楽の三部性が生まれる仕組み

民間の演奏家は楽器を替えて同じ小曲を移調し、元の調に戻すことで「主調 – 対比調 – 主調」の配置を作る（p0077）。**中国風の楽曲で自然な三部性を出すには、素材を保ったまま楽器と宮を替える。**
理論上、この方法は**単一主題**の構造に限られる。変わるのは調と楽器の音色で、第2の対比主題が現れると別の類型になる（p0077）。
西洋の比較例として、ショパン《玛祖卡舞曲》Op.33 No.2の第1部分がある。Aはニ長調、A1は4度下のイ長調、Aの再現はニ長調に戻り、素材はそのままで調だけが移る（p0078）。「同じ旋律を異なる調で提示する」固定旋律変奏とも捉えられる（p0078）。楽器と宮を替える中国の方法では音色の違いで対比を作り、素材もテンポも保てる。西洋の移調反復では素材を保ちながら調性が実際に移る。中国風の曲で音楽が進んでいく過程を感じさせたいなら（§5.1）、前者がより適している。
