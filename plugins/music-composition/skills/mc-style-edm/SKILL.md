# エレクトロニック・ダンス・ミュージックのスタイル層（EDM / Club）

**このスタイルがリポジトリ内の他のスタイルと最も異なるのは、歌ものの形式を前提としない点にある。**

> **歌ものの構成は「内容の並び」（Aメロではこの話、サビではあの話）。
> クラブミュージックの構成は「レイヤーの足し引き」。**

そのため、多くの共通ルールは、このスタイルの中で**形を変えて適用する必要がある**。

## 2. ★ 転用表

| 手法 | 歌ものに転用できるか | 説明 |
|---|---|---|
| **レイヤーの足し引きで曲形式を作る** | ✅ ★ **転用でき、非常に有用** | `mc-arrangement-arch` §5の「編成で曲形式を作る」を突き詰めた形 |
| **長い build** | ⚠️ **条件付きで転用可** | 歌ものでは、聴き手はそこまで長く待たない。**2–4小節に縮めれば使える**（= J-POPのサビ前の期待感、`mc-style-jpop` §6） |
| **ドラムだけのセクション** | ⚠️ 条件付きで転用可 | 歌ものでも音を減らす効果的な変化になる。**16小節も続けない** |
| **四つ打ちのキック** | ⚠️ 条件付きで転用可 | スタイルを強く印象づける |
| **サイドチェインによるポンピング** | ⚠️ 条件付きで転用可 | ★ スタイルを非常に強く印象づける。`example-01` の `exclude` では `modern sidechain pumping` を明示的に除外している |
| **完全なクオンタイズ** | ⚠️ ★ **前提を満たせば一部転用可**（§6） | |
| **反復を無意識に浸透させる** | ✅ 転用可 | §5.2。**歌ものでは歌詞の展開に合わせる** |
| **"purpose determines form" という考え方** | ✅ ★ **転用でき、取り入れるべき** | §3.2 |

★ **判断基準**：
> **構成の技法（レイヤリング、build、反復）は転用できる。
> 歌ものでは、16小節から始まるような長い前振りは持ち込まない。**

## 3. 構成

### 3.1 典型的な形

```
four-on-the-floor のキックから始める
 → hi-hat を加える
 → ピアノなどの反復伴奏を加える（8+ 小節単位で反復）
 → 本格的なイントロ → A メロ → サビ
 → ドラムだけのセクションに戻る → ループ……
```

**特徴**：
- **メロディはあってもなくてもよい**
- 構成が**長く、規模が大きい**
- **ドラムだけ**、または **pad だけ**が残るセクションがある → ★ **音の厚みの落差が極めて大きい**
- **ドラムを中心に**編曲する

### 3.2 ★ この構成が成立する理由

**理由は2つあり、どちらも聴く場所に関係する。**

1. **徐々にレイヤーを足すほうが踊りやすい**
2. ★ **ドラムだけのセクションがあると、DJが次の曲につなぎやすい**

> ★★ **自宅では冗長で退屈に感じる構成でも、ダンスフロアでは非常に効果的。目的が曲形式を決める。**

**このスキルで最も重要な考え方**で、他のスタイルにも転用できる。
**「このやり方でよいか」と迷ったら、まず「どこで聴くか、何回目に聴くか」を確認する**
（→ ARR-SPEC の `intent.listener_situation`）。

### 3.3 セクションの組み立て

クラブ向けの曲をどう区切るか、2つの方法を並べて見る。

★ **密度の変化で曲形式を作る方法（DeSantis p0299）**：伝統的なセクション分けに頼らず、「少量の素材を軸にテクスチャの密度を変え続ける」ことで曲形式を作る。そのまま使える単位が3つある。
- **Buildup（積み上げるセクション）**：**16または32小節**（もしくはその倍数）が多い。レイヤーを足して密度をそのセクションの頂点まで上げる
- **Breakdown（密度を落とすセクション）**：エネルギーを下げて対比を作る。**ドラム要素をすべて抜く**か、逆に**ドラムだけを残す**ことが多い。通常は buildup より短いが、ここでも **8または16小節**単位で作る
- **Drop**：曲中で最も密度が高いセクション。buildup または breakdown の後に置ける。**通常は1曲に1—2回だけ**で、buildup と breakdown はさらに多くてもよい

**クラシックな dub techno**（例：Chain Reaction レーベル）は対極にある。冒頭のベースラインやドラムパターンが曲全体を貫き、セクション間の明確な対比は設けない。新しい素材は既存の素材に重ね、編成の規模は大きく変えない（p0299）。

**判断基準（p0300）**：ポップスに近い系統では、より伝統的な song form を勧める。techno、trance、dubstep のような「純粋な電子音楽」では、少量の素材と持続的な密度の変化だけで構成を感じさせられるため、無理に verse/chorus に当てはめる必要はない。

## 4. Build と Drop

### 4.1 build の中心は期待感

**盛り上がらない build でよくあるのは、音を足すだけで、この先に何が来るかを予感させていないこと。**

効果的な build には**予測できる到達点**がある。
- **フィルターのスイープ**（cutoff を一方向に上げる → 聴き手は上限に向かうと分かる）
- **リズムの細分化**（8分 → 16分 → 32分 → 聴き手は残りの拍を数えられる）
- **音高の上昇**（riser）
- ★ **直前の無音**（→ `mc-style-jpop` §6の「突然すべてが止まり、その後一気に入る」）

**build の5つ目の到達点の作り方：Shepherd 音**（Howard & Angus p0248–0250）。スペクトルは1オクターブ内で循環し、半音上がるごとに各成分が一段ずつ上に移る。
高域の成分は弱まって消え、低域の成分は強まりながら現れる。**無限に上昇する音階**に聞こえるが、音響上は1オクターブの範囲を出ない。無限に続けられる唯一の riser であり、
drop が何小節目に来るか分からない場合や、期待感を長く引き延ばしたいセクションに向く。オクターブ間隔で部分音を重ね、それぞれの振幅を釣鐘型のエンベロープで制御する。

### 4.2 drop が決まらない3つの理由

| 理由 | 対処法 |
|---|---|
| **build がすでに drop と同じくらい音で埋まっている** | ★ `mc-arrangement-arch` §2に戻る。**エネルギーカーブには下降が必要**（62/62の強いルール）。build の頂点は **drop より低くする** |
| **build で低域を空けていない** | build で**低域をカット**し、drop で一斉に戻す。この変化が音響的な「落差」を作る |
| **drop に新しい要素がない** | drop には**それまで出ていない要素を1つ**入れる（音色や riff など） |

### 4.3 ★ 注意が必要なデフォルト

生成バックエンドにEDMを指定すると、**デフォルトで build + drop が入り**、しかも**定型どおり**になりやすい。
`example-01` の `exclude` で `EDM drop` を除外しているのはこのため。

**判断基準は他と同じ**。**意図して選んだのか、デフォルトに任せた結果なのかを確認する。**

## 5. レイヤリングで曲形式を作る

### 5.1 メロディなしで曲形式をどう作るか

> **ボーカルのない現代の電子音楽では、多くのジャンルで伝統的な verse や chorus を避け、
> 「レイヤーの足し引き」でセクション間に対比を作る傾向がある。**

**ARR-SPEC での書き方**：
- `form[].name` は引き続き記入し、**`Instrumental` / `Intro` / `Outro` を使う**。
  そのセクションに含まれるレイヤーは `note` に書く
- ★ **実際に曲形式を作るのは `roster[].entry/exit`**。`form[].name` にはセクション名を記録する
- 構成の記述は主に `energy_curve` が担う

★ これは `mc-arrangement-arch` §5の「編成で曲形式を作る」そのもの。EDMはそれが純粋な形で表れるスタイルである。

### 5.1a ★ パートが加わる順番そのものが構成になる：Acid の定番手法（野崎）

クラシックな Acid は riff、ベース、hi-hat、キックの4トラックだけで構成する。**各パートが順番に入り、その順番は決まっている**（p0271–0272）。

1. riff だけ
2. hi-hat を加える
3. ベースが入る
4. 最後に 4/4 のキックを鳴らす

★ **キックが最後に入る**。「先にドラムを置いて、その上に重ねる」という直感とは逆の順番で、次の3つの工夫を組み合わせる（p0273）。

- **冒頭で riff の CUTOFF をかなり低くして、フェードインのように聞かせる**。「どこから始まったか聞き取れない」フレーズを作るのが狙い。hi-hat が入るまでは、聴き手が感じている拍が実際と半拍ずれる。拍の位置は意図的に曖昧にしており、hi-hat が入って拍が合う瞬間に効果が出る
- hi-hat が入る前に、手で CUTOFF をゆっくり開け、単調な反復に飽きさせない。遅い LFO やフィルターエンベロープでもできるが、著者は**予測しにくい変化を作れるのは手動操作だ**と考えている
- **新しいパートが加わる際は、先に前のレイヤーの CUTOFF を下げる**。ベースの登場前に riff の CUTOFF を一時的に下げて、両方の帯域が同時に広がって干渉するのを防ぐ。キックが入った後は riff とベースを「自由に絡ませ」、CUTOFF と RESONANCE の2つを同時に操作する（一方を下げるときにもう一方を上げる）

**応用**：loop を軸にするスタイルでは、「どのパートが最初に入り、どのパートが最後に入るか」を判断して仕様書に書く。ドラムから始めることを前提にしない。

### 5.2 反復そのものが積み重ねになる

> **反復は無意識に浸透し、半ば無意識の身体反応を引き起こす。
> 大きなクライマックスがなくても、反復そのものが積み重ねになる。**

★ **これは一見すると `mc-melody` §8 の「反予定調和」と矛盾するが、聴き方が異なる**。
- **歌もの**：聴き手は**内容を追う**。先が読めると退屈する
- **クラブミュージック**：聴き手は**踊っている**。先が読めると動きを合わせられる

**ここではルールが実際に適用外になる**。`mc-melody` §8.1 の「同じフレーズを3回以上繰り返す」に関するルールは、
**クラブミュージックには当てはまらない**。

## 6. ★ クオンタイズ：このスキルで最も明確にしておくべき点

**2つの見解を並べて読む。**

| 出典 | 見解 |
|---|---|
| DeSantis (p0154) | **Techno、House、Electro、EDM** では、**完全なクオンタイズが十分に適している**。ベロシティも変化をつけず、完全にそろえることが多い |
| このリポジトリの裏付け表 | 「全パートを厳密にグリッドに合わせるべきではない」が **62/62 件で該当**。強いルール |

**両立させるには「全パート」に注目する。**

- ✅ スタイル上必要なら、**ドラムは完全にクオンタイズしてよい**
- ❌ **曲中のすべての楽器をグリッドに合わせてはいけない**。全パートがそろうのは生成モデル特有の傾向で、どのスタイルもそれを要求していない
- ★ **クオンタイズをかけるかは楽器ごとに決める**。曲全体で一律にオン・オフを切り替えない

**実際のやり方**：ドラムは100%クオンタイズし、**演奏パートを1つだけクオンタイズせずに残す**
（ベース、サンプル素材、ボーカル、または pad の1レイヤーの発音タイミング）。

### 6.1 本当にすべてを0にそろえる場合

判断の基準は§6のとおり。ここでは書き方だけを定める。**`checks.exemptions` に理由を明記する**（例「グリッドにそろえることが、このスタイルの表現手法だから」）。**例外を適用する際は必ず理由を書き、黙ってチェックを飛ばさない。**

### 6.2 ドラムマシンの美学

> ドラムマシンの美学（代表例：Roland TR-808）では、**hi-hat / snare のベロシティをあえて一切変えない**。
> **冷たく平坦な響きを持ち味にする。**

★ これは**正当なスタイル上の選択**で、手抜きではない。
ただし、仕様上は「ベロシティを調整し忘れた」場合と同じに見える。**区別できるよう exemptions に明記する。**

## 8. 実測：EDMと他のスタイルの比較

Cambridge-MT のマルチトラック音源から edm 10曲を実測（対照として pop、jazz を各10曲）。

| 指標 | edm | pop | jazz |
|---|---|---|---|
| roster の規模（中央値） | 32 | 36 | 22 |
| 曲のセクション数（中央値） | 10 | 10 | 9 |
| 冒頭から鳴っている楽器の割合 | 21% | 21% | 16% |
| 途中から加わる楽器の数 | 26 | 29 | 20 |
| **曲が終わる前に抜ける楽器の数** | **20** | 16 | 10 |

**読み取り方**：EDMでは**ポップスよりも多くの楽器が曲の途中で抜ける**（20 vs 16）。§3.1の「ドラムだけが残るセクション」と一致する。
**ただし、R&B（28）ほど差は大きくない。**

⚠ **BPMは引用しない**。edm の検出結果は中央値129、範囲68–152だったが、
電子音楽では beat tracking がテンポの倍数を誤検出する（68は明らかに136の半分）。

## 10. 書き上げた後の必須チェック

- [ ] **どこで聴くか**（ダンスフロア / ヘッドホン）を明確にし、構成をその場面に合わせた
- [ ] EDMの**どの系統か**を明確にした
- [ ] **build の頂点が drop より低い**（エネルギーカーブに下降がある）
- [ ] build で**低域をカットし**、drop で戻した
- [ ] drop に**それまで出ていない要素を1つ**入れた
- [ ] ★ **曲中のすべての楽器をグリッドにそろえていない**。すべてそろえた場合は **exemptions に理由を書いた**
- [ ] ドラムマシンの美学（ベロシティ変化なし）を**意図的に選び**、exemptions に記載した
- [ ] メロディのないセクションでは、**roster の楽器の出入りで曲形式を作った**
- [ ] プリセットを探して済ませず、音色を設計した（→ `mc-sound-design` §2）
- [ ] 歌ものに転用する際は、**変化にかける時間を短くした**（§2）
