# 旋律法（Melody Writing）

> **旋律は時間の中で音が動くこと。**
> その表現力は、動きの**方向、幅、音価、拍の位置**の四つから生まれる。

このスキルでは**旋律線そのもの**を扱う。どのコードを付けるかは `mc-harmony`、
どの言葉を載せるかは**作詞**で扱う。

## 1. 書き始める前の必須項目

| 必須項目 | 確認すること |
|---|---|
| **① 中心音域** | 1オクターブの範囲を明確に決める。**決めておかないと旋律が散漫になる** |
| **② 誰が歌うか** | 歌い手の音域と声区の切り替わりを確認する。**これで調が決まる**（§4.2） |
| **③ どこをクライマックスにするか** | 何小節目かまで決める。既定は**曲全体の2/3–3/4の位置** |
| **④ 旋律線の方向** | 全体として上行か下行か。その理由は何か |

## 2. 方向と音程の幅が生む表現

### 2.1 方向

| 動き | 表現 |
|---|---|
| **上行** | 緊張、高揚。**句末の上行は、問いかけ、投げかけ、相手への呼びかけ** |
| **下行** | 弛緩、安定。**句末の下行は、返答、うなずき、ため息、確信** |
| **狭い範囲で上下する** | 上行とも下行ともつかず、ためらいや迷いを表す |

**3音以上のフレーズでは、最初と最後の音の高低差で全体の方向を見る。**
末音へ向かう**局所的な動きが全体の方向と逆**なら、全体の方向感は**弱まる**。

★ **和声によって方向の意味が変わる**。上行しても、和声の働きで安定した音に着地すると
（G7→Cで主音に着地する場合など）、問いかけよりも解決として聴こえる。
**問いかけを強調するには、安定した音への着地を避ける。**

> 身体の動きにたとえると、上行は背伸びして遠くを見ること、下行は腰をかがめて近くを見ること。

### 2.2 音程の幅

| 幅 | 表現と制約 |
|---|---|
| **順次進行** | 滑らかに進む。音階に沿った上下で緊張が滑らかに増減するため、多用される。2度の補助音で飾ると輪郭を保ったまま動きを増やせる |
| **半音** | 最も狭い音程で、微妙なニュアンスや繊細さを表す。半音のある旋律には**艶やかさと深み**が出る。★ **多用すると（特に臨時記号を伴う半音階では）、神経質、病的、奇怪に聴こえる**ため、加減する |
| **跳躍** | ドラマ性を出し、感情を大きく揺らす。**跳躍先の字が強調される** |
| **同音反復** | 低音域では静かな語りかけや内に秘めた語り（または感情を押し殺す感じ）。高音域では緊張が続き、叫び続けるように聴こえる。★ 音高が動かないと聴き手はリズムに注意を向ける。シンコペーションや多様な音価を合わせると**話し言葉に近い表現**になる |

> **半音の使い方は、旋律の味わいを左右する二大要素の一つ**（もう一つはペンタトニックの密度）。

**音程の幅とテンポ**。狭い音程ほど歌いやすく、幅広いテンポに合う。広い音程ほど遅めのテンポと準備が必要。
**大きな跳躍を自然に歌うには、出発音か到達音、または両方に十分な音価を取る。**
**高音と低音を素早く交互に繰り返すと、特にぎこちなくなりやすい。**

## 3. 跳躍の準備と着地

### 3.1 ★ 三つの制約

1. **1回の跳躍は6度以内**。ただし、**完全8度は歌いやすく響きもよいため使える**
2. **4度以上の跳躍は同方向に連続2回までとし、両端の音程は1オクターブ以内に収める**
   - 適合例　3+5=7度、4+4=7度
   - 不適合例　5+5=9度、4+4+4=10度。ぎこちなく、歌いにくい
3. **7度の跳躍は中間音を足して3+5か4+4に分ける**のが最も一般的（踏み石のように二段階で進む）

### 3.2 上への跳躍は容易で、下への跳躍は難しい

（力を入れる動きは制御しやすく、力を抜く動きは安定させにくい。）

**大きな下行跳躍への二つの対処法**
1. 着地音には自然に**アクセント**が付く。それを見込んで**意図的に利用する**
2. **出発音を十分に伸ばしてデクレッシェンドする**。出発点で感情と緊張をためてから跳ぶ

**音程の狭い跳躍では、力を抜く下行のほうが容易**。短い高音から下へ跳ぶ動きを句頭に置き、アクセントを付ける手法がよく使われる。

### 3.3 四つの技法

| 技法 | 方法 |
|---|---|
| **タメ（勢いをためる）** | 跳躍の**前**に**逆方向**へ1音から数音動かす（通常は順次進行）。大きな動作の前の予備動作にあたる。跳躍の途中にも置ける |
| **助走** | 跳躍の前に**同方向**へ順次進行する音を1音から数音置く。助走音は跳躍音程の内側にも外側にも置ける |
| **着地を和らげる** | 跳躍が着地した**後**に、**同方向**へ1音から数音を順次進行させ、着地の衝撃を和らげる。**特に下行跳躍に有効** |
| **跳ね返り** | 大きく跳んだ後に**逆方向**へ順次進行する。★ 跳ね返った音は**次の跳躍のタメ**も兼ねられ、「跳躍→跳ね返り（タメ）→跳躍→跳ね返り（タメ）→跳躍」と連ねられる |

### 3.4 8度を超える跳躍

**旋律に強い切れ目が入り、一つのフレーズとして聴き取りにくい。**
**これを利用する**。区切りで音域を大きく離し、**擬似的な二声部**の旋律を作る
（低音域の動機と高音域の動機が掛け合う）。

### 3.5 不自然な動きの効果（いずれも使いすぎると効果が薄れる）

| 技法 | 効果 |
|---|---|
| 準備のない大きな跳躍 | **感情が突然あふれる**（中間音を足すと滑らかになるが、爆発力は失われる） |
| 跳躍後に逆方向へ解決せず、同方向に進む | 独特の**切なさ** |
| 跳躍が連続し、音同士のつながりが弱い | 浮遊するような軽さ、**無機質なポップ感** |
| 半音をずらし、どの音階か聞き取れなくする | 人工的な印象、距離を置いた皮肉 |
| 増音程 | 非西洋的な印象 |

> **局所的に不自然な動きを入れてフックにし、最後は自然な形で解決する。**

## 4. 音域と人の声

### 4.1 音域の基本

- **中心音域を先に約1オクターブに定め**、各フレーズの重心をその中に置く。
  外れると旋律が散漫になり、複数の声部が混ざったように聴こえることもある
- 曲全体の実際の音域は約 **1.5オクターブ、最大2オクターブ**（多くの声や楽器で使える範囲にあたる）
  - 1オクターブ以内に収めると、親密に聴こえ、歌いやすい
  - 2オクターブにわたると、変化は大きいが歌いにくい

**フレーズの効果は、音域内の位置によって変わる。**

| 位置 | 効果 |
|---|---|
| 重心が高め | 明るく緊張感がある。**普段の音域の上限を越える音では緊張が急増する**。極端に高いと苦しさを表す |
| 重心が低め | 穏やかでくつろいだ響き。**普段の音域の下限を割ると重くなる**。極端に低いと力が抜けて締まりを失う |

★ **同じ動きでも、音域内の位置によって効果が異なる。**
- 中音域での上行は、適度な緊張を生む
- 上限に向けて上行し、音域を突き抜けると、緊張が大きく増す
- 低音域から中音域へ戻る上行は、低音の重さが取れて響きが柔らかくなるため、緊張の高まりが相殺され、**むしろ緊張がほぐれることもある**
- 同じ句末の上行でも、低音域なら気軽な問いかけ、高音域なら切実な願い、場合によっては詰問になる

> **音高の性格は相対的**。同じ中央のCでも、低音域の旋律では高く、高音域の旋律では低く聴こえる。

### 4.2 ★ 声区の切り替わりで調を決める

男声は女声より約1オクターブ低い。慣例として、**男声は実際に鳴る音より1オクターブ高く記譜する**。
ポップスでは、男声は低音域をあまり使わず、高音域をよく使う。女声は極端な高音域をあまり使わず、低音域をよく使う。

| 声区 | 性格 |
|---|---|
| **胸声** | ポップスの生々しさと親密さを支える。音高の動きの性格が最も強く表れる。高音域の張り詰めた響きは**切実さ**（どうしても届けたい気持ち）を表せる |
| **中声（ミックスボイス）** | 声帯を半ば閉じた状態で、音域を上へ広げる。明るく開いた音色で、外向きの強い表現ができる。★ **同じ高音のフレーズでも、胸声では張り詰めた懇願、中声では遠くを見渡すような伸びやかさ**が出る。声区の選択で旋律の性格が変わる |
| **ファルセット** | **胸声とは別の楽器として扱う**。澄んで繊細で、きめ細かな柔らかい表現に向く。倍音が少なく発音がやや不明瞭になり、強弱を付けにくいため、親密な語りかけや感情の大きな振幅には向きにくい |
| **胸声からファルセットへ切り替える** | 声が裏返っても高音に届こうとする**必死さ**が、強い憧れや極度の切なさにつながる |

> ★ **男性歌手が中声を使えるか、声区がどこで切り替わるかを先に確認する。音域と調を決める大前提になる。**
> 切り替えが難しい歌い手には、**フレーズごとに声区を決める**（この句は胸声、次の句はファルセットか中声）。どのフレーズも切り替わりをまたがないようにする。

**基本の1オクターブは、出せる音域の中央に置く**。余裕を確保しつつ、表現としてあえて限界の音に触れる選択肢も残せる。

### 4.3 聴き手が一緒に口ずさむ効果

聴き手は頭の中で旋律を口ずさむ。

- わかりやすい反復で**聴き手が旋律と同調する**と、その後の高音を歌い手が楽に出していても、**聴き手は高さと緊張を感じる**
- **冒頭や句頭に突然出る高音**は、同調する時間を与えないため、聴き手は距離を置いて歌唱技術として鑑賞する

書くときに、**一緒に歌ってもらうのか、一歩引いて聴いてもらうのか**を決め、狙った聴き方へ導く。

## 5. 音価

### 5.1 よく使う範囲

よく使うのは **16分音符から全音符**まで。連符は通常、1拍または2拍の3連符に限る。
**ポップスでは聴き手が拍に乗り続けられるように、拍を見失わない音価の組み合わせを選ぶ。**

- 曲全体が3連の感覚なら、3連符を随所に書く代わりに**6/8、9/8、12/8で記譜する**
- まず **BPM ≈ 100** の中速で、音価の違いが音の長さとして素直に感じられる状態で性格を確かめ、極端なテンポでどう変わるかを検討する

### 5.2 長い音と短い音

| | 表現 |
|---|---|
| **長い音** | 持続する力が緊張を生む。音を伸ばしながら表情を付けられる（ビブラート、クレッシェンド、デクレッシェンド）。**クライマックスでは高音域に長い音を置くことが多い**（緊張を最も強く表現できる） |
| **短い音** | 軽快で敏捷。力を入れて歌うと鋭く、振り切るように聴こえる。低音域では重さが軽快さを打ち消す |

- 長い音が続き、音高もあまり動かないと緊張が持続する。**長引きすぎると締まりを失い、退屈になる**ため、跳躍を挟むか長い音の間に短い音を織り込む
- **長い音と大きな跳躍**を組み合わせると、大幅な音高の動きが滑らかになり、**スケール感が増す**
- **狭い音程と短い音で、話し言葉に近い旋律**になる（ニュースの読み上げ速度はBPM 120の8分音符程度だが、速くは感じない）
- 広い音域を短い音で連続して動くと軽やかに転がる。**長く続きすぎると神経質で強迫的に聴こえる**

★ **長短が混じる場合、長い音が重心と自然なアクセントを担い、短い音は従属する。拍の位置には左右されない。**
よくある循環は、短い音で高く長い音へ**近づく** → 緊張する → 低く短い音で**解放する** → 再び近づく、の繰り返し。
極端に圧縮すると、長短が交互に並ぶ**跳ねる感覚**が生まれる（6/8、12/8でよく見られる）。使いやすいが、**非常に予定調和になりやすい**。

## 6. 終止（Cadence）

### 6.1 音価の扱い

終止音を伸ばすと動きが止まる。その後に短い音を足して緊張を**解放する**か、休符で**力を抜く**。

★ **音価だけでは終止しきれない**。和声と旋法上の動き（音度）も同時に収まらないと、
終止感は中途半端になる。**逆に利用する**なら、サビは着地させつつ、曲全体は未解決のままにし、言い切らない余韻を残す。

### 6.2 大きな終止（セクション末／曲末）

| 技法 | 効果 |
|---|---|
| リタルダンド＋デクレッシェンド | エネルギーを抜く。**記譜によるリタルダンドは、終止前の音を一つずつ長くするか、2/4の小節を一つ挿入する** |
| 終止直前の音を十分に伸ばしてためを作り、**短い音**に着地する | 最後の瞬間まで緊張を保ち、一気に解放する |
| **旋律の終止音を省き、伴奏に委ねる** | 息を止められたような幻想的な余韻 |
| 遅くも長くもせず、アクセントのある短い音で終える | **歯切れよく、強い意志を感じさせる**（アクセント付きの短い音をもう一つ足して強調してもよい） |

### 6.3 休符も旋律の一部

旋律で休符が果たす二つの役割は、それぞれ別の節で詳しく扱う。区切りの合図は§7.2の六つの要因の第1項（長い音価と休符が最も明確）。フレーズの末尾で力を抜く方法は§6.1の音価の扱い（短い音の代わりに休符で緊張を解放できる）。

## 7. 動機 → フレーズ → セクション

### 7.1 用語と階層

```
部分動機（単独では成り立たないが、識別できる特徴がある）≈ 単語    a1、a2と記し、変形には ' を付ける
  → 動機：単独で成り立つ最小の旋律単位。1小節以上                 a、bと記す
     （これより短いと単独では拍の位置を判断できない）
     ★ 反復では通常、リズムの輪郭を引き継ぎながら変化を付ける
  → 小楽節：通常は動機二つ                                       A1、A2と記す
     → 楽節：8小節が最も多く、4小節もよく使う                       A、Bと記す
        （それ以外の小節数は、多くが8または4からの増減）
        一つの感情でまとまった単位
```

★ **異なる動機で部分動機を共有できる**（例 a'' = a1' + b2）。**構造に統一感を持たせる重要な手段**。

> **同じ素材でも、性格は文脈で変わる**。同じ動機が、静かなフレーズの後では小さなクライマックスに、
> 勢いのあるフレーズの後では気持ちを落ち着かせる返答になる。

### 7.2 区切りを作る六つの要因（明確な順）

1. **長い音価と休符**（最も明確）
2. **音程の跳躍**（音高の連続性を断つ）
3. **動きの型の反復**（反復の単位ごとにまとまりができる）
4. **明確な終止**
5. **明確な開始**（次のフレーズの始まりがわかった時点で、振り返って直前のまとまりが終わったと認識する）
6. **反復／対比**（これも振り返って認識する）

**2、4、8小節の区切りが最もつかみやすい**。奇数小節を含むまとまり（3+3+2など）は聞き取りにくい。

| | 効果 |
|---|---|
| **強い区切り**（主音＋強拍＋主和音＋長音／休符） | 仕切り直す感覚があり、新しいセクションの開始や反復・対比の強調に向く。**曲を二分するほど強いため、セクション末以外では慎重に使う** |
| **弱い区切り** | 滑らかにつながり、雰囲気が持続する。構造がぼやけたり、停滞感が出たりすることもある |

### 7.3 呼応の基本

二つのまとまりを示し、**後者が前者への反応として聴こえる**ようにする（文字どおりの一問一答である必要はない）。

- 似たフレーズで呼応するのが反響型、対照的なフレーズで呼応するのが継続型。**「答え」が先に現れる**こともある（先に安定した形を出し、その後に問いかける）
- **対をなす呼応は最も安定するが、予定調和になりやすい**。**鎖のように次々とつなぐ**と展開が豊かになる一方で、散漫になるおそれがある
- 呼応は動機やフレーズなど**複数の階層で同時に起こる**（一つの動機が直前の動機にも、前のフレーズ全体にも呼応する）

### 7.4 クライマックスの位置

**既定では曲全体の2/3–3/4の位置に置く。**

クライマックスのセクションには三つのわかりやすい特徴がある。音域が高くなり、音価が長くなり、強弱が強まる。楽器編成も広がる傾向がある（文海良 p0149）。
クライマックスへの進み方には二つある。
**段階的に高める**。旋律を連続して上行させ、リズムの疎密の対比、和声語法の変化、音色や調性の切り替えを組み合わせる。主題を提示するセクションとクライマックスの継ぎ目にドラムのフィルを入れ、推進力をはっきり出す（文海良 p0149）。
**静けさから一気に入る**。主題を提示するセクションを完全に止め、移行部を挟まずにクライマックスへ入る。落差そのものが推進力になる。十分に明確な停止箇所が必要で、つなぎ方が悪いと唐突に聴こえる（文海良 p0151）。

クライマックスの頂点と、セクション全体とでは締めくくり方が異なる。頂点に達した直後は急に減速してリズムを広げ、十分な終止感を出すことが多い。クライマックスのセクションでは、高揚を保ったまま先へ進み、すぐに締めくくらない（文海良 p0149）。

出だしに比べて終盤が弱い場合は、クライマックスの位置と締めくくり方を確認する。**動機やフレーズの終わり方を変え**、サビの後半でクライマックスを強める。
クライマックスを数回繰り返しても言い足りないと感じるなら、その続きを担う補足の楽節を加えてフェードアウトすると、突然切るよりも締めくくりに充足感が出る（文海良 p0152）。

### 7.5 楽想の展開の参照先　動機からセクションへ、セクションから曲全体へ

動機をセクションに、セクションを曲全体に発展させる方法は **`mc-development`**（L1）にまとめている。`material` と `form[].development`、十の技法、展開と素材の積み上げの違い、ポップスでの配置はそちらを参照。このスキルでは動機とフレーズそのものの書き方を扱う。

## 8. ★ 予定調和を避ける

> **予定調和とは、聴き手が次の動きを読めて、すべてが予想どおりに展開すること。旋律を書く際に特に注意したい。**

### 8.1 予定調和になりやすい型

- 同じフレーズを**そのまま3回以上繰り返す**
- 動機を**コード進行に合わせて平行移動させる**（3番目のコードで聴き手に曲全体の先を読まれる）
- 1小節に1コード、8小節目の末尾をドミナントにする定型的な和声リズム
- 第2ヴァースの冒頭で第1ヴァースのA−A'を**そのまま繰り返す**（聴き手は次にB−Cが来るとすぐ予測する）
- 長短が交互に並ぶ跳ねたリズムを**曲全体で使い続ける**
- 教科書どおりの導音→主音、iv→iiiの解決を**そのまま鳴らす**

### 8.2 六つの対策

1. **3回目は必ず変える**。第2ヴァースでは**冒頭の反復を省く**（A-A'-B-C → A-B-C）
2. **期待を作り、そのうえで裏切る**。先に聴き手の予測を誘い、予測が生まれた箇所で**大きく外す**。意外性でクライマックスを演出する
3. **旋律線を長く取る**。動機ごとに細切れにせず、長い曲線を作る（先取音でリズムの型をつなぎ、深く下がる → 跳ね返るように上行してクライマックスへ → 強い半音の倚音で第二の重心を作る → ゆとりをもって終止する）。
   ★ **長い旋律線は、方向感とさまざまな動きの受け渡しで成り立つ**。切れ目をなくすだけでは間延びする
4. **素材を最小限にする**。新しいフレーズを作るたび、どこが変わり、どこを引き継ぐかを明確にする（部分的な対比と反復）。**素材が少ない曲ほど理解しやすく、心を動かしやすい**
5. **掛留音、倚音、先取音で定型的な解決を崩す**
6. 「平凡」（既存の手法をそのまま使い、安心感はあっても価値が乏しい）と「意味不明」（共通の形式から離れすぎて聴き手が入り込めない）の間で、
   **作品の内部に一貫した論理を作り、独自性を支える**

### 8.3 いびつさと、それへの答え

**終始滑らかだと退屈になる**。どこかに**いびつな箇所**を作って揺さぶりをかける。
★ **いびつさには必ず答えを用意する**（不安定な音が続いた後の心を動かす解決や、アクセントに逆らう跳躍を支える強い感情）。
答えがなければ、単なる欠点として残る。

> 前半の工夫で「この曲は聴く価値がある」と感じてもらえれば、その後で平板なフレーズが現れても、
> 聴き手はその先によい答えがあると期待して待ってくれる。

## 9. 診断表

| 症状 | 確認点 → 対処法 |
|---|---|
| **平板で退屈** | 順次進行、和声音、表拍ばかりか → 非和声音（倚音／掛留音）、シンコペーション、タメ付きの跳躍を足す。ペンタトニックの密度や半音の使い方も単調でないか確かめる |
| **次の展開がすべて読める** | 同じ形を2回以上反復しているか。動機がコードとともに平行移動しているか → 3回目を変える。反復を省く。または期待を誘ってから裏切り、クライマックスを作る |
| **まとまりがなく、つかみどころがない** | 素材が多すぎるか。新しい動機が連続するか → 部分動機を共有し、新しいフレーズにも反復する要素を残す。音域を1オクターブに収め、2/4/8小節で区切る |
| **出だしは良いが終盤が弱い** | クライマックスの位置と締めくくり方は適切か → 2/3–3/4にクライマックスを置く。動機やフレーズの**終わり方**を変え、サビの後半を強める |
| **歌いにくい** | 6度を超える跳躍か。同方向の跳躍が2回を超えるか、両端が1オクターブを超えるか。大きな跳躍の両端に十分な音価がないか。声区の切り替わりをまたぐか。増2度があるか → 7度を3+5 / 4+4に分け、タメ／助走／着地の処理を足し、フレーズごとに声区を割り当てる |
| **伴奏に埋もれる** | 冒頭でベースと一緒に強拍に入るか。旋律がリズムパターンをなぞっているか。終始拍に張り付いているか → 入りをずらし、裏拍を空けるか裏拍に応答し、隙間を残す |
| **説明書や校歌のように聴こえる** | 導音→主音など、機能に従う動きが直截すぎるか → 掛留音や倚音で崩し、ペンタトニックを混ぜ、句末の最も強い終止（主音＋I＋強拍）を避ける |
| **ペンタトニックの旋律に個性がない** | 動きやすい隣接音ばかりを行き来しているか → モードを変える。ペンタトニックの主音と調の主音をずらす。大きな跳躍やアルペジオを挟んで密度を下げる。装飾の半音を加える |
| **終わりきった感じがしない** | 音価で動きを止めても、旋法や和声が終止していないか → 導音から主音に入り、Iに重ねると最も強い終止になる。余韻が欲しいなら、あえて条件を外す |
| **曲全体が単調** | 全セクションが主和音から始まるか。間奏はどれも同じ長さか → あるセクションを逆循環で始める。後半でフレーズを省く。最後のサビを繰り返して転調する |

## 11. 書き上げた後の必須チェック

- [ ] 中心音域が**1オクターブ以内**で、曲全体が1.5–2オクターブを超えない
- [ ] 1回で6度を超える跳躍がない（8度を除く）
- [ ] 同方向の連続跳躍が**2回以内**で、両端が**1オクターブ以内**に収まる
- [ ] 大きな跳躍ごとに**タメ／助走／着地を和らげる処理／跳ね返り**の少なくとも一つがある
- [ ] 歌い手の**声区の切り替わり**を確認し、どのフレーズもそこをまたいでいない
- [ ] クライマックスが **2/3–3/4** の位置にあり、何がクライマックスを作っているか説明できる
- [ ] **同じ形のまま3回繰り返す**フレーズがなく、第2ヴァースでは冒頭の反復を省いている
- [ ] 新しい素材を増やしすぎず、動機同士で**部分動機を共有している**
- [ ] **いびつな箇所**が一つあり、**それに対する答え**がある
- [ ] 終止で**音価、和声、旋法が同時に収まる**（余韻を残す場合は意図的に外す）
