# 対位法と声部書法（Counterpoint）

> **対位法を使えると、編曲で各声部に独自の役割を持たせられる。**
> **和声は同時に鳴る音を組み合わせ、対位法は各声部を独立した旋律として動かす。**
> 和声だけで組み立てた編曲では、主旋律以外はすべて「伴奏」になる。対位法を使えば、それぞれが**登場人物**になる。

**このスキルでは、練習課題の解き方ではなく、実際に第2の旋律を書く方法を扱う。**

## 1. 書き始める前に決めること

| 必須項目 | 確認事項 |
|---|---|
| **① この旋律の役割** | 独立した**登場人物**か、背景を支える層か。対位法が必要なのは前者 |
| **② 主旋律との対比の種類** | 異なる性格同士か、同じ性格同士か（§4） |
| **③ 4つの観点でどうずらすか** | §3。**少なくとも2つを具体的に挙げられなければ、その旋律は伴奏の域を出ない** |
| **④ 主従関係** | ★ **両方が独立していても、どちらが主でどちらが従かを決める** |

## 2. 対位法で可能になる表現

> **対比ポリフォニー**とは、独立した2つ以上の旋律を対位法の原則に従って組み合わせたポリフォニーの構造をいう (p0050)。

**表現上の固有の働き**

> **性格の異なる2つ以上の旋律が表す内容を同時に提示し**、
> 対位法の原則に従って調和のとれた一体としてまとめられる (p0050)。

**用途**。劇的な音楽や交響的な音楽で、異なる2つのイメージを組み合わせて**矛盾や衝突**を表したり、
壮大な劇的場面を描いたりする。

★ **映画音楽のような表現を実現する方法の一つ**。
単一の旋律と和声が伝える内容は一つだが、対位法なら**二つの内容を同時に表し、互いに関係づけられる**。

**譜例**（丁善德《长征交响曲》II、例 61）。
低声部では、ゆったりとした重苦しいオスティナートが変わらず3回繰り返され、民衆の苦しみを表す。
その上でクラリネットとイングリッシュホルンが交互に伸びやかな旋律を奏で、山岳地帯の風景を描く。
→ **重く沈んだ表情と、明るく広がりのある表情が対比される。**

## 3. ★ 相互に補い合う4つの観点

2つの旋律を組み合わせながらそれぞれの独立性を保つには、次の4つの観点で**互いを補う**。

| 観点 | 補い方 |
|---|---|
| **1. リズムの密度** | **一方の音が細かいところでは、もう一方の音を長くする**。★ 4つの中で最も効果が大きく、**両者のリズムが同期すると一つの旋律に聞こえる** |
| **2. 音程の響き** | 協和と不協和、3度・6度・4度・5度の割合に変化をつけ、平行3度を続けない |
| **3. 声部進行の方向** | **同進行、反進行、斜進行を交えて使う**。★ 同進行が全体を占めると、和声をつける声部として聞こえる |
| **4. 旋律の頂点と最低点** | **到達する時点をずらし**、同時に頂点に達しないようにする |

> ★ **確認方法**。2つの旋律について、4つの観点を一つずつ確認する。
> **互いを補っている項目が2つ未満なら、和声をつける声部として聞こえる。**

**同じ性格同士を対比させる技法も、この4つに集約される**。§4.2を参照。

## 4. 2種類の対比

### 4.1 異なる性格の対比

2つの旋律が描く**イメージそのもの**が異なる（§2の例 61）。
劇的な衝突、並行する2つの物語、映像音楽で2人の登場人物が同時に現れる場面に向く。

**譜例**（プロコフィエフ《第七交响曲》I、例 62）。
高声部は叙情的で穏やかな主部主題で、低声部の対旋律は**内に秘めた情熱と崇高さ**を備えている。

### 4.2 ★ 同じ性格の対比（ポップスの編曲で最もよく使う）

> 2つの旋律に**性格の明確な違いがない**場合も、
> 共通点のある旋律を対位法で組み合わせると、対比の効果が生まれる (p0052)。

**具体的な手段は§3の4つ。**

> ★ 対位法によって生まれる二声の対比では、**描くイメージが共通していても、主従は明確に分かれる**。
>
> **さまざまなジャンルで、すでに提示した主題に対旋律を添え、
> 主題の内容に厚みを加えて表現を深める例が見られる。** (p0052)

**2回目のサビに変化をつける方法の一つ**。
主旋律を保ったまま対旋律を加える。
（ほかの方法は `mc-arrangement-arch` §6を参照。）

**譜例**
- **プロコフィエフ《罗密欧与朱丽叶》**（例 63）。対旋律と主題は**表情の性格を共有している**が、
  組み合わせることで「主題を単独で奏でるより深く心に響く」
- **ベートーヴェン《第九交响曲》II**（例 64）。中間部のロンド主題は、**性格を同じくする**2つの旋律を対位法で組み合わせて提示する。
  ★ **ベートーヴェンはこの二声を一体として扱い、繰り返すたびに声部の入れ替えや平行3度の付加で変化をつける**
  （→ §6の二重対位法の用例）
- **陈培勋《第二交响曲——清明祭》**（例 65）。まずチェロとコントラバスがユニゾンで主題を奏で、
  次にヴィオラが主題を引き継ぎ、チェロが対旋律を添える

## 5. 対位法で用いる旋律の制約

**対位法で組み合わせる旋律には、次の4つの条件がある。**

### 5.1 合唱様式の特性

> ポリフォニーの合唱旋律は、多声で組み合わせやすいように、**旋律線を滑らかに、リズムの動きをゆったりと**書く (p0054)。

★ **器楽曲で反復音型を中心に作る旋律とは性質が異なる**。
**最も見落としやすい条件**。器楽的なリフを主旋律と組み合わせると、互いの動きがぶつかりやすい。

于苏贤の原文はこの点を上の一文で示しており、§5.3のように音程ごとの表にはしていない。
「滑らか」「ゆったり」は、細部を確認する前に旋律全体を判断する基準になる。
まず**合唱団が歌える旋律か**を考え、そのうえで§5.3の音程と§5.4のリズムの制約を確認する。

### 5.2 旋法と調性の特性

- **明確な方向性**を持たせ、冒頭と末尾で調性構造をはっきり示す
- ★ **主音の扱いが重要**。主音は対位法の基本構造を確立するうえで欠かせない調性上の機能を担う
- 厳格対位法の段階では**転調は求めない**

> シェーンベルクは《作曲基本原理》で、シェンカーと一致する見解を示している。
> **「大まかに言えば、一つの楽曲は一つの終止形に似ており、各小楽句は終止形の一部分に相当する。
> ただし、その複雑さには多少の違いがある。」** (p0054)

### 5.3 ★ 音程の特性（実作で最も確認しやすい項目）

| 規則 | 説明 |
|---|---|
| **人声の音域内に収める** | 合唱のどの声部も、その声部が歌える音域の限界を超えない |
| **増音程・減音程を避ける** | **7度・9度の大きな跳躍**も避ける |
| **大きく跳躍した後は反対方向に順次進行する** | その他の全音階的な音程で大きく跳躍した場合は、この進行で均衡を取る |
| ★ **完全4度・完全5度を活用する** | **旋律に特徴的な音の動き**を作り、調性を確立する構造上の働きも持つ。**旋律の展開に欠かせない要素** |
| **4度・5度の跳躍を連続させない** | |

> **順次進行を基本とし、上記の適切な音程の跳躍を組み合わせる。**

★ `mc-melody` §3では**単独の旋律の歌いやすさ**を扱い、ここでは**2つの旋律を組み合わせられるか**を扱う。
それぞれが独立した旋律として成立し、同時に鳴らしても成立する必要があるため、**制約はより厳しい**。

### 5.4 リズムの特性

**リズムの動きをゆったりと取る**と、2つの旋律を組み合わせたときに**互いに不協和音を交互に使える**。

2つの旋律のリズムを配置する具体的な方法 (p0055–0056)。
- **音の密度に交替をつける**。ゆったりした動きと細かい動きを交互に配し、一方が動く間はもう一方を静める。
- **シンコペーションを交互に置く**。一方が掛留音やシンコペーションを使うときは、もう一方に強拍を打つ音を置く。**強拍を空けず**、両方が同時にシンコペーションする書き方は避ける。
- **時折、1音対1音にする**。片方ずつ動く形を続けず、同じリズムで進むことで生まれる推進力も使う。
- **冒頭は入りをずらすとよい**。2つの旋律は同時より順に入る方がよく、特定の種の書法に固定せず、それぞれの旋律の性格にリズムを合わせる。

## 6. ★ 二重対位法で繰り返しに変化をつける

**編曲に対位法を取り入れやすい方法。**

**二重対位法**では、2つの声部の**上下を入れ替えても**対位法として成立する。
一度書けば**2つの版**が得られる。2回目に上下の声部を入れ替えれば、
同じ素材のままで新鮮に聞こえる。

| 種類 | 転位の方法 | 特徴 |
|---|---|---|
| **8度（および15度）の二重対位法** | 一方の声部を8度移す | **最もよく使う**。制約が最も少ない |
| **10度の二重対位法** | | 固有の書法がある |
| **12度の二重対位法** | | 固有の特性と書法がある |

★ **ベートーヴェンは《第九》第2楽章でこの方法を使っている**（§4.2の例 64）。
繰り返すたびに**声部の入れ替え**や**平行3度の付加**で変化をつける。

**その他の可動対位法**（詳しくは [reference.md](reference.md)）
- **水平可動対位法**。2つの声部の**時間的**な関係を変える（入りをずらす）
- **垂直・水平可動対位法**。声部の上下と時間の関係を同時に変える
- **鏡像対位法**。一方の声部を特定の音を軸に反行させる（第II音、第III音、第IV音を軸とする場合にそれぞれ規則がある）

> **このライブラリでの使い方**。ARR-SPECで2回目のサビの変化を設計するとき（lint #16）の発展的な方法として、
> **同じ対旋律を8度の二重対位法で転位させる**。
> 和声の層を足すより高度な手法で、新しい素材も必要としない。

## 7. 五種対位法（段階的な練習）

定旋律（cantus firmus）を土台に、リズムの自由度を段階的に上げる。

| 種 | 組み合わせ方 |
|---|---|
| **第1種** | 1音対1音 |
| **第2種** | 2音対1音 |
| **第3種** | 4音対1音 |
| **第4種** | 全音符に**シンコペーション**を対置 |
| **第5種** | 全音符に**混合リズム**を対置（華麗対位法） |

> **厳格な規則を学ぶ理由**
> **「厳格な規則のもとで多様なポリフォニーの技法を学び、身につけることは、
> 自由な様式のポリフォニーを書く際に個性や才能を発揮する妨げにはならない。
> むしろ厳格対位法の土台を固めてこそ、鋭い洞察力が養われ、
> 巨匠たちが実際の作曲でこれらの技法をいかに柔軟に用いたかを理解できる。」** (p0054)

★ **このライブラリでの位置づけ**。エージェントは練習課題を解く必要はないが、**5つの段階は把握しておく**。
この分類を、対位声部がどれだけ活発に動くかの目安にできるためである。
第1種は純粋に和声をつける声部に相当し、第5種は完全に独立した旋律に相当する。
各種の規則（音程の3分類、声部進行の6規則、弱拍上の音の4つの役割、掛留に使える音程と使えない音程）は [reference.md](reference.md) §2を参照し、副旋律に問題があれば該当する種を確認する。
**副旋律を書き始める前に、動きの段階を決める。**

各種の具体的な規則（和声音程、調性構造、声部進行、終止形）は [reference.md](reference.md) を参照。

## 9. 書き終えた後のチェック

- [ ] この旋律は独立した**登場人物**として機能する（背景を支えるだけなら和声で足りる）
- [ ] 主旋律と§3の4つの観点のうち**少なくとも2つで補い合っている**
- [ ] ★ **リズムの密度が互いを補っている**（最も効果が大きく見落としやすいため、個別に確認する）
- [ ] 声部進行に**同進行・反進行・斜進行**を交えている
- [ ] 2つの旋律が**異なる時点で頂点に達する**
- [ ] 両方の旋律が独立していても、**主従が明確**
- [ ] §5.3の音程の制約を守っている（増減音程や7度・9度の跳躍を避け、大きな跳躍の後は反対方向に順次進行する）
- [ ] 対位声部は**滑らかでゆったり**しており、歌える旋律として書かれている
- [ ] セクションを繰り返す場合、新しい素材を足す前に**二重対位法による転位**を検討した
