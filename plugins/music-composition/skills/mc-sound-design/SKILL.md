# 音色設計（Sound Design）

**このスキルでは、音色を編曲の段階で決める。**

音色を選び損ねると、その後の楽器の割り振り、レイヤー、ミックスのすべてで埋め合わせが必要になる。
しかし多くの場合、音色選びは「悪くない音が見つかるまでプリセットを試す」作業になっている。**それが AI らしさを生む最も恒常的な要因だ**。
生成モデルも同じように、そのカテゴリーで最も典型的な音色を選ぶからだ。

> このスキルの中心となる手法は野崎貴朗に由来する。**まず構想を明確にし、それからパラメータを操作する。**

## 作業別の参照先

| プリセットをいくら試しても合わない | §2 初期状態に戻す |
| 音色が「プリセットっぽい」、個性がない | §2 ＋ §4 |
| 音色自体は合っているのに、編曲に入れると合わない | §3 の②音域 |
| スマートフォンやノート PC でベースが聞こえない | §6 差音 |

## 1. 作業前に答える 4 つの質問

音色を設計する前に、**どんな役割を担い、どんな個性を持つ音か**を判断し、次の 4 項目に答える (p0091)。

| # | 質問 |
|---|---|
| **①** | **打楽器タイプ**（音高が不明確）か、**楽音**（音高があり、メロディやコードを演奏できる）か？ |
| **②** | おおよその**音域**は？ |
| **③** | 音色の**振幅エンベロープ**はどんな曲線を描くか？ |
| **④** | **明るい（倍音が多い）か、暗い（倍音が少ない）か**？ |

> 著者は習慣にするよう求めている。**「音色設計では、まず自分の構想を①～④と照らし合わせる習慣をつける」** (p0091)。

**4 つの質問で足りる理由**は、それぞれがシンセサイザーの 1 つのモジュールに対応しているため（§3）。
4 つすべてに答えれば、パラメータの設定は大半が決まり、**残りは好みで調整する**。

**自己チェック**。4 つのうち 1 つでも答えられなければ、つまみを操作する前に構想を詰める。
答えがないまま操作すると、当てずっぽうで試すことになる。

## 2. 初期状態に戻して「加工していない音」から始める

**問題**。シンセサイザーには、エレキギターやピアノのような分かりやすい「原音」がない。
起動した時点で誰かが作ったプリセットに入っており、**自分が下す判断はすべて誰かの判断が出発点になる**。

**方法**。「加工していない音」の初期設定を作る (p0088)。

| モジュール | 設定 |
|---|---|
| オシレーター | **のこぎり波を 1 基だけ使用** |
| フィルター | **CUTOFF を右いっぱい、RESONANCE 0、FILTER EG 0**（全開） |
| AMP EG | **ATTACK 0、DECAY 0、SUSTAIN 全開、RELEASE 0**（オルガンのようなエンベロープ） |
| LFO などのモジュレーション | **一切使わない** |
| エフェクター | **かけない** |

> **「ここまで調整して『元の波形が鳴る状態』にして初めて、ギターやピアノのような『加工していない音』になる」** (p0088)。

**推奨**。「初期状態 1 号」として保存し、**毎回ここから音色設計を始める** (p0089)。

**AI らしさを抑えられる理由**。プリセットには、そのカテゴリーの音に対する作成者の標準的な判断が表れている。
そこから始めると、その標準の近辺で微調整することになる。初期状態から始めれば、自分の構想から音色を組み立てられる。

**例外**。時間が極端に限られている場合や、特定の定番音色が必要な場合（TB-303 のアシッドベースなど）は、
最も近いプリセットから手を加えてよい (p0090 の方法②)。ただし、**どの 4 箇所を変えたか説明できること**。
説明できなければ、手を加えたことにはならない。

## 3. 4 つの質問とパラメータの対応

| 構想 | パラメータ | 決め方 |
|---|---|---|
| **① 打楽器タイプ or 楽音** | **オシレーターの波形** | 打楽器タイプ → **NOISE**。楽音 → **SAW** または **SQUARE** (p0092) |
| **② 音域** | **TUNE / TRANSPOSE** | 下の ★ を参照 |
| **③ エンベロープの曲線** | **AMP EG** | 下の 3 項目を参照 |
| **④ 明るい or 暗い** | **FILTER** | まず **−24 dB/oct のローパス**に設定し、次に **CUTOFF** で調整する (p0092) |

### ★ ②音域は最も見落としやすく、外したときの影響が大きい

> **「理想の音色にどれほど近づけようとしても、音域が違えば決してイメージどおりの音にはならない」** (p0092)。

これで、**単独で聴くと音色は合っているのに、編曲に入れると合わない**というよくある現象を説明できる。
たいていは音域が合っていない。
この点は `mc-texture-layering` §4.2 の「音域をずらす」に直接つながる。

### ③ エンベロープで決める 3 項目 (p0092)

| | 欲しい音 | 設定方法 |
|---|---|---|
| **立ち上がり** | 素早く歯切れよく / ゆっくり徐々に | ATTACK を短く / 長くする |
| **持続** | 自然に消える / 鳴り続ける | SUSTAIN=0 にして DECAY を調整 / SUSTAIN で音量を決める |
| **音を止めた後** | すぐ消える / 余韻を残す | RELEASE=0 / RELEASE を長くする |

> **基本原則は「何よりも、まず『決まっている部分』から設定に取りかかる」こと** (p0093)。
> 4 つの質問のうち最も答えが明確なものに対応するモジュールから操作する。

**コツ**。フレーズができているなら、**繰り返し再生しながら音色を設計する**と効果的 (p0093)。
音色は曲の中でどう聞こえるかで判断する。

### 3.5 ★ 音色を識別する手がかりは立ち上がりにある（Howard & Angus）

4 つの質問はスペクトルとエンベロープを扱うが、**音色の識別に役立つ情報はほとんどが最初の数十ミリ秒にある**。立ち上がりと減衰を取り除くと、バイオリンとトランペットは聞き分けにくい（p0222–0223）。
合成音が「作り物っぽい」と感じるときは、多くの場合、立ち上がりに必要な手がかりがない。書籍では 6 つを挙げている（p0223）。
弓と弦の摩擦、金管の子音のような立ち上がり、吹奏時の息のノイズ、リードが振動を始めるときの打音、ハンマーの打撃、弦が元に戻るときの音。

**音色を作るときの 3 項目**。

1. 実際の楽器をまねるなら、まず立ち上がりにどんなノイズや非調波成分があるかを確認し、次に定常部のスペクトルを見る。サンプルが「作り物っぽく」聞こえる主な理由は、定常部をループに使い、立ち上がりが切り落とされていること（p0217）
2. 立ち上がりは部屋の響きの影響を受けない。最初の反射は通常、立ち上がりが終わった後に届く（p0217）。**切り落とした立ち上がりはリバーブで取り戻せない**
3. 楽器の種類によって立ち上がりの長さは大きく異なる。金管は基音が先に出て極めて短い。フルートは基音に先立って約 70 ms の息のノイズがある。バイオリンの立ち上がりは約 160 ms で、ビブラートが現れるのは 250 ms 後（p0220–0221）。
   「速いスタッカート用」の音色には短い立ち上がりが必要。「ロングトーン用」の音色は少し長くしたほうが本物らしい

楽器の種類ごとの立ち上がりの比較表は `mc-texture-layering` reference §5a.2 にある。

### 3.6 ★ 音響動態の強調：立ち上がりの遅い層に速い層を重ねる（杨立青）

「音響動態」とは、音の立ち上がり、定常部、減衰が時間とともにどう移り変わるかを指す。**異なる音色を重ね、ある要素がもともと持つ音響動態を強めたり、誇張したり、作り変えたりすること**を、
音響動態の強調という（杨立青 下巻 p0287）。

最も一般的な使い方は、**音の出だしがはっきりしない pad や弦のロングトーンに、立ち上がりの速い音（pluck、ピアノ、ピチカート、mallet）を重ね、アタックを補う**こと。
聴感上は pad 自体の輪郭がはっきりするが、出だしの音は別の楽器から来ている。逆に、出だしが硬すぎる音には、立ち上がりの遅い層を重ねて角を取れる。

これは「2 つの層を重ねると、それぞれを単独で聴くよりよく聞こえる」理由のうち、よくあるものの 1 つ。仕様書には意図的な判断として記載し、
`roster[].note` に「この層がどの音のアタックを補うか」を明記する。

同じ考え方には音色に関わるもう 1 つの点がある。**心理的に最も強く感じる箇所と、物理的な音量が最大の箇所は一致するとは限らない**（p0283–0284）。
メロディの最高音や骨格となる音は、強弱が弱まる途中でも、別の音色を重ねて強調することが多い。ベルリオーズが ppp の箇所で最高音にホルンを重ねるのも、このためだ。
音色を重ねるときは、「聴かせたい箇所」に重ねられる音色を 1 つ用意するほうが、全体の音量を上げるより効果的。

## 4. 彫刻のモデルで考える減算合成

著者は音色設計を**彫刻**にたとえている（p0037）。

| 彫刻 | シンセサイザー |
|---|---|
| ① 素材を選ぶ（木材、石材） | **波形を選択する** |
| ② 複数の素材を組み合わせる | **複数のオシレーターを使う** |
| ③ 大きな原型から不要な部分を**削り取る** | **フィルターで不要な倍音を取り除く** |
| ④ 必要な部分を**補修し、強調する** | **RESONANCE** で特定の帯域を強調するか、**FM / OSC SYNC / RING MOD** で新しい倍音を作る |

**EG と LFO は時間的な変化を作る**。コマ撮りのクレイアニメーションに近い (p0037)。

**このモデルを使うと、音色を作る工程からエフェクターをかける工程を切り離せる**。
④ の 4 つの手段はすべてシンセサイザーの内部にある。**まず音源の中で狙った音色を作り、それからエフェクターを検討する**。

## 5. フィルターの選び方

| 種類 | 働き (p0037–0038) |
|---|---|
| **ローパス LPF** | 音の上端（高域の倍音）からカットする |
| **ハイパス HPF** | 音の土台となる下端（低域）からカットする |
| **バンドパス BPF** | 欲しい帯域だけを残し、その上下をカットする |
| **ノッチ Notch** | 指定した帯域だけをカットし、その上下を残す |
| **コム Comb** | 櫛でとかしたように、櫛の歯状の周波数特性を作る |

> **シンセサイザーの音色設計では9割以上でローパスを使う**。シンセサイザーのプリセット波形は通常の楽器よりも倍音が多く、
> 高域の倍音を削る必要があるため (p0038)。

**迷ったら**ローパスを使う。Notch や Comb を使うときは理由を説明できるようにする。

## 6. ★ 差音：純粋なサイン波のベースが消える理由

これは**心理音響**上の制約であり、好みで変わるものではない。

> **差音（difference tone）**：基音が聞こえなくても、脳は倍音から基音を推定する。
> たとえば 300 Hz と 400 Hz を同時に聞くと、脳は最大公約数の **100 Hz** を補い、
> 100 Hz の音が聞こえたように感じる (p0127)。

> ただし、**「サイン波には判断の手がかりとなる倍音が一切含まれないため、聴覚上の錯覚も起こらない」** (p0127)。

**結果**：純粋なサイン波のベースはモニタースピーカーではよく聞こえるが、**スマートフォン、ノートパソコン、Bluetoothスピーカーでは聞こえなくなる**。
こうした機器は基音を再生できず、サイン波には脳が基音を推定する手がかりもないため。

**対処法は2つ** (p0127)。

1. **倍音を補い**、聴覚上の錯覚が起こる音を作る ← ほぼ常にこちらを選ぶ
2. 大規模なダンスホールやコンサートホールなど、超低域を再生できる環境を前提とし、**一般的な視聴環境を対象から外す**

### 倍音を補う2つの方法

**方法1：移調して重ねる** (p0127)
同じ演奏を別トラックにコピーし、**TRANSPOSE で1オクターブ上、または1オクターブ＋完全5度上**に移調し、少量混ぜる。

> **「複数の倍音を補うのも効果的だが、多すぎると『サイン波の質感』が失われる。
> 聞こえるか聞こえないかくらいを目安にするとよい」** (p0127)。

**方法2：歪ませる**（初心者におすすめ。比較的自然に仕上がる）(p0127)
歪み系エフェクターを挿し、わずかに歪ませる。
> **「歪みが聞き分けられるなら、かけすぎ」** (p0127)。

**ルーティング**：サイン波のベースを Bus 経由で AUX トラックに送り、AUX で歪ませて原音に混ぜる。
歪み成分が少なすぎる場合は、**先に AUX で low cut をかけると、原音に干渉しない** (p0128)。

**確認方法**：サイン波や極端に暗い音色が低域の主体となるアレンジは、
**必ずスマートフォンの内蔵スピーカーで一度確認する**。このスキルで実機での試聴を求める唯一のチェック項目。

## 7. ARR-SPEC と各バックエンドでの対応

ARR-SPEC では音色を `roster[].instrument`（抽象的な楽器選択）、`roster[].timbre`（テキスト用バックエンド向け）、
`roster[].synth_params`（パラメーター用バックエンド向け）に記述する。
**同じ記述を3種類のバックエンドで使えるように**、書き方を使い分ける。

| バックエンド | 入力の扱い | 書き方 |
|---|---|---|
| Suno / MiniMax（テキストプロンプト） | 自然言語のみを解釈する | **聴感が伝わる表現**を使う。質感、年代、参考となる楽器など。CUTOFF の数値は書かない |
| YuE2（テキスト＋条件） | 同上。曲のセクションごとの差も指定できる | 同上。ただし曲のセクションごとに変えられる |
| MIDI / MusicXML → DAW | パラメーターを解釈する | `roster[].synth_params` に4つの問いへの答えと主要なノブの設定を書く |

**記述例**（同じ音色を2通りで記述）：
- テキスト用バックエンド：`warm analog saw bass, slightly detuned, short attack, filter opens over 2 bars`
- パラメーター用バックエンド：`{osc: saw×2 detune 8c, filter: LP24 cutoff 320Hz, FEG amount +40 decay 900ms, amp: A0 D200 S0.7 R120}`

**2つの記述は必ず同じ設計に基づける**。どちらも4つの問いへの答えから作る。
個別に作ると「テキスト用バックエンドと MIDI バックエンドで別々の曲に聞こえる」ことがある。

## 8. 書き終えたら必ず確認する項目

- [ ] 設計した音色ごとに**4つの問い**に答え、記録した
- [ ] **初期設定**から始めた。プリセットから調整した場合は変更箇所を説明できる
- [ ] **音域**を最初に決めた
- [ ] ローパス以外のフィルターを使った箇所は理由を説明できる
- [ ] ④ の倍音強調は、エフェクターを挿す前に**音源内部**（FM/SYNC/RING/RESO）で試した
- [ ] 低域の主体がサイン波や極端に暗い音色の場合、**倍音を補い**、**スマートフォンの内蔵スピーカーで確認した**
- [ ] roster の音色記述に**テキスト版とパラメーター版**があり、両方が同じ設計に基づいている
- [ ] 音色はソロ試聴だけで決めず、**フレーズの中で**試した
