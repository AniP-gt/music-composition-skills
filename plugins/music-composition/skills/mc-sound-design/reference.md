# mc-sound-design リファレンス：音色レシピ索引

> `SKILL.md` は音色設計の判断基準を扱う。ここでは具体的なレシピの掲載箇所と主要な設定を引ける。
> ページ番号はすべて **野崎貴朗《圖解合成器音樂創作法：99種技法一次學會》** のもの。
> 書籍で使用するシンセは **NoiseMaker**（無料の VST）。パラメーター名は多くの減算方式シンセで共通。

## 0. 音色設計の二つの原則

### 0.1 「削った成分は元に戻せない」

> 音色設計の大原則は「**削った成分は元に戻せない**」。
> **サンプルから削られた倍音や弱められたアタックは、サンプリング後の処理では復元できない。**
> 音色を柔軟に編集できるように、**プロの多くはシンセの音色をゼロから作る**。

これは `SKILL.md` §2 で初期化から始めるもう一つの理由。プリセットの画一性を避けつつ、
**あとで調整できる余地を残す**。他人のサンプルを使うと、すでに成分が削られた状態から始めることになる。

### 0.2 フィルターを音源として使う

フィルターも音源になる。**レゾナンス（RESONANCE）を最大にするとフィルターが自己発振し、
ピッチを調整できるサイン波が生まれる**。909 Kick はこの方法で作る（§5.1）。

純粋なサイン波が必要で、エンベロープでピッチを大きく変えるなら、サイン波オシレーターより柔軟に設定できる。

## 2. 全パラメーターを掲載するレシピ：909 Kick

**フィルターを音源にする**という珍しい手法のため、設定をすべて記載する。

> TR-909 のキックは**オシレーターを一切使わない**。909 Kick の波形はサイン波に近く、
> 音源となるサイン波は**レゾナンス（resonance）による自己発振**で得る。
> この方法ならピッチを柔軟に操作できる。

| モジュール | 設定 |
|---|---|
| **FILTER** | ローパス（LOW PASS）、**−24 dB/oct** |
| **RESONANCE** | **最大**（フィルターを自己発振させる） |
| **CUTOFF** | **8 時**付近（EG で大きく開いたあと低い位置に戻すため） |
| **FILTER EG** | ATTACK 0 / DECAY **11 時** / SUSTAIN 0 / RELEASE **11 時**（急速に減衰）。**EG AMOUNT 2 時** |
| **AMP EG** | ATTACK 0 / DECAY 0 / SUSTAIN **最大** / RELEASE **1 時** |

**得られる音**：アタック時はピッチが高く、キックらしい低音まで急速に下がる。
**微調整には CUTOFF または FILTER EG の DECAY を使う**。小さな調整でも音の細部が大きく変わる。

（譜例：図① p0235、CD TRACK 64 p0236）

その他のドラム音：TR-808 スネア = 技法 71、TR-808 ハイハット = 技法 72。

## 5. このスキルの対象外

野崎の書籍にある以下の内容は、本スキルの対象外。

| 内容 | 参照先 |
|---|---|
| 竹内一弘《EDM 制作》の EQ / コンプレッサーに関する全章 | `mc-mix-intent`（意図）／パラメーターはミックスで扱う |
| 歪み系エフェクトの挿し方とバスルーティング | ミックスで扱う |
| サンプルのスライス、素材管理 | `mc-rhythm-section` ／ その他は本パッケージの対象外 |
| Greatest Discs のレコード分析（COCHIN MOON、Aphex Twin 等） | コーパス層 L5 でリファレンス曲の候補にする |
