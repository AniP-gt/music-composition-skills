# 転調（Modulation）

**転調で難しいのは、移る先を決めることよりも、つなぎ目が意図した変化として聴こえるようにすること。**

このスキルの中心となるのは、**クッション・コード**と、
**転調の予告をどれだけ強く聴かせるか**という尺度。

## 1. 書き始める前に決めること

| 必須項目 | 確認すること |
|---|---|
| **① 目標調** | 具体的な調名を決め、元の調との**音程関係**を求める |
| **② 転調の理由** | 盛り上げたいのか、明暗を切り替えたいのか、場面を一変させたいのか。**「そろそろ転調するところだから」では理由にならない** |
| **③ 予告の強さ** | さりげなく移るか、強く印象づけるか（§3.2の5段階から選ぶ） |
| **④ 元の調への戻り方** | 戻るか。戻るならどう戻るか。**★ 最も見落としやすい項目** |

---

### 1.1 転調の4つの目的（黄虎威 p0010–0013）

内容を表現し、情景や人物像を描く。素材を展開する（同じ断片を異なる調で反復すれば、少ない素材で大きな効果が得られる）。色彩に対比をつける。
★ **声や楽器の音域、音区、音色に合わせる**。4つ目は以前の確認項目にはなかったが、最も実用的な理由でもある。歌手にとって音が高すぎるなら、転調で対応できる。それだけで十分な理由になる。
従属する調は本質的に不安定で、基本調に戻ろうとする。その力が曲を前に進める。属和音が主和音を導きやすいのと同じように、**基本調に戻るときは、まずその属調に移ると主調を導きやすい**（p0011）。

## 2. 近親調と遠隔調

一般に使われる調は24（長調12、小調12）。Key=Cを例に、**6種類の近親調**を示す。

| 関係 | 例 | 聴感・特徴 |
|---|---|---|
| **同主調** | C ↔ Cm | 主音が同じ長調と短調。**明暗の差を大きく出せる** |
| **平行調**（＝関係長短調） | C ↔ Am | 調号が同じで、ほぼすべてのコードを共有する。**わずかな変化で雰囲気が変わる** |
| **属調**（上行完全5度） | C → G | 音階の違いは1音だけで共通和音が多く、**最も滑らか** |
| **属調の平行調** | C → Em | Gと同じ調号 |
| **下属調**（下行完全5度） | C → F | 属調と対称の関係にあり、同じように滑らか |
| **下属調の平行調** | C → Dm | Fと同じ調号 |

**遠隔調**は上記以外のすべての調。雰囲気が大きく変わり、使い方次第で劇的な展開になる。
**半音関係と三全音関係はいずれも遠隔調にあたる。**

---

### 2.1 調の近さを3段階で定量化する（黄虎威）

近親調か遠隔調かは数で表せる（p0013–0017）。五度圏上で距離が短い方を採る。

| 関係 | 調号の差 | 共通するダイアトニック三和音 |
|---|---|---|
| 近い関係 | 1個 | **4個** |
| やや遠い関係 | 2個 | 2個 |
| 遠い関係 | 3–6個 | 0個 |
| 最も遠い関係 | 6個 | 0個 |

共通する三和音の数が、クッション・コード（§3）の候補数になる。共通和音がない場合は、異名同音を利用するか、直接転調する（§4.1）。

### 2.2 五音音階の転調

五音音階で宮音を基準とする体系を移す方法は2つ。変宮を角と読み替えると上行5度、清角を宮と読み替えると下行5度になる。同じ方向に2回続けると長2度の移動になる（黄虎威 p0041–0042、p0063–0064）。
★ **近い関係にある五音音階への転調は、旋律だけでは気づきにくい**。1つの宮音体系の7つの自然音だけで、元の調と2つの近い調の五音旋律を臨時記号なしで書ける（p0040–0041）。
そのため和声が転調感を担い、新しい調号を特徴づける音を和声に入れる必要がある（p0045）。体系と同主音の4変種は `mc-melody` reference §3.0 を参照。

### 2.3 転調と見なさないケース（過剰な分析を防ぐ）

セカンダリー・ドミナント、エクステンデッド・ドミナント、関連する II-7、モードの切り替え、代理ドミナント、経過和音が現れても、**通常は転調と見なさない**。1小節だけ現れるコードは、元の調のディグリーで解釈する方がよい
（陈云强《爵士和声》p0257）。§5の「その後も新しい調にとどまるか」と同じ判断基準で、**元に戻る場合は離調と捉える**。

### 2.4 歌の転調に使う3つの方法（Kachulis）

**同主調への転調**（主音を保ったままモードの色彩を変える。GミクソリディアンからGドリアンに移り、歌詞の物語の転機を示す）。**関係調への転調**（両方の調でディグリーが異なるピボット・コードを使い、予想されるコードを別の調のコードに置き換えて、その調にとどまる）。
**感嘆型の転調**（Vの直後に新しい調に入る）。この3分類は黄虎威の分類より大まかで、歌詞と結びつけて使う。物語の転機に転調を合わせる。歌詞があれば `meta.upstream.lyrics` から転機のあるセクションを読み取り、なければ `intent.emotional_arc` に示された転換点のセクションを使う。

## 3. ★ クッション・コード

### 3.1 役割

**転調のつなぎ目を滑らかに聴かせるための経過和音。**

> **最もよく使うのは目標調のVまたはV7**。転調前の最後の1–2拍に挿入し、
> **小節線をまたいで V7→I と解決する（ドミナント進行）**。

★ このV7は**元の調では調外和音になる場合が多い**（III7、IV7、VI7など）。
**その響きが、調の色彩が変わる合図になる。**

### 3.2 転調の予告をどれだけ強く聴かせるか

**弱いものから強いものへ。**

| 段階 | クッション・コード | 効果 |
|---|---|---|
| 1 | **V（三和音）** | **最も滑らかで、予告は最も弱い** |
| 2 | **V7** | 三全音を含み、解決へ向かう力が強い |
| 3 | **♭II7（裏コード）** | 調外音が加わり、**予告が最も明確**で、ジャズらしい響きが出る |
| 4 | **dim / aug**（V7(♭9)／V7(♭13)の代理） | 特徴的な響きで、**インパクトが最も大きい** |
| 5 | **IV(onV)型の分数コード**（F/Gなど） | ★ **第3音（導音）がない → 調性が曖昧になる → さまざまな調へ移りやすくなる** |

★ **第5段階は例外**で、予告とは別の働きをする。
第1〜4段階は転調を明示し、第5段階は元の調を聴き取りにくくする。
**気づかれにくい転調にはこの方法を使う。**

### 3.3 ディグリーで考える

**各コードをローマ数字のディグリーで捉えれば、移調してもディグリーは変わらない。**
これは条件つきの判定基準ではなく、コードを読み替えるときの習慣なので、原則はこの一文に尽きる。
§3.4の手法①（進行全体をそのまま移調）、§3.5の「共通和音の選び方」（前後の調で同じコードのディグリーを読み替える）、
§5の手順3（目標調のV7を求める）で繰り返し使う。具体的な使い方や注意点は、それぞれの節を参照。

### 3.4 統一感を保つ3つの手法

転調で最も避けたいのは、別の曲に切り替わったように聴こえること。対策は3つある。

1. **進行全体をそのまま移調する**（ディグリーをすべて保ったまま、同じ進行を移す）
2. **1本のクリシェを両方の調に通す**（低音・内声・最高音のいずれかを半音ずつ動かす）
3. ★ **共通音を最高音に置き**、メロディで転調の前後をつなぐ

---

### 3.5 クッション・コードの9つの使い方（黄虎威）

§3で説明したクッション・コードを使った具体的なつなぎ方を、調の関係が近い順に示す。

| 方法 | 要点 | ページ |
|---|---|---|
| **共通和音の選び方** | 隣接する複数のコードを両調が共有するときは、**転調和音の直前にある最後の1つだけを共通和音と見なす**。前後の調でディグリーは通常異なるが、機能が同じ場合もある | p0033–0034 |
| **特徴音を先取りする、または遅らせる** | 共通和音の段階で新しい調の特徴音を先取りしてもよい（経過音として入り込むことが多い）。後から出して新しい調を確かめることもできる。★ **旋律が先に転調して和声が追認する場合**と、**和声が先に転調して旋律が後から追う場合**では、聴感が大きく異なる | p0034–0035、p0049–0050 |
| **半音変化による転調** | 転調先が長調なら、共通和音にその調の自然な第VI音を含め、転調和音に入る際に半音下げる。転調先が短調なら、その調の自然な第VII音を含め、半音上げて導音にする | p0037–0039 |
| **中間調** | 共通の三和音の前後にその属機能を加えて一時的な調の中心とし、そこから目標調に向かう。遠隔調への転調を2段階に分けられる | p0057–0059 |
| **増三和音を共通和音にする** | 十二平均律で互いに響きの異なる増三和音は4つ。いずれも2つの異名同音の和音と合わせて12の調に解決できる。手早く選ぶには、**目標調の主和音の構成音を1つか2つ含む増三和音**を探す | 黄虎威の著書の増三和音の章を参照 |
| **属七と増六を異名同音で読み替える** | 元の調の属七を新しい調の増五六の和音と見なす → 半音下の調。元の調の増五六の和音を新しい調の属七と見なす → 半音上の調。上下半音への転調に使える別の方法 | p0120–0121 |
| **単声部で転調する** | 持続する単音か単声部だけで転調を成立させる。セクションの境目を最小限の音でつなげる | p0145–0153 |
| **短3度の循環** | 同じ方向に短3度ずつ転調すると、**4回目で元の調に戻る**。長3度の循環では、低音に長2度で進む経過音を加えると全音音階になる | p0163–0164 |
| **長短の主和音を入れ替える** | 予想される主和音の第3音を下げるか上げる。元の調の属機能の直後に置くため、機能上の結びつきが強く、**通常は転調として成立しない**。色彩の対比が明瞭で、少ない変更で転調風の効果を出せる | p0167–0168 |

**軸音**（p0061）は、前後の調を通じて鳴り、両方の調で旋法の骨格をなす音（元の調の属音が新しい調の下属音を兼ねる場合など）。§3.4の手法3「共通音を最高音に置く」を実践するときは、先に軸音を見つけ、その音を軸にメロディを組み立てる。

## 4. 転調の距離と聴感

| 方向 | 聴感・特徴 |
|---|---|
| **上行半音** | アウトロ前の定番のキー上げで、気分を高揚させる。★ §6を参照 |
| **下行半音** | 遠隔調ならではのインパクトがあり、**特別な技巧を要しない** |
| **上行全音** | 勢いが強く、**dimコードを経由すると悲壮感が増す** |
| **下行全音** | 隣接する調への移動。自然に**終曲らしい響き**や重みが出る |
| **上行短3度** | 長調なら華やかで壮大に、短調なら繊細に色彩が変わる |
| **下行短3度** | 長調なら明るく安定し、前向きで爽やかに聴こえる |
| **同主調** | 明暗をはっきり切り替えたり、徐々に色彩を変えたりできる |
| **平行調** | **明暗を最も滑らかに切り替えられる** |
| **属調／下属調** | 共通和音が最も多く、**全体で最も滑らか** |
| **三全音** | **最も遠い関係**。うまくつなぐと**最も劇的な効果**が得られる |

---

### 4.1 直接転調で調を対置する

**直接転調（調性の対置）**では、クッション・コードを使わず、2つの調を直接並べて色彩を対比させる（黄虎威 p0156–0164）。配置の原則は次のとおり。
**素材が異なる場合は楽段規模の大きな構造の間に、同じ素材を使う場合は楽句・楽節・動機規模の小さな構造の間に置く**。短い構造では前の印象が残っているため、対比が際立つ。
色彩の変化は、近い関係では機能の結びつきが強く対比が弱い → 3度関係は最も色彩豊か → 調号の差が5個なら唐突で新鮮 → 6個なら最も唐突で関係も最も遠い。
§6の終盤で半音上げる手法は、直接転調の中でも特に多用されている。

## 5. 転調を決める6つの手順

1. **目標調と方向を決める**。どこに移りたいか（サビのキー上げ、明暗の切り替え、最後のクライマックスなど）を決め、音程関係を求める
2. **方向別索引を引く**（[reference.md](reference.md) §1）。該当する方向の手法を確認し、求める**予告の強さ**で選ぶ
3. **目標調のV7を求める**。幅広く使えるクッションになる。粋な響きにするなら**裏コード**、インパクトを出すなら **dim/aug の代理和音**、
   さりげなく移るなら **IV(onV)型の分数コード**を使う
4. **統一感を保つ方法を選ぶ**。進行全体の移調、前後の調に通すクリシェ、最高音に残す共通音から1つ選ぶか、組み合わせる
5. **着地を決める**。クッション・コードを転調前の最後の1–2拍に置き、**小節線をまたいで新しい調のIに解決する**
   （または IIm7／IVm のようにツー・ファイブへ入れる和音に着地する）
6. ★ **元の調への戻り方を決める**。新しい調のIを属七に変える（I→I7）か、元の調のIImに変え、
   セカンダリー・ドミナントやツー・ファイブ・ワンで戻る

> **最も見落としやすいのは手順6。** 転調したまま戻れないと、曲の後半全体に違和感が残る。
> 20項目のチェックでは検出できないため、**この点は自分で確認する必要がある。**

---

### 5.1 完全な転調の4段階と転調の特徴音

上の6つは設計の手順。次の4つは**診断**用で、つなぎ目に問題があるときに順に確認する（黄虎威 p0032–0036）。

1. 元の調を示す
2. 共通和音を出す
3. **転調和音**を出す
4. 新しい調を確立する（完全正格終止）

実際の楽曲では4段階をすべて踏む場合も、一部をまとめたり省いたりする場合もある。最も極端なのは2つの調の主和音を直接対置する方法で、§4.1の直接転調がこれにあたる。

★ **転調の特徴音**（p0035）。転調和音には**元の調にはなく、新しい調に固有の音**を入れる。通常は両調の調号で異なる音（CからGなら F♯、CからFなら B♭）。
新しい調が和声長調なら下げた第VI音、和声短調なら上げた第VII音を確認する。**新しい調に移ったことが伝わるかを判断する目安**で、特徴音が一度も現れなければ、聴き手は転調に気づかない。

## 6. ★ 定番の使いすぎに注意：最後のサビで半音上げる

**ポピュラー音楽で特に多用される手法で、生成モデルも既定のように選びやすい。**

「epic / emotional / final chorus」のようなプロンプトを使うと、バックエンドが**高い確率で自動的に半音上げる**。

**判断基準は `mc-progressions` §3と同じ。**

> **意図して選んだのか、成り行きで採用したのか。**

### 6.1 最後を盛り上げる4つの代案

| 代案 | 効果 |
|---|---|
| **下行全音** | 安易な高揚感を避けつつ、終曲らしさと重みが出る。**下に移ることで、かえって重みが増す** |
| **上行短3度** | 華やかで壮大。半音よりも大きな展開として聴こえる |
| **調を保ち、編成を変える** | ★ **多くの場合はこれが有効**。キー上げで、編曲で作りきれなかった盛り上がりを補おうとしている場合が多い（→ `mc-arrangement-arch` §6） |
| **同主調に切り替える** | 長調から短調、または短調から長調に移ると、半音上げるよりも感情が大きく変わる |

### 6.2 半音上げる場合

**少なくとも次のどちらかを行う。**
- §3.2の第4段階（dim/aug）か第5段階（分数コード）で**予告の仕方を変え**、定番のV7を避ける
- **キーを上げるのと同時に編成を変える**（楽器を1つ抜く、または新しい楽器を1つ加える）。
  そうすると、半音の移動よりも編成の変化が聴き手の印象に残る

★ **自己チェック**。なぜここで転調するかを、ARR-SPECの `form[].note` に一文で書く。
理由を書けなければ転調を見送る。

## 7. 場面別の手法

| 場面 | 推奨する手法の番号（[reference.md](reference.md) を参照） |
|---|---|
| サビ全体のキーを上げる（アウトロ前の定番） | 10、15、41 |
| 大サビ（最後のクライマックスとなるサビ）でもう一段盛り上げる | 15、09、21 |
| Aメロからサビで一気に開ける（暗→明） | 05、12、17、23、36、39 |
| 明るいAメロ・Bメロから急に重いサビへ移る（明→暗） | 16、30、34、40 |
| アウトロに終曲らしさを出す／華やかに締める | 02、08、24、31、33、43 |
| 間奏・ソロで雰囲気を一変させる | 27、40 |
| イントロとAメロで対照的な調を使う | 30、35、45、48 |
| 洗練されたジャズの響き | 20、21、49 |
| 明暗を違和感なく徐々に変える | 36、37 |
| 複数の調を巡る／華やかなサビの進行 | 44、47、50 |

## 8. ARR-SPECのフィールドとの対応

| フィールド | 説明 |
|---|---|
| `meta.key` | **元の調**。転調してもこの欄には元の調を記す |
| `form[].harmony` | ★ 転調したセクションのディグリーは**新しい調を基準にし**、`note` に「このセクションは Key=X」と明記する |
| `form[].harmony_letters` | アルファベット表記には新しい調がそのまま反映される |
| `form[].note` | ★ **転調の理由をここに書く**（§6の自己チェック） |
| lint #9 | 「少なくとも1セクションに調外和音**または転調の記述**を含める」。転調を記せば、この項目を満たす |

## 9. 書き終えたあとのチェック

- [ ] 「そろそろ転調するところだから」より具体的に、ここで転調する**理由**を説明できる
- [ ] 慣例でV7を使う前に、クッション・コードの**予告の強さ**を選んだ
- [ ] §3.4の統一感を保つ手法を少なくとも1つ使った
- [ ] ★ **元の調への戻り方を決めた**（戻らない場合は、そう決めたことを明記した）
- [ ] 最後のサビで半音上げる場合は、§6のチェックを済ませた
- [ ] 転調セクションのディグリーは**新しい調が基準**で、`note` にその調を記した
- [ ] 転調点でメロディが大きく跳躍する場合は、その準備がある（→ `mc-melody` §3.3）
