# 映像向けの管弦楽と hybrid のスタイルレイヤー（Cinematic）

**このリポジトリでは、このスキルで「★『映画音楽らしさ』とは何か」を具体的に扱う。**
まず「映画音楽らしさ」の意味を押さえる。

> **音量を上げ、音を厚くし、弦楽器を増やすだけでは映画音楽らしい響きは得られない。**
> **複数のレイヤーが同時にそれぞれの役割を果たし、互いの関係まで設計されている状態を指す。**

★ 反例として、弦楽器の pad をいっぱいに広げ、金管と打楽器を足せば**音量は出る**が、**映画音楽らしさ**は生まれない。
違いを生むのは §3 の3つの配置原則。

## 2. ★ 応用の可否

| 手法 | ポップスに応用できるか | 説明 |
|---|---|---|
| **単一音色のレイヤーと混合音色のレイヤーを使い分ける** | ✅ ★ **応用できる。積極的に使う** | `mc-texture-layering` §2 の奥行きの3層を管弦楽に当てはめたもの |
| **ずらしたユニゾン／リズムの異質化** | ✅ ★ **応用でき、効果も大きい** | §4。ポップスでは「同じラインを複数の楽器でわずかにずらして演奏する」形で使う |
| **非機能和声**（平行三和音、旋法の色彩） | ⚠️ **一部を応用できる** | ポップスに入れるだけで「映画らしさ」が強く出る |
| **大規模なクレッシェンド（金管を重ねる）** | ⚠️ 一部を応用できる | 特徴が強く、すぐに trailer 風になる |
| **弦楽器群を分割して書く** | ✅ 応用できる | ポップスでは通常2つか3つのパートに分ける程度 |
| **打楽器を重ねてスケール感を出す** | ⚠️ 一部を応用できる | ★ epic trailer の定番で、生成モデルが特に出しがちな手法 |
| **2本の旋律線で展開を描く（対照的なポリフォニー）** | ✅ ★ **応用できる** | → `mc-counterpoint` §2 |
| **「映像に合わせる」構成** | ❌ **応用できない** | 映像が前提。楽曲単体には映像がない（§7） |

★ **判断基準**：
> **テクスチャの考え方（レイヤー分け、ずらしたユニゾン、2本の旋律線）は応用できる。
> スケール感を出す手法（金管の積み重ね、打楽器の連打）は楽曲ではボーカルを覆ってしまうので避ける。**

★★ **このリポジトリでの注意点**：
`example-01` の `exclude` では `orchestral epic` を明示的に除外している。
**生成モデルは「感情的な」プロンプトを与えると、内容を問わず管弦楽を足す傾向がある**。
このスタイルを使わない楽曲では、明示的に除外する。

## 3. ★ 3つの配置原則

**杨立青の管弦楽法の教材では、テクスチャの配置を次の3つに分けている。**
これをこのスキルの判断の軸とする。

| 原則 | 内容 |
|---|---|
| **a. 音色のレイヤー分け** | テクスチャを構成する要素に**単一音色のレイヤーを1つずつ割り当てる**（メロディは木管、ハーモニーは弦楽器、低音はコントラバス） |
| **b. 音色の並置** | 各構成要素に**混合音色**を使う（木管 + 弦楽器を並置してメロディを作る） |
| **c. レイヤー分けと並置の併用** | ★ **前の2つを組み合わせる** |

### 3.1 原則 c の定義（原文）

> **音楽表現上の必要に応じて、テクスチャの構成要素の一部は音色のレイヤー分けの原則で組み合わせ、
> 残りは音色の並置の原則で処理する。
> こうしてテクスチャに単一音色と混合音色の両方のレイヤーができ、
> より複雑な組み合わせと多彩な対比が生まれる。** (p0191)

> **この配置法を用いる例は数多くある。**

**譜例 XIV-48（陈怡『歌墟』）**：
**メロディと低音はいずれも木管と弦楽器の音色を並置し、和声伴奏の音型は金管だけで演奏する。**

★ **この例の構造に注目**：
- メロディ = 混合（木管+弦楽器）
- 低音 = 混合（木管+弦楽器）
- ハーモニー = **単一音色**（金管）

**混合音色の2レイヤーが主役で、単一音色のレイヤーは背景に回る。**
直感とは逆で、**単一音色でも前面に出るとは限らない**。

### 3.2 3つの原則を使った判断

**確認方法**：テクスチャを「メロディ / ハーモニー / 低音 / 装飾」の4つの構成要素に分け、
**各要素に単一音色か混合音色かを記す**。

- **すべて単一音色** → 明瞭だが薄く聞こえることがある（原則 a）
- **すべて混合音色** → 厚みは出るが濁りやすく、各レイヤーを聞き分けにくい（原則 b）
- ★ **両方を使う** → 原則 c。**複数のレイヤーが同時にそれぞれの役割を果たす**

> ★★ **これが制作時に使える「映画音楽らしさ」の定義。**
> 足した音の数よりも、**各レイヤーに単一音色と混合音色のどちらを使い、なぜ選んだかを説明できること**が重要。

## 4. ★ ずらしたユニゾン

**ユニゾン主体のテクスチャは硬くなりやすい。変化をつける方法は3つ。**

### 4.1 簡略化または部分的な書き換え

古典派から初期ロマン派にかけて、自然金管楽器を使う作曲家は、音域や演奏技術の制約に対処するために
**金管パートを簡略化したり、一部を書き換えたりした**。そこから **「ずらしたユニゾン」** という特殊なユニゾンが生まれた (p0192)。

★ **もとは制約への対処だったが、のちに作曲技法となった**：
> **20世紀以降の作曲家にとって、「ずらしたユニゾン」はユニゾン主体のテクスチャに新しさをもたらす変形の一つとなった。**

### 4.2 受け渡しと交替

近現代の作曲家は**異なる金管パート間で受け渡しや交替を行い**、演奏の難度を下げた (p0192)。
複数の楽器が同じラインを引き継ぎ、その途中で音色が変わる。

**§4.1 と同じ問題に対する2つの解法**。金管のユニゾンには音域と体力の制約がある。
古典派と初期ロマン派は簡略化や書き換え（ずらしたユニゾン）で、近現代は奏者間の受け渡しで対処した。

**受け渡し方**：

- **引き継ぐ側は早めに入り、渡す側は1音多く演奏する**。両者を重ねてラインの途切れを防ぐ
- 受け渡しは**フレーズの途中**に置く。境目では2つのフレーズに聞こえ、途中なら1本のラインの音色が変わったように聞こえる
- 演奏を容易にする以外にも使える。**同じラインの途中で楽器が変わること自体が聞き取れる音色変化**なので、
  cue を書くときには「セクションはそのままで、感情が変わった」ことを示せる

### 4.3 発音点の分散：1音でもドラマを作れる

★ 劇伴に特に応用しやすい手法。同じ音高を保ちながら、**音域と音色の組み合わせを次々に変え**、
音色の変化そのものにメロディのような動きを持たせる（p0192）。シェーンベルク楽派による初期の「音色旋律」の実験から
**ユニゾンを構成する音の発音点を分散させる手法**が直接生まれた。各パートを同時に発音させず、入りの位置をいくつにも分ける。

**ベルク『沃采克』第3場（例 XIV-49、p0193）にその極端な例がある**。
5小節近く続き、大きくクレッシェンドする同度の持続音に、**17の楽器パートが順番に加わる**。
3つの要素が同時に変化する。

1. **音色**：独奏 → 楽器群 → 全奏、弱音器あり → 弱音器なし
2. **強弱**：*pppp* から *fff* まで広げる
3. **テクスチャ**：発音点が次第に密になる

それ自体には変化のない持続音が、強い劇的効果を持つ。

**杨立青『荒漠暮色』（例 XIV-50、p0194）は、より簡潔な例**。
弦楽器群は背景のコードの発音点を分散させ、各構成音の出だしを金管の並置で強調する。
打楽器のロールで強弱の起伏を彩る。テクスチャの書法自体はきわめて単純で、発音点を散らすことで重層感が出る。

**制作への応用**：

- 持続音や pad を最初からすべて鳴らさない。**入りを複数の位置に分け**、そのたびに楽器や音域を変える
- 3つの要素（音色、強弱、発音の密度）を**同時に一方向へ進める**と劇的な効果が出る。強弱だけを変えればクレッシェンドにとどまる
- この手法は §4.4 のリズムの異質化と対になる。**リズムの異質化はユニゾンの内部に動きを作り、発音点の分散はユニゾンの立ち上がりに動きを作る**

**コード主体のテクスチャでも同様**（p0193）。20世紀後半の音束によるテクスチャもリズムの異質化や発音点の分散を使っており、
後期ロマン派や印象派の「均質なテクスチャを異質化する処理」の流れをくむ。
美学上の狙いは**単一の素材の中に変化を作ること**。この一文を cue を書く際の指針にできる。

### 4.4 ★ リズムに変化をつけたユニゾン

**谢德林『海鸥』の冒頭（例 IV-85）**：
> 「**节奏异化的齐奏奏法**」（リズムに変化をつけたユニゾン奏法。「**节奏性支声复调**」、すなわちリズムによるヘテロフォニーとも呼べる）という特殊な書法を用い、
> 冒頭の「ユニゾン」で持続する長音Gに、**推進力と内的な緊張感**を与えている。

★★ **このスキルで最も応用しやすい手法**。
**同じ音、同じラインを使い、声部ごとにリズムの細部を変える。**
ユニゾンに聞こえながら、**内部には動きがある**。

**ポップス／電子音楽での応用**。同じパッドを3レイヤーで鳴らし、
レイヤーごとにアタック、ビブラートの速さ、または16分音符の刻み方を変える。
→ `mc-rhythm-section` §2.2の「楽器の一部だけをクオンタイズする」と同じ考え方を別のレベルで使っている。

## 5. 非機能和声をよく使う

**映像音楽の和声では、機能的な進行を外れることが多い。** その場合は次の手法を使う。

| 手法 | 説明 |
|---|---|
| **モードの色彩** | ドリアン、リディアン、フリジアンの特徴音（→ `mc-melody` [reference.md](../mc-melody/reference.md) §2） |
| **平行コード** | トライアドを形ごと平行移動する。★ **機能を持たせず、色彩の変化を作る** |
| **持続低音（pedal）** | 上のコードが変わっても低音は固定する。**低音との音程差で緊張感を作り、解決を保留する** |
| **コード機能より音程関係を重視** | 短3度、トライトーン離れたコード同士の関係（→ `mc-modulation` §4） |
| **クラスターや不協和音の持続** | 解決を保留し、**不協和を持続させて**緊張感を保つ |

★ **ポップスの和声との最大の違い**。
**ポップスでは「不安定 → 解決」で曲を進め、映像音楽では「解決しない」ことで緊張感を持続させることが多い。**

**適用外となる場合**。叙情的な曲のセクション、主題歌、エンディング曲では引き続き機能和声を使う。
**判断基準は、その音楽が「歌」かどうか。**

## 6. Hybrid（管弦楽＋電子音）

**このライブラリが目指す「映画のようなサウンド」はここにある。純粋な管弦楽サウンドを作るには実際のオーケストラが必要なため。**

### 6.1 レイヤーの考え方

| レイヤー | 使う音 | 理由 |
|---|---|---|
| **低域の土台** | シンセの低音 / 808 / sub | ★ 管弦楽サンプルのコントラバスでは十分に低い帯域まで出ない |
| **打楽器** | オーケストラの打楽器と電子パーカッションを**混ぜる** | hybridを最も特徴づけるレイヤー |
| **和声の土台** | 弦楽器群とパッドを**並置する**（原則 b） | 弦楽器サンプルに不足する音のつながりをパッドで補う |
| **旋律** | 単一音色（独奏楽器）か混合音色 | §3に従って決める |
| **彩り／効果音** | 加工したサンプル、reverse、riser | ★ 「映画らしさ」を作る大きな要素 |

### 6.2 ★ 差音に関する注意

**低域の土台を純粋なサイン波だけで作ると、スマートフォンでは聴こえなくなる**
（→ `mc-sound-design` §6 差音）。
普段はモニター環境が良いため、**hybridでは特にこの問題を見落としやすい**。

## 7. ★ 映像に合わせる場合と曲を書く場合の適用範囲

このスキルで扱う音楽は、**曲の形式で構成を決め、尺を自分で決め、聴感で判断する**。成果物はARR-SPEC（曲のセクションと尺の読み方は `mc-workflow` §5）。
映像で構成が決まり（spotting、タイムコード、編集点）、映像で尺が指定され、監督と編集担当が判断する場合は、**映像のために音楽を書く仕事**に当たる。

★ **このスキルの対象は「cinematicスタイルの音楽」まで。**
映像に合わせて書く音楽は、このパッケージの範囲外。

**判断基準**：
> **曲のセクションの区切りは、音楽自体で決まるか、映像で決まるか？**
> 後者 → 映像音楽の仕事で、このパッケージの範囲外。全体の尺と合わせるべき数か所の指定だけがあり、曲のセクションは曲の形式で決まる場合は、`meta.upstream.picture` に従って記述すれば、このパッケージで扱える。

## 8. 管弦楽のモックアップが不自然に聞こえる6つの原因

**サンプルライブラリで管弦楽を作るときによくある問題を、起こりやすい順に並べる。**

| # | 原因 | 解決法 |
|---|---|---|
| **1** | **CC11（エクスプレッション）が平坦** | ★ 最も多い。フレーズごとに息づかいを表すカーブを付ける（→ `mc-orchestration` reference §5.1） |
| **2** | **すべての声部が完全にそろっている** | → §4.4のリズムの差をつける方法を使うか、声部ごとにタイミングをわずかにずらす |
| **3** | **ロングトーンのパッチしか使っていない** | 奏法（運弓法）を変える。→ `mc-orchestration` reference §2.1 |
| **4** | **音域が適切でない** | 楽器の限界に近い音域や不自然に聞こえる音域に書いている。→ `mc-orchestration` reference §2.2 |
| **5** | **ユニゾンで奏者の人数感が合わない** | ソロパッチの重ね合わせ ≠ 合奏。合奏パッチで弾いた独奏ライン ≠ 独奏 |
| **6** | **全体に同じリバーブをかけている** | 楽器群ごとに音場の奥行きを変える（→ `mc-mix-intent` §4.2。**均等に並べるより奥行きに一貫性を持たせる**） |

★ **特に1つ目は重要**。
**CC7とCC11の混用**は、モックアップが不自然に聞こえる最大の原因。
CC7で音量の位置を決め、CC11で息づかいを作る。**混用すると「フェーダーを上げてもフレーズは生きてこない」。**
