## 7. 中国民族楽器法早見表

> 楽器配置の判断（4群の特性、群の組み合わせ、全編成での割り振り、処理法）は`SKILL.md` §8を参照。ここでは**数値と慣例**を確認できる。
> 各行末尾の「ページ」がその行の出典。**出典に明記された数値だけを採用し**、音域が図示のみの場合は空欄とした。2冊の記述が異なる場合は併記する。
> **オクターブ記譜と譜表の一覧は§8.3**。楽器を割り振る前に確認する。

### 7.2 撥弦・打弦楽器群

| 月琴 | 柳琴と同じ**d²、g¹、d¹、g**。3弦のものは**a²、d¹、a** | | 高音域では柳琴より音が短い | 奏法は柳琴と同じで、音色は厚く、音量は比較的大きい。京劇の主要3楽器の一つで、**第1弦の1オクターブ以内の音だけを使う** | 朱晓谷 p0097, p0098 |

| **揚琴** | **十二平均律**の配列で、変音溝で転調する。合奏では402型を多く使う | 大譜表、実音 | **4オクターブ**（駒を追加すると低音はE、高音はa³まで）。低音域は厚く、**余韻が長い**。中音域は歯切れよく明るく、主要な音域に当たる。高音域には**木を打つような雑音が混じる** | D、F、C、A、bBをよく使う（江南絲竹はD調、広東音楽はC調に調律）。**長い余韻は音色をなじませる一方、扱い方によっては音が濁る**。和音が頻繁に変わる場合は注意する。**各音を同時に鳴らす和音、アルペジオ、複数声部を演奏できる**。**撥弦・打弦楽器群では音量差を大きくつけられるほうである** | 朱晓谷 p0120, p0121；杨春林 p0079 |
| **古筝** | **21弦**。伝統的には**D調の五音音階に調弦**し、新作では**人工音階に調弦し、1曲ごとに配列を変える**ことが多い | 大譜表、実音 | **4オクターブ**。低音域は厚く、中音域は柔らかく、高音域は明るい。**最高音はd³**。弦を押して#d³、e³、さらにはf³、g³も出せる | **弦を押さず、駒を動かさなければ1つの調しか弾けない**。D→Gは駒を4つ、D→Aは5つ、**D→Cは8つ動かす必要があり、非常に難しい**。**伝統的な筝には第4音と第7音の位置がない**ため、どちらも弦を押して音を滑らせて出す | 朱晓谷 p0128, p0129, p0130, p0137；杨春林 p0089 |

**撥弦・打弦楽器群に共通する要点**：基本の発音は**点状**。**輪指、ロール、揺指はいずれも点状の音をつないで線状にするが、奏法も効果も異なる。できるだけ明記する**。指定がなければ奏者が選ぶ。琵琶、揚琴、古筝は**3つの音域にまたがって演奏できる**。複数の運指を組み合わせる書法は、撥弦楽器、特に琵琶でよく使うが、**無理につなぎ合わせず、弾きやすい運指にする**（朱晓谷 p0067, p0074, p0079, p0081）。

### 7.5 少数民族の楽器の記譜慣例

中国民族管弦楽で使う場合は、**出典の記譜法に従い**、一律に実音で書かない（朱晓谷 p0227, p0230, p0232）。

- **実音より1オクターブ下**：トン族の笛。**実音より1オクターブ上**：ラワープ、ホブス。
- **実音**：芒筒、咧咧、伽倻琴、ドンブラ、扎木聶、独弦琴、四胡、馬頭琴、馬骨胡、ギジャク、ドゥタール、奚琴。
- チャン族の笛、篳篥、口琴、吐良、蘇奈爾、根卡、チベット京胡、鉄琴、弦子は、出典では音域を図示するだけである。少数民族の打楽器は名称と使用する民族だけを挙げている。
- 同じ楽器でも高音、中音、低音などの種類がある場合がある。ここではよく使うものを挙げた。

## 8. 中国民族管弦楽の総譜の書き方

### 8.1 総譜での楽器の順序

**配列**：上から管楽器群 → 撥弦・打弦楽器群 → 打楽器群 → 擦弦楽器群（杨春林 p0302）。

**総譜テンプレート（上から順に）**（杨春林 p0475）：
- **管楽器**：梆笛、曲笛、新笛、高音笙、中音笙、低音笙、高音スオナ、中音スオナ、テナースオナ、低音スオナ
- **撥弦・打弦楽器**：柳琴、琵琶、揚琴（大譜表）、中阮、大阮、古筝（大譜表）
- **打楽器**：ティンパニ、雲鑼、編鐘、中国大鼓、排鼓、スネアドラム、シンバル、タンブリン、木魚
- **擦弦楽器**：高胡、二胡、中胡、低胡、倍低胡

群内の決まり。**擦弦楽器群では高胡を最上段に、中胡を第3段に置く**（杨春林 p0034, p0035）。

**もう一つの代表的な順序**：《豊収鑼鼓》の総譜には24段のパートがあり、「声部の配置は代表的なもので、中国で刊行される民族管弦楽の総譜で最もよく見られる」。管楽器（短い膜付き笛、長い膜付き笛、中音笙、スオナ、中音スオナ）／撥弦・打弦楽器（揚琴、琵琶、中阮、三弦、大阮）／打楽器（水鑔、頂鈸、大鑼、風鑼、十面鑼、排鼓、雲鑼、ティンパニ）／擦弦楽器（板胡、高胡、二胡、中胡、チェロ、コントラバス）（李民雄 p0151, p0156）。**どちらも打楽器を撥弦・打弦楽器と擦弦楽器の間に置く。提出先の楽団の慣例に合わせて選び、曲の途中で変えない。**

**打楽器群の段数**：西洋の総譜では通常、打楽器は4種類を超えない。**中国の打楽器群は7～8段に及ぶことがあり、楽器の種類は十数種以上にもなる**（杨春林 p0288）。

**スオナ群の3つの記譜形式**（杨春林 p0144, p0145）：① 4段で、高音／中音／テナー／低音を各1段に置く。② 3段で、高音と中音を各1段に置き、テナーと低音は同じ段にまとめる。③ 2段で、高音と中音を同じ段に、テナーと低音を同じ段にまとめる。

**この表から導かれる2つの制約**：**特別な場合を除き、梆笛の最高音は記譜上のe³を超えない**（G調の梆笛の最高音は上第3加線のE）。**♭が2つ以下の調では、倍低胡の最低音を記譜に使わない**。また、下第1加線のEより下に書かない（杨春林 p0063, p0136, p0352）。

**杨春林が明記した常用音域**（すべて記譜音）：G調の梆笛 d¹—e³、F調の梆笛 c¹—d³、小c調の梆笛 g¹—a³、D調の曲笛 A—b²、中音の36枚リードの笙 c—b²、低音の36枚リードの笙 C₁—b¹、D調の高音スオナ a¹—b³（別に、伝統的なD調の高音スオナの常用音域を17度、a¹—e³と記す）、C調の高音スオナ g¹—a³、高胡 g¹—g³（杨春林 p0034, p0136, p0137, p0140, p0141, p0142）。キー付き中音／テナースオナの常用音域は2オクターブと短3度だが、**2オクターブ以内が最も吹きやすく、音色もよい**（杨春林 p0142, p0143）。

**調を持つ楽器の選び方**：
- 笛1本で、本来の調、5度下の調、5度上の調、2度下の調、短3度上の調の5つを吹ける。合奏では主に最初の3つの運指を使う。楽団ではD、C、E、F、G、A調の笛を常備し、♭が多い場合はbE調を加える。**E調とbE調の笛は梆笛にも曲笛にも属さず、中笛と呼ぶ**（杨春林 p0135, p0137）。
- **♯が3つを超える場合や、最高音域が記譜上の嬰Fに達する場合には、A調の梆笛が必要**。♭が3つ以上の旋律を独奏するならbEまたはbA調の笛が必要（杨春林 p0137）。
- **旋律がG調またはC調で、下第2加線のGが出る場合はC調の曲笛を選ぶ**。最もよく使うD調の曲笛は使えない（杨春林 p0138）。
- **調を決めるときは二胡を先に考える**。総合編成で二胡は最も重要な旋律楽器である。調を決める前に、二胡の2本の開放弦がその調のどの音に当たるか、響きが十分に明るいか、旋律をオクターブ移す必要がないかを確認する（李民雄 p0010, p0011, p0075）。

**最もよく使う全体の音域**：7つのオクターブ帯にまたがる6オクターブ。最低音Eは倍低胡、最高音g³はG調の梆笛で決まる（杨春林 p0351）。

### 8.4 分奏と演奏記号

| 楽器群 | 規則 | 出典 |
|---|---|---|
| **管楽器** | 同種の2本が同じ旋律を奏でるときは**a²**、第1パートだけなら**I**、第2パートなら**II**と記す。別の方式では、第1パートの符幹を常に上向き、第2パートを下向きにし、斉奏時だけa²と記す。スオナの分奏は笛と同じ。**奇数本の編成でも2声部として扱い**、1本だけで奏でる場合は**solo**と記す | 杨春林 p0347, p0348 |
| **a¹の注意点** | 1本で吹く指定にa¹を使う作曲家もいるが、**これでは誰が吹くかを指定できない**。通常は第1パートが担当するものの、第2パートに吹かせたい場合に指定できず、a²と書けば2人で吹く指定と誤解される | 杨春林 p0347 |
| **笙** | もともと複数音を鳴らせるため、**通常は分奏せず、記号も付けない**。1本の独奏は**solo**、斉奏に戻るときは**tutti**と記す | 杨春林 p0348 |
| **撥弦・打弦楽器** | どの楽器も重音が弾けるため、**通常は分奏を指定しない**。楽器が1つだけなら、その楽器が両方の音を弾く。揚琴を除き、同じ楽器が2つあれば重音を分奏することが多く、分奏しない箇所には**unis.**を記す。**揚琴の重音は通常、分奏させない**。他の撥弦・打弦楽器でも、3音・4音をアルペジオにする場合や強い和音では分奏させない | 杨春林 p0348 |
| **擦弦楽器** | 高胡、二胡、中胡は**単音のみ**。1声部に2音以上を同時に書く場合は**div.が必須**で、斉奏に戻るときは**unis.**。独奏は**solo**（1人）、**soli**（2～3人）、再び斉奏するときは**tutti**。**低胡の重音にはdiv.またはnon div.を必ず記す**。低胡では3音・4音をアルペジオにする場合や強い和音では通常、分奏しない。**倍低胡は通常、重音を弾かない** | 杨春林 p0348, p0349 |
| **記号の対応** | **div.の後にはunis.、solo／soliの後にはtuttiを必ず記す。** 開始の記号だけでは不十分 | 杨春林 p0348 |

**譜面に指定する奏法と、奏者に任せる奏法**（杨春林 p0460, p0462）：
- **通常の演奏に伴う装飾**（擦弦のビブラートと運指、撥弦の単発の撥弦と輪指、管楽器の短い音とつなぐ音）は奏者に任せ、省略できる。ただし、**同じ声部では統一する**。和声の持続音では擦弦のビブラートをできるだけ控え、撥弦は単発の撥弦と輪指の使い方をそろえ、管楽器はブレスの位置を合わせる。
- **元の音に変化を加える、様式を特徴づける奏法**（擦弦のポルタメント、抹音、トリル、打音。撥弦の掃弦、推弦、拉弦、挽弦、摘弦。管楽器のタンギング、呼音、フラッタータンギング、連続する経過音、打音）は、**作曲者か編曲者が決め、譜面に必ず記す**。

#### 8.4.1 擦弦楽器群の3種類の分奏（杨春林 p0050–0054）

中国の擦弦楽器は通常、重音を奏せず、可能な場合でも並行5度までである。**分奏では楽器ごとに異なる音を奏でる**。低胡と倍低胡は例外で、重音から4音の和音まで弾ける（p0051）。分奏はdiv.／分奏と記し、元に戻すときはunis.／斉奏とする（p0051）。

| 分類 | 書き方 | 用途と制約 |
|---|---|---|
| **和声型の分奏** | 同じ楽器群を2～4つの和声声部に分ける | 和声を均等に配分し、響きのバランスを取り、色彩を豊かにする。**5声部を超える配置はあまり適さない**。音の塊が必要なら1人1音にもできる（p0050） |
| **付随型の分奏** | 同じ楽器群を2～4つの旋律声部に分ける。**下の声部は旋律と同じリズムを異なる音高で奏で、同時に和声を作る**（p0052–0053） | 時間に沿った旋律の流れと、同時に鳴る和声の両方があり、立体的な響きが得られる |
| **対比型の分奏** | 2声部のリズムを対比させる（p0053） | 出典の例では、高胡と2組の二胡が旋律を奏で、第I二胡の第2声部が旋律と対照的なラインを奏でる。中胡がそのラインに付随し、低音とともに4声の和声を作る |

擦弦楽器群は人数が多いので分奏させやすいが、**分けると群全体の音量が下がる**（p0054）。

#### 8.4.2 撥弦・打弦楽器群を分奏させる判断基準（p0118）

撥弦・打弦楽器の多くは2音以上を弾けるため、擦弦楽器群より分奏しやすい。柳琴は分奏せずに和音を弾け、琵琶は分奏せずに2音以上を弾き、2つの旋律を同時に奏でることもできる（p0118）。判断基準は6つ。
1. アルペジオ記号のある3音以上のアルペジオは**分奏しない**。
2. 掃弦を指定した箇所は**分奏しない**。
3. 楽器が各種1つずつ（琵琶1挺、中阮1挺など）の場合は**分奏しない**。
4. **同種の楽器が2つ以上あれば、合奏では一般に分奏する。重音が弾きやすくても分ける**。
5. 揚琴はできるだけ分奏せず、重音でも分けなくてよい。編曲者は演奏できない音の組み合わせを書かない。
6. 古筝は五音音階に含まれない音をできるだけ避ける。旋律では速くなければ使えるが、**和音では五音音階外の音を極力使わない**。

#### 8.4.3 和声を提示する5方式と単独・混合音色群（p0121–0124、p0246–0252）

擦弦楽器群と撥弦・打弦楽器群の和声提示法は共通で、**同時発音型、分散型、リズム型、付随型、アルペジオ型**がある（p0121–0124）。第9章では同時発音型、リズム型、分散型、付随型、混合型として整理している（p0246）。七の和音では、**低音部に置いた構成音を他の声部に重ねない**（p0121）。
擦弦楽器群全体と撥弦・打弦楽器群全体は、それぞれ**単独音色群**である。両者を合わせると**混合音色群**になる（p0246）。出典の8通りの組み合わせは、そのままひな型として使える（p0247–0252）。

| 旋律 | 和声 | 低音 |
|---|---|---|
| 混合音色群全体 | 同時発音型 | |
| 擦弦の単独音色群 | 撥弦・打弦の単独音色群がリズム型を担当。チェロとコントラバスはpizz.で撥弦のリズム感を模倣 | |
| 撥弦・打弦の単独音色群 | 揚琴の2声部と中阮が付随型、擦弦楽器群の一部がリズム型。チェロはarcoとpizz.を交替 | |
| 混合音色群の高音域を担う楽器 | 各群の中音域を担う楽器がリズム型を奏でる | 各群の低音域を担う楽器 |
| 混合音色群が付随型で旋律を提示 | 中阮と大阮は同時発音型（混合型） | |
| 混合音色群がリズム型の同時発音で提示。高胡と揚琴、二胡と琵琶、中胡と中阮はそれぞれ**リズムが完全に同じ** | | |
| 擦弦の単独音色群（管楽器も加える） | 撥弦・打弦楽器群が分散型とリズム型を混ぜた音型を奏でる | |
| 高胡・二胡・琵琶 | 揚琴と柳琴が分散和音を奏でる | |

**旋律と和声を別々の群に割り振る**のが原則。同じ群が旋律と和声の両方を提示するときは、付随型かリズム型の同時発音を使い、2群の楽器を個別に対応させる。

### 8.5 総譜を書く前に：李民雄の作業順序と楽器配置の3つの分担

**① 主旋律を分析 → ② 低音声部を書く → ③ 伴奏のテクスチュアを選ぶ → ④ 縮約譜を書く → ⑤ 楽器を割り振る**（李民雄 p0007, p0012, p0036, p0074）。**縮約譜は旋律、低音、伴奏からなり、総譜の楽器配置の下書きとなる**。楽器の割り振りを進めながら、縮約譜に戻って音域や和音配置を変えてよい（李民雄 p0084, p0085）。

- **調を決める**（§8.3も参照）。**主音の高さ**と**旋法**を区別する。譜面上の1=Cは「1」の高さだけを指定し、旋法までは指定しない（李民雄 p0010）。
- **低音声部**の7つの書法。リズム型、旋律型、分散和音型、ポリフォニー型、固定音（固定音型）、補強型、主旋律を奏でる型。**低音と旋律は斜行と反行を多く用い、同方向の進行は控える**。**速い箇所では和声を頻繁に切り替えない**。笙、琵琶、阮など、複数音を奏でることが多い楽器では演奏が難しくなる（李民雄 p0017, p0028, p0033）。
- **伴奏のテクスチュア**は10種類。斉奏、和音型、持続音で旋律を支える型、リズム音型、分散和音型、ヘテロフォニー、対比的ポリフォニー、模倣的ポリフォニー、対位法的な伴奏、混合型（李民雄 p0036）。**旋律と伴奏の音域を分けると旋律が明瞭に聞こえる**（全奏の多オクターブの重ね合わせは例外）。**密集配置と混合配置をよく使う**。**中音域の伴奏声部は滑らかに動かす**。内声が大きく跳躍すると旋律の印象が薄れる（李民雄 p0078, p0081, p0083）。
- **和声の楽器配置 vs ポリフォニーの楽器配置では、楽器の選び方が逆になる**。和声では**バランスと融合**を求め、**同じ群の楽器が最も適する**。ポリフォニーでは**各声部の個性**を保つため、**異なる種類の楽器**または**異なる音域**に分ける。**和音の第3音は通常、省略できない**。ただし五音音階の旋律では、第3音が音階外の「4、7」に当たることが多く、際立ちやすいので、**第3音を担う声部を強くしすぎない**。管楽器群で**和声を担うのは笙だけ**（李民雄 p0101, p0102, p0105, p0106）。
- **打楽器の5つの編配法**（李民雄 p0109, p0114, p0120, p0123, p0128）：**補強型**（旋律と句の区切りを完全にそろえ、一方のリズムが疎なところでもう一方のリズムを密にする）／**対比型**（短い鑼鼓の音型を繰り返し、旋律の句の区切りから明確にずらす。旋律と同等の重みを持つことが多い）／**挿入型**（旋律を分断する。民間では「拆頭」と呼び、展開部やクライマックスで使う。**挿入が長すぎると展開の効果が弱まる**）／**接続型**（旋律が終わる前に鑼鼓が入る）／**装飾型**（開始、転換、締めくくりにだけ短く入る）。**打楽器の全奏は響きが大きく、旋律声部を補強しないと旋律が埋もれることがある**（李民雄 p0155）。
