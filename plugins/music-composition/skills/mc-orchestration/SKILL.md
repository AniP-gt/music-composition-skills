# 管弦楽法（Orchestration）

**このskillでは「どの楽器でこのラインを奏でるか」「複数の楽器を重ねるとどんな音色になるか」を扱う。**

管弦楽法では、**楽器の選択そのものが音楽を変える**。
同じ和音でも、弦楽器で持続させる場合と木管楽器で短く切って奏でる場合では、効果が異なる。

> **関連skillとの分担**：このskillでは**使う楽器**を決める。
> `mc-texture-layering`では**各楽器が担う周波数帯域と、重なった帯域の譲り方**を決める。
> `mc-arrangement-arch`では**各楽器が入る時点と抜ける時点**を決める。
> 3つを併用することは多いが、帯域配分や楽器の出入りの表はそれぞれのskillで扱う。

### 1.1 ★ テクスチュアの種類を見極め、融合させるか分けるかを決める

以降の§2から§6までの手法は、ここでの判断によって使い方が決まる（杨立青 p0240–0241）。

| テクスチュアの種類 | 特徴 | オーケストレーションの原則 |
|---|---|---|
| **同質** | 要素は1種類で、各声部の性質や提示の仕方（特にリズムの形）が共通する。斉奏型、和音をまとまりとして奏する型、分奏型 | **合唱型のオーケストレーション**：バランスをとり、できるだけ融合させて統一感を出す |
| **異質** | 異なる性質の要素が2種類以上ある。ポリフォニー、旋律と伴奏、点描など | **音色の分離**：音色、音域、強弱で要素を分け、各要素の内部では同時に鳴る音色の相性を保つ |

同質のテクスチュアでは3点を確認する（p0241）。選んだ音色がその箇所の表現意図に合うか、楽器の音域・強弱・奏法を生かせる書法か、複数の音色を重ねて一体に聞こえるか。
異質なテクスチュアでは、音色と音域で各要素を分け、主従を明確にし、前景・中景・遠景のある立体的な構造を作る（p0241）。
目指すのは、マーラーの言う「最大限の明瞭さ」、シェーンベルクの言う「譜面に書かれたものはすべて聞こえるべきだ」という状態である（p0241）。

★ **旋律と伴奏からなるテクスチュアの基本原則は、あらゆる手段を使って層ごとの音色を分けること**。
ポピュラー音楽の編曲はほとんどが異質なテクスチュアなので、このskillの§3で扱う「混合」は**一つの要素の内部**にだけ用い、**異なる要素の音色は混ぜない**。
分離の6つの手法は`mc-texture-layering` §3.4を参照。

## 2. 単独音色と混合音色

楽器を割り振るときはまず、**以下のどちらの効果を求めるか**を決める。

| | 単独音色 | 混合音色 |
|---|---|---|
| 得られるもの | その楽器の**個性** | **構成楽器を聞き分けられない新しい音色** |
| 代償 | 音量と厚みに限界がある | 個々の楽器の個性が薄れる |
| 適した用途 | 楽器を聞き分けてほしいライン（主奏、solo、耳に残る要素） | 下支え、厚みや聞き慣れない響きが必要な箇所 |

**判断基準**：「これはオーボエだ」と聴き手が分かるようにしたければ、単独音色を使う。
「温かみと厚みのある響き」と感じさせたいだけなら、混合音色を使う。

**境界が曖昧になる場合**：ポピュラー音楽や電子音楽では、シンセサイザーの音色自体が混合の結果であることも多い。
この場合も、**音色の構成要素を聞き分けられるようにするか**は判断できる。

## 3. 混合の3つの形態

### 3.1 同度での混合（unison）

異なる楽器が同じ音高を奏でるときは**融合度が最も高く**、楽器を聞き分けにくい。実際に融合するかは楽器の選択次第で、同じ群の音色が似た2楽器を同度で重ねるのが最も自然である（例 VII-11、イングリッシュホルン＋ファゴット、杨立青 中巻 p0032）。異なる群を重ねるなら、ファゴット＋チェロ、クラリネット／イングリッシュホルン＋ヴィオラ、フルート／オーボエ＋ヴァイオリンといった定番の組み合わせ（p0033）のように、音色の**「接点」**を探す。接点がなければなじみにくい。重ねすぎると「中和」が起き（§3.4）、奏法が合わなくても音色が分離する（§3.5）。

### 3.2 オクターブの重ね合わせ（coupled / 結合）

★ **上に置く楽器は、総譜の順序よりも、その音域での音の強さで決める**（逆順の組み合わせ、杨立青 中巻 p0046）。
クラリネットの中音域はやや弱いが、c²以上の「トランペット音域」は豊かで明るく、強い音が出る。オーボエの中低音域は、同じ音域のクラリネットよりはるかに豊かに響く。
そこでクラリネットを1オクターブ上に置き、下からオーボエで支えると、通常の順序で配置するより明瞭で力強くなる。
リムスキー＝コルサコフはこの配置を「音域の混在」として批判したが、著者は同意していない。ドビュッシーには音色のためだけに順序を逆にした例もある。
**手順**：オクターブで重ねるときは、まず2つの音域で各楽器がどの程度強く響くかを確認し、強みが出る音域に配置する。

異なる楽器をオクターブ隔てて配置する。理論上は**「音色の結合（coupled）」または「重ね合わせ」**と呼ぶ。
**融合度は同度での混合より低い** (p0039)。

> **上のオクターブの楽器は、下の楽器の倍音を補強することが多い** (p0039)。

オクターブを重ねる際に最も重要なのは、上の楽器を独立した旋律として扱わず、
**下の楽器の倍音を際立たせる**ことである。上の音色は、下の楽器をどのように明るく響かせたいかで選ぶ。

**例 VII-17 ロッシーニ《セミラーミデ》**：木管群のさまざまなオクターブの重ね合わせと単独音色が交替する。
色彩の変化がきわめて豊かで、**ほぼすべての「結合」で、構成楽器の音色を明瞭に聞き分けられる** (p0039)。
→ オクターブを重ねたときの融合しきらない響きは、効果として使える。

### 3.3 異なるオクターブ帯の重ね合わせ —— 音色を添える

弦楽器と木管楽器を**別々のオクターブ帯に置き**、同度でまったく重ねない場合 (p0039–0040)：

- 通常、弦楽器の音色が優勢になる
- **別のオクターブ帯にある木管はたいてい完全には埋もれず、色彩や明るさを添える**
- **古典派では典型的な書法**（例 VII-18 ハイドン《交響曲第94番》IV、G長調）

**用途**：「何を加えたかは分からないが、全体が明るくなった」という効果を出したいときに使う。

### 3.4 ★ 中和現象：加えるほど個性が薄れる

直感に反し、特に見落としやすい現象 (p0037)：

> 音域の条件が同等なら、**通常は奏者数の多い楽器が響き全体を大きく左右する**。
> 弦楽器と木管を組み合わせると、**異なる木管の音色同士が中和して、それぞれの個性が薄れ、
> 第2ヴァイオリンなどの弦楽器の音色がひときわ鮮明に浮かび上がる**ことがある。

**例 VII-15 マーラー《交響曲第1番》IV（変B長調）**：
10本の木管と第2ヴァイオリンを同度で重ねると、**木管同士の音色が打ち消し合い、第2ヴァイオリンの鮮明な音色が引き立つ** (p0037)。

**実際の聞こえ方と使い方**：
- 10本の木管を加えても、厚みのある木管の音色を得られるとは限らない。この例では木管の個性が薄れて背景に回り、弦楽器が際立つ
- **ある楽器を際立たせたい場合は、その周囲に互いの音色を中和する楽器を重ねる**方法がある
- **予想外に目立つ声部があれば、その周囲の楽器の音色が互いに中和していないか確認する**

**確認**：重ねた後に新しい音色として聞こえるか、個性が薄れた背景から一つの音色が浮き出ているかを聴き比べる。

### 3.5 奏法が融合度を決める

> **異なる楽器群の音色を混ぜるときは、各楽器の奏法が響きの融合度に与える影響も考える** (p0038)。

**例 VII-16 シェーンベルク《管弦楽のための変奏曲》**（Presto ♩=120）(p0038)：
- 第441小節：フルートと同じ音をハープとチェレスタが奏でる。**フルートが音を短く切るため、発音後の時間変化が装飾を担う楽器に近く、比較的よくなじむ**
- 第448小節：クラリネットとハープの響きは、**奏法（＝音の時間変化）の違いによってある程度分離する**

**判断基準**：音色の明暗に加え、**音の時間変化**（立ち上がりと減衰の形）が近いかで融合の度合いが決まる。
弦をはじくハープと短く切って奏でるフルートはなじむが、音を伸ばすクラリネットとはなじみにくい。

**MIDI/シンセサイザーでも同じ原理が働き**、違いはさらに明瞭に出る。§7を参照。

### 3.6 同じラインの音色を時間とともに変える方法（杨立青 中巻 p0059–0063、下巻 p0327–0342）

§3.1から§3.5までは、同時に鳴る音の混合を扱った。ここでは**時間軸**に沿って、同じラインの音色をどう変え、そのつなぎ目をどう処理するかを扱う。

**4つの方法**（中巻 p0059–0063）：

| 方法 | 処理 | 要点 |
|---|---|---|
| **音色の対置** | 異なる音色を直接対置して交替させる | **交替の位置を楽句や動機の構造上の区切りに合わせる**（p0059）。ベートーヴェン《英雄》では、3音の動機をオーボエ → クラリネット → フルート → ヴァイオリンと受け渡して音色変化のリズムを作り、最後に全奏へ移る（p0060–0061）。点描的な書法にもこの原則が当てはまる |
| **レイヤーの段階的な追加と削減** | 楽器を1つずつ加えるか減らす | 音色の複雑さに加え、強弱やラインの音域幅も次第に変わる（p0061）。削減は「繭の層を一枚ずつ剥がし、クラリネット本来の音色を現す」ようなもの（p0062） |
| **音色の微細な入れ替え** | ラインの基調を保ちながら、音色が似ていてわずかに異なる楽器を入れ替えて色彩を添える | 音色の成分や質感が繰り返し微妙に変わる。ロマン派以降によく見られる（p0062） |
| **音色の移行** | **橋渡しとなる音色**を介してラインをAからBへ移す | 最も簡単なのは、AとBを短時間重ね、その響きを橋渡しにする方法（p0063） |

**ポピュラー音楽での例**：padを替える際に橋渡しとなる音色を重ねてから元の音色を外すのが音色の移行。サビのたびに楽器を一つ足すのが段階的な追加。同じriffを4小節ごとに別の楽器で奏でるのが対置である。

**受け渡しの2つの方法**（下巻 p0336）：前の部分の終わりと次の部分の頭を重ねる**重複型**と、重ねずに切り替える**切替型**がある。重複型はなだらかに移行させ、切替型は軽やかに流したい場合や、重複によってアクセントが生じるのを避けたい場合に使う。
同じ楽句内で併用できる。細かい単位に分けた速い経過句では、すべて重複型でつなぐ（p0339）。

**つなぎ目を隠す方法**（p0339–0342）：1音ではなく2音を重ねる。つなぎ目を拍節上のアクセントからずらす。楽器を交替しない声部を重ね、つなぎ目を覆う。いずれも構造上の各単位を一続きに聞かせるための方法である。

**呼応とエコー**（p0327–0331）：呼応は同じ素材または似た素材の動機の間で起きる。**音色・音域・音域幅の少なくとも一つに対比があり、強弱と奏法はおおむね共通する**。
エコーは呼応の一種。**強い音の後に弱い音を置き、距離が感じられるほど強弱の差をつける**。元の音とエコーには**同系統の音色**を使うことが多い。
★ 最も手軽なのが**人工的な残響**。弱い音色の持続音を強い楽句の末尾に重ね、sfpのように急に弱めることが多い（p0330）。
エコーを担う楽器を1拍前からpで重ね、そのまま伸ばすと、急な変化が自然に聞こえる（p0331）。

### 3.7 重ね合わせの3分類と、変形を伴う重ね合わせの5類型（杨立青 中巻 p0150–0155）

§3.1から§3.3までは**同じラインをそのまま重ねる**方法を扱った。実際には、異なるラインを重ねる方法もよく使う。

| 分類 | 処理 |
|---|---|
| 完全な重ね合わせ | 異なる音色を完全に重ね、混合音色を作る |
| **部分的な重ね合わせ** | 声部の中で特徴の強い部分だけを、場合によってはごく短い箇所だけを、別の楽器で重ねて強調する |
| **変形を伴う重ね合わせ** | 重ねる声部の構成にさまざまな程度の違いをつける |

変形を伴う重ね合わせの5類型（p0150–0151）：**音の時間変化を変える変形**（音高とリズムを保ち、発音後の時間変化が全く異なる奏法に切り替える。例としてレガートにスタッカートを重ねる）、**簡略化した変形**、装飾的な変形、リズムの変形、和声的な変形。

**簡略化の方法**（p0151）：元の声部からいくつかの骨格音を抜き出し、主ラインに終始沿いながらも一定の独立性を持つ「骨格声部」を作る。
音の起伏が大きい、または形が複雑なテクスチュアの輪郭が明瞭になる。次の2点を守る。
- **変形した声部と骨格には対照的な音色を使う**。同系統の音色なら、奏法と音域を分ける（p0151、p0154）
- ★ **簡略化した声部の強弱記号は1段階弱くする**。強いままだと全体がこもる（p0155）

ポピュラー音楽の編曲で「padを分散和音に沿わせる」のは簡略化に当たる。padをアルペジオの層より1段階弱くする指定は、仕様書にほとんど書かれない。

### 3.8 2つの楽器群の和声層を組み合わせる方法（杨立青 中巻 p0074–0079）

| 方式 | 処理 | 結果 |
|---|---|---|
| **並置** | 両群がそれぞれ完全な和声を奏で、和声層全体を重ねる | 最も豊かで緻密になり、よく響く（p0074） |
| **部分的な重複** | A群が完全な和声を奏で、B群は骨格となる声部だけを重ねる | **A群の音色が優勢になる**（p0075）。弦楽器群が完全な和声を担い、木管とホルンが部分的に重なる例も多い |
| **層別の組み合わせ** | 各群が和声の一部を分担し、全体の和声を作る。各群の音域は接していなくても、一部が重なっていてもよい | 最も均等に響きにくく、少しのずれでバランスが崩れるが、**うまく処理すれば最も独特な色彩が出る**（p0078） |

ポピュラー音楽で「弦楽器群＋pad＋金管」の3層を重ねるときも、この3方式を使う。仕様書には方式を明記する。特に層別で組み合わせるときは、抜けがないか1音ずつ確認する。

### 3.9 5つの強調法：聴かせたい箇所に何を重ねるか（杨立青 下巻 p0275–0288）

| 方法 | 処理 |
|---|---|
| **リズムの強調** | 基本のリズムを担う層の**拍節上のアクセントに、別の音色を周期的に重ねる**（p0275）。★ 強調する位置の周期を拍節上のアクセントの周期から**ずらす**と、音楽の流れから生じるアクセントと拍節上のアクセントがずれ、拍節感が浮いたように聞こえてリズムに変化が生まれる（p0277） |
| **音色による強調** | ある音色を基調とする箇所で、**最も特徴的な部分だけに異なる音色を重ねる**（p0279）。デュカス《魔法使いの弟子》では、弱音器付きの弦楽器で基調を作り、骨格音にピッコロとフルートの軽快なタンギングを重ね、ハープと独奏弦楽器のハーモニクスで動機の輪郭を描く |
| **強弱による強調** | 聴感上の強調点（旋律の最高音、骨格音）が物理的に最も大きく響くとは限らないため、別の楽器の音色を重ねて強調する（p0283–0284、詳しくは`mc-sound-design` §3.6） |
| **構造の強調** | 楽句や動機の**構造上、最も特徴的な部分**に異なる音色を重ね、輪郭を明瞭にする（p0286） |
| **音の立ち上がりの強調** | 立ち上がりが速い音色を重ね、立ち上がりが遅い層のアタックを変える（p0287、`mc-sound-design` §3.6） |

**使い方**：仕様書に各区間で何を主役にするかを書き、**5つの方法のどれで主役を際立たせるか**を追記する。どれも使わなければ、§4で扱う、強弱を上げるだけの最も効果の弱い方法に頼ることになる。

★ リズムの強調を徹底した例（p0276）：弦楽器層にある不規則なアクセントをホルン群のsfで補強すると、2/4、2/8、6/8、3/8が交替するように聞こえ、強調そのものが「リズムの主題」になる。

## 4. バランス：奏者数と音域

**基本原則** (p0037)：**音域の条件が同等なら、奏者数の多い楽器が響き全体を大きく左右する。**

数えるのは、実際の編成における奏者数である。

| | 標準的な交響楽団 |
|---|---|
| 第1ヴァイオリン | 約16人 |
| 第2ヴァイオリン | 約14人 |

> このため**奏者一人で弾くのが難しい重音の箇所も、オーケストラで分奏（divisi）すればかなり弾きやすくなる** (p0067)。
> —— 弦楽器群なら、演奏困難な重音を2つの声部に分けられる。

**確認**：書いたパートのバランスを、ラインの本数と実際に弾く人数のどちらで見積もったか。

### 4.1 ★ 奏者数より先に、音域での強さをそろえる

奏者数を考える前に、**各楽器を同程度の強さで響く音域に置く**。すべて強く響く音域か、すべて弱く響く音域に置くとバランスを取りやすい（杨立青 中巻 p0021）。

| 組み合わせ | 結果 |
|---|---|
| フルート＋ファゴット | 音域での強さがそろわず、**強奏でも弱奏でもファゴットが突出する** |
| オーボエ＋クラリネット | 強奏ならおおむね釣り合うが、弱奏ではオーボエが強すぎる |
| オーボエ＋ファゴット | 音域での強さがおおむねそろい、強奏でも弱奏でも均等になじむ |

和声を重ねるときは、**倍音が豊かで音色の個性が強い楽器は、音量が同じでも目立つ**（p0021）。
「バランスは相対的なもの」であり、大半のテクスチュアで完全に釣り合わせる必要はない（p0021）。

### 4.2 時間軸でのバランス：次の楽器が前の楽器の響きを引き継ぐ

同時に鳴る音に加え、**ラインを楽器間で受け渡す際に、聞こえる音量を保てるか**も確認する（p0021–0023）。
出典の推計では、第1ヴァイオリンの声部が約83.5 dB、独奏フルートが約72 dB、a2でも75 dBにとどまる（p0022）。
低音域のフルートではファゴットの勢い（80 dB以上）を引き継げないため、オーボエかクラリネットに受け渡す。
オーボエから低い音域に受け渡すときも、フルートかクラリネットに替えないと、つなぎ目で聞こえる音量に段差ができる（p0023）。
**手順**：受け渡しを書く前に、つなぎ目の音域で両楽器の音量を比べ、引き継ぐ楽器が前の楽器より1段階弱くなるのを避ける。

## 5. 特定の楽器群が聞こえる3つの条件

木管のパートを書いても聞こえないのは、管弦楽法で最もよくある失敗である。シベリウス《交響曲第2番》Iには成功例がある (p0040)。
**全体の響きの中から木管の音色が明瞭に聞こえる**。以下の3条件がすべてそろっている。

1. **木管の本数を増やしている**
2. **オクターブの重ね合わせと同度での混合を併用している**
3. **最上層のフルートが力強く響く音域にあり、音の立ち上がりが非常に明瞭で、輝きがある**

**最も見落としやすいのは第3の条件**。同じ楽器でも音域を変えると、合奏の中での通り方が大きく異なる。§6を参照。

## 6. 音域ごとの特性

**同じ楽器でも、音域によって別の楽器のように響く。** ヴァイオリンの4本の弦を例にとる (p0065–0067)。

| 弦 | 特性 |
|---|---|
| **G** | 4本のうち最も太く、音は最も丸く深い。**高いポジションに移ると響きの緊張感が強くなる**。弦の振動部分が次第に短くなるため |
| **D** | Adlerは、4本のうち**最も特徴に乏しい**かもしれないが、温かく叙情的で、高いポジションへ移るとまろやかさが増すとする。★ 杨立青（p0129）の見解は異なり、4本のうち**最も甘美で心に響く**とする。弱奏では柔らかく明るく、カゼッラは「気品と詩情がある」と評した。D弦を指定する場合は通常、A弦より芯があり豊かな音色を求めている。本資料の方針に従い、両者の見解を併記する |
| **A** | **第1ポジションで弦の特性が最もよく出る**。高いポジションでは輝きと力強さがやや失われ、柔らかく叙情的な音に向く。高音域で輝きが欲しい場合はE弦に替える |
| **E** | **最も華やかな音色**で、音域の上端はきわめて明るい。**柔らかな強弱で奏でると、静かで神秘的な響きも得られる** |

**使用する弦の指定**：`sul E` / `sul A` / `sul D` / `sul G` (p0065)。

**使用する弦やポジションを指定する場合としない場合** (p0065)：

> 同じ音を複数の位置で出せる場合、**奏者に特定の位置を指定しても、通常は意味がない**。
> 作曲者がその楽器の運指に十分通じていれば、求める音色を得るために総譜とパート譜に具体的な運指を書ける。
> それ以外の場合は、**奏者自身に運指を任せるのがよい**。

**開放弦の特性** (p0065)：
- 開放弦は指で押さえないため、**より自由に振動する**
- 速い箇所では、開放弦と指で押さえた音を混ぜても違和感はない
- **表情豊かな遅い箇所では、通常はすべての音の音色をそろえる。そろえないと開放弦の音だけが際立つ**
- 例：ブラームス《交響曲第1番》IV、第61–75小節はすべてG弦で奏でる。「G弦の開放弦が生み出す振動と響きに耳を傾ける」

**他の楽器への応用**：どの楽器にも強く響く音域、弱く響く音域、音色が切り替わる境目がある。
**譜面を書く前に、対象の音高でその楽器がどう響くかを確認する**。楽器別の音域表はreference.mdを参照。

## 7. MIDIオーケストレーション：実演との共通点と相違点

**共通点**：§2–§6はすべて当てはまる。音色の中和、奏法による融合度の違い、音域ごとの特性は、
実際の楽器を録音したサンプル音源でも同様に現れる。

**4つの相違点**：

| | |
|---|---|
| **① 奏者による調整がない** | 奏者は演奏中に音程とバランスを調整するが、サンプルは自動調整しない。そのためオーケストレーションの不均衡が、MIDIでは**そのまま表れる** |
| **② 奏法の切り替えを明示する** | 実演ではスタッカート、レガート、ピッツィカートを一言で指定できるが、MIDIではarticulationまたは音色レイヤーを切り替える。**§3.5の融合度の違いは自分で作る** |
| **③ 分奏に工夫が要る** | 実演ではdivisiで簡単に分けられるが、MIDIでは16人のヴァイオリンが一つのサンプルになっている。divisiの厚みを出すには、複数のインスタンスにわずかな差をつける |
| **④ 開放弦、ポジション、弦の切り替えが反映されない** | サンプル音源では通常、§6の弦ごとの特性を区別しない。**sul Gの緊張感を出したければ、音色レイヤーの選択か独奏サンプルで対応する** |

**実践での判断基準**：MIDIが不自然に聞こえる場合は、音色の質よりも、
**実演で奏者が担う判断を省いたこと**が原因である場合が多い。強弱の起伏、奏法の変化、音域の選択を確認する。

> MIDIオーケストレーションの詳しい手法は[reference.md](reference.md) §5を参照。§5.1はオーケストレーションで使うCC、§5.3はサンプルを生き生きと聞かせるチェックリスト（レイヤー構成とCC#1によるクロスフェード、キースイッチを記録する2つの方法、重ねた音色のドライ／ウェット比、各群に生楽器を一つ重ねる方法、CC#7/CC#11のエンベロープ、ベロシティによるアタックとフィルターの制御、クオンタイズの基準点、楽器に伴う自然なノイズ）。

## 8. 中国民族管弦楽：西洋の管弦楽との違いと楽器配置の原則

**§2–§6の原理は中国民族管弦楽にも当てはまる。楽器が異なるため、まず以下の4点を考慮する。**
本節で書名を添えていないページ番号は、いずれも杨春林《中国民族管弦乐配器法教程》を指す。朱晓谷と李民雄の出典は個別に示す。

| 違い | 楽器配置への影響 |
|---|---|
| 管楽器／撥弦・打弦楽器／擦弦楽器／打楽器の4群に分かれる。西洋のオーケストラには独立した撥弦・打弦楽器群がない (p0012–0013) | 点状に発音する楽器が一群加わるため、点状の音と線状の音をどう融合させるかが中心課題となる |
| 胡琴類は**音域が高くなるほど音量と力強さが落ちる**（皮膜が高周波の振動に追随できない）(p0038) | 西洋楽器の「高いほど明るい」という感覚は当てはまらない。クライマックスを二胡の高音に頼らない |
| 梆笛、曲笛、高音スオナは**実音より1オクターブ低く記譜**し、倍低胡は1オクターブ高く記譜する (p0352) | 譜面上は低く見える笛の和声も、実際にはかなり高い (p0162)。楽器の配置は**実音**で考える |
| 常用する全体の音域は7つのオクターブ帯にまたがる6オクターブ。最低のE（倍低胡）からg³（G調の梆笛）まで (p0351) | 交響楽団より狭い。ヴァイオリン属が担う低音域は中国民族楽器の擦弦だけでは対応できず、撥弦・打弦楽器で補う (p0442) |

**用語**：同じ旋律を同度で提示するのを**単一オクターブ帯**、1オクターブ隔てるのを**2オクターブ帯**、2オクターブ隔てるのを**3オクターブ帯**と呼ぶ。いくつのオクターブ帯で重ねても**単一声部**であり、並行オクターブとは見なさない (p0045)。

### 8.1 4群の特性と音域

| 楽器群 | 特性 | 音域の要点 | 確認事項 |
|---|---|---|---|
| **擦弦楽器** | 楽団の土台となる声部で、線状の音を作り、最も歌わせやすい (p0026, p0072)。高胡／二胡／中胡は皮膜で、チェロ／コントラバスは響板で振動を伝えるため、同度で重ねても音色はそろわない (p0037) | 二胡は加線のいらないト音譜表内が最良の音域 (p0040)。高胡は高音を担い、低音域ではやや鼻にかかった音になる (p0034)。中胡は和声を担い、高音域では厚みが失われる (p0041)。中胡の最低音はGまでなので、群全体では**テノール声部が不足する** (p0057, p0061) | 4声の配分は高胡＝高音、二胡＝中音、中胡＝テノール、低胡と倍低胡＝低音。中胡の層が響きの中核となる (p0056–0057)。高胡・二胡・中胡は**原則として単音のみ**（例外は並行5度まで）(p0051)。複数音にはdiv.が必要。分奏すると群全体の音量が落ちるため、弱奏や和声の色彩に向き、強奏では分けない (p0054) |
| **撥弦・打弦楽器** | 点状の音を出す (p0275)。一般に擦弦楽器より音域が広く、「擦弦楽器は音色、撥弦・打弦楽器は音域で優位に立つ」 (p0224)。音色は、締まって直線的な柳琴＋揚琴＋中阮と、ゆるやかで歯切れのよい琵琶＋古筝に分かれる (p0094) | 柳琴は高音、琵琶は中音、揚琴は高中音、中阮は中音、大阮は低音を担う (p0074–0088)。群全体の和声では、大阮が低音、中阮と揚琴が中音、琵琶・古筝・柳琴が高音を担う (p0119)。揚琴はどの音域でもよく響き、和声に最も適する (p0120) | 同じ旋律では**単発の撥弦と輪指の使い方をそろえる**。混在するとまとまらない (p0092)。同音反復では「単発の撥弦と輪指を交互に」用いる (p0093)。古筝は五音音階に調弦する。音階外の音は和音ではできるだけ避け、旋律では速くなければ使える (p0118)。琵琶と揚琴で同じオクターブ帯の和音の第3音を重複させると効果が悪い (p0120) |
| **管楽器** | 楽団の音色の幅と音の勢いを担い、クライマックスではほぼ常に使われる (p0133)。笙は複数音を奏でられ、吹いても吸っても発音するため、合奏の音色をなじませる (p0132–0133)。スオナは他の楽器と融合しにくく (p0281)、1本の音圧レベルが二胡16挺に相当する (p0415) | 梆笛は中音域が最良で、低音域は芯が薄く、最高の2音は鋭い (p0136)。曲笛はどの音域でもよく響く (p0150)。新笛は同じ調の梆笛より1オクターブ低く、膜がなく、落ち着いた音色 (p0138, p0150)。高音笙はd¹—d³が最も美しい (p0150)。低音笙の旋律はg¹を超えない (p0151)。高音スオナは中低音域の響きがよく、**音域を下げたほうが効果的** (p0152)。中音スオナは音色の魅力に乏しく、主に他の声部の重複や和声に使う (p0143) | 笛の群には低音楽器がない。色彩を添える和声に限り、厚く書かない (p0162, p0267)。スオナの和声には細心の注意が要る。リードが不安定で、楽器の中低音域も合奏ではすでに高音域に当たる (p0162)。高音スオナの和声は記譜上#c²/d²を超えない (p0165)。竹笛は1本につき1つの調なので、総譜に使用する笛の調と持ち替えの箇所を明記する (朱晓谷 p0014) |
| **打楽器** | 固定の編成はなく、曲の必要に応じて選ぶ (p0192)。強弱の幅は他群よりはるかに広い (p0288)。中国の打楽器は**強く明瞭に**、西洋の打楽器は**弱く控えめに**使う。中国と西洋の楽器数の比は約2:1。奏者は楽団の10分の1以下 (p0220) | ティンパニの使用頻度が最も高く、強調や音の勢いを担う (p0192)。雲鑼は中音域が最も美しい (p0206)。木魚は軽快なリズムならほぼ何にでも使える (p0211)。スネアドラムとマリンバは中国民族管弦楽の様式に合いにくいため、慎重に使う (p0178, p0217) | 4つの原則。必要な箇所に限る。複数を併用する場合は効果の相殺を防ぐ。主役を引き立てる役割に徹する。持ち替えを積極的に検討する (p0289)。音高が定まらない打楽器は擦弦楽器と混合音色を作らず、打音がそのまま聞こえる (p0292) |

### 8.2 楽器群の組み合わせと相性

**同度で主になる音色**：擦弦と撥弦・打弦、または擦弦と管楽器を同度で重ねると、どちらも**擦弦の音色が優勢になる** (p0256, p0281)。例外はスオナで、高胡のセクションに対し、1本でも明瞭に聞こえる (p0281)。

| 組み合わせ | 相性のよい例 | 相性の悪い例と条件 |
|---|---|---|
| 擦弦＋撥弦・打弦 | 二胡＋琵琶、中胡＋中阮、低胡＋大阮が最も実用的で、使用頻度も高い (p0228, p0231, p0233)。高胡＋柳琴は高音域が最もなじむ (p0226)。原則は**同じ音域を担う楽器を重ねること**。例えば中胡には、柳琴より音の厚みが近い中阮を合わせる (p0235) | 高胡＋琵琶は高音でも低音でもなじみにくい (p0227)。高胡＋古筝、中胡＋柳琴は実用性が低い (p0228, p0231) |
| 擦弦＋管楽器 | 擦弦は管楽器の音色を柔らかく整え、管楽器は擦弦の音量と持続音の力強さを増す (p0267)。低胡＋低音笙が最も実用的 (p0260) | 管楽器は撥弦・打弦楽器より音量が大きいため、先にバランスを見積もる (p0267)。スオナは個別に見積もる (p0256) |
| 撥弦・打弦＋管楽器 | 柳琴＋梆笛、琵琶＋高音笙、中阮＋中音笙、大阮＋低音笙 (p0273)。笙の群があれば和声を組みやすい (p0275) | 点状の発音と線状の発音の違いを考慮する (p0275)。笛で音を滑らせて下げる奏法は柳琴ではできないため、下降音を省くか、輪指に替える (p0271) |
| 打楽器＋各群 | 撥弦・打弦楽器とはともに発音が点状なので、最も融合しやすい (p0292)。管楽器とは音量が釣り合い、相性が非常によい (p0295) | 擦弦楽器と合わせる場合は音量のバランスが重要 (p0292) |

**異なる群をオクターブで重ねる際の注意**：擦弦（線）と撥弦・打弦（点）をオクターブ隔てて重ねると、音色の違いが非常に目立つ。**両方のオクターブ帯で混合音色を使う**ことで対処する。第1オクターブ帯を高胡＋柳琴、第2オクターブ帯を二胡＋琵琶とする (p0240)。擦弦と管楽器も同様で、高胡＋曲笛／二胡＋新笛とする (p0263)。**適用しない場合**：点状の音と線状の音を意図的に分離させたいとき。

### 8.3 全編成：旋律、低音、分奏、伴奏の割り振り

3種類の分奏（和声型、付随型、対比型）、撥弦・打弦楽器群を分奏させるかどうかの6つの判断基準、5種類の和声提示法と単独・混合音色群の8通りの組み合わせは[reference-minyue.md](reference-minyue.md) §8.4.1–8.4.3を参照。

- **旋律**：1群で提示する、2群で共同提示する、3群で共同提示する、の3通り。旋律を提示しない群も**合奏に参加させる**。省けるのは音高が定まらない打楽器だけ (p0302–0303)。旋律は高音域で最も埋もれにくいが、中国民族管弦楽の擦弦と撥弦・打弦は高音域が比較的弱い（高胡は胴が小さく奏者数も少ない）ため、楽器を加えて補うことが多い (p0414–0415)。中音域の旋律は内声となるため、他の声部は同じ音域を空ける (p0415, p0451)。
- **層別の和声**：各楽器群で高／中／低の和声配置をそろえる。高＝笛の群、高音スオナ、柳琴、琵琶、揚琴、高胡、二胡。中＝笙、中音スオナ、阮、中胡。低＝低音笙、低音スオナ、大阮、低胡、倍低胡 (p0352)。**上は密に、下は疎に、中は空けない**。テノール域D—dと中音域G—gが響きを決める (p0375, p0451)。強奏と同系統の楽器には密集配置を、弱奏で色彩を出したい場合や異なる楽器を使う場合には開離配置を用いる (p0375)。和音の第3音は重複させず、七の和音では低音に置いた構成音を上声に重ねない (p0375)。**確認**：笙、阮、中胡の層が空いていないか。
- **低音**：擦弦の低胡・倍低胡、撥弦の大阮、管楽器の低音笙・低音スオナを使う。笙とスオナは線状の音を、胡琴と阮は線状と点状の両方の音を出せる (p0336)。大阮の最低音は低胡より長2度、低音スオナの最低音は5度高い (p0336)。低音笙と他の低音楽器は倍音列に沿って配置し、濁りを防ぐ (p0140)。低胡の弓奏と倍低胡のピッツィカートを重ねると線状と点状の低音を組み合わせられる (p0062)。低胡が旋律を奏でるときは倍低胡と少なくとも5度離す (p0062)。
- **伴奏**：リズムを刻む和声には一般に8分音符を使う（4分音符ではグルーヴが出にくい）。担当は高音笙、中音笙、中阮が多い (p0359)。撥弦・打弦には16分音符の和声を用い、一斉に鳴らす和音の濁りや硬さを避ける (p0361)。管楽器が旋律、撥弦・打弦または擦弦が和声を担うといった、楽器群ごとの分担が基本となる (p0370)。
- **分奏と記号**：同種の管楽器2本にはa²／I／IIを使う (p0347)。笙は通常分奏せず、独奏はsolo、斉奏はtuttiとする (p0348)。撥弦・打弦楽器の重音は通常、分奏の指定をせず、揚琴は分奏しない (p0348)。擦弦ではdiv./unis.、solo/soli/tuttiを対応させる (p0348)。低胡の重音にはdiv.またはnon div.を必ず明記する (p0349)。

### 8.4 処理法と確認事項

| 方法 | 要点 | 確認事項 |
|---|---|---|
| バランス | 旋律を明瞭に保つ。和声は厚すぎると濁り、薄すぎると乾いた硬い音になる (p0414–0415)。同じ強弱記号でも楽器ごとに聞こえる音量が違うので、記号は楽器ごとに調整する (p0413) | 分奏後の音量低下を見込んだか |
| 強調 | 旋律以外のすべての楽器でアクセントを補強する (p0416) | 強弱記号だけに頼っていないか |
| 受け渡し | 同じ旋律の途中で楽器を替え、個々の中国民族楽器の音域の不足を補う。次の楽器は**早めに入り**、前の楽器は1音多く奏でる (p0418) | 受け渡しの箇所に重なりがあるか |
| 編成の拡大／縮小 | 加える順序は「擦弦、撥弦・打弦、管楽器、最後に打楽器」 (p0421)。弱めるときは強弱を下げ、声部も減らす (p0421) | クレッシェンドとデクレッシェンドをすべて指揮者任せにしていないか (p0450) |
| 音の勢い | 装飾音、ロール、グリッサンドで短い推進力を加える (p0422) | |
| 対話と呼応／音色の対置 | 民間音楽の掛け合い。同じ素材を異なる楽器群で順に奏でる (p0424–0427) | |
| 補足 | 一時的に声部を加えるか、終止の勢いを抑える (p0428–0432) | |
| 音色の温存 | 重要な旋律が入るまで、担当楽器の音色を使わない。旋律が中低音域にあるときは、他の声部がその音域を空ける (p0451) | |

李民雄は2点を加える。音色を変える頻度やタイミングを楽節・楽句・楽段の区切りに合わせ、展開部や劇的な箇所では変化を多くする (李民雄 p0097)。一つの区間に一つの**主導音色**を置き、他の音色はそれを軸に変化させる (李民雄 p0100)。

### 8.5 合奏の中の独奏楽器

- 独奏は、1つの楽器が奏で、総譜のどの声部にも同じパートがないものを指す (p0394)。原則は**独奏が埋もれず、明瞭に聞こえるようにすること** (p0410)。
- 5つの方法 (p0411)。伴奏の音量を抑える。伴奏は独奏と同じ音域を避ける。独奏と異なる系統の音色で伴奏する（擦弦の独奏には撥弦・打弦、撥弦の独奏には管楽器）。音域を対比させる（低音の独奏に高音の伴奏）。伴奏のリズム型を独奏と変える。
- 楽器別の注意。スオナと笛は埋もれにくく、笙では伴奏を減らす。柳琴の低音域での独奏は慎重に扱う。中阮は埋もれやすく高音域の響きもよくないため、中音域を使う。二胡の独奏には撥弦・打弦楽器の伴奏が多い。中胡の独奏では伴奏に同じ音域を使わない (p0410)。
- 協奏曲で対比させる4要素。音色（スオナの独奏にはスオナを伴奏に使わない）、音域（独奏の音域を空ける）、リズム、強弱 (p0412–0413)。

### 8.6 編曲と編成の置き換え

- **編曲**は旋律だけをもとに総譜全体を書くこと。**編成の置き換え**は既存の総譜を別の楽団編成に移し、和声とテクスチュアを保つこと。特別な場合は移調してよい (p0440)。伝統器楽の名曲を編曲する際は**移調しない** (p0440)。
- 編成を置き換えるときは音域を先に、調性を後に確認する (p0441)。ヴァイオリン↔柳琴は音域が完全に重なる。琵琶はc³以下、揚琴はg³以下、古筝はd³以下、高胡はg¹以上で重なる (p0441)。オーボエ→高音笙が最適。クラリネット→中音笙、ファゴット→低音笙、トランペット→高音スオナ（オクターブ記譜の違いに注意）、ホルン→中音笙、ハープ→古筝（変化音が多ければ揚琴）(p0444–0447)。**フルートの譜面はそのまま竹笛に渡せない**。竹笛は実音より1オクターブ低く記譜する (p0444)。
- 全体の設計。最も適した調は♭2つから♯3つまで (p0449)。《花好月円》ではG調を使うと、D調の場合より楽団全体が明るく響く (p0449)。各楽器の最良の音域を使い、胡琴をむやみに高く書かない (p0450)。斉奏・全奏と最強の強弱は慎重に使う (p0450)。和声の変化はゆったりさせ、分散和音に非和声音を加えて西洋風の響きを和らげる (p0451–0452)。

> 楽器ごとの調弦、音域、奏法、総譜での楽器順、移調の慣例はreference-minyue.md §7–§8を参照。

## 10. 記入後のチェックリスト

- [ ] 各ラインの**役割**と**その楽器を選んだ理由**を説明できる
- [ ] 混合した箇所が**同度／オクターブの重ね合わせ／異なるオクターブ帯**のどれに当たるか説明できる
- [ ] オクターブを重ねた箇所で、**上の楽器が下の楽器のどの倍音を補強しているか**を説明できる
- [ ] **中和現象**を確認した。新しい音色ができているか、個性が薄れた背景から一つの音色だけが突出しているかを聴き分けた
- [ ] **奏法を記入し**、融合させたい楽器同士でアタックや減衰の形が近いことを確認した
- [ ] 各楽器の音域を**音名で示し**、その音域でどう響くかを確認した
- [ ] 実際の**奏者数**を基準にバランスを見積もった
- [ ] MIDIでは、強弱の起伏、奏法の切り替え、音域の選択をすべて指定した

**中国民族管弦楽のチェック項目**：

- [ ] 4群が**すべて参加する**（音高が定まらない打楽器のみ省略可）。旋律を提示するのが1群、2群、3群のどれか説明できる
- [ ] 層別の和声では**中声部（笙、阮、中胡）を空けず**、上を密に、下を疎に配置した
- [ ] 各楽器を**実音**で照合した。梆笛、曲笛、高音板胡、京胡、高音スオナ、海笛は実音より1オクターブ低く、倍低胡、雷琴、ティンパニは1オクターブ高く記譜する。中阮と伝統スオナはどちらの記譜を使うか明記する
- [ ] 竹笛とスオナは使用する**楽器の調**を明記し、途中で持ち替える箇所も記した
- [ ] 胡琴は高くなるほど音量と力強さが落ちることを踏まえ、過度に高く書いていない。クライマックスを二胡の高音に頼っていない
- [ ] 分奏記号を対で使った。`div.`には`unis.`、`solo`／`soli`には`tutti`を対応させ、低胡の重音には`div.`または`non div.`を記した
- [ ] 様式を特徴づける奏法（ポルタメント、フラッタータンギング、掃輪、打音など）を譜面に記し、同じ声部の中で統一した
- [ ] 編成の置き換えや編曲では、音域を確認してから調を決めた。伝統器楽の名曲は**移調していない**
