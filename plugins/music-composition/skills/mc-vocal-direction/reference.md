## 0. 生成バックエンドを使う場合に参照する項目

**半分ほどは生成バックエンドでも役立つ。**

| 内容 | 生成バックエンドでの扱い |
|---|---|
| マイク選び、マイキング、近接効果 | **録音時のみ**。ただし §1 の組み合わせ方は **voice persona の選び方**にも応用できる |
| モニター（cue mix）の設計 | **録音時のみ** |
| ボーカルチェーンの設定（§3） | **参考**。生成ボーカルに足りないものを判断する |
| De-Esser と歯擦音 | **活用できる**。生成ボーカルでは歯擦音の問題がよく起こる |
| §4 録音データの規格 | **活用できる**。納品するボーカル素材の最低要件がわかる |

> L4 のコンパイル層は MIDI/DAW バックエンドにも対応し、この経路では生の歌声を録音する。
> また、これらの設定は**生成結果を評価する基準**にもなる。
> 良いボーカル素材の作り方を知っていれば、モデルの出力に何が足りないか判断できる。

## 1. マイク選び

**カメラに例えると**、マイクがレンズ、マイクプリアンプとオーディオインターフェースがカメラ本体、DAW がフィルムにあたる。
**同じマイクでも、マイクプリアンプが変わると音が変わる。**

| | ダイナミック | コンデンサー |
|---|---|---|
| 特性 | 頑丈、安価、電源不要 | 繊細で壊れやすい、高価、ファンタム電源が必要 |
| 用途 | **ライブの定番** | **スタジオ録音の定番** |
| 音 | — | 音質に優れ、**息遣いまで拾える**。高域から低域まで周波数特性が均一 |

**選び方**。**歌手に実際に歌ってもらい、マイクを通した音を聴く**。確認する点は三つ。
1. 音の硬さや厚みが**曲に合っているか**
2. 欲しい**中域**を拾えているか
3. **歌手がそのマイクで気持ちよく歌えるか**

**アレンジに合わせた選び方**

| アレンジ | マイク |
|---|---|
| 柔らかい | 柔らかい音のマイク |
| 硬い | 硬質な音のマイク |
| ロックの力強さ | **中低域に個性がある**もの |
| R&B の質感 | **きらびやかな高域** |

> レコーディングエンジニアがいるなら、**普段の言葉で欲しい雰囲気を伝えればよい**。
> 「もう少し華やかに」「もっと明るい音で」「夏っぽく」など。
> ★ `SKILL.md` §2.2 と同じ考え方で、プロンプトにも応用できる。

## 2. マイキング、距離、録音環境

| 項目 | ポイント |
|---|---|
| **向き** | できるだけマイクに正対する。**歌詞カードを見つめたまま歌うと音がぼやける**ので、譜面台とマイクの位置関係を先に決める |
| **指示は必要な分だけ** | 要求が多すぎると歌手が硬くなる。**体を動かしてもらい、グルーヴのある歌を録る**ほうがよい（足を踏み鳴らす音はスタジオのカーペットが吸収する） |
| **近接効果** | マイクに近づくほど**低域が強調される**ので、適度な距離を取る。ロックらしい音には**あえてマイクに寄って録る**手もある |
| **高さ** | マイクは口の正面が基準。**口がマイクより上 → 低域を多く拾う。口がマイクより下（マイクを上から斜めに向ける）→ 高域を多く拾う** |
| **普段の歌い方** | ギターを抱えて歌う、座って歌うなど、歌手が慣れている姿勢で録れるように調整する |

**例外**。モニターの音が鮮明すぎて歌手が神経質になり、うまく歌えない場合は、
**あえてグレードの低いマイクを使う**か、**cue mix のリバーブを増やす**。

### 2.1 モニター（cue mix）

- ヘッドホン内の自分の声の音量は**歌手が決める**。大きすぎると**音程が取りにくい**
- リズムパートを大きくするとグルーヴに乗りやすい一方、**音程の基準になるパートが埋もれる**
- ★ **モニターには強いコンプレッションをかけない**。自分のダイナミクスが聞こえず、歌の上達を妨げる。
  力を込めてもその手応えが返ってこないと、かえって薄い声になる

## 3. リードボーカルの処理チェーン（伴奏の中で声を前に出す）

**処理順**

| # | 処理 | パラメーター（実例） | ポイント |
|---|---|---|---|
| 1 | **コンプレッサー** | WAVES Renaissance Compressor、**Ratio ≈ 4:1（4.27:1）、Attack 16 ms、Release 160 ms**（アタックはやや遅め） | **潰しすぎない**。通常のセクションではメーターがほぼ動かず、**サビでレベルが上がったときに 3–4 dB 圧縮する**ようにスレッショルドを設定する。目的はボーカルのレベル差を少しならすこと |
| 2 | **リミッター** | WAVES L1 | 全体のラウドネスを上げる。Maximizer なら**歌の抑揚を保ちながらラウドネスを上げられる**（埋もれかけている部分も聞こえやすくなる） |
| 3 | **EQ** | WAVES Renaissance Equalizer | **高域をブースト**して声のエッジを出す。**125 Hz 付近の低域もブースト**する（実例：151 Hz のピーク、**+6.9 dB**）。声らしさが薄い帯域だが、**声が持つ厚みと存在感**を引き出せる（欧米の歌手に近い質感を作る手法）。レベル上昇によるクリッピングに注意 |
| 4 | **ショートディレイ** | AVID Mod Delay II、**send で送る** | コーラスに似た広がりが出る。かけすぎると音がにじむので、**かろうじて聞き取れる程度**に設定する |
| 5 | **リバーブ** | AVID Reverb One | 最後に**薄く**かける |
| 6 | **最終バランス** | — | ボーカル処理後に伴奏を前に出したければ、**ボーカル全体を少し下げる** |

### 3.1 R&B でボーカルを最前面に張り付かせる手法

**マルチバンドコンプレッション**。WAVES C4（4 バンド。主に低域と高域を強調）を **EQ とコンプレッサーの両方の役割**で使うと、
ボーカルが最前面に張り付いたように聞こえる。

**トレードオフ**。**サビなどで歌唱表現の起伏が失われる**。
R&B 以外のポップスでは、ボーカルの表情を損なうことがある。

**この処理を使うときは、オートメーションで音量を微調整し、曲本来の抑揚を保つ。**

### 3.2 De-Esser

> De-Esser は**歯擦音の帯域に特化したコンプレッサー**（実例：**FREQ 7.0 kHz / RANGE −5.0 dB**）。

**かけすぎると舌足らずで不明瞭な声になる**。
それだけ**子音は重要**（`SKILL.md` §2.3 参照）。

> ★ 生成ボーカルでは、歯擦音が強すぎたり弱すぎたりすることが多い。
> **舌足らずに聞こえたら De-Ess のかけすぎ**。歯擦音は少し残すほうがよい。

## 4. Treatment の具体的な手法

### 4.1 ポップノイズ（pop noise）を一時的な EQ で除去する

1. ポップノイズの位置を特定し、**その短い区間だけをループ再生する**
2. **急峻なハイパスフィルター**を挿し、破裂音が消えるまで**カットオフ周波数を低い位置から徐々に上げる**
   （実例：**300 Hz 付近、正確には 309.6 Hz**）
3. **その区間だけオフラインでレンダリングして書き出し**、**元のトラックの同じ位置に戻し**、**両端をクロスフェードでつなぐ**

### 4.2 レベル差が大きすぎるボーカルを整える

- **コンプレッサーの設定例**。WAVES Renaissance Compressor、
  **Attack 24.9 ms / Release 16.6 ms / Ratio 4.72:1** + WAVES L1
- ★ **スレッショルドが重要**。自然さを保てるぎりぎりに設定する。
  **圧縮が浅すぎるとレベル差が縮まらず、深すぎると歌唱が不自然になる**
- 圧縮で十分に整わなければ、**フェーダーオートメーション**で波形の小さい箇所を持ち上げる
- > DAW では、**オートメーションだけでレベルを整えられる**。
  > コンプレッサーが追従できない複雑なカーブも描けて、自然に仕上がる。**まずオートメーションでレベルを整えるのがおすすめ。**

## 5. ハモリとダブルの EQ 実例

ミックス時に参照できるよう、設定例を示す（各型の定義は `SKILL.md` §5 を参照）。

| 型 | EQ の方針 |
|---|---|
| **型 1**（地声で歌う上ハモ） | **リードボーカルとハモリの帯域をずらす**。低域を大きく削り、**声の芯になる中域をカット**。必要に応じて高域を強調する |
| **型 3**（控えめな下ハモ） | 低域を削る。実例：**110 Hz low cut、123 Hz −10 dB、247 Hz −4.9 dB、621 Hz −4.2 dB**（中低域全体を減衰） |
| **型 4**（合いの手） | **まず EQ で質感を変える**（ラジオ風の音色でもよい）。グループ全体で空間系エフェクトを共有する。チェーンは **EQ → コンプレッサー → コーラス → ディレイ** |
| リバーブの組み合わせ | 型 1、型 2 は**高域が豊かなリバーブやディレイ**で華やかさを加える。型 3 は**直接音を減らしてリバーブを増やし**、存在感を抑える |
