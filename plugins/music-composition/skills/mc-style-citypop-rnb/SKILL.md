## 3. 和声

### 3.1 ジャズの語法を密度を抑えて使う

| ジャズ由来の手法 | シティポップでの使い方 |
|---|---|
| セブンスコード、ナインスコード | ★ **セブンスコードを基本形にする** |
| テンション 9/11/13 | **一度に一つか二つ**使う |
| ツーファイブ、セカンダリードミナント | 多用する |
| **sus・分数コードによるドミナント代用** | ★ **F/G をよく使う** |
| オルタードドミナント、ディミニッシュスケールのリック | ❌ 使うとジャズの色が強く出るため避ける |

★ **シティポップはジャズの和音をポップスの構成で使う。**
コードの響きはジャズから取り入れ、機能和声の進行やセクションを保ち、コーラスを曲の中心に置く。

### 3.2 代表的なコード進行

`mc-progressions` を参照。

- **丸サ進行 4361**（`IV–III7–VIm–I`）は、シティポップやネオソウルを特徴づける。
- **`IV△7–IIIm7–IIm7–I△7`** はポップスや R&B の定番（"Lovin' You"）。
  ★ **ループの折り返しに #IVm7(♭5) を一つ挟むと色合いが出る**。
- **`C△7–D7–F–F/G`** は浮遊感を出す。セカンダリードミナント II7 が向かう V7 には着地しない。

## 4. ★ グルーヴ。前ノリのベースとグリッドに沿うドラム

**再現しやすく、設定を誤りやすい手法。**

**実測サンプル（example-01、112 BPM）**

| パート | タイミングのずれ | 役割 |
|---|---|---|
| **ベース** | **−12 ms（前ノリ）** | ★ **この曲に前へ進む感覚を作る唯一のパート** |
| クリーンギター | **+8 ms（後ノリ）** | ベースとのタイミング差で**広がりを感じさせる** |
| **ドラム** | **0** | ★ **グリッドに沿って基準を示す** |

### 4.1 グリッドに沿うパートが必要な理由

**前ノリはパート同士の相対的な関係**。全員が早く入るだけではテンポが少し上がったように聞こえる。
**動かない基準を置くことで、前ノリが聞き取れる。**

★ `mc-rhythm-section` §2.0 の「クオンタイズは楽器単位で判断する」をこのスタイルに適用した例。

### 4.2 ベースとキックの関係

シティポップでは通常、**かみ合わせ型**（`mc-rhythm-section` §7.1）を使う。
低域を厚くしたい箇所では重ね、その他ではずらして**ベース独自の旋律線を保つ**。
★ **このスタイルのベースはリズムを刻むとともに旋律を担う。**

### 4.3 feel

`straight16` を選ぶ。16分音符の密度は**ミュートストローク**で出す。スウィングと感触が近いため、取り違えやすい。§4 の前ノリのずれをミリ秒で判断するには均等なグリッドが必要になる。一般的な feel の選び方（スタイル、テンポの順で決める、バックビートを基準にする、in the crack のような中間のフィールを扱う）は `mc-rhythm-section` §1.1 を参照。

## 5. 編成

### 5.1 実測した roster の例（example-01）

| 楽器 | 役割 | 周波数帯域 | 入り / 抜け |
|---|---|---|---|
| **アコースティックドラム + ゲートスネア**（70年代風の収音） | グルーヴ | 60 Hz–12 kHz | A1 / end（**D セクションはすべて休む**） |
| **Precision Bass**。指弾き、短いサステイン | 低域 | 40–250 Hz | A1 / end |
| **Rhodes Mk I + 軽いコーラス** | 和声の下地 | 200 Hz–2 kHz | I / end |
| **Strat のシングルコイル、16分音符のミュートストローク** | テクスチャ | 1–3 kHz | A1 / **C2**（★ 以降はサックスのために空ける） |
| **Prophet 系のノコギリ波の単音、ゆるやかなグライド** | **耳に残るフック** | 1.5–4 kHz | I / end（★ **フックだけを弾く**） |
| **ストリングス、高いポジションのロングトーン** | 彩り | 400 Hz–6 kHz | C1 / end（A2 でいったん抜け、C2 で戻る） |
| **テナーサックス** | 旋律 | 250 Hz–4 kHz | **D** / O（★ **曲の後半に入り、アウトロを引き受ける**） |
| **女性ボーカル**。息の成分を多めにし、近くに定位させすぎない | 旋律 | 200 Hz–8 kHz | A1 / **C3**（★ **アウトロは歌なし**） |

★ **三つの設計がこのライブラリの主要ルールに対応する**。

1. **サックスは曲の後半になってから入る**。途中で加わる楽器を設ける（**59/59 の強いルール**）。
2. **ギターは C2、ボーカルは C3 で抜ける**。最低1つのパートを早めに抜く（**59/59 の強いルール**）。
3. **シンセはフックに専念する**。ボーカル以外に耳に残る要素を設ける（lint #8）。

### 5.2 ★ 音域の分担

**200–500 Hz は Rhodes、ストリングス、ボーカルが重なるため、最も音が濁りやすい。**

実測例での解決方法

- **Rhodes は C3–C4 に限定する**。
- **ストリングスは C4 以上に書く**。

★ `mc-texture-layering` §4.2 の方法②にある**音域をずらす**手法の例。
音が重なる帯域は、音を配置する時点で空けておく。

## 6. 実測例の帯域配分

| 周波数帯域 | 優先する楽器 | 競合する楽器 | 解決方法 |
|---|---|---|---|
| **40–120 Hz** | ベース | ドラム | Kick を Bass にサイドチェインし、リリースは 30 ms。キックの打点でベースを 3 dB 下げる（**帯域を譲る**） |
| **200–500 Hz** | Rhodes | ストリングス、ボーカル | ★ **音域をずらす**。ep は C3–C4 に限定し、strings は C4 以上に書く |
| **1–3 kHz** | ミュートギター | シンセリード | ★ **交互に出す**。ギターは A/B、シンセリードは I/C/O のフレーズ末尾の隙間にだけ入れる |
| **6–12 kHz** | ドラム | ストリングス | ストリングスの高域を 8 kHz でロールオフし、ハイハットの空気感を残す |

★ **4箇所の競合に対して3種類の方法をすべて使っている**。帯域を譲る、音域をずらす、交互に出す。
`mc-texture-layering` §4.2 に従い、各箇所でどの方法を選んだかを明記する。

## 7. シティポップと R&B の違い

| | **シティポップ** | **R&B / ネオソウル** |
|---|---|---|
| **グルーヴの方向** | ★ **前ノリ**（ベースを早めに弾く） | ★ **後ノリ**（laid back） |
| **ボーカル** | 比較的素直な歌い回しで、ミックスでは奥に置く | **装飾、メリスマ、アドリブ**が多い |
| **和声** | ジャズの和音をポップスの構成で使う | ジャズに近く、**テンションが多い** |
| **編成** | バンド編成（ドラム、ベース、ギター、鍵盤にストリングス、管楽器） | **サンプリングと打ち込み**への依存が大きい |
| **ボーカルの重ね方** | コーラスでハモリを加える | ★ **ボーカルの多重録音が中心**（`mc-vocal-direction` §5 の4タイプをすべて使う） |

★ **和声の語法は共通していても、グルーヴの方向は逆。**
**ネオソウルにシティポップの前ノリのベースを入れると、スタイルを損なう。**

### 7.1 ★ 実測結果。R&B は途中で音を抜くことが多い

Cambridge-MT のマルチトラックにある hiphop-rnb 10曲の実測値

| 指標 | hiphop-rnb | pop | jazz |
|---|---|---|---|
| **曲の終わりより前に抜ける楽器数（中央値）** | ★ **28** | 16 | 10 |
| 曲の冒頭から入っている楽器の割合 | **24%** | 21% | 16% |

**R&B・ヒップホップは冒頭の編成が厚く、途中で抜けるパートも多い。**
**パートを順に抜くことで構成を伝える。**

★ **R&B を書くときは、他のスタイルより `subtraction_events` を多く設ける。**

> コーパスの10曲は hiphop-rnb の混合集計。**ヒップホップ側**の第三の時間感覚、808 の分担、サンプルで作るテクスチャは `mc-style-hiphop` を参照。この節では R&B 側を扱う。

### 7.2 ★ 欧米と日本の R&B の傾向（藤谷）

| | 欧米の R&B | 日本の R&B |
|---|---|---|
| 音符の数 | **少ない** | **多い** |
| 雰囲気 | 暗くクール | きらびやかで明るい |
| 和声 | ジャズの影響があり、複雑なコードをよく使う | |

（p0154）。書く前に、どちらの方向を目指すか明記する。**音数が少ない場合は、一音ずつ響きを吟味する**。
ビートは R&B の要。キックとスネアの音色を選び込む（p0154）。

### 7.3 欧米風 R&B の打ち込み方（藤谷 p0157–0162）

- **ドラムはすべて電子音色にし、ヒップホップの手法で打ち込む**。3つの音色ともレコードからサンプリングしたように太く粗い質感にする。キックやスネアとともにハイハットも鳴り込むサンプルの特性がグルーヴになる（p0157）。
- **キックは2層にする**。主となるキックに、短く鳴る超低域のキックを重ね、**小節の頭だけ**で鳴らす（p0157）。
- **ハイハットは8分音符で打ち込み、ベロシティは一定にする**（p0160）。フィルは偶数小節の末尾に置き、スクラッチ音を使う（p0160）。
- **ベースはルート音だけを弾く**。1拍目と3拍目の裏の8分音符の位置にだけ置く。2拍目・4拍目の頭に重ならない範囲で音を伸ばす。伸ばしすぎると締まりがなくなる（p0161）。
- **エレクトリックピアノは2分音符か全音符だけを使う**。トレモロと音色を整えると心地よく響く。他のスタイルで厚みや広がりを出したいときにも使える（p0162）。

§4 のシティポップではベースが前ノリでドラムはグリッドを保つ。ここで扱った R&B では、ベースの打点は2箇所、ハイハットのベロシティは一定。編成時に守る条件はスタイルごとに異なる。

## 8. ★ 余白で作るスタイル

このスタイルは、**どこで音を抜くか**が個性の半分を決める。

実測例でパートを減らした3箇所

| 位置 | 変化 | 理由 |
|---|---|---|
| **C2 の直前** | **最後の半拍はドラムを含めて全パートが休む** | ★ 直前に余白を作り、音量を上げずに2回目のコーラスを強く感じさせる |
| **D セクション** | ドラムとベースを**セクション全体で抜き**、エレクトリックピアノ、ボーカル、サックスだけを残す | ★ **曲全体で最も静まる箇所を C3 の前に置く**ことで C3 の盛り上がりが成立する |
| **A2** | ストリングスとギターの半分が抜ける | ★ **2番のヴァースは1番よりも編成を薄くする** |

★★ この3つの理由は他のスタイルの編曲にも応用できる（`mc-arrangement-arch` §3）。
