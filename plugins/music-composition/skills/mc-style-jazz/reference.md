## 1. コード → スケール対応表

### 1.1 メジャースケールのモード

| モード | コード | アボイドノート |
|---|---|---|
| Ionian | △7 | **4**（第3音と半音でぶつかる） |
| Dorian | m7 | 6（文脈による） |
| Phrygian | m7 / Sus♭9 | ♭2（特性音でもある） |
| **Lydian** | **△7(♯11)** | ★ **なし**。Ionian より開放的に聞こえる理由 |
| **Mixolydian** | **ドミナント7th** | 4 |
| Aeolian | m7 | ♭6 |
| **Locrian** | **m7(♭5)** | ♭2 |

★ **アボイドノートも経過音として使える。そこにとどまらないこと。**

| 度数 | 名称 | コード |

| 4 | **Lydian Dominant** | **7(♯11)** ★ ポップスに最も応用しやすい |
| 5 | Mixolydian ♭6 | 7(♭13) |

## 2. Levine の補足ルール（SKILL §3 の補足、p0055–0110）

### 2.1 アボイドノートの使い方（p0055–0059）

Levine は "avoid note" より **"handle with care"**（扱いに注意）のほうが正確だと言う（p0055）。I△7 上の第4音は経過音として素早く通れば、不協和がほとんど聞こえない。**意図して弾くなら、通常は下の第3音に解決する**（Stella By Starlight の第9小節、E♭ から D、p0056）。アウトサイドの箇所や一つの △7 が長く続く箇所では、第4音が最も面白い音になることもある（p0056）。ドミナント7th 上の第4音（11）も同様に、弾いてから半音下の第3音へ進める（p0059）。
**協和音と不協和音にはそれぞれ役割がある。不協和音は緊張、解決、勢いを生む**（p0056、p0059）。

### 2.2 Lydian を使う場面と控える場面（p0057–0058）

- コード記号に ♯4 がなくても、ほとんどの △7 で第4音を上げられる。**IV の △7 では特に響きがよい**。任意のため、fake book では表記されないことが多い（p0058）。
- Lydian はポップスでは曲調から浮くこともあるが、Oliver Nelson は Yesterday の編曲で使った（p0057）。古くは1926年の Someone To Watch Over Me の bridge の最初のコードや、1893年の Happy Birthday の第6小節にも現れる（p0058）。
- 表記は第4音の上方変位。1960年代以前は ♭5 と呼んでいたが、モードを基準に考えるようになってからは ♯4／♯11 と呼ぶ（p0057、p0060）。

### 2.3 Sus コードのボイシング（p0061、p0064–0065）

**第4音がアボイドノートに聞こえない V のコード**（p0061）。
- 右手で**ルートより全音下のメジャートライアド**を弾く（Dsus なら右手は C のメジャートライアド）。構成音の一つをオクターブで重ねて厚みを出す（p0064）。
- 1960年代以降は **第3音と第4音を同時に使える。ただし第3音を第4音より上に置く**。逆にすると「最後の不協和音程」とされる短9度が生じる（p0064–0065）。
- Miles Davis は In Your Own Sweet Way で A♭sus と A♭7♯11 を交互に使う（p0064）。

### 2.4 メロディックマイナーで置き換えが成立する範囲と特性音（p0091–0095）

- メロディックマイナーには**アボイドノートがなく**、同じ調の各コードで使える音が一致する。F-△ のどのフレーズや voicing も、Gsus9、A♭△♯5、B♭7♯11、Dø、E7alt にそのまま移せる（p0091）。
- ★ **メジャーには当てはまらない**。D-7 と C△ はどちらも C メジャーに属するが、D-7 の voicing に含まれる F は C△ のアボイドノート（p0091）。
- "Think key, not chord"。コードを弾くときも調全体を意識する（p0092）。
- **特性音**。メロディックマイナーの 3、5、7、9 の組み合わせと 1、3、5、7 の組み合わせは、そのメロディックマイナーに固有。ほかのメロディックマイナーやメジャーにはなく、弾けばすぐに調性が伝わる（p0095）。
- ピアノでは白鍵から外れる音だけ覚える。G メロディックマイナーは B♭ と F♯、D メロディックマイナーは C♯（p0092–0093）。

### 2.5 ディミニッシュとホールトーンの対称性と反復（p0096–0110）

| | ディミニッシュスケール | ホールトーンスケール |
|---|---|---|
| 構成 | 半音と全音が交互の8音。**対称性**があり、3種類のみ（p0096–0097） | すべて全音。対称性があり、2種類のみ（p0108） |
| 反復 | ★ **lick、コード、voicing はすべて短3度間隔で反復できる**。同じ voicing を4つの V7♭9 に使える（p0100–0102） | ★ **全音間隔で反復できる**ため、長3度やトライトーンでも反復できる。アボイドノートがなく、同一スケール内で相互に置き換えられる（p0108–0109） |
| 表記 | | G7♯5 に対応する。G7+ は + の対象が第5音と伝わりにくく、G7♭13 は ♭9 ♯9 を伴う alt と読まれかねない。**G7♯5 が明確**（p0108） |
| 制約 | | 西洋音楽の音程の半分（短2度、短3度、完全4度など）を欠く。**響きが均一なので少量にとどめるとよい**。fake book の100曲で、ホールトーンのコードが出るのは1、2曲（p0109）。多くの奏者は **alt で代用**する（Stella の第17小節では G7♯5 を G7alt で弾く、p0110） |

響きの目安（p0109）。△7 は明るく穏やか、メジャートライアドは勝利を思わせる。メロディックマイナーは暗く悲しげで神秘的。ドミナント7th は緊張感、ディミニッシュは極度の緊張感。ホールトーンスケールは独特の響き。

### 3.1 五度圏で進行を展開する3つのレシピ（Valerio p0028–0033）

静的な進行は、五度圏を反時計回りにたどってコードを補うと展開できる。そのまま使える例を三つ示す。

| つなぐ箇所 | 補い方 | 完成形（C メジャー） |
|---|---|---|
| **I → V** | A–D–G の五度関係をたどる | Cmaj7 – Am7 – Dm7 – G7 |
| **I → II** | B7 から五度を4回たどる | Cmaj7 – B7 – Em7 – A7 – Dm7 – G7 |
| **I → IV** | 4小節にわたって五度を7回たどる | C6 – Bm7♭5 – E7 – Am7 – D7 – Gm7 – C7 – F7 |

**五度下降と半音下降は機能上等価**。五度圏を1ステップ下る動きは、トライトーン・サブスティテューションによる半音下降に置き換えられる（Dm7 – G7 – Cmaj7 ↔ Dm7 – D♭7 – Cmaj7）。
上のどのレシピでも、ドミナント7th を裏コードに置き換えると、五度下降の連鎖を半音下降のベースラインに書き換えられる（p0033）。
隣接和音と倚和音は `mc-harmony` reference §2.8 を参照。

## 5. ドミナント機能の系統：セカンダリー、エクステンデッド、代理ドミナント、関連 II-7（陈云强《爵士和声》）

### 5.1 セカンダリーかエクステンデッドかは、和声リズム上の位置で見分ける

主ドミナント機能を持たないドミナント7th は、**弱位置ならセカンダリードミナント**（完全5度下のダイアトニックコードに解決）、**強位置ならエクステンデッドドミナント**（ドミナント機能を持たないダイアトニックコードが出るまで、ドミナント7th が完全5度ずつ下降する）（p0134 前後）。

| | 主ドミナント7th | セカンダリードミナント | エクステンデッドドミナント |
|---|---|---|---|
| 位置 | 多くは弱位置 | 弱位置 | **強位置** |
| ルート | 第5音 | ダイアトニック音 | 主に **第6、3、7、2音**。ルートが第1音か第4音ならブルースからの借用とみなす |
| 解決 | 任意のダイアトニックコード | 通常は五度下降。**偽解決**も可能 | 五度下降の連鎖 |
| テンション | 変化テンション全6種 | 主にダイアトニック音 | |

（p0134、p0138、p0140）**偽解決**。弱位置のセカンダリードミナントが、エクステンデッドドミナントなどのノンダイアトニックコードに解決すること。セカンダリードミナントの記号を括弧付きで表記する。
シェーンベルクの偽終止（`mc-harmony` reference §7.4）や Kachulis の偽終止（SKILL §3.1）も、予想された解決先を外す手法。併せて参照する。

### 5.2 関連 II-7 はどのドミナント7th の前にも置ける

**ドミナント機能を持つすべてのドミナント7th の前に、ルートがそのドミナントへ完全5度下降する m7 を挿入できる**。ダイアトニックかどうかは問わない。ダイアトニックなら二重機能を持つ関連 II-7 と呼ぶ（p0145–0147）。
セカンダリーやエクステンデッドの連鎖では各ドミナントの前に関連 II-7 を挿入でき、その後も連鎖は成立する。これが「連続ツーファイブ」の作り方。`mc-harmony` reference §3 では連鎖できることに触れている。

### 5.3 セカンダリードミナントのスケールは解決先で決まる

| セカンダリードミナント | スケール |
|---|---|
| V7/II、V7/III、V7/VI | Mixolydian ♭9 ♭13（V7/II は ♭13） |
| V7/IV、V7/V | Mixolydian |

★ **仕組み**。どのセカンダリードミナントのスケールでも、第4音は解決先のルートに当たるため、アボイドノートになる（p0126–0132）。変化スケール（♭9、♭13、♭9♯9、♭9♯9♭13、Altered）のアボイドノートは個別に示す。Altered にはアボイドノートがない。
代理ドミナントと代理の関連 II-7 は、ダイアトニックかどうかを問わず、テンションに **9、♯11、13** を使える（p0225）。

### 5.4 主ドミナント7th は I 以外にも進める

V7 の進行先には、ダイアトニックの代理 **III-7、VI-7** と、ノンダイアトニックの代理 **♯IV°7、♭IIImaj7、♭VImaj7、♭IImaj7** がある（後者の4つはマイナーからのモーダルインターチェンジ。**コードスケールはすべて Lydian で、アボイドノートはない**）。
ノンダイアトニックの代理は一時的な経過で、最終的には I に戻る。**最初の代理コードと最後の I はどちらも強位置に置く**。進行例：♯IV°7 → IV-7 → III-7（I/3 で代用可）→ ♭III6 → ♭IImaj7 → I。

エクステンデッドドミナントに代理を使う方法は二つ。**交互型**（元の連鎖を一つおきに代理ドミナントへ変えると、ルートが短2度ずつ下降する。最初のドミナントのルートがダイアトニック音かどうかで判別する）と、**挿入型**（隣り合うエクステンデッドドミナントの間に代理ドミナントを挟む。先行する二つが共に次のコードへ解決する）。

### 5.5 転調の3分類（p0250 前後）

直接転調（遠隔調、近親調、同主調）、ピボット転調（ダイアトニックコードかモーダルインターチェンジのコードをピボットにする）、ドミナントを介した転調（元の調の最後のドミナント7th を、新しい調の主ドミナント7th、セカンダリードミナント7th、代理ドミナント7th、あるいはドミナント機能を持たない7thコードとして扱う）。
`mc-modulation` §3.5 にある黄虎威の9つの方法と併せて参照する。
