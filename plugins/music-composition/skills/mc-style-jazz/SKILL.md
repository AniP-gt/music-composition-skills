# ジャズのスタイル層（Jazz）

**L3 のスタイル層にある各スキルでは、まず次の問いに答える。**

> **このスタイルに固有の手法はどれで、一般的な音楽理論をこのスタイルに当てはめた手法はどれか？**

ジャズではこの区別が特に重要になる。**ジャズ理論は「高度な音楽理論」として広く教えられている**が、
そのうち多くの内容は一般的な和声として `mc-harmony` で扱う。

## 2. ★ 他のスタイルへの応用可否

**すべての L3 スタイルスキルにこの表を載せる。手法を持ち込んだ結果、曲調が意図せず変わるのを防ぐためだ。**

| 手法 | 応用できるか | 説明 |
|---|---|---|
| **ツーファイブワン、セカンダリー・ドミナント、裏コード** | ✅ **そのまま応用できる** | もともと `mc-harmony` の範囲。J-POP や city pop でも多用する |
| **テンション（9/11/13）** | ✅ 応用できる | 同上。ただし**密度は下げる**。ポップスではテンションを詰め込むと響きが濁る |
| **コードスケールの考え方** | ⚠️ **一部応用できる** | **音選びの根拠**として応用できる。**即興の枠組み**としては応用できない（ポップスには即興セクションがない） |
| **メロディックマイナーから得られる 4 つのコード** | ⚠️ 一部応用できる | 単発で使うなら応用できる（例として Lydian Dominant で彩りを加える）。**連続して使うとすぐにジャズに聞こえる** |
| **オルタード・ドミナント（Altered）** | ❌ **基本的に応用できない** | ポップスに入れると、響きが「高度」になるというより「ジャズ風」になる |
| **ディミニッシュスケールの lick** | ❌ 応用できない | ジャズの語法だと強く印象づける |
| **Sus コードのジャズでの用法** | ⚠️ 一部応用できる | ★ **F/G のような分数コードによるドミナントの代理は city pop の主力**（→ `mc-progressions` reference §3） |
| **Comping のリズム** | ❌ 応用できない | 即興奏者のために余白を残すことが前提になっている |
| **Head–Solos–Head の曲式** | ❌ 応用できない | ポップスにはこの構成がない |
| **Swing のグルーヴ** | ⚠️ 一部応用できる | shuffle はブルースロックや R&B でも一般的だが、**スウィングの比率が異なる** |
| **小編成で余白を多く取る** | ✅ **応用でき、積極的に応用すべき** | §7 を参照 |

★ **判断基準**。
> **応用できるかどうかは「誰かが即興演奏をしている」という前提の有無で決まる。**
> その前提がある手法（comping のリズム、solo の構成、アウトした音の扱い）は応用できない。
> 前提がない手法（ハーモニーの素材、編成の考え方）は応用できる。

## 3. コードスケール

### 3.1 基本の考え方

**各コードには 1 つ（または複数）の音階が対応し、その音階で使える音が決まる。**
ジャズ理論と古典の機能和声では、まず何を問うかが大きく異なる。
**古典では「この音はどこに解決するか」を、ジャズでは「このコードの上でどの音が使えるか」を問う。**

| 旋法 | コード |
|---|---|
| Ionian | △7 |
| **Dorian** | m7 |
| **Mixolydian** | ドミナント 7th |
| Aeolian | m7（自然短音階の響き） |
| **Locrian** | **m7(♭5)**（ハーフディミニッシュ） |
| **Lydian** | △7(♯11) |
| Phrygian | Sus♭9 |

### 3.2 アヴォイドノート（Avoid Note）

**使うことはできるが、その音にとどまらない。**
典型例は、長調の II-V-I における **I△7 上の第 4 音**（コードの第 3 音と半音でぶつかる）。

★ **ここで Lydian が役立つ**。4 を ♯4 に上げると**アヴォイドノートがなくなる**ため、
**△7(♯11) は △7 より「開放的」に聞こえる**。ドミナント 7th 上の ♯11 も同様。

> Levine は「**不協和音の捉え直し**」に章を丸ごと割いている。ジャズの歴史では、それまで「使えない」とされた音が次々に取り入れられてきた。

### 3.3 ★ メロディックマイナーのハーモニー：ジャズの中核

**メロディックマイナーには 7 つのモードがあり、そのうち 4 つからジャズを特徴づけるコードが得られる。**

| モード | コード | 用途 |
|---|---|---|
| 第 1 音 | **マイナー・メジャーセブンス（mMaj7）** | 短調のトニックコードをジャズらしくした形 |
| 第 2 音 | **Sus♭9** | |
| 第 3 音 | **Lydian Augmented** | |
| 第 4 音 | **Lydian Dominant**（ドミナント 7th♯11） | ★ 最もよく使い、**ポップスにも最も応用しやすい** |
| 第 6 音 | **ハーフディミニッシュ（m7♭5）** | 短調のツーファイブの II |
| **第 7 音** | ★ **オルタード・ドミナント（Altered）** | **ジャズの響きの中核** |

★★ **相互置換性（Interchangeability）**。
**同じメロディックマイナーの音階からできるこれらのコードは、互いに置き換えられる。**
これが「調性を軸にした考え方」で、個々のコードよりも**「今はどのメロディックマイナーにいるか」**を考える。

> **ここがジャズとポップスのハーモニーを分ける最大の違い。**
> ポップスのハーモニーは**コードの連なり**。ジャズのハーモニーは**音階が適用される区間の連なり**で、コードはその一断面にすぎない。

### 3.4 その他の素材

| 素材 | 用途 |
|---|---|
| **ディミニッシュスケール** | dim7 と V7♭9 に合わせる。★ **ディミニッシュセブンスコードは V7♭9 が「姿を変えたもの」**。bebop 以降はディミニッシュコードの代わりに V7♭9 を直接使う。**短三度ごとに反復する**ため、1 つのヴォイシングを複数の V7♭9 に使い回せる |
| **全音音階** | オーギュメントコード、V7♯5 に合わせる |

### 3.9 ★ ブルースのハーモニー：ジャズ、ロック、R&B に共通する土台（陈云强）

このリポジトリには以前、「♭3 ♭5 ♭7 をこすりつける音」という 1 行しかなかった。ブルースのハーモニーには一通りの体系がある。ページ番号は《爵士和声》による。

**機能の骨格は固定する**（p0192）。最初の 4 小節はトニック機能の I7、第 5・6 小節はサブドミナントの IV7、第 9・10 小節は終止形。
★ **I 度でドミナント 7th コードがトニック機能を担えるのはブルースだけ**（p0187）。

**4 つの基本進行の変遷**（p0186–0187）。I と IV の長三和音だけ → すべてをドミナント 7th にする → 最後の 4 小節に IV–V–I を加える → 最後の 4 小節を **V–IV–I** に変える。
★ **逆方向の終止はブルース固有の特徴**。

**変化をつけられる 3 箇所**（p0192–0193）は、和声リズムの弱い位置、和声機能が切り替わるつなぎ目、コードとコードの間。小節ごとのよくある変化は次のとおり（p0193–0195）。

| 小節 | 変化 |
|---|---|
| 2 | I7 → IV7 |
| 4 | I7 → III-7♭5（ルートを省いた I9 と同じ） |
| 5 | IV7 の後に I7 を加える |
| 6 | IV7 の後に **♯IV°7**（IV7 に ♭9 を加えてルートを省いた形と同じ）を加える。次に第 7 小節の I7 を転回し、第 5 音をベース音にして、IV → ♯IV° → I/5 のベースを**半音ずつ上行**させる |
| 8 | 第 9 小節の最初のコードで何を加えるかが決まる。II-7 なら V7/II、IV7 なら III-7♭5 を加える |
| 9–10 | II-7 – V7 – I7 – ♭VII7 に変えられる |
| 11–12 | セカンダリー・ドミナントやエクステンデッド・ドミナントを加える |

★ **ブルースかどうかは曲式から切り離して判断する**（p0196）。I7、IV7 とブルーススケール（1 ♭3 4 ♯4 5 ♭7）を使えばブルースになる。**12 小節に限らず**、8 小節や 16 小節もよくある。

テンションについては、**I7、IV7、V7 のいずれでも 11th は使えない**。I7 では ♭3 を ♯9 として使える（p0189–0190）。
ハーモニーと音階の間に生じる短二度の衝突こそがブルースらしい響きで、`mc-melody` reference §4 の説明とも一致する。
`mc-style-rock-band` と `mc-harmony` はどちらもここから骨格を取っている。

## 4. Comping（伴奏）

**Comping の目的は、即興奏者のために余白を残すこと。**

| 原則 | 説明 |
|---|---|
| **隙間を埋め尽くさない** | ★ ポップスの伴奏との最大の違い。ポップスの伴奏はテクスチャの中で安定した位置を占める。comping は**入ったり抜けたりする** |
| **下地を敷き続けるより、演奏に応答する** | 即興奏者が直前に弾いたフレーズを聴き、それに応答する |
| **ヴォイシングからルートを省く** | 低音はベースに任せる。**第 3 音と第 7 音が骨格**（guide tones） |
| **Sus コードの音の配置** | Levine は専用の節（p0064）を設けている。「解決しない」響き |

★ **応用時の注意**（§2）。**comping のリズムはポップスに応用できない**。
ポップスには即興奏者がいないため、残した余白が音の抜けた箇所になる。

---

### 4.1 ガイドトーンのライン：内声の書き方（陈云强 p0093–0096）

§4 では第 3 音と第 7 音が骨格だと述べた。ここではそのつなぎ方を示す。

**特徴音**。七の和音では第 3 音と第 7 音、シックスコードでは第 3 音と第 6 音。**ディミニッシュセブンス、ハーフディミニッシュ、オーギュメントセブンスなど、第 5 音が変化したコードでは第 5 音も特徴音になる**。

**連結のルール**。ルートが五度、四度、三度で動くときは **3 → 7 または 7 → 3**。ルートが順次進行する、三度で動く、または同じ音にとどまるときは、**3 → 3 または 7 → 7** と同方向に動かす（三度の場合はどちらの方法も選べる）。

ラインが単調になったり、声部が高すぎたり低すぎたりするのを防ぐ**4 つの調整方法**がある。ルートまたは第 5 音を加える（必要に応じて使えるテンションも加える）。コードが持続している間にオクターブ跳躍する。コードの持続中に第 3 音と第 7 音を入れ替える。ひとまとまりのハーモニーが終わったら、次の開始音を決め直す。

★ **ジャズ以外でも使える**。内声や対位法的なラインを書く方法なので、副旋律にも応用できる。All The Things You Are のメロディは主にガイドトーンのラインでできている。
`mc-counterpoint` §3 では声部間の相対的な動きを扱い、ここでは音の選び方を扱う。

## 5. 曲形式：Head–Solos–Head

```
Head（テーマ、1回または2回）
  → Solo 1（head のコード進行を数回繰り返す）
  → Solo 2 …
  → （4s / 8s：ドラマーと交互にフレーズを演奏する）
  → Head（もう1回）
  → エンディング（tag / フェードアウト / 定型の終わり方）
```

★ **ポップスの曲形式との根本的な違い**：
- **ポップスの構成は「内容の並び」**（Aメロではこの話、サビではあの話）
- **ジャズの構成は「同じコード進行を何周もする」こと**で、即興演奏者が周回ごとに内容を作る

**したがって、ジャズでは `form[].bars` の意味が異なる**。
セクション全体の長さとは区別し、「1 chorus が何小節か」を表す（32小節のAABAが標準）。

**よくある head の形式**：AABA（32小節）、ABAC、12小節ブルース。
既存曲は Fake Book を参照（付録「出典」）。

## 6. Bebop のフレーズ作法

Valerio による整理。

| 要素 | 要点 |
|---|---|
| **和声の基礎** | テンション（Extensions）＋ オルタレーション（Alterations） |
| **三和音と七の和音のかみ合わせ** | アッパー・ストラクチャー・トライアドで複雑なコードを表現する |
| **和声と旋律の即興** | 即興の旋律そのものが和声を示す |
| **リズム** | — |
| **フレージング（Phrasing）** | — |
| **アクセント（Accents）** | ★ bebop の特徴の一つは**裏拍にアクセントを置くこと** |
| **旋律の輪郭（Contour）** | — |

**歴史の流れ**：Ragtime → Blues → Swing → Bebop。
★ この流れを知っておくと、**「ジャズ」という言葉が時代ごとに異なる音楽を指す**ことが分かる（§1①）。

## 7. ★ 実測：ジャズとポップスの編曲の違い

**Cambridge-MT のコーパスで、jazz-acoustic 10曲を他のジャンルと比較。**

| 指標 | jazz-acoustic | pop | rock | hiphop-rnb |
|---|---|---|---|---|
| **roster の規模（中央値）** | ★ **22トラック** | 36 | 30 | 37 |
| **曲のセクション数（中央値）** | 9 | 10 | 10 | 9 |
| **冒頭から鳴っている楽器の割合** | **16%** | 21% | **8%** | 24% |
| **途中から加わる楽器の数** | ★ **20** | 29 | 26 | 26 |
| **曲が終わる前に抜ける楽器の数** | ★ **10** | 16 | 18 | 28 |

**データから読み取れる3点**：

1. ★ **ジャズの編成は明らかに小さい（22 vs 36）**。
   理由の一つは**同時録音**で、オーバーダビングが少ないこと。
   **この手法は転用できる**。少人数の編成で各楽器に役割を持たせることは、ポップスに取り入れられるジャズの手法の中でも特に価値が高い。
2. ★ **楽器が加わる回数も抜ける回数も、ジャズが最も少ない（20入り / 10抜け）**。
   編成の入れ替えに頼らず、**同じ奏者が演奏内容を変える**ことで変化をつける。
3. **曲が終わる前に抜ける楽器が最も多いのは hiphop-rnb（28）**。最も「引き算」の多いスタイル。

> ⚠ **信頼できない指標**：BPM。jazz の検出結果は中央値117、範囲74–162だったが、
> スウィングのグルーヴでは beat tracking がテンポの倍数を誤検出することが知られている。**この数値は引用しない。**

- [ ] ポップスにオルタード・ドミナントやディミニッシュ・スケールの lick を持ち込んでいない（意図的にジャズらしさを出す場合を除く）
