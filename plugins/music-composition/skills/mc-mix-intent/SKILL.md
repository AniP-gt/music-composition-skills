# ミックスの意図（Mix Intent）

**このスキルでは、ミックスで実現したいことを言葉にする。**

両者を区別することが重要。
- 「ボーカル 3 kHz +2 dB」は**パラメーター**。DAW でしか実行できず、別のバックエンドでは使えなくなる
- 「最も音が密なサビでも、ボーカルがいちばん明瞭に聞こえること。ボーカルにスペースを譲るのはパッドで、ギターはそのまま聞かせる」は**意図**。
  エンジニアと DAW が実現でき、テキストベースのバックエンドでも一部を反映できる。受け入れ確認では項目ごとに照合できる

**本パッケージが提供するのは、意図を記した `mix_intent` まで。** EQ の周波数、コンプレッサーのレシオ、マスタリングチェーンはミックス工程で扱う。

## 1. 書き始める前の必須項目

| 必須項目 | 記入内容 |
|---|---|
| **① ムード** | このミックスが伝えるものを一文で書く。**最初に書き、以降の判断がこれに反する場合は見直す** |

## 2. 5 つの領域と音場

ミックスで扱う主な領域は **5 つ** (p0089)。

| # | 領域 |
|---|---|
| 1 | **時間（Time）** |
| 2 | **周波数（Frequency）** |
| 3 | **レベル（Level）** |
| 4 | **ステレオ（Stereo）** |
| 5 | **奥行き（Depth）** |

> **ステレオと奥行きが合わさって「空間（Space）」を作る** (p0089)。

**音場（Sound stage）**
> ミックスは**想像上の音場**に展開する。各楽器には**左右（ステレオ）**と
> **前後（奥行き）**の位置がある (p0089)。

**音場図 1 枚と、5 領域それぞれの方針を示す一文**があれば、ミックスエンジニアは作業に着手できる。

**左右と前後の定位の手がかり**（Howard & Angus）
- パンポットで付けられるのは**レベル差**（p0112）。レベル差は主に高域の定位に、時間差は主に低域の定位に効く。
  **700 Hz–2.8 kHz は 2 つの手がかりの移行帯域で、定位が最も曖昧になる**（p0108）。
  → 低域の要素では pan がほとんど効かないので、中央に置けばよい。楽器の位置を明確にするには 3 kHz 以上の成分が必要。
  この考え方が当てはまらない条件はヘッドホンでのモニタリング（頭内定位、p0109）。
- 前後の手がかりは直接音と残響音の比率と時間差（p0261、p0264）。30 ms 以内に届く遅延音は別の音として聞こえず、
  先行音の位置に定位する（先行音効果、p0110）。初期遅延 10–20 ms は自然な前後感を生み、50 ms ではエコーとして聞こえる（p0346）。
  → 奥行きは「近／中／遠」の 3 段階で記述し、ミリ秒は指定しない。

**ミックス全体と個別パートの処理** (p0089)

| | 対象 | 例 |
|---|---|---|
| **マクロなミックス** | ミックス全体に影響する要素 | ミックスの周波数バランス |
| **ミクロなミックス** | 楽器パートごとの処理 | ボーカルが自然に聞こえるか |

**本スキルでは主にマクロな方針を書く。** 個々の処理はミックスエンジニアの判断に委ね、編曲仕様書で固定しない。

## 3. 4 つの目標

ミックスには **4 つの基本目標**がある (p0089)。

| # | 目標 |
|---|---|
| 1 | **ムード（Mood）** |
| 2 | **バランス（Balance）** |
| 3 | **明瞭さ（Definition）** |
| 4 | **面白さ（Interest）** |

> **ミックスを評価するときは、まず主要領域での一貫性と魅力を確認し、その後で各目標の達成度を分析する** (p0089)。

### 3.1 ★ ムードを最優先する

> ムードとは、ミックスが楽曲に含まれる**感情**を表現できているかどうかを指す (p0090)。

曲のムードを損なう 2 つの例 (p0090)
- **強いコンプレッション、極端な EQ、耳障りなディストーション、強すぎるスネアのアタック** → **しっとりしたジャズ**の持ち味を損なう
- **甘い響きのボーカルリバーブ、まとまりすぎたドラムセット、穏やかなギター** → **怒りに満ちたヘヴィメタル**の持ち味を損なう

2 つ目の例では、**個々の処理は「よいミックス」の特徴**に見えても、組み合わせると曲に合わない。
**技術的な出来と、曲の感情を表現できているかは別の判断になる。**

> **特定のジャンルを得意とするミックスエンジニアは、ほかのジャンルでは十分な結果を出せないことが多い** (p0090)。

生成モデルも、特定のジャンルを得意とするエンジニアのように、
入力を学習データで最もよく見たバランスに寄せる傾向がある。
そのため `mix_intent.mood` は明記し、**prompt の前のほうに置く**。

### 3.2 明瞭さ

> **明瞭さは、音がはっきり聞こえ、何の音か判別できるかを表す** (p0090)。

仕様書では §1③ の**セクションごとの主役**として、どの要素が聞き取れる必要があるかを書く。

明瞭さは音の分離の一部で、楽器の音を聞き分けられるか（聞き取りやすさ）、自然に聞こえるかで判断する。音量との関係は小さい (p0260)。たとえば、水底から聞こえるようなピアノ録音や、基本となる高域成分を欠いたハイハットは、レベルが適切でも明瞭さを失っている (p0260)。

「楽器のレベルが高いほど明瞭に聞こえる」と考えられがちだが、これは楽器の周波数特性に問題がないときに限る (p0100)。帯域に欠落がある楽器は、レベルを上げても音が大きくなるだけで、明瞭さは改善しない (p0100)。パートが不明瞭なら、ラウドネス不足と帯域の欠落のどちらが原因かを先に見極め、レベルを上げるか判断する。

### 3.3 面白さ

面白さは**バランスを崩すこと**から生まれる場合がある（§4.3）。それは極端な手法の一つで、根底には聴覚の順応がある。音が長く変化しないと注意が薄れ、変化があると再び耳を引く (p0091)。Aメロとサビの反復、トラックのダブリング、楽器編成の変更は、いずれも変化を作って注意を保つ方法だ (p0091)。

ミックスでも、編曲の構成に変化を加えられる。具体的なパラメーターの指定は避け、「どのセクションにその変化があるか」を記す (p0092)。
- 特定のセクションだけ、オートメーションであるパートのレベルを上げる
- 特定のセクションだけ楽器を加える（例として、Aメロが繰り返されるときだけトランペットを入れる）
- 同じ楽器でもセクションごとに処理を変え、明るさに変化をつける
- サビでは全体に強めのコンプレッションをかけ、ベースの歪みを許容する
- セクションごとにスネアのリバーブを変える

変化の度合いはジャンルによる。アンビエントでは、耳を引きすぎずに興味を保つ。trance は同じテーマの反復が軸なので、飽きさせないために変化をより細かく作る (p0092)。

変化はセクションごとに `focus_by_section[]` に書く。意図的にバランスを崩す箇所は `deliberate_imbalance[]`（§4.3）に記し、どちらも曲全体に一律の状態として指定しない。

## 4. バランスを取る 3 つの領域と、奥行きの一貫性

### 4.1 バランスを取る 3 つの領域 (p0090)

1. **周波数バランス**。中高域が不足すると、ミックスが濁ってぼやけ、音像も遠く感じられる (p0090)。数値目標を設ける代わりに、「濁る」「ぼやける」「遠く聞こえる」という 3 つの聴感を中高域不足の目安にする。

2. **ステレオ定位のバランス**。レベルと周波数の両面でバランスを取り、楽器全体の配置ができるだけ左右対称になるようにする（ギター、シェイカー、コーラスなど）(p0252)。ここでのバランスは**全体**の音像分布を指す。個々の楽器は中央に置く必要がなく、中央はむしろ明瞭さが最も低い位置になる（§2 の定位の手がかりを参照）。

3. **レベルバランス**。着目するのは**相対レベル**。各楽器がほかの楽器に比べてどれくらい大きく聞こえるかを評価する。モニター全体の音量を上げても、楽器同士のレベル差は変わらない (p0097)。相対レベルは通常、その時点での楽器の重要度に合わせ、曲の進行に応じて変える。たとえば、リードギターのレベルは伴奏時よりソロ時のほうを高くする (p0098)。
   打音をすべて同じレベルにそろえると、演奏の強弱による音色の変化が失われ、ドラムセットが「ドラムマシン」のように聞こえる。レベルバランスを取るときも、打音ごとの強弱は残す (p0388)。

### 4.2 ★ 奥行きはグループ内でそろえる

> **奥行きで求められるのは一貫性** (p0090)。

> たとえば、**キックが顔のすぐそばで鳴り、スネアが隣の家から聞こえるほど遠い**と、
> ドラムセット全体の**奥行きが極端に不自然になる** (p0090)。

**グループ全体を手前にも奥にも配置できる。同じ音源グループの中では奥行きをそろえる。**

**確認方法**。ドラムセット、キーボード群、弦楽器群といったグループごとに各楽器の奥行きを並べる。
**グループ内の差がグループ間の差を上回る場合は修正する。**

物理的には「同じグループ」とは、同じ初期反射と残響の尾を共有することを指す。音像の位置によって初期反射は異なってよいが、
残響の尾の減衰率は同じである必要がある（Howard & Angus p0348–0350）。

### 4.3 バランスを崩してよい 2 つの場合 (p0090)

1. **創造的な音響効果を作る**
2. **曲に面白さを加える**

> Delgados の『The Past That Suits You Best』では、ミックスエンジニアの Dave Fridmann が、
> **ドラムセットとボーカルの音像を完全に片方のチャンネルに寄せ**、左右非対称で魅力的な効果を作った (p0090)。

> **面白さを生むアンバランスは、通常、一時的な処理**。たとえば、ダンス曲の華やかな見せ場で一部の低域信号を倍にする (p0090)。

**「通常、一時的」という点が重要**。バランスを意図的に崩す処理は特定の箇所に限定する。
曲全体にわたってバランスが崩れている場合はミスとして扱う。

`mix_intent.deliberate_imbalance[]` に、**開始・終了小節**と**理由**を書く。小節範囲の記載がないアンバランスは、すべてミスと見なす。

## 5. マスキング：パッドがドラムより問題になりやすい理由

> **マスキングの基本原則**。ラウドネスの高い音は低い音を覆い隠す。
> ある楽器の周波数帯域は、別の楽器の周波数帯域をマスキングすることがある (p0038)。

**時間の領域**では、ここから次のことが言える。

> - **打楽器（キックなど）は発音が短く、マスキングの影響は小さい**
> - **持続音の楽器（ノコギリ波のパッドなど）は周波数帯域とステレオ空間を占め続けるため、マスキングの影響が大きい** (p0038)
> - ★ **音が密なパッドのレベルを上げると、キックのレベルを上げるよりもマスキングが増える。
>   パッドがキックを覆い隠し続けることが大きな問題になる** (p0038)

Howard & Angus はその仕組みを次のように説明している。
- **マスキングは高域側に広がる。低域は高域を覆い隠しやすい**。高域が低域を覆い隠す効果ははるかに弱い（p0239）。
  → パッドの低域はキックだけでなく、それより上の帯域も覆う。まずはパッドの低域に空きを作る。
- マスカーがある臨界帯域では、マスキング閾値はマスカーのレベルより約 20 dB 低いだけ（p0240）。
  → スペースを譲るには、同じ帯域で 20 dB 以上低くする。3 dB 下げる程度では音がぼやける。
- **時間マスキング**。大きな音が止まってから 100–200 ms 以内は、小さな音の立ち上がりがまだ聞こえない。逆方向（後方マスキング）は約 10 ms と短く、ほとんど生じない（p0241）。
  短い打音自体も、持続時間に応じてラウドネスが下がる。200 ms 以内では短い音ほど小さく聞こえる（p0095）。
  → **ボーカルや hook が crash／fill の直後に入る場合は、≥ 200 ms の間を空けるか、最初の音自体を十分な音量にする。**
  各主役パートの入りを確認し、直前の 200 ms 以内に、より大きな音が鳴り終わっていないかを調べる。

音が濁るときは、**打楽器より先に持続音を確認する**。
ドラムが大きすぎると思いがちだが、鳴り続けているパッドや下支えのギターが原因である可能性のほうが高い。

**まず編曲の段階でパッドの低域に空きを作る**（編曲を書き換える方法は `mc-texture-layering`）。
**サイドチェインでパッドを下げるミックス処理は、編曲で解決できないときに使う。**

## 6. リファレンストラックによる基準合わせ

### 6.1 6 つの使い方 (p0051–0052)

| 使い方 | 説明 |
|---|---|
| **手本としてまねる** | 優れた練習法だが、**「模倣は創造の最大の敵」**。作品の種類が違えば、そのまままねても通用しない |
| **発想の材料にする** | ミックスを**始める前**に聴き、方向性を探る |
| **行き詰まりを解く** | 自分のミックスとリファレンスの**違い**を調べる |
| **完成時の比較に使う** | 仕上がったミックスと周波数特性やレベルを比較する |
| **耳の基準を合わせる** | 慣れない環境では、よく知っているリファレンスを先に流し、スピーカー、部屋、座る位置による聞こえ方を把握する |
| **スピーカーを評価する** | 販売店で流している流行曲より、自分がよく知っている曲のほうが判断しやすい |

### 6.2 選び方と注意点

- リファレンストラックは**ミックスの種類に合わせる**。弦楽器のミックスには弦楽器を含む曲、chill-out には同系統の曲を選ぶ (p0051)
- MP3 ではなく**可逆圧縮形式または非圧縮形式**で保存する (p0051)
- すばやく比較できるよう、**聴き比べる箇所を事前に選んでおく**。**ミックス前のトラック**を加えてもよい (p0051)
- ★ **マスタリングの影響に注意する** (p0052)。マスタリング済みのリファレンスは、相対レベルがそろい、コンプレッションが強いため、通常はダイナミクスが詰まっている。また、アルバムで**最も条件の悪い曲**に合わせて周波数特性が調整されている場合がある
- ★ **比較する前にラウドネスをそろえる**。等ラウドネス曲線の形は音圧レベルで変わる。音量を下げると、中域に比べて低域と高域が聞こえにくくなり、音が薄く暗くなる（Howard & Angus p0091）。音圧レベルが +10 dB になると、ラウドネスは約 2 倍になる（p0094）。
  少し大きいほうがほぼ常によく聞こえるため、音量差がミックスの比較結果を左右しないようにする。

完成音源から指標を逆算する際、測定できるダイナミックレンジは**マスタリング後**の値。
その値を目標にすると、一貫してダイナミックレンジを狭く見積もることになる。
同様に、リファレンスの測定前にはビットレートと高域のカットオフを確認する。非可逆圧縮では高域が削られるため、異なるビットレートのファイル同士は単純に比較できない。

## 7. バックエンドごとの対応範囲

| バックエンド | 対応できる内容 | 対応できない内容 |
|---|---|---|
| **Suno / MiniMax** | ムードと全体の質感を表す言葉（`warm`、`dry`、`wide chorus`） | 音場図、ducking_map、セクションごとの奥行き |
| **YuE2** | 同上。セクション単位でより細かく指定できる | 正確な定位と奥行き |
| **MIDI / DAW** | すべて。direction sheet としてそのまま使える | — |

**★ 評価ルール**。バックエンドの profile で `honors: none` とされている項目は、
**反映率の集計対象から除外し、0 点を付けない**。
そうしないと、定位に対応できないと正直に申告したバックエンドが、対応できると装ったバックエンドより低い点になり、評価がゆがむ。

## 9. 記入後の必須チェック

- [ ] `mood` を**一文**で書き、後続の判断と矛盾していない
- [ ] 周波数を含む 5 つの領域に**一文ずつ**書いた
- [ ] 音場図で各楽器に**左右と前後**の 2 つの値を付けた
- [ ] **同じグループ内で奥行きがそろっている**（ドラムセット内、弦楽器群内）
- [ ] 各セクションで**最も明瞭に聞かせる要素**を書いた
- [ ] バランスを崩す箇所ごとに**開始・終了小節と理由**があり、曲全体への指定になっていない
- [ ] 音の濁りを診断するときは、ドラムより**先に持続音を調べた**
- [ ] 各主役パートの入りの直前 200 ms 以内に、より大きな音が鳴り終わっていない（§5）
- [ ] 低域の要素を中央に定位させ、リファレンス比較時にはラウドネスをそろえた（§2、§6.2）
- [ ] 作曲段階で解決できる競合は **`mc-texture-layering` で解消済み**で、ミックスに持ち越していない
- [ ] リファレンストラックを少なくとも 1 曲選び、**何を参考にするかを明記した**
- [ ] EQ の周波数やコンプレッサーのレシオは、ミックス工程で決める項目としてこのファイルへの記載を省いた
