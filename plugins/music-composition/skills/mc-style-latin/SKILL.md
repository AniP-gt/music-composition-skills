# ラテンのスタイルレイヤー（Latin）

**このスタイルレイヤーの3本柱は、適切な系統を先に選ぶこと、claveをリズムの文法とすること、グリッドをベル類に任せること。ドラムはグリッドを担わない。**

★ **「ラテン」には、混同できない3つの系統がある。**
『The Drummer's Bible』はブラジルの章の冒頭で、**ブラジルとAfro-Cubanを混同しないよう明言している。
それぞれに固有の特徴とリズムがあるため、「Latin」と指定された曲では、まずどの系統のリズムを演奏するかを確認する**（p0059）。
このスキルでは系統の選び分けを扱う。具体的なドラムパターンは別途参照する。

## 1. 書き始める前に必ず埋める項目

| 必須項目 | 確認内容 |
|---|---|
| **① どの系統か** | ★ Afro-Cuban／ブラジル／カリブ／ラテンロック。**4つから1つ選んでから次に進む**（§8） |
| **② 系統内のどのスタイルか** | Afro-Cubanはson-salsa／mambo／cha cha／songo／mozambique／guaguanco／6-8 bembe、ブラジルはsamba／batucada／bossa／baião、カリブはcalypso／soca／ska／reggaeに分かれる |
| **③ どのclaveを、どちらの側から始めるか** | ★ sonかrumbaか、2-3か3-2か。**これを決めると、全パートの2小節パターンの向きが決まる**（§3） |
| **④ 実際のパーカッション奏者がいるか** | ★ 役割分担を決める。いなければ、ドラマー1人でconguero、timbalero、bongo bellの3人分を担う（p0029）。奏者が複数いる場合は、各自が意識して音数を減らす（p0099、p0103、p0109） |
| **⑤ 本来のスタイルで作るか、別の曲に応用するか** | そのスタイルを本来の形で作るか、表面的な特徴をポップスの編曲の彩りに使うか。★ §2の応用可否の表の使い方が決まる |

## 2. ★ 他のスタイルへの応用可否

| 手法 | 応用できるか | 説明 |
|---|---|---|
| **baiãoの付点8分＋16分のキック** | ✅ **そのまま応用でき、すでに広く使われている** | Charlestonにも、多くのhip-hop grooveにも使われる基本形（Groove Essentials p0095）。別のスタイルで使ってもブラジル音楽には聞こえない |
| **ブラジル式の「第4拍の裏で先取る」** | ✅ 応用可 | 第4拍の「+」で先取るのはブラジル音楽によくある特徴（Jazz Guitar Groove p0037）。先取りそのものは共通レイヤーで扱う（`mc-rhythm-groove` §3） |
| **bossaのコード切り替えのタイミング** | ✅ ★ **応用でき、効果も大きい** | 奇数小節は頭で、偶数小節は半拍前でコードを変える（藤谷 p0104）。どんな曲でも、この切り替え方をそのまま使うだけでbossaらしさが出る |
| **「各小節の最後の16分音符をきれいに切る」** | ✅ 応用可 | songoの特徴（Groove Essentials p0104）。同書は、ラテンに限らず16分音符を基調とする音楽の重要な特徴と明記している |
| **conga／tumbaoの2小節ループ** | ⚠️ 一部応用可 | パーカッションの土台には使える。claveとbellを合わせると、セクション全体がAfro-Cubanに聞こえる |
| **cascara／palitoのパターン** | ⚠️ 一部応用可 | 「claveの反対側を補う」パターン（p0034、p0048）。claveから切り離すと、シンコペーションした16分音符のラインだけが残る |
| **Cha Cha bellの4分音符の連打** | ❌ **基本的に応用不可** | スタイルを強く特徴づけるため、鳴った瞬間にcha chaに聞こえる（p0038） |
| **Mambo bell / Mozambique bell** | ❌ 応用不可 | bellのパターン自体が、この2つのスタイルを特徴づける（p0037、p0108） |
| **claveそのもの** | ❌ ★ **応用不可** | 全声部の向きを支配するリズムの文法（§3）。ラテン以外の曲にclaveだけを足すと、かみ合わない2小節ループになる |
| **one drop（第3拍でリムとキックを同時に打つ）** | ❌ 応用不可 | 鳴った瞬間にreggaeに聞こえる（p0074） |
| **「パーカッション奏者と共演するときは音数を減らす」という原則** | ✅ ★ **応用でき、取り入れる価値がある** | §4.3を参照。ラテンから一般の編曲に応用できる工夫のうち、最も価値が高い |

★ **判断基準**：
> **応用できるかどうかは、claveに依存するかで判断する。**
> claveに依存する手法（bellのパターン、cascara、tumbaoの向き）は、切り離すと機能しない。
> claveに依存しない手法（キックの付点パターン、先取りのタイミング、音数を減らす原則）は自由に応用できる。

## 3. ★ claveはこのレイヤーのリズムの文法

### 3.1 claveとは

Claveはスペイン語で「key」。ピアノの鍵盤のkeyを指し、錠を開ける鍵のllaveとは異なる（p0030）。
定義上は**2小節のリズムパターン**で、3音の「3」側と2音の「2」側に分かれる。
**どちらの側からも始められる**ため、3-2と2-3の2通りがある。ほとんどのAfro-Cubanのリズムの土台になる（p0012）。

★ **編曲での役割**。claveはパーカッションの1トラックを足すかどうかという話ではなく、
**ほかのすべての2小節パターンの向きを決める文法である。**

### 3.2 sonかrumbaか

| | son clave | rumba clave |
|---|---|---|
| **「3」側の最後の音の位置** | ★ **第4拍の表** | ★ **第4拍の「+」** |
| **唯一の違い** | 上の行のとおり（p0030） | |
| **よく使うスタイル** | 比較的伝統的な系統。Mambo、Cha Cha（p0013） | 比較的現代的な系統。Songo、Mozambique（p0013） |

**判断基準**。スタイルを先に決めればclaveの種類も決まるため、別途当てずっぽうで選ぶ必要はない。
Guaguancoは3-2 rumba（p0036）、Mamboは2-3 son（p0037）。
MozambiqueとSongoはともに2-3 rumba（p0039、p0040）。Pilonは2-3 sonを土台にする（p0049）。

### 3.3 2-3か3-2か

**判断基準**。合奏のフレーズがどちらの側から始まるかを見る。
Mamboは「2」側でも「3」側でも始められる（p0037）。Guaguancoは通常「3」側から始まる（p0036）。
つまり、音楽学の問題というより、**フレーズの始点をどう記譜するかの問題**である。
先に旋律と合奏のパターンを書き、claveのどちら側を最初の小節に合わせるか決める。

★ **向きを反転させるときは、2小節パターンをすべて一緒に反転させる。**
claveに対するcascaraとpalitoの各音の位置は決まっており、
**3-2でも2-3でも、claveとの対位関係は変わらない**（p0034、p0048）。
claveを反転するときは、そのトラックだけでなく、2小節パターンのグループ全体を反転する。

### 3.4 claveに沿うとはどういうことか

編曲時は、次の3つの打点を確認する。

| 名称 | 位置 | 用途 |
|---|---|---|
| **bombo** | ★ claveの「3」側の**第2拍の「+」** | キックの最も伝統的な打点。キューバらしさを強めるなら、キックをこの打点だけに絞る（p0035）。Guaguancoでもここを強調する（p0036） |
| **ponche** | 4/4小節の**第4拍**のアクセント | つなぎに使うパターン（p0013） |
| **各小節の最後の16分音符** | きれいに切る | songoの特徴であり、16分音符を基調とする音楽にも共通する原則（Groove Essentials p0104） |

**沿っている場合**。各2小節の反復パターンのアクセントが、claveと同じ側に来る。
**かみ合っていない場合**。パターンのアクセントが反対側に来る。
典型例では、**bomboの「+」が2音しかない側の小節に入る**。
すると低域の重心がclaveの3音側と反対になり、セクション全体がかみ合わなく聞こえる。
> ⚠ ラテン音楽ではこのずれをcruzadoと呼ぶ。**底本にはこの用語の説明がない**。上の判断基準は、
> 「palito／cascaraとclaveの対位関係は一定である」（p0034、p0048）という記述から逆に導いたもの。

### 3.5 claveを書かない場合

- **songoで足で踏むrumba clave**。グルーヴが安定する前に加えると、全体のまとまりを崩す（p0040）。
  ★ 一般化すると、**グルーヴを安定させてからclaveを加える。安定させるためにclaveを足さない**。
- **もともとclaveを使わないスタイル**。Bomba（p0042）、Cumbia（p0047）、Plena（p0050）では通常claveを演奏しないため、無理に足さない。
- **Pilon**。claveは土台にあるが、通常はドラマーが演奏するものではない（p0049）。

### 3.6 6/8の系統

Afro-Cuban 6/8は3拍子の感覚を基礎とし、ナイジェリアのヨルバ人に由来する。キューバではBembeやAbakwaと呼ばれることが多い（p0013、p0031）。
**独自のclaveとbellパターンがある**（p0012）。bellパターンは6/8 claveと同じ形に
2音を加えたもので、その2音はほかの音より弱く打つ（p0032）。

★ **記譜の判断**。曲中の4/4のセクションと相互に換算したい場合は、4/4の3連符のまとまりとして記譜する。
**同書によれば、この記譜法の目的は4/4のキューバのclaveとの関係を示すことにある**（p0031）。
演奏者に3拍子でフレーズを捉えてほしい場合は6/8で書く。
拍の数え方がこの系統の主な難所であり、Groove EssentialsはNañigoを「6対4で拍を数える問題」と呼んでいる（p0106）。

## 4. ★ グルーヴの役割分担：何を誰が担うか

### 4.1 4つの役割

| 役割 | 担うもの | 根拠 |
|---|---|---|
| **conga tumbao** | conga の標準的な反復パターン。主に高音の太鼓 quinto で叩く | p0013 |
| **bass tumbao** | ★ **Afro-Cuban のベースの基本パターン**。ドラムセットが入る場合は、**通常キックがアクセントを重ねて補強する** | p0013 |
| **piano montuno** | ピアノで反復するシンコペーションのパターン | p0013 |
| **timbale cascara** | 胴を叩く2小節のパターンで、**clave の反対側を補う**。palito に由来し、もとは中をくり抜いた竹の gua gua を叩いていた | p0012、p0048 |
| **ベル類（bell）** | ★ **持続するパルスでグリッドを支える** | §4.2 |

### 4.2 ★ グリッドを支えるパート

**ラテンでグリッドを支えるのは、手で叩く太鼓よりもベル類と足で鳴らす音。**

- Cha Cha を特徴づけるのは cha bell の**絶え間ない4分音符**で、hi-hat が同じリズムを重ねることが多い（p0038）
- 6/8 の hi-hat は**表拍ごとに足で1回踏む**（p0033）
- Merengue、Soca、Ska は four on the floor のキックをパルスにする（p0042、p0072、p0073）
- Plena を強く特徴づけるのは**シンプルな4分音符のキック**（p0050）

★ **これが重要な理由**。clave は2小節にわたるシンコペーションで、グリッドの表拍から外れる。
**表拍を鳴らし続けるパートがなければ、clave の基準がなくなり、拍を外した音が続くだけに聞こえる。**
`mc-style-citypop-rnb` §4.1 の「グリッドを支えるパートがあって初めて前ノリが成立する」と同じ原理が、別の形で現れている。

### 4.3 パーカッション奏者に合わせて音数を減らす

底本で繰り返し述べられているので、ルールとして覚えておきたい。

| 状況 | やり方 | 根拠 |
|---|---|---|
| パーカッション奏者がいない | ドラマー1人で conguero、timbalero、bongo bell の3役を担う。手足を高い水準で独立させる必要がある | p0029 |
| パーカッション奏者が1人 | 音数の少ない変形を選ぶ（Cha Cha、Mambo、Merengue にはいずれも「conga 奏者と演奏するときに使う」簡略形がある） | p0038、p0043、p0100 |
| パーカッション奏者が複数 | ★ **自分から音数を減らして場所を譲る**。Merengue の説明が最も明快で、自分の音を控えめに減らし、他のパートを邪魔しない | p0099、p0109 |
| 複雑な掛け合いを整理できない | **bell のパターンだけを叩く**。Mozambique の要はもともと bell なので、tom の掛け合いが乱れるなら、まずそこを省く | p0108 |

★ **この4つのルールは、どの編曲にもそのまま使える**。**編成が密になるほど、奏者一人ひとりの音数を減らす。**

### 4.4 拍に先行する演奏について底本が述べていること

- **ブラジル系では明確な先取りがある**。第 4 拍の「+」で先取りするのは、ブラジル音楽によくある特徴（Jazz Guitar Groove p0037）。
- **bossa では和声パートがコードを先取りする**。ギターとエレピは偶数小節で半拍早くコードを変え、
  **ベースは常に拍の頭で切り替える**（藤谷 p0104）。
- **Afro-Cuban ではキックとベースが同じラインを二通りに担う**。キックはベースの tumbao を支え、**ユニゾンすることも、分担することもある**（p0037）。
  Cumbia のキックの反復パターンは、通常ベース奏者のパターンにそのまま合わせる（p0047）。Samba では足で surdo を模倣しながらベース奏者に合わせる（p0059）。

> ⚠ **「salsa のベースは必ず前のコードが鳴っているうちに次のコードを先取りする」という説は、底本の記述範囲外。**
> 根拠が確認できるのは上の3項目。`groove.push_pull` はこの3項目に沿って書き、出典が確認できないミリ秒値は記入しない。

★ **そのまま使えるルール**。Afro-Cuban の `arrangement.bass_kick_relation` は**連動型が標準**。
（キックがベースの tumbao にアクセントを重ねる。p0013）。city pop のように互いの隙間を埋める方式とは対照的。

## 5. ブラジル系

### 5.1 surdo が低域の土台

ブラジル系のドラムセットでは、足のパート（主にキック）で**大型の太鼓である surdo を模倣**しながら、ベース奏者に合わせる（p0059）。
Batucada ではさらに、**ride を叩く手をフロア tom に移して surdo の音を再現する**。ミュートした打音も含む（p0061、Groove Essentials p0097）。

★ **編曲への落とし込み**。**ブラジル系の低域は、1台の大太鼓をドラムセットの複数の音に振り分けたものと考える。**
低域を書くときはまず「これは surdo のどの打音か」を考え、そのあとで何拍目に置くかを決める。

### 5.2 partido alto

Partido Alto はブラジルで最も人気のある samba の系統の一つであり、samba と bossa の両方で使われるリズムパターンでもある。
伝統的には agogo、cuica、pandeiro、tamborim で叩き、ドラムセットでは通常スネアで演奏する（p0013）。
Samba の手の動きはこれを軸に組み（p0059）、Batucada ではスネアで叩く（p0061）。Bossa のリムを叩くパターンの変形の一つにも使われる（p0064）。

★ **判断基準**。**3つの系統では同じ partido alto でも、楽器と強弱を変えることでスタイルが変わる。**
何のスタイルかを示すのは、**そのパターンを鳴らす楽器と強弱**。

### 5.3 bossa の「軽さ」はどこから来るか

出典で確認できる要素は3つあり、すべてそろって初めて成立する。

| 要素 | 具体的な内容 | 根拠 |
|---|---|---|
| **ドラムの音色と奏法** | ★ **ドラムセットは控えめな音色**にし、派手なロック向けのセットは避ける。**クローズドリムショットが主な奏法**なので、リムの音がよいドラムを選ぶ | 藤谷 p0105 |
| **タッチと余白** | ★ **軽く触れ、間を空ける**。double-time をほのめかす場合はごく繊細に扱う | Groove Essentials p0091 |
| **コードを変えるタイミング** | ギターとエレピは奇数小節の頭でコードを変え、偶数小節は半拍先取りする。**ベースは常に拍の頭** | 藤谷 p0104 |

**2つの資料の記述**。《The Drummer's Bible》によると、bossa の**キックは samba とまったく同じ**。
違いは、テンポが遅めでゆったりしており、アメリカのジャズからハーモニーを取り入れていること（p0063、p0064）。
藤谷は編成とコードを変えるタイミングに重点を置く（p0102–0108）。
★ 両方を合わせると、**bossa ≈ samba の骨格 ＋ ジャズのハーモニー ＋ 演奏全体で音数や力を抑えること**。

### 5.4 samba の揺れが一定の位置に収まらない理由

Samba の feel は**ストレートを基調にごくわずかに揺れ、一つの位置に落ち着かない**。バンドに必要なのは「ゆるやかさ」で、「曖昧さ」とは大きく異なる。
各楽器は音量をそろえ、hi-hat は pandeiro を模倣する（Groove Essentials p0092）。
速い samba のキックは軽く、前に流れるようにし、ほかの楽器の邪魔をしない（p0094）。

**2つの資料の記述**。Jazz Guitar Groove によると、**samba と bossa の8分音符はストレートに近い**（p0040）。
Groove Essentials は、ストレートとわずかなスウィングの間を流動的に動くと述べる（p0092）。
★ `groove.feel` には **`straight16` と書き、`quantize_policy` に「ストレートに近く、ごく小さな揺れを許す」と明記する**。
スウィング比による指定は避ける。

### 5.5 baião

主な打楽器は zabumba という大型のバスドラムで、両面を使ってシンコペーションを叩く（p0062）。
主リズムはブラジルの clave の第1小節と同じで、テンポは bossa より samba に近い（p0062）。
キックは定番の**付点8分音符に続く16分音符**（Groove Essentials p0095）。
bossa と samba の両方のリズム要素を持つが、独立したスタイルである（p0062）。

★ **この付点パターンは、このスキルで最も応用しやすい**（§2）。Charleston や多くの hip-hop groove の土台にもなっている（p0095）。

## 6. 編成と音域のルール

### 6.1 bossa の編成に欠かせない楽器

| 楽器 | 必要度 | 説明 |
|---|---|---|
| **クラシックギター（ナイロン弦）** | ★ **必須** | 藤谷は bossa の主楽器は間違いなくこれだと述べる。**ギターと歌だけでも bossa を演奏できる**（p0104、p0107）。高音側の3本がナイロン弦で、甘く柔らかい音色はここから生まれる（p0107） |
| アコースティックドラムセット | 標準編成 | 控えめな音色で、リムの音がよいもの（p0105） |
| **アコースティックベース** | 本格的な bossa ではこれを使う | ポップ寄りにしたい場合はエレキベースも使える（p0106）。★ **狙う方向に合わせて選べると明記されている** |
| ピアノまたはエレピ | 標準編成 | エレピは主に Fender Rhodes 系を指す。トレモロ、コーラス、フェイザーがよく使われる（p0107） |
| パーカッション類 | よく加える | シェイカー、トライアングル、tamborim（6インチの片面フレームドラム）、pandeiro（10インチのタンバリン）（p0108） |

実演曲のテンポは BPM 120（p0108）。

### 6.2 Afro-Cuban の編成

- **パーカッションは3人組が標準**。conguero、timbalero、bongo bell 奏者（p0029）
- **Mambo の歴史的な組み合わせ**。アメリカの swing の楽器編成、即興、和声配置 ＋ キューバの son のリズム（p0036）。
  ★ mambo のセクションに金管を入れるのは、この経緯に基づく

各系統の伝統的な楽器の一覧（Danzon のスナッピーを切ったスネア、Plena、Merengue、Calypso など）は [reference.md](reference.md) §4 を参照。

### 6.3 roster の提案

★ **以下の帯域は楽器の性質に基づく相対的な位置を示す。このリポジトリでは実測しておらず、引用できる周波数の測定値はない。**

| 楽器 | 役割 | 帯域（相対位置） | 出入りの目安 |
|---|---|---|---|
| **surdo / zabumba / bombo** | 低域のパルス | 最低域 | ブラジル系と baião では全編を通して入れる。抜くとその系統らしさが失われる |
| **アコースティックベース** | 低域の旋律 | 低域 | 全編 |
| **conga（tumbao）** | 中低域のハンドドラムのループ | 中低域 | セクション単位で抜いて音数を減らせる |
| **timbale／tom の cascara と timbale の旋律** | 中域のシンコペーションのライン | 中域 | ★ **bell とどちらか一方にすると明瞭になる**（§6.4） |
| **cowbell / agogo / cha bell** | ★ **グリッドを支える持続的なパルス** | 中高域 | セクションごとの対比をつけたい場合は、そのセクション全体で抜く |
| **clave / rim click / palito / 木魚** | リズムの規則を耳で分かる形にする | ★ **中高域の木質の打音。曲全体で最も混み合う箇所** | §6.4 |
| **shaker / cabasa / güiro / トライアングル / pandeiro** | 高域に連続感を出す | 高域 | hi-hat と同じ帯域で競合する |
| **ナイロン弦ギター（bossa）** | ハーモニー ＋ グルーヴ | 中域 | ★ bossa に欠かせないので、曲の途中で抜かない |
| **ピアノ／エレピ（montuno）** | 和声を担うシンコペーションのループ | 中域 | montuno のセクションが最も自然な入りどころ（§7.1） |

### 6.4 ★ 音域のルール：ラテンで最も濁りやすいのは中高域の木質の打音

**clave、rim click、palito、木魚、胴を叩く cascara の音はすべて、中高域の同じ狭い範囲に集中する。**
ほかのスタイルでは中低域が混み合うが（→ `mc-texture-layering`）、ここでは**打音のトランジェント**が重なる点が特徴。

次の3つは、編曲の段階で音数を減らす方法。

1. **楽器を減らす**。パーカッション奏者が複数いるときは、一人ひとりが自分から音数を減らす（p0099、p0103、p0109）
2. **骨格だけ残す**。掛け合いを整理しきれないときは bell のパターンだけを叩く（p0108）
3. **叩く面を替える**。cascara は、閉じた hi-hat、フロア tom の胴またはリム、cowbell、ride bell から選んで叩ける（p0034）。
   ★ **叩く面を選ぶことは、帯域を選ぶことでもある**

★ 一般化すると、この3つは `mc-texture-layering` §4.2 の「音域をずらす／帯域を譲る／交互に出す」の3択に対応する。
**ラテンでは、ほとんどの場合「楽器を減らす」を選ぶ。**

## 7. 和声

**和声の一般論は別のスキルで扱う**。七の和音、テンション、ツー・ファイブ、セカンダリー・ドミナント、分数コードの体系は `mc-harmony`、
bossa が借用したジャズ和声そのものは `mc-style-jazz` §3を参照。
ここでは3系統に固有の2点を扱う。

### 7.1 montuno：音型とセクションの両方を指す

| 意味 | 説明 |
|---|---|
| **① 音型** | 通常はピアノで弾く、**反復するシンコペーションの音型**（p0013） |
| **② セクション** | ★ **Afro-Cuban の編曲で即興を支えるセクション**（p0013） |

**歴史的な裏付け**：本来の Danzon には決まった構成がある（paseo、フルートのテーマ、イントロの反復、バイオリンのセクション）。
son が入って第4部が加わった。当初は "Nuevo Ritmo" と呼ばれ、のちに Mambo となった。**即興はこの部分から導入された**（p0048）。

★ **そのまま使える編曲上の判断基準は2つ**：
1. **montuno セクションは、曲形式の中で即興を受け持つ。** solo の場所は montuno セクションに設け、
   テーマのセクションは途中で切らない（曲形式の一般論は `mc-form` を参照）。
2. **montuno の和声は短いループにする。** シンコペーションのあるピアノ音型を反復するには、和声も反復する必要がある。
   セクションの展開は、密度の変化と各パートの出入りで作る。コード進行は短いループを保つ。

> ⚠ **具体的にどのコードを循環させるかは、底本の範囲外。** 底本は音型の性質とセクションの機能を示しているが、salsa のコードの度数は示していない。
> 具体的なループは `mc-progressions` から選び、`form[].harmony` に度数を明記する。

### 7.2 bossa の和声

藤谷の解説（p0103–0104）：

- ジャズと同じように、**四和音、テンションを加えたコード、分数コードを多用する**（p0103）
- ★ **メロディとコードのルートが大きく離れることが多く、それが独特の浮遊感を生む**（p0103）
- 冒頭の **C△7(9)** は bossa でごくよく使うコード。メロディが5度にとどまることはよくあり、M7 と 9 を加えると、普通の C より洗練された響きになる（p0103）
- 特定の小節に変化をつけたいときは、C を **C/E**（第3音を低音にする）に替えると浮遊感が出る（p0104）
- 終わりの **D♭△7(9) → C△7(9)** では、メロディが最も安定する Do にとどまり、その上に置くコードに対して、この Do が M7 になる。そこからコードが半音下がってトニックに戻り、曲を締めくくる（p0104）

《The Drummer's Bible》の説明（p0063）では、bossa の作曲家の多くは中上流階級の出身で、
**アメリカのジャズから旋律性とコード構造を借り、samba のドラムのリズムを残した**。テンポはより遅く、リラックスしている。
どちらの本も、和声の源はジャズだとしている。
> ⚠ **「bossa はジャズより和声の密度が低い」という説明は、底本の範囲外。**
> 底本が裏付けているのは「より遅く、リラックスしている」（p0063）ことと、「四和音、テンション、分数コードも使う」（p0103）こと。
> 密度を下げる場合は編曲上の判断として `form[].harmony` の注記に書き、スタイルの定義にはしない。

### 7.3 コードを切り替えるタイミングも和声の一部

★ bossa では**奇数小節は拍頭、偶数小節は半拍先取りでコードを替え、ベースは常に拍頭で弾く**（藤谷 p0104）。
このリポジトリの体系では、これは和声リズムとグルーヴの両方にまたがる。
両方に記録し、`form[].harmony` にはコードを、`groove` 側には「和声を担う楽器は半拍先取りし、ベースは先取りしない」と書く。

## 8. ★ 3系統と、そこから派生した1系統の違い

| | **Afro-Cuban** | **ブラジル** | **カリブ海** | **ラテンロック** |
|---|---|---|---|---|
| **代表的なスタイル** | son-salsa、mambo、cha cha、songo、mozambique、guaguanco、6-8 bembe | samba、batucada、bossa、baião | calypso、soca、ska、reggae | 左の3系統のリズムをロックの曲形式に取り入れる |
| **clave の有無** | ★ **あり。リズムを組み立てる文法になる**（son／rumba × 2-3／3-2） | 「ブラジルの clave」と呼ばれるものがあり、bossa と baião で用いる（p0064、p0062） | ★ **基本的に clave は使わない** | どのスタイルから借りるかで決まる |
| **低域の役割** | キックがベースの tumbao を重ねて鳴らす（p0013、p0037） | ★ **キックで surdo を模倣する**（p0059） | four on the floor（soca、ska）、または第3拍の one drop（reggae） | 簡略化した標準的なロックのキック（p0131） |
| **グリッドを保つパート** | ベル系打楽器の途切れないパルス | 手で刻む連続した16分音符（pandeiro の模倣、p0092） | キック | 標準的なロックの backbeat |
| **feel** | ストレート | ★ **ストレートと軽いスウィングの間で、どちらにも固定しない**（p0092） | ska はストレート、reggae はその中間（p0073、p0074） | ストレート |
| **典型的なテンポ** | 中速から非常に速いものまで。reference を参照 | 速い。samba は ♩=170 から（p0059） | やや遅めの中速から中速 | ♩=110–120 から、double-time の 200–232 まで（p0131） |

★ **混ぜられない理由は本に明記されている**（p0059）。混ぜると、2種類の2小節単位のリズムの文法がかみ合わず、
低域の重心とベル系打楽器のパルスがそろわない。結果としてキューバ風にもブラジル風にも聞こえなくなる。

### 8.1 カリブ海のスタイルを見分ける2組の比較

| 比較項目 | 違い | 根拠 |
|---|---|---|
| **Ska vs Reggae** | どちらも第3拍でリムを打つ。★ **Ska はストレート ＋ four on the floor が特徴** | p0073 |
| **Reggae の one drop** | 第3拍のリム打ちとキックを**1つの音として同時に鳴らす**。この打ち方に名前が由来する | p0074 |
| **Calypso vs Soca** | Calypso はキックのシンコペーションが多く、一定のスネアパターンが続かないため、groove は Soca ほど明瞭ではない。Soca はより速く、four on the floor を強く出し、スネアのシンコペーションを際立たせる | p0071、p0072 |
| **Ska のギター** | ★ **すべての裏拍を強く均等に強調する**。特徴的な響きの主な要因で、ギタリストはこの弾き方を「裏拍の伴奏」と呼ぶ | p0073 |

★ **Calypso の演奏では次の点を押さえる**。**スナッピーを必ずオフにし、手のひらでスネアを打ってクロススティックの音を作る。
そうしないと、カリブ海のリズムセクションの響きから離れ、マーチングバンドのように聞こえる**（Groove Essentials p0089）。

### 8.2 ラテンロックでは本場のパターンを意図的に簡略化する

- 定義：Afro-Cuban とブラジルのリズムをロックの曲形式に取り入れる。3系統の打楽器を同時に使うことも多い（p0131）
- ★ ドラムセットのパターンは、**本場のスタイルを扱う2章に比べて忠実度が低く、簡略化されることが多い**（p0131）。これは本での位置づけで、否定的な評価ではない。
  簡略化するのは他の打楽器奏者との重複を避けるため。単独で演奏するときは音を戻し、本場の響きに近づけられる（p0131）
- テンポ：標準的なロックの ♩=110–120 から、Afro-Cuban／ブラジルの感触を出す double-time の ♩=200–232 まで（p0131）
- すぐ使えるレシピ：標準的なロック ＋ cha cha（p0131）、baião ＋ ロックの感触（p0132）、キックで2小節それぞれの第1拍を強調するよう変えた mambo（p0133）

★ **ポップスの編曲への応用**：**本場と同じ役割分担まで取り入れずに「ラテンらしさ」を出したいなら、ラテンロックが適した選択肢になる。**
ラテンロックを選び、その旨を `meta` に書く。漠然と "latin" と書くより意図が正確に伝わる。

## 10. 書き上げた後の必須チェック

- [ ] **どの系統に属する、どのスタイルか**を明記し、漠然と "latin" と書いていない
- [ ] ★ **同じセクションにブラジルと Afro-Cuban の音型を混ぜていない**（p0059）
- [ ] スタイルに基づいて clave の種類と始まる側を決めた
- [ ] ★ 2小節単位の定型パターンはすべて**同じ側にそろえ**、bombo は "3" 側の第2拍の "+" に置いた（§3.4）
- [ ] 本来 clave のないスタイル（bomba、cumbia、plena）**に無理に clave を当てていない**
- [ ] ★ **いずれか1つの楽器が表拍を刻み続け**（ベル系打楽器または four on the floor）、clave が参照するグリッドを作っている
- [ ] 打楽器の数と役割分担が合っている（奏者の人数で演奏できる量まで減らす。§4.3）
- [ ] 中高域の木質のアタック音は**必要な楽器だけを残し**、楽器を減らす／主要な音だけ残す／叩く面を変える、のどれで対処したかを明記した
- [ ] bossa：ナイロン弦ギターを使い、ドラムはリムを打つ。**和声を担う楽器は半拍先取りでコードを替え、ベースは拍頭で弾く**
- [ ] samba：低域には surdo の打音を指定した
- [ ] montuno セクションの和声は**短いループ**で、即興または密度の変化を受け持つ
- [ ] ★ 他のスタイルに転用する際は§2を確認し、**clave に依存する要素を持ち出していない**
- [ ] 「ラテンらしさ」だけが欲しい場合は、ラテンロックを明示的に選び、`meta` に書いた（§8.2）

## 付録：出典

- **《The Drummer's Bible》**（Afro-Cuban、Brazilian、Caribbean、Latin Rock の4章と用語集）：
  clave の体系と son／rumba の唯一の違い、bombo と ponche、cascara と palito、
  tumbao と montuno がそれぞれ持つ2つの意味、partido alto、6/8 と Bembe／Abakwa、
  各スタイルで用いる clave とテンポ、3系統を混ぜられないという判断、ラテンロックの位置づけ。
- **《Groove Essentials》（Tommy Igoe）World 章**：
  samba の「タイミングを固定しない」感覚、bossa の軽いタッチと余白、batucada の全体の雰囲気を優先する考え方、
  baião の付点パターンと Charleston／hip-hop との近さ、songo の抑え方、salsa の左右の手の分担、
  打楽器奏者と共演するときに音数を減らす原則、Calypso でスナッピーをオフにすること、**テンポ指定を固定すべきかについての相反する見解**（p0116）。
- **《圖解樂風編曲入門》（藤谷一郎）bossa nova の節**（p0102–0108）：
  編成と必須の楽器、音色の選び方、コードとメロディの距離、★ **編曲を変えるコード切り替えのタイミング**、デモ曲の BPM 120。
- **《Jazz Guitar Groove》**：samba と bossa のギターのグルーヴとポジション、第4拍の "+" の先取りはブラジル音楽の特徴、
  samba／bossa の8分音符はストレートに近い、サイドスリップと静的なソロでテンションを作る方法。
