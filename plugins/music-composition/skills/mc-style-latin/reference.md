# ラテンのスタイルレイヤー詳細表（mc-style-latin reference）

SKILL.md では系統の分類と判断基準を扱い、ここには参照用の詳細をまとめる。
**具体的なドラムパターン、手足それぞれの打点、スタイル別ドラムセットのテンポ早見表は `mc-rhythm-section` reference-styles §8.6（Afro-Cuban）、§8.7（Brazilian）、§8.8（Caribbean）にあり、ここでは繰り返さない。**

## 1. 判断に使う用語

| 用語 | 意味 | ページ |
|---|---|---|
| **Clave** | ① 2小節のリズムパターン（son または rumba）。大半の Afro-Cuban のリズムの土台で、"3"側（1小節に3音）と"2"側（1小節に2音）があり、どちらからでも始められる。② このリズムを叩く打楽器 | p0012 |
| **Son Clave** | clave の2種類のうちの1つ。**"3"側の3音目が第4拍ちょうどに来る**。比較的伝統的な系統（Mambo、Cha Cha）でよく使う | p0013 |
| **Rumba Clave** | **"3"側の3音目が第4拍の"+"に来る**。比較的新しい系統（Songo、Mozambique）でよく使う | p0013 |
| **Bombo** | ① clave の"3"側の**第2拍の"+"**に置くアクセント。② Afro-Cuban の民俗音楽で使う大太鼓 | p0012 |
| **Ponche** | 4/4 の第4拍を強調するアクセント。通常はつなぎのパターンに使う | p0013 |
| **Tumbao** | ① **主にベースが演奏する**リズムパターン。ドラムセットがある場合は通常、キックを重ねるか、キックのアクセントで強調する。② conga の定型的な反復パターン。主に高音の太鼓 quinto で叩く | p0013 |
| **Montuno** | ① 通常はピアノで弾く**反復的なシンコペーションの音型**。② Afro-Cuban のアレンジで**即興を支えるセクション** | p0013 |
| **Cascara** | Afro-Cuban のリズムパターンで、Palito と呼ばれるパターンを再現する。「殻」の意味で、timbale のヘッド／シェルを叩くことを指す | p0012、p0034 |
| **Palito** | ① もとは gua gua（中をくり抜いた竹）で演奏した Afro-Cuban のリズムで、のちに Cascara のパターンとみなされた。② それを叩く棒 | p0013、p0048 |
| **Partido Alto** | ① ブラジルで最も普及した samba の系統の1つ。② samba と bossa の両方で使うリズムパターン。伝統的には agogo、cuica、pandeiro、tamborim で演奏し、ドラムセットでは通常スネアで叩く | p0013 |
| **Baqueteo** | timbale 奏者のパターン。主に Danzon で使う | p0012 |
| **Abanico** | timbale の曲出しのパターン。第3拍に rim shot、第4拍から次の小節の第1拍までロールを入れる | p0012 |
| **Bateria** | 打楽器パート／打楽器隊 | p0012 |
| **Comparsa** | キューバのカーニバルで Conga のリズムを演奏する団体。打楽器が中心で、金管（主にトランペット）が加わることも多い | p0012 |
| **Conguero / Timbolero** | conga 奏者 / timbale 奏者 | p0012、p0013 |
| **In The Crack** | スウィングとストレートの**中間**のリズム感。★ **底本にはほとんど記譜できないと明記されている**。耳で聴き、練習して身につける | p0012 |
| **Linear** | 音を1つずつ続けて出し、両手足のうち2つが同時に打つことはない | p0012 |
| **Marakatu** | ポルトガル統治下のブラジルで行われた奴隷の王と王妃の戴冠儀式。現代ブラジルの音楽、祭り、踊りの大半はこの伝統から発展した | p0012 |
| **Yoruba** | ナイジェリアの民族。**6/8 clave パターンの起源** | p0013 |
| **Rumba（音楽形式として）** | 伝統的な Afro-Cuban の形式で、Columbia、Guaguanco、Yambu の3系統が派生した。北米のダンスホールの同名の rumba は、これを大まかに取り入れたもの | p0013 |
| **Salsa** | ★ **広い意味を持つ言葉**。大半の Afro-Cuban のスタイル、特にダンス向けに演奏されるものを総称する | p0013 |

★ **最後の項目はアレンジにも関わる**。曲目表に "salsa" とだけ書いても、具体的なスタイルは伝わらない。
`meta` にはその下の具体的な系統を書く。

## 2. clave の4通りの並べ方

| 並べ方 | "3"側の最後の音 | 開始側 | 代表的な系統 |
|---|---|---|---|
| **3-2 son** | 第4拍 | "3" | 伝統的な系統 |
| **2-3 son** | 第4拍 | "2" | Mambo（p0037）、Pilon（p0049） |
| **3-2 rumba** | 第4拍の"+" | "3" | Guaguanco。通常は"3"側から始まる（p0036） |
| **2-3 rumba** | 第4拍の"+" | "2" | Mozambique、Songo（p0039、p0040） |

**底本から確定できる音の位置**：
- **"3"側に3音、"2"側に2音がある**（p0012）
- **"3"側の第2拍の"+"の音が bombo**（p0012）
- **"3"側の最後の音**は son では第4拍、rumba では第4拍の"+"（p0030）

> ⚠ **"2"側の2音の正確な位置と、"3"側の最初の音の位置は底本の文章には記載されていない**（底本では譜例に示され、文章で触れているのは上の3点のみ）。
> 1音ずつ譜面に起こす場合は実際に聴き取って位置を決める。この項目の記述から推測しない。

### 2.1 6/8 clave

- 3拍子のフィールを基にし、ナイジェリアのヨルバ人に由来する（p0013、p0031）。キューバでは **Bembe** または **Abakwa** と呼ぶことが多い（p0031）
- **独自の clave と bell パターンがある**（p0012）
- 4/4 の3連符のまとまりで記譜することが多い。**4/4 のキューバの clave との関係を示すため**（p0031）
- **6/8 の bell パターン = 6/8 clave ＋ 2音**。その2音は通常、ほかの音より軽く叩く（p0032）

## 3. 系統別のテンポ、feel、clave

**判断に必要な4列だけを示す。ドラムパターンと手足それぞれの打点は `mc-rhythm-section` reference-styles §8.6／§8.7／§8.8 を参照。**

### 3.1 Afro-Cuban

| 系統 | clave | テンポ | グリッドを保つパート | ページ |
|---|---|---|---|---|
| **6/8 Bembe / Abakwa** | 6/8 clave | ♩=92–120 | 足で hi-hat を各拍の頭に踏む | p0032–0034 |
| **Cascara** | 4種類とも使える。パターンと clave の位置関係は変わらない | ♩=126–250 | ride を叩く手の cascara ライン | p0034–0035 |
| **Guaguanco** | **3-2 rumba**。通常は"3"側から始める | ♩=200 | 足で hi-hat を 1&3 に踏む | p0036 |
| **Mambo** | **2-3 son**。どちら側からでも始められる | ♩=200 | Mambo bell | p0037 |
| **Cha Cha** | son 系（Mambo の half-time 版） | ♩=110 から | ★ **cha bell の連続する4分音符** | p0038–0039 |
| **Mozambique** | **2-3 rumba** | ♩=200 から | Mozambique bell | p0039–0040 |
| **Songo** | **2-3 rumba** | およそ ♩=200 から | ride を叩く手の安定したパルス | p0040–0041 |
| **Bomba** | ★ **通常は clave なし** | ♩=200 から | 反復するキックのパターン ＋ bell パターン | p0042 |
| **Merengue** | なし | ♩=240 から | four on the floor のキック | p0042–0043 |
| **Bolero** | ゆったりとした叙情的な曲調。もとはカスタネット／maracas でリズムを叩く | ♩=74–120 | rim または固く閉じた hi-hat で再現するパターン | p0045 |
| **Cumbia** | ★ **clave なし** | ♩=160–252（double-time 感） | スネアの強い backbeat ＋ ベースに合わせたキック | p0047 |
| **Danzon** | ドラムセット以前からあり、スナッピーは外す | ♩=110 | rim click／指で叩く音／スティックで叩く音の繊細な組み合わせ | p0048 |
| **Palito** | 2-3 rumba（この例） | ♩=120–264 | 両手を閉じた hi-hat と rim click の間で動かす | p0048–0049 |
| **Pilon** | **2-3 son**。通常はドラマーが叩かない | ♩=172–224 | 足で刻む2分音符 | p0049–0050 |
| **Plena** | ★ **通常は clave を叩かない** | ♩=208–276 | ★ **単純な4分音符のキック** | p0050 |
| **Conga（Comparsa）** | — | ♩=216–264 | — | p0045 |
| **Beguine** | — | ダンスホールでは ♩=112。ドラムの Beguine は ♩=280 まで | — | p0044 |

**feel**：上記はすべてストレート系。
★ Groove Essentials には演奏上のポイントが3つある。Mambo はリズムの密度が高く、各パートを重ねて「1つの音」に聞かせることを目指す（p0102）。
速い Mambo の第1小節で繰り返される合奏パターンは、同書の中でも特に合わせるのが難しい（p0103）。
Songo の特徴は各小節の最後の16分音符をすっきり止めること（p0104）。

### 3.2 ブラジル

| 系統 | テンポ | feel | 低域の組み方 | ページ |
|---|---|---|---|---|
| **Samba** | ♩=170 から | ★ **ストレートの中にごくわずかなスウィングがあり、どちらか一方に定まることはない**（Groove Essentials p0092） | 足で surdo を模倣しながらベース奏者に合わせる | p0059 |
| **Batucada** | ♩=170 から | 同上。手数を増やし、クライマックスに使う | ride を叩く手でフロア tom を叩き、surdo を再現する（ミュート打ちを含む） | p0061–0062 |
| **Baião** | ♩=170 から（bossa より samba に近い） | 主パターンはストレート。march の変形では in the crack で叩く | ★ **付点8分音符に16分音符が続く**。主パターン = ブラジルの clave の第1小節。元の楽器は zabumba | p0062–0063 |
| **Bossa Nova** | ♩=100–168（藤谷の実演曲は BPM 120） | straight | ★ **キックは samba と完全に同じ** | p0063–0064、藤谷 p0108 |

★ **samba の feel に関する2つの説明**：Jazz Guitar Groove では samba と bossa の8分音符は**ストレートに近い**とする（p0040）。
Groove Essentials ではストレートとごくわずかなスウィングの間を流動的に行き来し、どちらか一方に定まることはないとする（p0092）。
`groove.feel` には `straight16` を入れ、「どちらか一方に定まらない」ことは `quantize_policy` の説明に書く。

**batucada の surdo パターン**（低域の骨格なので個別に記録する価値がある。p0061）：
- **型 A**：2小節とも第1拍をミュートし、第3拍を鳴らす
- **型 B**：第1小節は第1拍をミュートし、第3拍、第3拍の"+"、第4拍の"+"を鳴らす。第2小節は第1拍をミュートし、第3拍と第4拍を鳴らす
- ★ **上記のどのパターンでも、第1小節と第2小節は入れ替えられる。フィールに合わせて決める**（p0062）

★ **読み方**：ブラジル系統の低域ではミュートも使う。**響かせない打音にも役割がある**。
MIDI ではこの打音を省略せず、短く詰まった打音として書く。

### 3.3 カリブ海地域

| 系統 | テンポ | feel | 近い系統との違い | ページ |
|---|---|---|---|---|

### 3.4 ラテンロック

| 項目 | 内容 | ページ |
|---|---|---|
| 定義 | Afro-Cuban とブラジルのリズムをロックの曲形式に取り込む。3つの系統の打楽器を併用することが多い | p0131 |
| ドラムセットのパターン | ★ **本格的な奏法を扱う2章に比べて原型から離れており、簡略化されることが多い**。ほかの打楽器奏者と役割が重複するのを避けるため | p0131 |

## 5. 代表的なパターンの骨格（文章による説明）

★ **底本ではパターンが譜例で示され、各音の位置が文章で明記されている箇所は少ない。以下には文章で明記されたものだけを挙げ、残りは未収録と記す。**

### 5.1 bass tumbao とキックの対応

| 場合 | キックの位置 | ページ |
|---|---|---|
| **最も本格的なキューバの奏法** | ★ **bombo（clave の"3"側の第2拍の"+"）だけを打つ**、または**2小節とも第2拍の"+"だけを打つ** | p0035 |
| Songo の tumbao の変形1 | ★ 同上。2小節とも第2拍の"+"だけ | p0041 |
| Cha Cha | 第2拍の"+"と第3拍でベース奏者に合わせる | p0038 |
| Mambo | ベース奏者の tumbao を支え、**同時に鳴らす場合と位置を分ける場合がある** | p0037 |
| Cumbia | 繰り返しのパターン。**通常はベース奏者とそのまま同じ位置で打つ** | p0047 |
| Samba | 足で surdo を模倣しながらベース奏者に合わせる | p0059 |

★ **読み方**：**「第2拍の+」がこの低域レイヤーの共通項。**
tumbao の書き方に迷ったら、まずこの1打の位置を決めてからほかの音を加える。

> ⚠ **ベース自体の tumbao の各音の位置は底本に記載がない**（キックが重ねる、または補強するという記述のみ）。

### 5.2 cascara / palito

- 2小節のパターンで、**clave の特定の側を補う**（p0034、p0048）
- ★ **3-2 でも 2-3 でも、son でも rumba でも、各音の clave に対する位置関係は変わらない**（p0034、p0048）
- 叩く場所は閉じた hi-hat、フロア tom のシェルかリム、cowbell、ride bell。**この4択は帯域の選択でもある**（p0034）
- Mambo や Guaguanco のパターンに代えてほかの打楽器奏者との重複を避けるときや、アレンジの穏やかなセクションで使う（p0034）

> ⚠ **各音の位置は底本に記載がない。**

### 5.3 montuno

- シンコペーションを含む反復的なピアノの音型（p0013）
- アレンジで**即興を支えるセクション**も指す（p0013）
- 歴史的な補足。本来の Danzon は構成が固定されていた（paseo、フルートの主題、イントロの反復、ヴァイオリンのセクション）。son が入ると第4部が加わり、当初は "Nuevo Ritmo"、のちに Mambo と呼ばれ、**ここから即興が取り入れられた**（p0048）

> ⚠ **montuno の具体的なリズムの骨格と定番のコード進行は底本に記載がない。** 循環するコード進行は `mc-progressions` を参照。

### 5.4 partido alto

- samba の手のパターンの中心（p0059）。batucada ではスネアで叩く（p0061）。bossa の rim click の変形の1つでもある（p0064）
- 伝統楽器は agogo、cuica、pandeiro、tamborim。ドラムセットでは通常スネアで叩く（p0013）

> ⚠ **各音の位置は底本に記載がない。**

## 6. ギターの奏法（samba と bossa）

『Jazz Guitar Groove』より。

| 項目 | 内容 | ページ |
|---|---|---|
| **samba と bossa の関係** | **samba のリズムは bossa nova に似ており、テンポがやや速い** | p0029 |
| **8分音符の処理** | ★ **samba と bossa の8分音符はストレートに近い**（対照として、swing と bop の8分音符は4分音符の3連符相当の長さに8分音符の3連符相当の長さが続く） | p0040 |
| **先取り** | ★ **第4拍の"+"で先取りする。ブラジル音楽によくある特徴** | p0037 |
| **フレーズの単位** | bossa のコードを学ぶときは、まず各コードを個別に覚え、次に頭の中で 2/2 を 4/4 に置き換える。**最終的には「2拍のフィール」で演奏する** | p0037 |
| **低音弦** | 即興の伴奏は指弾き。合奏時やピックだけで弾く場合は**ベース音を省いてもよい** | p0029、p0037 |
| **ポジションの選択** | samba の例は A フォームを使う。第5弦の最低ルートから上に長13度の音域が取れる。第3弦から第2弦へ移る際に内側のポジションが第3フレットに移るため、A フォームをまたぐことはまれ | p0029 |
| **bossa の例は D フォーム** | 第4弦がルートで、その上に完全11度がある。第6弦の最低音から主音までは、幅の広い短7度になる | p0037 |
| **調性を保つソロ ＋ 動くハーモニー** | ★ ハーモニーだけが半音ずつ上行し、ソロが同じ調性の中心にとどまることで緊張感が生まれる。コードが静止しているときにソロ全体を時折半音上下させる手法を**サイドスリップ**と呼ぶ | p0029 |
| **衝突を避ける方法** | ソロは伴奏（またはソロより高い音域のパート）よりも**明らかに大きい音量**を保つ | p0034 |

**bossa の既成コード進行（譜例用）**：
`Gmaj7 – B♭dim7 – Am7 – Cdim7`（伴奏、p0037）。
ソロのセクションでは `Gmaj7 – B♭dim7 – Am7 – D7 – Dm7 – G7 – G7♭5 – Cmaj7 – Cm7 – F7♭9` に展開する（p0038）。
★ **調性の中心から外れるコード（2つの dim7、Cm7、F9）があり、アヴォイドノートは衝突を起こす**（p0038）。

**bossa のハーモニー（藤谷 p0103–0104）**：
`C△7(9) – Am7 – F△7 – Dm7/G – C/E – F△7 – Dm7/G – G7 – D♭△7(9) – C△7(9)`。
4和音、テンション、分数コードを多用する。**メロディとコードのルートは大きく離れていることが多く、そこから浮遊感が生まれる**。
第5小節では C を C/E に替えて浮遊感を出す。終わりでは D♭△7(9) を使って安定した Do を M7 に変え、半音下行して C△7(9) に戻る。
