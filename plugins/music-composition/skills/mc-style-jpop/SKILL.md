# J-POPのスタイル層（J-POP）

**J-POPと欧米のポップスの大きな違いは、曲全体をどこまでサビのために設計するかにある。**

> 欧米のポップス：ヴァースとコーラスは**それぞれ独立した内容を持つ**。
> J-POP：AメロとB メロが**サビのお膳立て**をする。

この違いから生まれたJ-POP独自の作曲・編曲の手法を扱う。

## 2. ★ 他ジャンルへの応用の目安

| 手法 | 応用できるか | 補足 |
|---|---|---|
| **A–B–サビの3段構成** | ✅ **応用可。中国語圏のポップスでも広く定着** | `mc-form` §2.2 |
| **B メロ（プリコーラス）** | ✅ ★ **応用可。J-POPが世界のポップスに与えた大きな影響の一つ** | サビに向けて盛り上げるためのセクション |
| **和声語彙**（王道/小室/カノン/丸サ） | ✅ 応用可 | `mc-progressions` に収録 |
| **落ちサビ（伴奏を薄くしたサビ）** | ✅ **応用でき、効果も高い** | `mc-arrangement-arch` §3 の引き算の具体例 |
| **サビを最大限に聞かせる（反復）** | ⚠️ **一部応用可** | ★ 欧米のポップスはサビの反復が明らかに少ない。そのまま持ち込むとくどくなりやすい |
| **大サビ（C メロ）** | ⚠️ 一部応用可 | 英米の bridge に相当するが、**内省的でハーフタイムに聞こえることが多い** |
| **キメ（印象に残るフレーズ）** | ⚠️ 一部応用可 | ロックでは一般的。スローな曲で使うとJ-POPらしくなる |
| **頭サビ（冒頭からサビ）** | ✅ 応用可 | ショート動画の時代にはさらに一般的 |
| **曲全体をサビのために設計する発想** | ❌ ★ **応用しにくい** | 欧米のポップス、インディー、ジャズではヴァース自体にも聴かせどころがある。そのまま応用するとヴァースが形だけのつなぎになる |

★ **判断基準**
> **B メロ、落ちサビ、頭サビなどの手法は応用できる。
> ヴァース自体にも聴かせどころを作る。**

## 3. サビらしく聞こえる理由

**基本原則**。サビは曲全体で最も高揚する箇所で、歌詞で最も伝えたいことを置く。

### 3.1 メロディーの曲線

> **Aメロは低く歌う → Bメロで徐々に上がる → サビで高音域に跳び、その音域にとどまる。**
>
> ★ **典型的な構成の曲なら、アカペラでもサビの位置がわかる。**

**確認方法**。メロディーをアカペラで歌う。**サビの位置が聞き分けられなければ、サビを書き直す。**

### 3.2 メロディーの曲線に合わせて伴奏を変える

| 軸 | Aメロ | サビ |
|---|---|---|
| **縦軸（厚み）** | 薄く柔らかい | **張りのある歌声に負けない強さ**で、低域から高域まで使う |
| **横軸（時間あたりの音数）** | 四分音符・八分音符が中心 | **十六分音符のフレーズを加えて**密度を上げる |

### 3.3 ★ メロディーの下降に伴奏で余白を作る

> **サビのメロディーが上下するとき、下行する箇所は伴奏に埋もれやすい。
> その箇所では伴奏に意図的に隙間を作る。**

`mc-texture-layering` §3 の奥行きを決める手がかりに対応する。
メロディーが下行すると高さと速さの両面で目立ちにくくなり、伴奏の余白で補う必要がある。

### 3.4 毎回サビの終わり方が同じ場合

毎回アレンジと終わり方が似ていると、最後のサビでそれ以上盛り上がらない。藤谷の方法は最後のサビの前半と後半に対比をつける。**前半は一度熱量を落とす**（ピアノかリード楽器だけに絞る）と、後半の聴かせどころが単なる繰り返しを超えた盛り上がりに聞こえる。**後半は聴かせどころに合わせて一気に盛り上げる**。メロディーには譜面を崩してフェイク（fake）を添えてもよく、ストリングスなどはさらに高い音域へ進む（藤谷 p0069）。

尺に余裕があれば、最後のサビをそれまでの**2倍の長さ**にする手もある。同様に前半は静かにし、後半はサビに近づくにつれて盛り上げる（藤谷 p0062）。どちらも**一度引いてから押し上げ、展開に差をつける**。同じ音域に音を重ねるだけではこの対比は得られない。

## 4. ★ サビが盛り上がらないときの対処法

**以下の順に試す。**

| # | 方法 | 注意点 |
|---|---|---|
| 1 | ボーカルが高音まで上がらない → **高音域の楽器を重ねる** | ★ **ボーカルが埋もれないよう、高音のフレーズは歌の隙間に入れる** |
| 2 | **低音域の楽器とリズム楽器を足し**、密度を上げる | |
| 3 | ★★ **最も効果が高いのは声を足すこと** | **ハモリ**や aah/ooh/hah の**コーラス**を入れると、すぐにサビらしくなる |

> ★★ **声は楽器の約3倍の効率で高揚感を出せる。**
> **楽器で大がかりな編曲が必要な盛り上がりも、声なら容易に作れる。**

★ 本スキルで最も実用的な原則。
**サビの勢いが足りなければ、まず声を足すことを考える。**

> 豆知識。英語でサビを表す "chorus" の語源は、**曲の最高潮でみんなが一緒に歌うこと**。

## 5. サビを最大限に聞かせる方法 A：反復

**繰り返し耳にするものには愛着が湧く。まず、サビをできるだけ多く聞かせる。**

- 冒頭に **頭サビ**を置く
- **間奏と平歌をできるだけ短くする**
- 1 サビ、2 サビ、3 サビ、4 サビと重ねる
- 最終セクションは `A−B−C−C（−C−C）` とし、サビを反復して曲全体のクライマックスを作る

### 5.1 ★ 反復と飽きのバランス

> **曲中ずっとサビが続くと飽きる。
> ポップスの編曲では、聞き飽きない範囲でサビをできるだけ多く聞かせる。**
> **少なすぎると覚えられず、多すぎると単調になる。**

**飽きを防ぐ手法**

| 手法 | 方法 |
|---|---|
| **同じメロディーで編成を変える** | 3回目のサビを急に静かにする = **落ちサビ**。頭サビは冒頭に合う編成にする（薄い伴奏 + 遅め + 自由なテンポで語りかける導入にするか、そのまま演奏して華やかに始める） |
| **転調** | 編成を保ったままキーを変えて単調さを避ける（→ `mc-modulation`。★ §6 の定型化に関する注意を参照） |

---

## 6. ★ サビを最大限に聞かせる方法 B：期待感

> **サビ直前のセクションが重要。**
> **入る直前に変化をつけると**、そのままサビに流れ込むよりも耳を引く。

| 方法 |
|---|
| **突然全パートを止める（ブレイク）**。そのあと勢いよくサビに入る |
| コード進行に小さなひねりを加える |
| シンプルな八分音符で**クレッシェンド**する |
| **サビ前にドラムの fill を入れる**。曲を知っているリスナーは、fill を合図に気持ちが高まる |

> **いずれも「来るぞ来るぞ」という期待感を作る。**

### 6.1 ★ 平歌にも聴かせどころを作る

> **サビのアレンジに加えて、平歌（Aメロ）にも同じだけ魅力が必要。
> 平歌が弱ければ、リスナーはサビまで聴かない。**

§2 の表の最終行と同様に、**平歌をサビの前振りだけにすると、そのセクション自体の魅力が薄れる。**

## 7. サビの内部構造

- サビも一つの楽節として、**内部のクライマックスを 2/3–3/4 の位置に置く**
- ★ **竜頭蛇尾を防ぐ**。サビの頭から高揚していても、
  後半に十分な盛り上がりがあり、しっかり締めくくれるか確認する。
  **モチーフの一部を繰り返してもう一度盛り上げ、勢いを保つ**

### 7.1 サビの二つの作り方

| 型 | 説明 |
|---|---|
| **掛け声型** | **短いモチーフの反復**を軸にする（ロックに多く、一度で覚えられる） |
| **歌い上げる型**（声を張って歌う） | **長いメロディー**。日本語の「サビ」の本来の意味（melo = sabi 形）で、J-POPやバラードによくある |

### 7.2 サビに向くモチーフの配置

以下の二つは、サビ内のフレーズの配置例。モチーフを繰り返して盛り上げ、後半で締めくくるには、この節の冒頭にある「2/3–3/4 の位置」と「竜頭蛇尾を防ぐ」の二つに従う。メロディーの曲線は §3.1 を参照。

| 構成 | 効果 |
|---|---|
| **a a b a** | 最後に再現し、満足感が強い |
| **a b a c** | a で耳を引き、**c で最高潮を作る**（c が 2/3–3/4 付近に来るため、上の原則に合う） |

### 7.3 ★ 落ちサビの実例

（バラード）
> 2番のサビの後、後半の伴奏を**フル編成にする** →
> リスナーは3番も勢いよく入ると予想する →
> **ピアノとボーカルだけのささやくようなサビにする** →
> **2または4小節後にバンド全体が一気に入る**。感情が大きく動く。

★ **期待を作ってから裏切る手法（`mc-melody` §8.2）の典型例。**

## 8. ★ 大サビ（C メロ）は必要に応じて加える

### 8.1 大サビの役割と書き方

| 項目 | 説明 |
|---|---|
| **役割** | 「ところで」や「だけど」と語りかけるように別の視点を示し、曲に**奥行き**を与える |
| **性格** | 内省的で抑えたメロディーが多い。速い曲では音価を伸ばすことが多く、**このセクションだけハーフタイムに聞こえる** |
| ★ **別の考え方** | 藤谷（p0060）は、Dメロを**サビの派生形**と捉える。初出の要素をいくつか加えてもう一つの山場を作り、**穏やかな雰囲気にはなりにくい**。別の視点を語る書き方と、第二の山場を作る書き方がある。**次のサビを際立たせるのに対比が必要なら内省的にし、必要がなければサビを発展させる** |
| **手法の例** | 音高の動きを抑える + 転調 + 短3度関係のコードを中心にした和声 |
| **位置** | ★ **機能はヴァースなので、直後には必ずサビを置く**。いったん気持ちが落ち着くからこそ、次のサビの山場に重みが出る |

### 8.2 ★ 加えるかどうかの判断

> **大サビは任意。**
> **習慣で加えるだけなら、曲の勢いを弱めることがある。**
>
> **各セクションのサビの反復が本当に予定調和に聞こえるか確かめてから、加えるか決める。**

**確認方法**。C メロを外して一度聴く。**曲が悪くならなければ外す。**

## 10. 書き上げたあとの確認

- [ ] **アカペラでサビの位置がわかる**（§3.1）
- [ ] サビのメロディーが下行する箇所で**伴奏に隙間を作った**
- [ ] サビが盛り上がらないとき、**楽器を足す前に声を足した**
- [ ] サビの回数を**意図して決め**、飽きさせない工夫を入れた
- [ ] **サビに入る直前に変化をつけた**
- [ ] **平歌自体に聴かせどころがある**
- [ ] サビの**後半にも山場がある**
- [ ] ★ C メロを入れた場合は、**外した状態でも聴き、加える効果を確認した**
- [ ] 他ジャンルに応用するときは §2 を参照し、**ヴァース自体にも聴かせどころを作った**
