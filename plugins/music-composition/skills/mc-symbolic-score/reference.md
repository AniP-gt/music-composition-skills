## 1. ABC構文早見表

### 1.1 ヘッダーフィールド

| フィールド | 意味 | 例 |
|---|---|---|
| `X:` | 番号（必須、通常は 1） | `X:1` |
| `T:` | タイトル | `T:Night Drive` |
| `C:` | 作曲者 | |
| `M:` | 拍子記号 | `M:4/4`、`M:6/8`、`M:C`（=4/4）、`M:C|`（=2/2） |
| `L:` | デフォルトの単位音価 | `L:1/8`、`L:1/16` |
| `Q:` | テンポ | `Q:1/4=112` |
| `K:` | 調号（**必ずヘッダーの末尾に置く**） | `K:D`、`K:Am`、`K:Dphr`（旋法） |
| `V:` | 声部 | `V:1`、`V:2` |

### 1.2 音高

```
C,, C, C c c' c''      ← 低い順。コンマで1オクターブ下がり、アポストロフィで1オクターブ上がる
^C  _C  =C             ← シャープ / フラット / ナチュラル
^^C  __C                ← ダブルシャープ / ダブルフラット（まれで、ポップスや映像音楽の譜面ではほとんど使わない）
```

★ **大文字と小文字の違いはオクターブを示す**。`C` から `B` は中央付近の音域、
`c` から `b` はその1オクターブ上。コンマ（`,`）でさらに下がり、アポストロフィ（`'`）でさらに上がる。
重ねて書くこともでき、`C,,` は `C,` よりさらに1オクターブ低い。

★ **臨時記号は同じ小節内で有効**。次の小節線まで、または同じ小節内で別のシャープ、フラット、ナチュラルが付くまで効力が続く。
この規則を見落とすと、譜面が正しく見えても読み込んだときの音高がずれる。
第 8 節の構文チェックでは検出できないため、1音ずつ照合する。
小節をまたいで変化音を維持するには、次の小節で臨時記号をもう一度書く。ABCでは自動的に引き継がれない。

### 1.3 音価（`L:` を基準とする）

```
C2   単位音価の2倍
C/2  単位音価の半分（C/ とも書ける）
C3/2 単位音価の1.5倍（付点）
C>D  付点リズム（C が長く、D が短い）
C<D  逆付点
z    休符。長さは音符と同じ書き方で z2、z/2
Z4   複数小節休符（Z に続く数字は小節数を表す）
(3CDE  3連符。2単位分の長さに3音を入れる（(3:2:3 と等価）
```

★ **`L:` は「1」に相当する音価を定義する**。
同じ `C2` でも、`L:1/8` では4分音符、`L:1/16` では8分音符になる。
出力時にヘッダーの `L:` と実際に音符に使った単位がずれると、
音符間の長さの比は保たれるが、**曲全体の絶対的な長さが変わる**。
この誤りは第 8 節の構文チェックでは見つからない。
総演奏時間や総拍数を計算して照合するか、レンダリングして速さを耳で確かめる。

★ **付点記号は連続して書ける**。`C>D>E` は3音の音価が付点記号によって順に短くなる。
ウェスタンやジャズのスウィング感のある旋律でよく見られる。連続する音が2、3音を超えると読みづらくなるため、
それ以上は小節内で複数の記号に分けると管理しやすい。

### 1.4 小節と構成

| 記号 | 意味 |
|---|---|
| `|` | 小節線 |
| `||` | 複縦線 |
| `|]` | 終止線 |
| `|:` `:|` | 反復（★ **サビでは使わない**。SKILL.md §3.4 参照） |
| `[1` `[2` | 1番括弧と2番括弧 |
| `%` | 行内コメント |
| `%%` | ディレクティブ |

### 1.5 コードと装飾

```
"F#m7"C     ← コードネームを引用符で囲み、音符の前に書く
(CDE)       ← スラー（slur）
C-C         ← タイ（tie）
(3CDE       ← 3連符
~C  .C  HC  ← 装飾音 / スタッカート / フェルマータ
```

### 1.6 複数声部

```
V:1 name="Melody"
V:2 name="Bass" clef=bass
```

★ **YuE2が複数声部に対応するかは未確認**（SKILL.md §7.2）。まずは単声部で出力する。

## 3. よく使うMIDI CC（オーケストレーション関連）

完全な一覧は `mc-orchestration` [reference.md](../mc-orchestration/reference.md) §5 にある。ここではよく使うものを挙げる。

| CC | 用途 | ★ 注意点 |
|---|---|---|
| **1** | モジュレーション（通常はビブラート） | 音量を制御するライブラリもあるので、**使用前にマッピングを確認する** |
| **7** | 音量 | ★ **編成内でのトラックの音量バランスを決める**。フレーズ内の強弱には使わない |
| **11** | エクスプレッション | ★ **フレーズ内の強弱を付ける** |
| **64** | サステインペダル | |
| **68** | レガートの切り替え | 0–63 オフ / 64–127 オン |
| **74** | フィルターのカットオフ（明るさ） | |
| **91** | リバーブのセンド量 | |

★★ **CC7 と CC11 の混用は、オーケストラのモックアップが不自然に聞こえる最大の原因**
（→ `mc-style-cinematic` §8）。

## 4. MusicXMLとMIDIの使い分け

完全な比較表は [SKILL.md](SKILL.md) §6 を参照。用途別の要点は次のとおり。

- **YuE2に演奏させる → ABC**
