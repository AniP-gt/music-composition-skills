## 2. ★ 転用表

**中国語ポップスの編曲には、J-POP や欧米から借りた手法が多い。どの要素に使えるかを判断する。**

| 手法 | 中国語ポップスに使えるか | 補足 |
|---|---|---|
| **J-POP の和声語法**（王道進行、小室進行、カノン進行） | ✅ **そのまま使える**。すでに主流 | `mc-progressions` を参照 |
| **J-POP の A–B–サビの三部構成** | ✅ 使える。すでに主流 | `mc-form` §2.2 |
| **J-POP の B メロ（プリコーラス）** | ✅ 使える | 中国語圏のプリコーラス「预副歌」に当たる |
| **欧米の Verse–Chorus の二部構成** | ✅ 使える | 初期の中国語ポップスにはこの形式が多い |
| **シティポップの編成と音色** | ✅ 使える | `mc-style-citypop-rnb` を参照 |
| **J-POP の旋律の密度** | ⚠️ **調整が必要** | ★ **日本語では一音節に一音、中国語では一字に一音が目安だが、中国語は一字の重みが大きい**。J-POP と同じ密度では発音を聞き取りにくい |
| **英語ポップスのリエゾン・弱形の処理** | ❌ **そのままでは使えない** | 中国語には英語と同じ弱形がなく、そのまま使うと発音が不明瞭になる |
| **英語ラップのフロウ** | ⚠️ 調整が必要 | 中国語ラップはアクセントの規則が異なる。★ ラップと中華風を混ぜるときの分担は `mc-style-hiphop` §8.1 と `mc-workflow` §2.4 |
| **旋律が大きく跳躍する位置** | ⚠️ ★ **倒字の制約がある**（§3） | 中国語の旋律を作るうえで特に厳しい制約 |

★ **判断基準**
> **和声、編成、構成は自由に借りられる。旋律の音高の動きは声調に合わせる。**

## 3. ★ 倒字。中国語の旋律にかかる厳しい制約

### 3.1 倒字とは

標準中国語には四つの声調があり、**字ごとに音高の推移がある**。
その字に入る旋律の音程が声調の向きと食い違うと、聞き手には**別の字**に聞こえる。これを**倒字**と呼ぶ。

**判定モデル**

```python
contour  = TONE_PITCH[t][1] - TONE_PITCH[t][0]   # 対象の字の声調
incoming = notes[i] - notes[i - 1]               # 対象の字に入る音程
if   contour > 0 and incoming < 0: リスクあり    # 上昇する陽平に下行で入る
elif contour < 0 and incoming > 0: リスクあり    # 下降する去声に上行で入る
elif contour == 0 and abs(incoming) >= 3: リスクあり   # 平らな声調に大きく跳躍して入る
```

`TONE_PITCH` には、趙元任の五度式声調表記で各声調の始点と終点を入れる。陰平 55（平坦）、陽平 35（上昇）、上声 21（下降。続けて発音するときは半上声を採り、全上声 214 は単独で読むときと文末に現れる）、
去声 51（下降）、軽声はおよそ 3（平坦。本来軽く短いので重みは半分）。**陽平には下行で入らず、去声・上声には上行で入らず、平坦な声調には半音三つ以上の跳躍で入らない。**

★ 比較するのは**対象の字に入る旋律の音程**と**その字自体の声調**。
初版で使った「前の字の終点と次の字の始点」の比較では、教科書の典型例を検出できない。

### 3.2 編曲にかかる三つの制約

**倒字の判定と修正は作詞担当が行い、その結果を編曲に反映する。**

1. ★ **旋律を大きく跳躍させる位置を選ぶ**。跳躍の着地点となる字には倒字のリスクがある。
   → `mc-melody` §3 で跳躍を配置するときに考慮する。
2. ★ **中国語では曲先の負担が大きい**。旋律を先に書くと、作詞家は意味、韻、声調を同時に満たす必要がある。**詞先で書くか、歌詞と旋律を並行して直すことが多い。**
3. **同じ旋律でも歌詞が変われば再点検する**。2番のヴァースで歌詞が変わると、倒字の起こりやすい箇所も変わる。
   → `form[].note` に「A1 と同じ旋律で歌詞が異なるため、倒字を再点検する」と記す。

### 3.3 自己点検

> **各セクションを歌詞と旋律に合わせて一度読んでみる。別の字に聞こえたら倒字。**
> 体系的に調べる場合は、各セクションの最高音、各フレーズの最初の字、半音五つ以上の跳躍の到達点を確認する。§3.1 のモデルで、対象の字に入る音程とその声調を比べる。

| セクション数の中央値 | 10 |
| 曲の長さの中央値 | 217秒 |

⚠ **3件ではスタイル全体の特徴を判断できない。** ここでは確認できるデータの範囲を示す。
★ BPM 137 は3件の中央値。楽譜上の BPM は §4.3 を参照。

### 4.2 歌本コーパス

| 書籍 | ページ数 | 用途 |
|---|---|---|
| 《同一首歌·20 世纪中国流行歌曲精品》 | 569 | 20世紀の曲集。四項目の対応表の選曲に使う |
| 《2012 流行歌曲精选》 | 140 | 和声と曲構成の集計 |
| 《我的流行吉他》1 / 2 / 4 | 100/111/107 | ★ **コード記号とセクション別の和声分析**があり、進行の集計に適している |

### 4.3 歌本の集計（5種931件。楽譜上のデータのみ収録）

中国語の歌本4種（《同一首歌》の20世紀の作品379曲、《2012 流行歌曲精选》102曲、《我的流行吉他》3冊83曲、計 n=564）

| 指標 | 値 |
|---|---|
| 調（移動ドの主音。転調する場合は開始時の調） | F 15%、C 13%、G 13%、D 10%、♭B 10%、E 9%、A 9%、♭E 8%（n=550） |
| 拍子 | 4/4 69%、2/4 25%、3/4 4%、6/8 2%（n=546） |
| BPM（楽譜に数値がある曲のみ） | P10 58 / 中央値 **84** / P90 120（n=78、**ほぼすべて《同一首歌》の20世紀の作品**） |
| 速度・発想標語 | 中速 58、やや遅く 28、やや速く 24、次第に遅く 18、情感を込めて 12、情熱的に 9、自由に 8 |
| 楽譜に記されたジャンル | 映画挿入歌、映画主題歌、新疆民謡、陝西民謡、オペラからの選曲 |

**集計の読み方**

- 調の分布は比較的均等。F、C、G、D、♭B の5つで6割を占め、どの調も2割を超えない。近年の作品（2012年選集とギター譜）では C、G、D、♭E が主で、ギター譜にはカポを付けて C や G のフォームで弾く例が多い。
- ★ **現代の中国語ポップスの BPM は、この歌本コーパスでは未計測**。数値のある78曲はほとんどが20世紀の民族歌謡や映像作品の楽曲で、中央値84を現代の曲に当てはめることはできない。2012年選集とギター譜には速度標語（中速、やや遅く）のみが載る。BPM の把握には音源コーパスが必要。
- 2/4 拍子が4分の1を占めるのは20世紀の歌本の特徴。現代の中国語ポップスはほぼすべて 4/4 拍子。

欧米の比較資料として、英語圏の Fake Book（1955–1986年の Billboard 上位20曲、n=367）の調、コードループ、進行の骨格を `mc-case-studies` の reference §1.2 に収録している。

### 4.3 ⚠ コード進行を試験集計した結果

**方法**。《我的流行吉他》シリーズから「1=X」の調表記とセクション別の和声進行を抽出し、度数表記に変えて、連続する4コードを集計した。

**結果**。解析できたのは **10曲**。頻度上位は
`I V I V`（3回）、`V I IV V`（3回）、`I IV IV I`（2回）。

**結論**。★ **サンプルが少なく、結果も一般的な進行であるため、中国語ポップス固有の特徴を示す根拠には使えない。**

## 5. 広東語への拡張

> **このスキル集はレイヤーを組み合わせる設計なので、広東語・韓国語の詳細な言語レイヤーは後から追加できる。**

広東語について現時点で扱う範囲を示す。

| 項目 | 内容 |
|---|---|
| **協音** | 広東語の九声は標準中国語の四声より旋律への制約が**ずっと厳しい**。判定は**作詞**の担当 |
| **このスキルの範囲** | その制約があることと、標準中国語より厳しいことまで。個別の規則は扱わない |

★ **広東語の協音には厳密な体系がある。規則は底本を確認してから記述する。**

### 5.1 時代区分を編曲に生かす（黄志华《粤语流行曲四十年》）

| 時期 | 背景 | 編曲への示唆 |
|---|---|---|
| 1949–1959年 | 上海から伝わった**標準中国語の時代曲**と、黄金期の**広東オペラ（粤劇）・広東歌謡（粤曲）**がルーツ（p0047） | 初期から、時代曲のダンスホール楽団と、粤曲の小調で使う鉦・太鼓と梆黄の二系統がある。昔ながらの広東語ポップスを作るときは、どちらを下敷きにするか選ぶ |
| 1960年代 | 広東語映画の影響で、**粤曲に寄りすぎる**か、**西洋化を狙ってちぐはぐになる**例があった（p0048）。粤劇の小曲など、既存の曲に新しい詞を付ける例が多い（p0048） | ★ 現代のレトロな広東語ポップスにも当てはまる。鉦と太鼓を前面に出すと粤曲そのものに近づき、西洋の手法を無理に足すと様式がまとまらない |
| 1980–1982年 | 台湾のキャンパスフォークが流行し、若者の自作を後押しした（p0051）。市場が停滞し、レコード会社は新人歌手や作詞家を起用した（p0051–0052） | フォークのギター編成を取り入れる。アコースティックギターを軸に、編成を軽くし、歌詞を前に出す |
