# リズムとグルーヴ（Rhythm & Groove）

**このスキルは、リズムそのものの設計を扱う。**
`mc-rhythm-section` は、**それを人間らしく演奏する方法**を扱う。

具体的には、次のように使い分ける。
- **「この曲は 16 beat で、ベースが裏拍で先に入る」 → このスキル**
- **「ベースを 12 ミリ秒早め、hi-hat のクオンタイズを 60% にする」 → `mc-rhythm-section`**

## 2. 拍、拍子、強弱の構造

### 2.1 ★ テンポとビート感は独立している

| | 定義 |
|---|---|
| **Tempo** | **拍の速さ**（BPM = 1 分間の拍数。BPM 60 → 1 拍 = 1 秒。BPM 120 → 1 拍 = 0.5 秒） |
| **ビート感**（8 beat / 16 beat） | **各拍をどれだけ細かく分けるか**（2 等分 → 8 beat、4 等分 → 16 beat） |

★ **両者は独立している**。hi-hat を同じ時間間隔で鳴らしても、BPM 120 では 8 beat、BPM 60 では 16 beat に聞こえる。

**音の密度はテンポを保ったまま上げられる。** ゆったり聞かせたいときも、テンポを保ったまま拍の分割を変えられる。
**まず、どちらを変えたいのかを明確にする。**

### 2.2 4/4 の拍の強弱

（二拍子を二層に重ねると）**第 1 拍が最も強く、第 2 拍は弱く、第 3 拍は中程度に強く、第 4 拍が最も弱い。**

```
◎    ○    大○   小○
1    2     3     4
```

リズムパターン、**コードを切り替える位置**、旋律のアクセントは、いずれも強拍を基準に置く。
★ **コードが変わる強拍では、ベースにルートを置く。** これで曲の土台が安定して聞こえる。

### 2.3 表拍 / 裏拍

**表拍**は拍の頭、**裏拍**は拍と拍の間にある。分割の細かさは §2.1 のビート感に従う。8 beat では拍の後半にあたる八分音符が裏拍になり、16 beat では八分音符をさらに分けた後半の十六分音符にも裏拍ができる。

この区別は、シンコペーションと先取りで弱い位置と強い位置の音を区別する（§3）、hi-hat の強弱を交互に置く（§4.1）、オモテノリとウラノリで動きの起点を決める（§5.2）という 3 つの判断に使う。

### 2.4 変拍子

- **セクション単位で拍子を変える**と劇的な効果が出る。曲が分断されて聞こえやすいため、**同じ旋律音型を使って統一感を保つ**
- ★ **局所的に 2/4 を 1 小節挟む**と、サビの前でタメを作り、弱起で勢いよく入れる。**定番の手法**
- **拍子が変わる箇所では、ドラムとベースの動きを事前に決める**

## 3. シンコペーションと先取り

| | 手法 | 効果 |
|---|---|---|
| **シンコペーション（Syncopation）** | 弱拍（または裏拍）の音を**タイで次の強拍まで伸ばす** → その音が強拍の重みを持つ → 次の動きが**後ろにずれる** | **タメと、ゆったりした遅れ** |
| **先取り（Anticipation）** | 強拍の音を**手前の弱い位置で鳴らす** → 進行が**早く到達する** | **切迫感、落ち着かなさ、前へ進む勢い** |

### 3.1 ★ 両者に共通する前提

> **聴き手がすでに拍子をはっきり感じ取れていること。**
>
> 無伴奏の箇所や拍子がまだ定まっていない曲の冒頭で使うと、**効果が出ず、拍もつかみにくくなる**。

冒頭からシンコペーションを重ねて拍の位置が聞き取れなくなるのは、よくある失敗である。

### 3.2 拍が定まらない状態

**無伴奏で始め、音価を単調にそろえる**と、**拍が定まらない状態**（拍がまとまりを作らない状態）に陥りやすい。旋律の発音間隔が均等で、音価の長短の差が小さいほど、この傾向が強まる。

★ 拍が定まらない状態は、意図的にも使える。中国語歌曲の作曲には「**散板华彩式前奏**」（自由なテンポのカデンツァ風前奏）という手法がある。主題に由来する短い動機を軸に、アルペジオや音階の走句を多く使い、小節に縛られずに展開して、情景や感情を描く（p0138）。
**その後に明確な拍が現れ、聴き手がそこから拍をつかめるか**で、導入として機能するかどうかが決まる。

## 4. グルーヴの 3 要素

> **規則的な拍に強弱をつけることがグルーヴの核になる。**

| 要素 | 説明 |
|---|---|
| **1. Velocity の強弱** | velocity は文字どおり「打鍵速度」。打鍵が速いほどアタックが鋭く、音量も大きくなる |
| **2. わずかなタイミングのずれ** | グリッドから少しずらすと、人間らしさが出る |
| **3. 音の長さと隙間（休符）** | ★ 最も見落としやすい要素 |

### 4.1 8 beat の各パーツの velocity 設計

1. **Hi-hat** の各拍にある 2 つの八分音符を**「強–弱」と交互に打つ**
2. **Snare** の第 2、4 拍は拍子の上では弱い位置にある。**意図的に強く打つと前進する力が生まれる**（backbeat）
3. **Kick** は第 1 拍を強く、第 3 拍の裏を弱く打つ。
   ★ **第 2 拍裏の kick が第 3 拍の強拍を八分音符 1 つ分先取りしている場合は、強く打つ**

### 4.2 重さと軽さを左右するもう一つの要素（相対的なタイミング）

> **スネアがキックより少し遅れると重く、少し早いと軽く聞こえる。**

★ `mc-rhythm-section` §3 の push_pull は、**ここで決めた感触をミリ秒単位のずれで実現する**ための設定。

## 5. 表ノリ、裏ノリ、跳ね

### 5.1 拍にそろえ続けたときの聴こえ方

> 旋律が終始拍にそろうと、素朴でまっすぐな力強さが出る一方、**四角張って聞こえる**。
> 伴奏も拍の頭を打つと、**旋律が埋もれる**。
>
> ★ **入りを拍からずらし、適度にシンコペーションを使うと、旋律が浮き立ち、伸びやかに聞こえる。**

### 5.2 ウラノリ / オモテノリ

**裏拍または表拍を、動きの起点**として感じるグルーヴの捉え方（起点 → 解決）。

| | 感触 |
|---|---|
| **オモテノリ**（表拍の感覚） | どっしりした安定感と打撃の強さ |
| **ウラノリ**（裏拍の感覚） | 跳ねと軽やかな流れ |

★ **どちらが優れているということはなく、ノリによって歌詞のどの音節が際立つかが決まる。**
（裏ノリでは、裏拍から始まる音節が際立つ。）
**強調したい音節があれば、ノリに合わせて音符の位置を調整する。**

- 8 beat の旋律は**四分音符の裏拍**、16 beat の旋律は**八分音符の裏拍**で動くことが多い
  → シンコペーションや先取りが自然に生まれる

### 5.3 Bounce と Shuffle

| | 定義 |
|---|---|
| **Bounce** | 裏拍の音を**遅らせて次の表拍に近づける**（≒ 表拍の音が長くなる）。**テンポが遅いほど大きく跳ねる** |
| **Shuffle** | bounce を**三連符の位置に固定する** |

★ **bounce の効いた曲では、旋律に三連符を使っても自然に聞こえる。**

## 6. リズムパターンとのかみ合わせ

### 6.1 ★ 旋律を書くときはリズムパターンを思い浮かべておく

> **旋律自体にリズムパターンを感じさせる。** 作曲中に頭の中で 8 beat / 16 beat のグルーヴを鳴らし、
> そのノリの中で旋律を動かす。
> **既成のリズムパターンにあとから旋律を押し込むと、動きが不自然になる。**

### 6.2 旋律と backbeat の 3 つの関係

（8 beat では第 2、4 拍のスネア）**次の 3 つから必ず 1 つ選ぶ。**

1. 旋律を **backbeat の位置で休ませ**、backbeat と**掛け合い**にする
2. 完全に空けなくても、**backbeat が聞こえるよう少し譲る**だけで効果がある
3. 旋律の強いアクセントを **backbeat と同時に鳴らす**。部分的に重ね、
   旋律が休むところでは backbeat が聞こえるようにする

### 6.3 ★ リズムパターンは伴奏が担う

> **旋律に隙間を作り、そこからリズムパターンが聞こえるようにする**と、響きに立体感が出る。
> **旋律でリズムパターンをなぞると**、音が重複して混み合い、互いの効果が弱まる。

★ これは `mc-melody` §9 の診断表にある「伴奏に埋もれる」症状の 2 つ目の原因。
（1 つ目は、旋律の冒頭が低音と同じ強拍に落ちること。）

## 7. リズムそのものの展開

**リズムは音価のまとまりとアクセントの位置で決まる。**
★ **アクセントの位置が変われば別のリズムになる。** **高い音は自然にアクセントになる**ため、
高い音の置き方だけでもリズムを組み立てられる。**表と裏を入れ替える（ウラオモテ）と、リズムの性格が大きく変わる。**

| 手法 | 効果 |
|---|---|
| **そのまま反復** | 安定するが硬くなりやすい。**反復単位を 2 小節以上に広げると窮屈さが和らぐ**。音価の種類が少ないほど反復がはっきりし、窮屈さも増す |
| **位置をずらして反復** | 4/4 で 1.5 拍（付点四分音符）の単位を反復する。3/4 で 2 拍の単位を反復すると **hemiola** になる。★ **ずれ自体が緊張感を生む** |
| **形を変えて反復** | 全体を縮めると焦りや切迫感、全体を伸ばすとゆとりや安定感が出る。**先取りで伸ばすと、切迫感が増す** |
| **一部分だけ反復** | 間を置いてフレーズの末尾にゆったり応えると **echo**（内省、心残り、独り言）になる。反復部分を徐々に短くし、拍ごとに詰めると **たたみかける**（一歩ずつ迫る）切迫感が出る |
| **対比** | ★ **リズム型は特徴がはっきりしていると聞き分けやすい**。最も明瞭なのは**短い音価のまとまりと長い音価のまとまりの対比**。**順序を逆にしてさりげなく対比を作る**と、唐突さを避けつつ単調さを減らせる |

### 7.1 シンコペーションの明瞭さの加減

> **シンコペーションが聞き取りにくいとリズムがくどくなり、分かりやすすぎると単調になる。**
>
> **耳に引っかかる音価と拍の位置で緊張をため、素直な位置で解放する**と、開放感が出る。

## 9. 書き終えた後のチェック

- [ ] **BPM とビート感を別々に決めた**。「速い曲だから 16 beat」と一律に決めていない
- [ ] 表ノリか裏ノリかを決め、重要な音節をそのノリで際立つ位置に置いた
- [ ] シンコペーションや先取りを使う箇所では、**拍子がすでに定まっている**（冒頭の無伴奏部分を避けた）
- [ ] 旋律と backbeat の関係は §6.2 の **3 つから 1 つ選んだ**
- [ ] ★ **旋律がリズムパターンをなぞらず**、旋律の隙間からリズムパターンが聞こえる
- [ ] セクション間に**リズムの対比**がある（最も明瞭なのは短い音価のまとまりと長い音価のまとまりの対比）
- [ ] 反復箇所で、ずらす、変形する、一部だけ繰り返す、のうち少なくとも 1 つを使った
- [ ] 拍子が変わる箇所でのドラムとベースの動きを決めた

## コードが変わる速さもグルーヴの一部

1 小節あたりのコード数は `mc-harmony` で扱う。ここでは、その数がグルーヴにどう影響するかを扱う。

- **和声リズムを倍にすると推進力が増し、半分にするとゆとりが出る**。同じグルーヴでも、2 小節ごとのコード変更を 1 小節ごとにすると、ドラムの音を一つも変えずに曲が速く感じられる
- **A メロとサビで和声リズムを変えるだけで、編成を増やさずにセクションを対比できる**。Kachulis は同じコード進行の 2 種類のリズム変奏で A メロとサビを作る（`mc-harmony` reference §6）
- 和声リズムとドラムのアクセント周期がずれると、`mc-orchestration` §3.9 のリズムによる強調と同じように、拍の重心が浮いたように感じられる。意図した効果か、避けたい結果かを仕様書に明記する
