# 楽想の展開（Thematic Development）

> **1曲 = ひとつの主題素材 ＋ 各セクションでその素材に施すひとつの操作。**
> このスキルが扱うのは後者、つまり**このセクションで先に出た素材をどう扱ったか**。

旋律そのものの書き方は `mc-melody`、セクションの配置と長さは `mc-form` と `mc-arrangement-arch` が扱う。
このスキルは仕様書の `material` と `form[].development` を担当する。
これらの項目で、従来の仕様書では答えられなかった**このセクションの素材はどこから来たか**という問いに答える。

## 1. 書き始める前の必須項目

**`material` の3項目をすべて埋めてから `form[].development` を記入する。**

| 必須項目 | 確認事項 | 判定基準 |
|---|---|---|
| **① 動機の内容** | 音程の輪郭、リズム型、長さを文章で明記する | シェーンベルクによれば、動機の特徴をなすのは**音程とリズム**で、両者が結びついて記憶に残る輪郭を作る（p0025）。この2つを記述できる段階で動機とみなす |
| **② 性格を一文で** | 動機がどんな性格を持つか | 李吉提によれば、リズム型の性格はアクセントの位置で決まる。強弱型は下降に向き、弱強型は推進力があり、強強型は力強く、弱弱型は穏やか（p0016–0017） |
| **③ 原型を提示するセクション** | セクションの id。複数指定可 | 杨儒怀によれば、原型の提示は以後のあらゆる展開の出発点となる。途中で現れ、以後の展開の出発点となる新しい楽想も含む（p0110） |
| **④ 曲を進める主な手法** | 加工処理／漸次的な展開／対比から主となるものをひとつ選ぶ | 李吉提の3種の展開手法（p0020）。§5.1 参照 |

**動機に必要な特徴**。重要な楽想には、リズム、旋法、旋律の進み方といった特徴が**有機的に結びついた**、明確な音型上の個性が必要となる（杨 p0110）。
李吉提の基準はさらに厳しく、音群を動機と呼ぶには、独立して加工でき、そこから音楽を発展させられる必要がある（p0016–0018）。
動機と音群を同一視する理論体系もあるため、書き始める前にどちらの定義を採用するか明記する。

★ **動機の提示位置**。重要な楽想は曲の要所で提示する。イントロがなければ冒頭、あれば主要部分の冒頭に置く。
イントロで原型の一端を先に示しておくこともできる（杨 p0110）。

★ **展開に向く動機は単純なもの**。主題に興味深い特徴がすでに多すぎると、変奏で新たな要素を加える余地がなくなる（シェーンベルク p0229–0230）。
旋律、和声、テンポ、強弱、テクスチュア、音域はいずれも中庸に保つのが望ましい（李 p0165）。

## 2. ★ 展開と素材の寄せ集めの境界

> **判定基準はひとつ。聴き手が先に出た素材に由来すると分かるか。**
> 拡張、反復進行、断片化、変奏、対位法、再現はいずれもこの基準を満たす。別の旋律に差し替えると、そのつながりは失われる。

### 2.1 素材のつながりが聴き取れるための2条件

**シェーンベルクの基準**（p0025）。動機を使うには変奏が必要で、単純な反復では単調になる。一方、特徴をすべて変えると、
素材同士のつながりが失われ、断片化して動機の基本形が崩れる。**副次的な特徴を変え、重要な特徴をいくつか残す。
とりわけリズム型**は、連続性を保つのに最も効果がある。

**派生の条件**（p0038–0039）。リズムと音程、その方向を同時に変えるなど、元の形から離れた動機型は理解しづらくなりうる。派生した動機は一つひとつが
**ひとまとまりの短いフレーズとして成立する**必要がある。これを欠くと断片になる。元の形から離れるほど、リズムや補助音など別の手がかりで認識しやすさを保つ。
**テンポが速いほど、曲の中で許容できる変化の幅は狭くなる**（p0040）。

### 2.2 新素材を使う分量

杨儒怀は新素材の導入について、どの手法よりも用途が広いだけに**最も濫用されやすい**と警告している（p0122）。
無関係な新素材を何でも持ち込めるわけではない。李吉提は曲の形式の側からその仕組みを説明する（p0025）。セクションを並列に置くとその対比で音楽を刷新できるが、
**並べる数が増えすぎると「遠心力」が働き、全体をまとめる構造が弱まる**。各セクションを新素材で書くと、この作用が全曲に及ぶ。

- §9 の3つの注意事項のうち、最も重要なのは **`new` を指定するセクションを半数以下に抑える**こと。
- 歌詞側には比較に使える実測値がある。中国語圏の歌詞コーパスでは、歌手ランキング上位100組の楽曲のうち、ラップ以外の3631曲をセクションラベルに基づいて集計した結果、全曲に占めるコーラスの割合は25〜70%、中央値は約半分で、すべてのコーラスの歌詞が一字一句同じ曲は27%だった。
  **コーラス全体を反復に充てると、ヴァースで語りを進める余地が生まれる**。曲の側でいえば、`recap` と `repeat` に相応の長さを割くことになる。
- セクションの比率は `mc-arrangement-arch` §4 が扱う。

### 2.3 判定基準の運用

杨儒怀は展開形態を一通り説明した後、**異なる形態の間には移行やさまざまな中間形態がありうる**と注意を促している（p0127）。
「どんな場合でも、教条的で機械的な分析は音楽芸術の実態を損なう」。そこで `development` には主値をひとつと、必要な数の副値を記入する。
ひとつのセクションに拡張と反復進行を併記できる。10個の値で表しきれない場合は、最も近い値を選んで `note` に一文を添え、独自の値は作らない。

## 3. 10種の手法とその用途・代償

`form[].development` の値は以下の10個。**各セクションに主値をひとつ指定し、必要に応じて副値を加える**。主値を先に書く。
各手法の定義、判定基準、代償、出典ページは [reference.md](reference.md) §1 の対照表にまとめている。ここでは作曲時に使う要点を扱う。

### 3.1 `repeat` 反復（原形、冒頭または末尾の差し替え）

繰り返す楽想を際立たせ、印象を深める。**短く重要な楽想ほど、反復の必要性が高い**（杨 p0111）。

- **代償**。機械的な反復がもたらすのは統一感で、対比は生まれない。通常は2回までとし、3回以上続くと欠点になる。クレッシェンド、加速、
  音域の移動を伴えば単純な反復の域を出る。短く重要な動機と持続低音は例外で、何度も繰り返せる。楽想は対をなすように反復することが多く、
  偶数回が最も明瞭に聴き取れる（p0111–0112）。
- **冒頭・末尾の差し替え**。一致させる部分と差し替える部分が前後をつなぎ、別のセクションに分断されることなく、ひと続きの長い楽想を作る。判定基準は、
  **「新しい部分があるからこそ一致が際立ち、同じ部分の反復があるからこそ差し替えが際立つ」**（p0128）。

### 3.2 `sequence` 反復進行

楽想を別の音度で反復し、ときには調性も変える。「変化の中の統一」をもたらす（杨 p0115）。

- **推進力**。上行する反復進行は響きを高揚させ、下行する反復進行は弱める。縮小や断片化と組み合わせると推進力が際立つ（p0115–0116）。
- ★ **使う段階を誤ると紋切り型になる**。旋律をさらに発展させる段階（承、転への移行、クライマックス前の準備）に最も適している。
  **初期提示には不向きで、転調を伴うものは特に避ける**（p0116）。
- **型どおりになるのを防ぐ**。各反復の一部で音程、旋律線、間隔、テクスチュアの細部を変える。**最後の反復は、後続する音楽につながるように調整することが多い**。
  五音音階では音程を厳密にそろえられないため、方向が一致すれば厳密な反復進行とみなす（p0116）。シェーンベルクによれば（p0092）、ダイアトニックな反復進行は
  調性が明瞭な一方で展開の幅は限られ、代用音を使うと転調できる。

### 3.3 `extend` 拡張

再提示の際に**楽想の内部から**引き伸ばす。伸ばした部分は元の楽想と有機的につながり、両者の間に終止感がないか、意図的に隠されている（杨 p0131）。

- ★ **反復との判別基準**。拡張がどこで始まり、どれほど大きくなっても、**通常は元の終結素材に戻らない**。
  冒頭を共通にして末尾を差し替える場合は通常、楽想全体の長さを保つ。内部拡張では長さが変わる（p0131–0132）。
- **3類型**。終止形の前の内部拡張、終止形で解決を回避した後の拡張、終止形の後の緊密な拡張。よく使われるのは最初の2つ（p0131–0133）。
- **方向の判定**。内部拡張が新たな性質を育てるなら展開的、情緒を鎮めるなら終結的と判定する（p0132）。
  拡張が次の新しい楽想を準備する機能に変わることもある。この場合、和声を開いたまま属和音にとどまるか、転調する（p0134）。
- **代償**。内部拡張は原型の提示と比較しないと判別しにくい場合がある（p0133）。

### 3.4 `contract` 縮小

再提示の際に原型の提示よりも構造を短くする（杨 p0136）。

- **性格**。収束に向かう。短い回顧、要約した再提示、補足などの形をとり、**情緒の高揚をもたらさない**。曲末やその手前で多く使う。
- **3つの方法**。中間の音型を省いて冒頭と末尾だけ残す。省く箇所を均等に分散させ、起伏を調整する。転調を伴う縮小では、原調に戻りながら長くなった提示を通常の規模に戻す。
  拡張より使われる機会が少なく、方法も単純（p0136）。**曲末を盛り上げたい場面には向かない。**

### 3.5 `fragment` 断片化

楽想を構成する断片を取り出し、そのまま、あるいは加工して個別に使う（杨 p0137）。

- ★ **典型的には複数の箇所から繰り返し切り出す**。切り出した断片を続けてさらに切り詰め、**短くなるほど展開が緊密になる**（p0137）。
- **用途**。情緒をクライマックスへ押し上げ、活気や緊張を次第に高めながら、強い統一感と多層性を作る。断片は主要声部にも
  背景にも使え、編成を厚くすることで高揚を生み出せる（p0137–0139）。
- **代償**。断片が短くなるにつれて旋律性が失われる。極限では動機の痕跡が単発のリズムだけに切り詰められ（シェーンベルク p0280）、
  そのセクションには歌える旋律線が残らない。

### 3.6 `vary` 変奏

原型の大まかな輪郭、旋律の動きの全体像、構造の規模を保ち、**新たな表情を与えながら原型とのつながりを聴き取れるようにする**（杨 p0114）。
方向は2つある。装飾を加えて流動的にしたり、単純化して形を明瞭にしたりする範囲にとどめ、基本的な性格を保つ方法。
もうひとつは輪郭と構造上の比率を保ちつつ異なる性格を与える**性格変奏**で、対象のジャンルに固有のリズム型、音型、テンポを見つける。**とりわけリズム型が重要**（p0114–0115）。

- **変化反復との境界**（p0113–0114）。変化反復では旋律全体の印象を保ちながら、繰り返すたびに局所的な旋律の処理を変える。各回で異なる変え方をしてよい。
  変奏は全体を通じて展開し、**変化の手法に一貫性を持たせる**。
- **シェーンベルクの4種の変奏法**（リズムの変更／音程の変更／和声の変更／旋律の適応、p0030–0031）は最も詳細な一覧で、
  全表は [reference.md](reference.md) §3 にあり、7種の和声変奏は同節末尾にある。基本条件は（p0028）、
  **生まれた動機型を基本動機から遠ざけすぎない**こと。

### 3.7 `augment` 音価の拡大と縮小

同じか近い拍子とテンポの中で、楽想の音価を1倍、2倍、3倍に相当する比率で伸ばすか詰めて再提示する（杨 p0116–0117）。

- ★ **判定基準は相対的な音価が整数比で変わること**。記譜の違いや演奏テンポの変化とは区別する。譜面上で音価が2倍に見えても、
  実際に拍を基準とした音価が倍になっていなければ拡大には当たらない（p0117）。
- **拡大**。荘重さ、安定感、重みが生まれる。曲末では雰囲気が次第に静まり、速度感が緩やかになる。**楽想の一部だけを拡大することもできる**（p0117）。
- **縮小**。音価を短くして動きを増やし、前に進む力を強める。**連続的な音価の縮小**は強い緊張を蓄え、クライマックスへ導いたり、
  新しい楽想を引き出したりしやすい。離れていた楽想同士の間隔だけを詰める**時間的縮小**もある（p0118）。音価を縮小した形は、そのままオスティナートの伴奏音型にも使える（p0119）。

### 3.8 `counterpoint` 対位法による展開

ある声部が、ある音高から楽想の**音価を拡大または縮小して原型を提示した声部を模倣する**。ポリフォニーの展開や声部間の模倣で広く使われる（杨 p0118–0119）。
**このスキルはセクションを対位法による展開と判定するところまでを担当する**。模倣、カノン、フガート、ストレッタの作り方は `mc-counterpoint` §7
と reference §7 を参照。**代償**。各層が聴き分けられる必要があり、周波数帯域や奥行きの配置が悪いと2本の旋律線が混ざって1本に聞こえる。

### 3.9 `new` 新素材

展開の途中で、元の楽想を特徴づける音型や旋律の輪郭を引き継がず、前述の手法によるつながりも持たない新しい楽想が現れる（杨 p0122）。
**この値は「このセクションは既出の素材に依存しない」という宣言に当たり、10個の値で唯一、該当セクション数を数える（§9）。**

杨儒怀は元の素材とのつながりが残るものから完全に途切れるものまで、性質に応じて3種に分ける。**継承型の新素材導入**では、各要素を刷新しながらも、リズムの動きの範囲、旋律の展開幅、
テンポ、様式、旋法・調性、曲調などに共通点が多い。**合成型の新素材導入**では、前後をつなぐものが拍子、テンポ、調性、表情と強弱の共通性に絞られ、
**主題素材の対比が主体となる**。**対置型の新素材導入**では、前後のつながりが分断されるが、曲全体の劇的な展開から見れば筋が通る。
対置には強いものと穏やかなものがあり、**割り込み型の対置**では楽想が終わる前に新素材が突然入り、同時に新しい形式部分が始まる。
各型の判定基準と用途の詳しい表は [reference.md](reference.md) §1 末尾にある（p0123–0126）。

**李吉提の2分類**（p0020–0021）。派生的対比は元の楽想と内的なつながりがあり、**対比を生みながら素材の由来による統一性を保つ**。
並置的対比は素材間に内的なつながりがなく、**対比がより強くなるため、全曲を統一する方法が別途必要になる**。`new` を書く前にどちらかを判断し、
判断できなければ構想を詰める。シェーンベルクの挿入句（p0224）では長さにも目安がある。流れを一時保留して緊張を生むが、連続性を中断する代償があり、通常は短く抑える。

### 3.10 `recap` 再現

新しい対照的な提示を経た後、以前の楽想を再び提示して「原型の提示、対比、原型の再提示」の3段階を形作る。
最初の楽想を際立たせ、構造と主題素材を総括して統一する役割を持つ（杨 p0112）。

- ★ **`recap` を記入する際は原形か力動的かを明記する**。静的再現（原形再現）ではテクスチュア、オーケストレーション、強弱を除いて本質的な変更を加えない。
  変形再現では構造と内容を本質的に変える（p0112–0113）。**力動的再現**では中間部の展開が再現部にまで及ぶ
  （李吉提 p0023–0024。5種の形態の全表は `mc-form` §6.2）。
- ★ 杨儒怀の指摘（p0112–0113）。**小規模で前後から切り離されていない再現のほうが、素材を統一する効果は明瞭になる**。
  コーラスを繰り返すときの小規模な再現はこれに当たる。
- **変更の限度**（シェーンベルク p0188）。再現部のあらゆる要素に変奏を適用できるが、構造を実質的に変える場合を除き、
  **旋律の輪郭をすべて変えることは避ける**。装飾変奏で輪郭が実質的に変わるとは限らないものの、**リズムの変更やアクセントの移動が多すぎると、原型を判別しづらくなる**。

## 4. 動機から楽句へ

### 4.1 2つの単位体系

| | シェーンベルク（p0006） | 李吉提（p0016–0019） |
|---|---|---|
| 最小 | 動機 motive | 音群（ひとつのアクセントを中心にまとまった音の集まり） |
| ↓ | 単位、要素 | 動機（独立して加工できる音群） |
| ↓ | **短句 phrase** | 楽節（2つの音群、2〜4小節。旋律が一息つくことが条件） |
| ↓ | 前句／後句 | 楽句（2つの楽節、4〜8小節。**終止が必要**） |
| ↓ | 断片、セクション、部分 | 楽段 → 主題（単純二部形式や単純三部形式ほどの規模にもなりうる） |

**楽節と楽句を分ける基準は終止の有無**であり、長さとは区別する（李 p0018）。どちらの体系でも長さはテンポによって決まる。中庸なテンポでは1句が
4小節程度で、動機の反復進行を何度も行う長い句は数十小節に達することがある（李 p0018–0019）。極端に遅いテンポでは短句が半小節に収まり、極端に速いテンポでは8小節以上でようやく1句を成し、
ほぼ常に小節線をまたぐ（シェーンベルク p0019）。★ ひと息に進み、音群や楽節に分けられない楽句もある。その場合は楽句自体が最小単位となる（李 p0019）。

### 4.2 動機の処理

シェーンベルクは**厳密な反復、変化を伴う反復（変奏）、展開的な反復**の3種に分ける（p0026）。厳密な反復ではすべての特徴と音の関係を保つ。
したがって**別の音度への移置、反行、逆行、逆行反行、縮小、拡大はいずれも厳密な反復**に当たる。判定の基準は音の関係が厳密に保たれているかどうかで、表面的な類似度とは区別する。
聴感上は大きく異なる操作が同じ分類に入るため、誤読されやすい。4種の変奏法の全表は [reference.md](reference.md) §3 にある。

### 4.3 動機型の組み合わせ

**論理的に組み合わせられるかは3つの要素で決まる**（p0036）。内容の共通性（同じ基本動機から派生）、リズムの類似性（統一をもたらす）、
和声の連続性（関係を強める）。いずれかが欠けると論理性が弱まる。これに関連する原則がある。

- **冒頭が後続を決める**（p0041）。主題は冒頭の断片で基本動機を明示する。冒頭が2小節の短句なら、
  第3、4小節では原形のまま、または音高を移して反復できる。細かな変化を加える場合も、**反復だと分かるようにする**。
  第1短句を主和声に、第2短句を属和声に置く「主の形と属の形」の関係は、フーガの主題と応答に似ている（p0041–0045）。
  和声配置の対照表は [reference.md](reference.md) §5 にある。

### 4.4 楽句の収束と解体

**解体（liquidation）とは「特徴的な要素を徐々に取り除き、特徴のない要素だけを残すこと」**。際限なく延びる傾向を抑えるために行う。
残った痕跡は基本動機との共通点が少ないことが多く、終止形と組み合わせて境界を示す（シェーンベルク p0091）。
★ **認識しやすさを意図的に手放す**。動機が判別しづらくなるのは目的を達成するための代償として許容される。
これは §2 の「先に出た素材だと分かる」基準の唯一の例外で、収束する箇所に限って用いる。

★ **シェーンベルクの「展開」には2つの方向がある**（p0091）。成長、拡張、延長、拡大と、切り詰め、凝縮、強化の両方を指す。
このため、このスキルは `extend` と `contract` を別の値として扱う。これに対応するモデルが**展開的変奏**（p0095）。
旋律中のすべての動機型と短句が、冒頭の3音、場合によっては最初の2音から徐々に発展する。
`material.motif` はこの出発点を明記するための項目である。

## 5. 楽句からセクション、全曲へ

### 5.1 段階の連なりと3つの展開手法

**杨儒怀の3種の進行モデル**（p0093）。4段階（起承転結）、3段階（導入・展開・結び）、2段階（呼応）。
★ 段階の区分は相対的で、それぞれをさらに細分できる。全曲、セクション、楽句の各階層は独自の起承転結を持ち、互いに位置をそろえる必要はない。

**李吉提の3種の展開手法**（p0020）から `material` の④を選ぶ。

| 手法 | 内容 | `development` の値 |
|---|---|---|
| **加工処理** | 反復、変化反復、変奏、反復進行、音程やリズムの拡大・縮小。元の構造を分解して加工する点が特徴 | `repeat` `sequence` `vary` `augment` `extend` `contract` `fragment` |
| **漸次的な展開** | 元の楽想を出発点にして**素材を徐々に更新する**提示法。とりわけ中国の伝統音楽でよく見られる | 主値は `vary` または `extend`、副値は `new` |
| **対比** | 楽想を切り替える。派生的対比と並置的対比がある | `new` |

**杨儒怀の3段階**（p0120–0126）は元の楽想からどの程度離れるかを示す。この体系では漸次的な展開を変容と呼ぶ。

- **リズム型を踏襲する展開**。リズム型を保ち、旋律の進む方向または音程だけを変える。★ 統一性をもたらすのは、リズム型を踏襲する展開ではリズムの一致、
  反復進行では音程関係の規則性。したがって**呼応感にはリズム型の踏襲、運動の推進感には反復進行を使う**（p0120–0121）。
- **変容による展開**。核となる音型と大まかな旋律の輪郭を保ちながら、リズム型、音程、構造を変える（部分的な音価の拡大・縮小、構造の拡張・縮小、転調も可）。
  ★ **展開の度合いはさらに大きく、詳しく分析しなければ対照的な新しい楽想に聞こえることもある**（p0121）。
- **新素材の導入**。§3.9 参照。★ ひと続きの長い旋律の中で、3種の導入法が展開段階に応じて現れ、互いにつながることがある（p0126）。

### 5.2 全曲をまとめる手法

- **末尾の共通化**（p0129–0130）。すべての主題を同じ調性、同じ旋律断片で終え、内容と主題素材の両面で全曲に統一感を与える。
  ★ 中間部が継承型の新素材導入による対照的なセクションでも、末尾を共通にすることでほかのセクションと統一できる。
  関連する手法が**末尾の差し替えによる終止の呼応**（p0129）。末尾を差し替えて反復する際に終止音を旋法の主機能を担う音に変えると、2回の提示が前句と後句としてつながる。
- **末尾と冒頭の連結（連鎖）**（p0130–0131）。先行する楽想が明確な終止形で終わった後、後続する楽想は同じ終止部分を反復して始まる。
  別の形として、再提示で冒頭と末尾をそろえ、中間に変化反復を施す方法もある。★ **中間に長めの変化反復を置くと、
  楽想の再提示でクライマックスを形成したり、最初のクライマックスを超えたりできることが多い**。
- **動機の貫徹**（p0139）。通常の断片化と区別する条件は、どの形に断片化しても動機の核が残ること。

### 5.3 重なりによる接続

**重なり（overlap）**。前後の楽想を切れ目なく緊密につなぎながら、両者の境界と切り替わりが明瞭に聴き取れるようにする（杨 p0139）。
4種あり、拍頭での重なり（小節を共有）、シンコペーションによる重なり、イントロと主題の重なり、伴奏の重なりに分かれる。

★ ポップスの編曲で最も有用なのは4番目。前の楽想の末尾に新主題の伴奏音型や持続する和声を重ね、その響きをしばらく聴かせてから主題を入れる。
雰囲気を作りながら主題の入りを遅らせて新鮮さを出し、**登場を待たせることで聴き手の注意を主題の入りに向けられる**（p0140–0141）。
★ **劇的な割り込み**（p0141）もある。新素材は前の終止形の主和声と一致せずに始まる。和声上は偽終止、素材の扱いでは拡張に似ており、
独立した展開の筋を持つ。

### 5.4 終止後の補足

**補足**。楽想や主題が完全終止または半終止で終わった**後**に、内容と情緒が前と一致し、終結的な素材を持ち、
調性が明確で同じ原調に着地する音楽をつなぐ（杨 p0141）。

★ **拡張との判別基準**（p0142）。拡張では終止形が現れる**前**に区切りの感覚を意図的に隠し、楽想を内部から有機的に発展させる。
補足は完全終止または半終止の**後**に別途行い、外から付加する補助的な提示として現れる。
（緊密な拡張は境界が曖昧。これも終止後に行うが、典型的な補足では緊密なリズムがこれほど重要な条件にならない。p0133。）

用途は3つ（p0142）。性急な終止を補強する。情緒と響きを弱めて音楽の形象を徐々に遠ざける。終結時の高揚と明るさを維持または増強する。

★ **補足の機能転換**（p0143–0144）。音楽の形象が変わろうとする箇所では、補足の途中で性格を変え、展開を続けて終止形の到来を先送りできる。
この場合、補足は移行をつなぐ機能を担う。これが Outro を bridge に作り替える仕組み。
シェーンベルクには延長、挿入句、小コーダの3概念がある（p0224–0225）。コーダの内部では3つのことが同時に進む。
**素材の大半は既出の主題に由来し、構造の組み直しと解体が進み、断片は次第に短くなる**（p0253）。

## 6. 変奏による展開

★ シェーンベルクは「変奏」が働く4つの階層を示している（p0229）。主題の構築では動機型を生み、中間部では対比を生み、
反復に多様性を与え、「主題と変奏」の形式では作品全体を構成する原理となる。

### 6.1 2つの主要なタイプ（李吉提 p0159、p0166）

- **厳格変奏**。元の主題素材と構造の輪郭を維持することを前提に加工する。
- **自由変奏／性格変奏**。元の主題の構造を分解して展開し、新素材を加えることもできる。音楽の性格が変わることが多い。素材の扱い方は3つあり、
  主題の基本素材すべてを変奏する、ひとつの素材に絞って展開する、ときどき新素材を挿入して対比させる。**曲全体が変奏を軸に構成されていることが前提**。

各タイプ（固定低音、固定和声、固定旋律の3型、古典的な装飾変奏、自由変奏）の全表は [reference.md](reference.md) §4 にある。
★ **ポップスに応用できる2つの判断基準**。

1. **厳格変奏から自由変奏へ**（p0166）。**冒頭の数回は通常、厳格変奏から始める**。まず聴き手に元の主題の構造と音型を覚えてもらう。
   展開が進んだところ（たとえばクライマックスに入った後）で、回帰の性格を持つ厳格変奏を再び出し、内部にもう一度起伏を作る場合もある。
   自由変奏だけでは冒頭で主題をつかみにくく、厳格変奏だけでは劇的な起伏に乏しくなる場合がある。
2. **固定する要素が多いほど、変化する要素が際立つ**（p0169）。《波莱罗》はリズム、和声、調性をすべて固定し、
   音色とオーケストレーション、段階的なクレッシェンドだけで変化をつける。

### 6.2 主題を見失わないための条件（シェーンベルク p0231–0234）

- どの変奏でも主題を判別できるようにする。性格が変わっても、**出来事の順序と進行（断片の数と順番）は維持する**。
  拍子やテンポを変えたり、小節数を規則的に倍増させたりしてもよいが、各部分の比率、構造上の関係、主要な特徴は保つ。
- 主題そのものから取った**変奏動機**を体系的に使って統一する。まず副次的な成分をすべて省き、基本構造の骨格が分かるようにして抽出する（p0232）。
  変奏動機が**2小節を超えることはまれで、半小節以下の場合も多い**。
  ★ **和声の動きが密なほど、維持できる動機は短くなる**（p0232–0234）。

### 6.3 ポップスでの変奏の使い方

- **コーラスを重ねるたびに変奏で展開する**。新しいコードを加えない7種の変奏で、各コーラスに異なる表情を与える。
  同じ進行でリズムを変える方法の対比が最も弱く、進行も最初のコードも異なる2つのセクションの対比が最も強い（[reference.md](reference.md) §3 末尾）。
- **有節歌曲には固定旋律変奏を使う**（李 p0163–0164）。歌詞の節が多く単純な反復では飽きやすいため、旋律はそのままに、
  伴奏とオーケストレーションで異なる情緒を作る。**ヴァースの旋律を保ちながら編曲を節ごとに厚くするポップスの定石は、これに由来する。**
- **古典的な装飾変奏の限界**（李 p0165–0166）。構造と和声の基本骨格が変わらず、元の主題が定めた趣の範囲を超えることは少ない。
  同じ情緒を掘り下げるのに適しており、**劇的な転換を求めるセクションには向かない**。

## 7. ポップスへの適用

> 本節の既定値（2番のヴァースは末尾を変える `repeat`、プリコーラスは `fragment`、最後は `recap`）は、古典の判定基準から導いた妥当な初期案であり、**中国語圏や日本のポップスのコーパスでは未集計**。歌詞側には実測値があり（中国語圏の歌詞コーパス。数値は §2.2、§7.4）、曲の側は今後の課題。

### 7.1 2番のヴァースの展開

**既定では何らかの変化を加える。** 代償の小さい順に3つの方法がある。

1. **`repeat` で末尾を差し替える**。冒頭を共通にし、末尾を差し替えても楽想全体の長さは変わらず（p0131–0132）、最も負担が小さい。
   「同じ部分の反復があるからこそ差し替えが際立つ」という基準も満たす（p0128）。
2. **`vary` で変化反復**。旋律全体の印象を保ったまま、個々の音の差し替え、リズムの補完、装飾、単純化を行う。
   ★ 歌唱では歌詞の声調が変わると、ごく自然に変化反復が起こる（p0113–0114）。**中国語の歌ではこの性質をそのまま活用できる**。
3. **`contract`**。2番のヴァースを1番より短くする。セクションの長さの慣例は `mc-arrangement-arch` §4.4 を参照。このスキルでは、
   その切り詰めを縮小とし、性格は収束的で高揚を生まないと判定する（p0136）。

★ **ヴァースでは転調を伴う反復進行を避ける**（p0116）。1番のヴァースも2番のヴァースも提示段階にあり、ここに反復進行を置くと `mc-melody` §8
で述べる紋切り型の印象につながる。

### 7.2 プリコーラス

機能は移行的な提示。前の楽想を補った後に転調し、新しい楽想を導くか、**次を予期させる和音**で止まる（李 p0022）。
`development` の値は次のように選ぶ。

- 主値には `fragment` が多い。**切迫感を増すには断片化を使う**。テンポを上げずに、切り出した断片を次々に切り詰めて短くする（杨 p0137）。
- 副値には `sequence`（「クライマックス前の準備」は反復進行に適した位置。p0115–0116）、または `augment` の音価縮小（p0118）を組み合わせることが多い。
  **拡張の機能転換**（p0134）もここで使える。和声を開き、属和音で止まるか転調して、先行する楽想を強調しながら新旧の楽想をつなぐ。

### 7.3 bridge

以下の2つから選んで `note` に記入する。

- **断片化**。既出の素材を次々に切り詰め、活気や緊張を高めながら統一感を保つ（p0137）。
  最後のコーラスをさらに盛り上げるには、楽器を追加するより `counterpoint` のストレッタのほうが効果的。
- **新素材の導入**。`new` を指定する前に、**継承型、合成型、対置型のどれかを明示する**（§3.9）。決められない場合は構想を詰める必要があり、
  そのまま進めるとこのセクションが別の曲のようになる可能性が高い。

★ **入りと抜けは非対称**（李 p0065）。中間部に入るときは、対比の境界を明確にするため、通常はつなぎを設けない。抜けるときは迂回し、徐々に移行する形が多い。
**入りは唐突に切り替え、抜けは段階的につなぐ。** 唐突な切り替えには割り込み型の対置を直接使える（杨 p0125–0126）。

### 7.4 最後のコーラスの展開

`recap` を指定し、原形か力動的かを明記する。具体的な方法は4つ。

| 方法 | 根拠 |
|---|---|
| **原形を保ち、テクスチュア、オーケストレーション、強弱のみ変える** | 静的再現（杨 p0112）。最後と最初のコーラスの歌詞が一字一句同じ曲は3割近くあり（中国語圏の歌詞コーパス、ラップを除く）、意図的な選択として成立する |
| **力動的再現** | 動機を再加工し、和声を変化させ、テクスチュアを厚くする。構造の拡張をもたらし、全曲のクライマックスになることも多い（李 p0023–0024。5形態は `mc-form` §6.2） |
| **hook の音価を2倍にする** | 音価の拡大で安定感と重みが生まれ、曲末では雰囲気が落ち着く（杨 p0117）。**一部だけの拡大も可能**で、hook の最初の楽節だけを伸ばせる |
| **末尾の追加（拡張または補足）** | 主調に戻って終止する前に拡張することが多い（p0135）。完全終止の後に補足をつなぎ、終結時の高揚と明るさを強める方法もある（p0142） |

★ **歌詞側との対応**。中国語圏の歌詞コーパスで標準中国語のラップ以外の487曲を1曲ずつ確認した結果、最後のコーラスは変更なし43%、文字の変更25%、末尾の追加21%、全面書き換え4%だった。主な処理は変更なし、1〜3字の変更、末尾の追加の3つで、
**全面書き換えは少数にとどまる。書き換えると前の2回で作った期待が失われる**。曲の側でも同じで、最後のコーラスに `new` を指定するのは、ほぼ常に不適切。

### 7.5 曲全体の終わり方

まず**このセクションの前に完全終止があるか**を確認する。まだ終止していないなら、縮小で提示そのものを短くする。
すでに終止していて、さらに一節続けたい場合に補足を使う。3つの方法にはそれぞれ用途がある。

- **縮小**。高揚を伴わず収束へ向かい、展開と響きを次第に静める。主に曲末やその手前で使う（杨 p0136）。
  中間の音型の省略、均等に分散した省略、転調を伴う縮小の選び方は [reference.md](reference.md) §2.2 を参照。
- **補足**。完全終止の後に一節をつなぎ、目的は3つからひとつ選ぶ。性急な終止を補強する、
  情緒と響きを徐々に弱める、すでに達したクライマックスを保つかさらに強める（杨 p0142）。用途の詳細は [reference.md](reference.md) §7.2。
- **音価を縮小してオスティナートの伴奏にする**。旋律や hook の音価を縮小してひとつの音型を作り、旋律が本格的に入ってからも下で鳴らし続ける。
  こうしてオスティナートの伴奏音型になる（ドヴォルザーク《催眠曲》の前奏がその例。杨 p0119）。
  Outro のループ音型は hook の音価を縮小してそのまま作れるため、別に書く必要がない。

## 8. ARR-SPEC の項目との対応

| 項目 | 型 | 必須 | 説明 |
|---|---|---|---|
| `material.motif` | str | ✅ | **譜面を使わず文章で記述する**。音程の輪郭、リズム型、長さを記入する。音程またはリズムが欠けていれば未記入扱い（§1） |
| `material.character` | str | ✅ | 性格を一文で記述する |
| `material.stated_in` | list | ✅ | 原型を提示するセクションの id。複数指定可。**途中で現れ、以後の展開の出発点となる新しい楽想も含む**（杨 p0110） |
| `form[].development` | str | ✅ | **値は所定の集合から選ぶ**。主値を先に書き、副値は `+` でつなぐ（例 `fragment+sequence`）。リスト形式も可。指定できる値は以下の10個。<br>`repeat` `sequence` `extend` `contract` `fragment` `vary` `augment` `counterpoint` `new` `recap` |

- 10個の値で表しきれない場合は、最も近い値を選んで `form[].note` に一文を添え、独自の値は作らない（§2.3）。
- `recap` を指定したら `note` に**原形か力動的か**を記し（§3.10）、`new` を指定したら**新素材導入の類型**を記す（§3.9）。

```yaml
material: {motif: "4音で順次下行した後、4度跳躍して戻る。前が短く後ろが長い弱強型。1小節半", character: "何か言いかけて口をつぐむような性格", stated_in: [A1]}
form:
  - {id: A1, name: Verse,      development: repeat, note: "原型を提示し、第2句の末尾を差し替える"}
  - {id: B1, name: Pre-Chorus, development: "fragment+sequence", note: "動機の後半を取り出し、上行する反復進行を2回行う"}
  - {id: D,  name: Bridge,     development: new, note: "継承型の新素材導入。拍子、テンポ、調性は維持する"}
  - {id: C3, name: Chorus,     development: "recap+augment", note: "力動的再現。hook の最初の楽節を2倍の音価にする"}
```

| 関連項目 | 担当 | このスキルとの関係 |
|---|---|---|
| `form[].harmony` | `mc-harmony` | 同じセクションで `vary` を指定する場合、和声側では新しいコードを加えない7種の変奏を使える（§6.3） |
| `form[].melody_register` | `mc-melody` | セクション間に対比をつける。力動的な `recap` では音域を引き上げることが多い |
| `form[].bars` | `mc-form`／`mc-arrangement-arch` | `extend` と `contract` では必ず `bars` が変わる。セクション名と展開手法は別項目なので、最後のコーラスの名称が Chorus で展開手法が `recap` でも矛盾しない |
| `arrangement.energy_curve` | `mc-arrangement-arch` | `fragment` と連続的な音価の縮小はエネルギーを高め、`contract` と補足はエネルギーを下げる |

★ **記入順**。`material` と `form[].development` は骨格を決めた後、旋律と和声を書く前に決める。根拠は、シェーンベルクの「冒頭が後続を決める」（p0041）と、
杨儒怀の「原型の提示は以後のあらゆる展開の出発点となる」（p0110）。素材を先に決めてから旋律を書くことで、各セクションの素材がどこから来たかを説明できる。

## 9. 書き終えた後の必須チェック

**素材と各セクション**

- [ ] `motif` に**音程の輪郭、リズム型、長さがすべて揃い**、譜面を使っていない。`character` は一文で性格を説明している
- [ ] `stated_in` は空ではなく、指定したセクションの `development` に `new` を使っていない
- [ ] すべてのセクションに `development` があり、主値が先頭にある。`extend` と `contract` は `bars` と整合している
- [ ] すべての `recap` で**原形か力動的か**を明記している
- [ ] すべての `new` で**新素材導入の類型**（継承型／合成型／対置型、または派生的／並置的）を明記している

**全曲に関する3つの注意事項**（目安を外れる場合は `note` に理由を明記する。★ 3つの閾値はこのリポジトリ独自の基準。底本が示しているのは、機械的反復は2回を超えない、新素材導入は最も濫用されやすい、変奏の主題は2つまで、という方向性に限られる。曲の側で「各セクションがどの手法を使ったか」を集計したコーパスはまだなく、データが得られた段階で目安を見直す）

- [ ] ★ **`new` を指定したセクションは全体の半数以下**。半数を超えたら、まず既出の素材を展開できずに新素材を積み重ねていないか確認する（§2.2）
- [ ] ★ **全曲のうち少なくとも1セクションが `recap` または `repeat`**。ひとつもなければ、曲中で戻ってくる素材が何もない（杨 p0112）
- [ ] ★ **すべてのコーラスの `development` を `new` にしない**。毎回まったく新しいと、そのたびに聴き手に hook を覚えてもらうことになる

**その他**

- [ ] 全曲を主に進める手法が、加工処理、漸次的な展開、対比のどれかを説明できる（§5.1）
- [ ] 全曲をつなぐ仕掛けが少なくともひとつある。末尾の共通化、末尾と冒頭の連結、動機の貫徹、セクションをまたぐ伴奏音型のいずれか（§5.2）
- [ ] 1番、2番のヴァースの初期提示に反復進行を置いておらず（§7.1）、最後のコーラスに `new` を指定していない（§7.4）
- [ ] セクション間の接続を検討し、唐突な切り替え、重なり、補足のいずれを使うか決めた（§5.3、§5.4）

## 付録：底本が扱っていない内容

- `counterpoint` について杨儒怀が述べているのは、音価の拡大・縮小を用いた模倣のみ。技法そのものは `mc-counterpoint` が扱う。対位法による展開と判定するための実用的な基準は未整備。
- 副値の組み合わせ（どの主値にどの副値を合わせるか）は底本に記述がない。reference §1.1 の代表的な組み合わせは、ここで整理したもの。
- 3つの注意事項の閾値と §7 のセクション別の既定値は、ポップスのコーパスに基づく調整を行っていない。
- ループ、サンプリング、電子音楽で、音の層の増減やフィルタリングによって展開するセクションは、10個の値のうち `repeat` または `vary` に近い。《波莱罗》のモデル（李 p0169）が唯一近い例で、それ以外は `mc-arrangement-arch` §5 の「編成が形式を作る」を参照する。
- ラップの素材の展開（flow の変化を `vary` とみなせるか、verse 間の素材にどんな関係があるか）は底本の範囲外。
- 記憶に残る hook の動機の長さについて、具体的な数値を示した底本はない。シェーンベルクは変奏動機が2小節を超えることはまれだと述べ（p0232）、李吉提は音群、楽節、楽句の小節数の範囲を示している（p0016–0019）。
