# mc-rhythm-section 参考資料　ドラムキットの楽器別編曲ルールと譜例索引

> `SKILL.md` ではリズムセクションを生演奏らしく聴かせる方法を扱う。このファイルには**楽器ごとの編曲ルール**と譜例の参照先を掲載する。
> 主な出典は **文海良《编曲》**（流行音乐学院系列）、
> **Dennis DeSantis《Making Music》**、
> **Mick Berry & Jason Gianni《The Drummer's Bible》**、
> **Tommy Igoe《Groove Essentials》**。

## 1. ドラムのリズムを組む三つの原則

> **強弱を明確にし、適度にシンコペーションを入れる。打点をずらして互いの隙間を埋める。動きと静けさを組み合わせ、音の空間に厚みを出す。** (p0037)

以下の楽器別ルールは、この三つの原則に基づく。
- **強弱を明確にし、適度にシンコペーションを入れる** → kick / snare の骨格（§2.1、§2.2）
- **打点をずらして互いの隙間を埋める** → 楽器同士の補完（§2 全体）
- **動きと静けさを組み合わせ、音の空間に厚みを出す** → 時間軸上で楽器を足し引きする（§3）

## 2. 楽器別の編曲ルール

**まずキックとスネアで強弱の骨格を作り**、次にシンバル、最後に色彩を添える楽器を加える (p0037)。

| 譜例 | 内容 |
|---|---|
| 2.1.1-1 | 4/4、キックとスネアの基本パターンで強弱の骨格を作る |
| 2.1.1-2 | クローズド・ハイハットの8分音符を加える |
| 2.1.1-3 | オープン・ハイハットをスネアと同時に鳴らし、スネアの力強さを増す |

### 2.1 キック（Kick）(p0037–0038)

| 位置 | 役割 |
|---|---|
| 強拍 / 拍内の強い位置 | **リズムの規則性**を強め、アクセントを際立たせる |
| 弱拍 / 拍内の弱い位置 | **シンコペーションの感覚**を強め、アクセントに変化をつける |

譜例 2.1.1-4、2.1.1-5（弱拍と強拍の両方にキックを置く）

### 2.2 スネア（Snare）(p0038)

- パターンに変化をつける。**強拍や拍内の強い位置にも、弱拍や拍内の弱い位置にも置ける**
- キックと**掛け合い、互いの隙間を埋める**ようにして、主要なリズムの骨格を作る

譜例 2.1.1-6、2.1.1-7（キックとスネアの補完関係）

> スネアの主な打点の間に入れる**ゴーストノート**は `SKILL.md` §5 を参照。生演奏らしさを出すにはゴーストノート、編曲の骨格を作るにはここでのルールが必要になる。

### 2.3 クローズド・ハイハット（Closed Hi-hat）(p0038–0039)

| 用途 | 説明 |
|---|---|
| **安定させる** | キックとスネアが広い範囲でシンコペーションするとき、規則的に刻んでリズムを安定させる（譜例 2.1.1-8） |
| **前進させる** | クローズド・ハイハット自体で**シンコペーションを演奏**し、前進感を出すこともできる（譜例 2.1.1-9） |

**二つの使い方は逆の効果を持つ**ため、hi-hat で曲全体のリズムの安定感を調整できる。
キックとスネアの打点が細かく散っていれば hat は規則的に刻み、両者が規則的なら hat でシンコペーションしてもよい。

### 2.4 オープン・ハイハット（Open Hi-hat）(p0039)

- クローズド・ハイハットと組み合わせて強弱をつけ、**強拍や拍内の強い位置を示す**（譜例 2.1.1-10）
- スネアと合わせて**スネアの力強さを増す**（譜例 2.1.1-11）

### 2.5 クラッシュシンバル（Crash）(p0039)

- **フレーズの強拍**に置き、フレーズの頭を強調したり、クライマックスを盛り上げたりする（譜例 2.1.1-12）
- 全体でシンコペーションするときに**その効果を強める**（譜例 2.1.1-13）

### 2.6 タム（Tom）(p0040)

- リズムに**装飾やフィル**を加え、フレーズの始まりと終わりを際立たせる（譜例 2.1.1-14）
- ★ タムで前進感を出す方法は、**スタイルによって適否が分かれる**。
  **ポップスではスネアのフィルで代用することが多い**

> ポップスで tom fill がひっきりなしに聴こえる場合は、たいてい古いスタイルか、編曲上の使い方に問題がある。

## 3. 時間軸上のテクスチュアを変える二つの方法 (p0040–0041)

### 3.1 曲調に合わせる

| 曲調 | 方法 |
|---|---|
| **叙情的** | リズムを穏やかにして音数を抑え、**アコースティック打楽器**を選ぶ |
| **激しく力強い** | **アタックの強いドラムキットの音色**を選び、リズムの密度と打音の強さを上げる |

### 3.2 楽器を足し引きする

**定義**　各打楽器の**出入りをずらし**、感情の起伏に合わせて楽器を足したり引いたりする。

譜例 2.1.1-15 の全体の流れ

| 小節 | 鳴っている楽器 |
|---|---|
| 1–2 | クローズド／オープン・ハイハットのみ |
| 3–4 | キックを加える |
| 5–6 | スネアを加える |
| 7–8 | キックとスネアを**抜く** |

**効果**　音楽に段階的な変化をつけ、感情表現に幅を持たせる。

> ★ 第 7–8 小節で楽器を抜く点に注目。このライブラリの検証表にある
> **「少なくとも一つの楽器を先に抜く」という 59/59 の強いルール**をキット内で実践している。
> キット全体を一括で出し入れせず、キット内の楽器にも出入りを作る。

### 3.3 対比をつける

**定義**　前後のドラムパターンに**リズムの速さ**や**音色**で違いをつける（文海良《编曲》p0041–0042）。

時間軸上のテクスチュアを変える方法は、§3.2 の足し引きと、ここで扱う対比の二つ（p0040）。
足し引きでは**鳴っている楽器の数**を変える。対比では**楽器の数を保ったまま、パターンの形を変えられる**。

**方法一　リズムの速さで対比をつける**（譜例 2.1.1-16）

| | 前半の四小節 | 後半の四小節 |
|---|---|---|
| ハイハット | 8分音符（ゆったり） | 16分音符（細かい） |
| スネア | | 音価を短くする |
| キック | | 打点を増やす |

**方法二　音色で対比をつける**（譜例 2.1.1-17）

| | 前半の四小節 | 後半の四小節 |
|---|---|---|
| ハイハット | クローズド・ハイハット | オープン・ハイハット |
| スネア | リム打ち（Ride） | 通常のショット |
| キック | 同じ | 同じ |

★ **特に覚えておきたいのは二つ目の方法**。**リズムパターンの音符は一つも変えず**、ハイハットを閉から開へ、スネアをリム打ちから通常の打ち方へ替えるだけで、
後半の四小節の熱気が明らかに増す。

**使い分け**　楽器を増やさずに前進感を出したいときに対比を使う。
すでにセクションの音が詰まっていて、さらに重ねると濁る場合は、楽器を増やすよりパターンを変えるほうが効果的。

## 5. 和声楽器（テクスチュアの「壁」）(p0049–0051)

この話題は `mc-rhythm-section` と `mc-texture-layering` にまたがる。
**リズムの形はここで、帯域は後者で扱う**。

> ドラムのリズムとベースで作った土台と骨格の上に、和声楽器で**さらにテクスチュアの厚みを増し、
> テクスチュアの「壁」を作る**。

| 形 | 定義 | 譜例 |
|---|---|---|
| **和声型**（静的） | **コードの長音**を持続させて動きの少ない和声の下地を作り、**さまざまな楽器の音色をなじませる** | 2.1.3-1（String 全音符） |
| **リズム型**（動的） | **リズムパターン**として**ブロックコードや分散和音**を内声部に入れ、音楽に**前進感**を与える | 2.1.3-2（E.Piano の分散和音）、2.1.3-3（E.Piano のブロックコード、**リズムはベースと同じ**） |

**厚みの選択**　単音、二音の重なり、コードのいずれも使える。**その声部に必要な厚みで決める** (p0050)。

> 譜例 2.1.3-3 の「リズムはベースと同じ」という点に注目。
> 和声楽器をリズムセクションと一体化させる方法で、グルーヴに締まりが出る一方、その声部の独立性は下がる。

---

### 5.1 ★ コードからピアノ伴奏の音型を作る四つの手順（图解编曲 p0065–0073）

§5 の二つの形を踏まえ、ここでは実際の作り方を示す。

1. **音域を決める**。先にギターの音域を決め、ピアノの左右の手で高低から**挟む**。★ **一部だけ重ねるのがよい。完全にすみ分けると、かえってピアノの出番がなくなる**。ギターとベースを先に編曲し、ピアノは後にする（p0065–0066）
2. **左手で基本のグルーヴを作る**。オクターブで重心を上下に動かし、**バスドラムでは低音、スネアでは高音**を弾く。表拍のバスドラムではオクターブ、裏拍のバスドラムでは低音だけ、スネアでは高音だけを弾く（p0068–0069）。
   バラードではオクターブを重ねず、速い曲では重ねる。連続するオクターブの間に第五音を入れると滑らかになるが、硬質さは弱まる。★ **基本のグルーヴに含まれない音はゴーストノート程度の音量で入れれば、グルーヴが崩れない**（p0070）
3. 右手を加える
4. **右手に合わせて左手を微調整する**。★ **両手で同時に裏拍を弾くのは避ける**。特に左手がオクターブだと影響が大きい。裏拍を強調したい場合やシンコペーションでは例外とする（p0072）

**背景声部の基本は分散和音**（ベースによる分散和音を含む）。少し上行や下行を加えて旋律性を出し、さらにアプローチノートを加えて分散和音らしさを薄める（p0107–0109）。

★ **ピアノのコードの最高音は滑らかにつなぐ**（p0110–0111）。コードが変わるときは共通音を残し、共通音がなければ最も近い構成音を選んで最高音の移動を最小にする。
この処理を欠くと、つながりが悪く散漫に聴こえる。これは `mc-harmony` のボイシングの基本ルールでもあり、そちらでは低音、ここでは最高音を扱う。

### 5.2 音型を構成する四つの要素（文海良 p0051–0054）

音型は「和声楽器で一定のパターンを繰り返す奏法」で、音楽に内側から前進感を与える点が和声型と異なる（p0051–0052）。基本形は分散和音とブロックコードの二つで、ブロックコード中心の音型は単純明快に聴こえることが多い（p0052）。形を決めたら、四つの要素を調整する。

| 要素 | ルール | ページ |
|---|---|---|
| **音価** | 曲調とスタイルで決める。穏やかな曲では8分音符以上の長さを使い、激しく盛り上がる曲では16分音符で音型の動きを速める。★ **異なる音価の音符を組み合わせた分散和音は、新鮮な音型を作る重要な手段**。同じ長さの音符ばかりでは単調になる | p0053 |
| **音高の間隔** | 密集配置ではまとまりが出る。開離配置では音域が広がり、ブロックコードに厚みが出る | p0053 |
| **非和声音** | 音型に経過音、刺繍音、掛留音を加えると、意外な色彩が生まれ、**分散和音の機械的な単調さが和らぐ** | p0053–0054 |
| **つなぎ方** | コードが変わるときは、音型同士を**なるべく4度以内で滑らかにつなぐ**。跳躍は限られた箇所に使う。音型を模進させる方法もある | p0054 |

**使い方**　AI が生成する伴奏音型で最も多い問題は、四要素がすべて定型どおりなこと（等しい音価、密集配置、コード構成音のみ、次のコードの同じ形への直接の跳躍）。一つか二つの要素を変えるだけで定型から外せる。

### 5.3 アルペジオ化と転回で分散和音の跳躍を抑える（Allen 第二十一章）

ブロックコードをアルペジオにすると、和声の色彩を保ったままリズム感とグルーヴが生まれる（21.1）。方法は三つ。
1. **拍を埋める**。三和音を16分音符に合わせるには四つ目の音が必要なので、ルートのオクターブを加えて 1-3-5-1、または第三音に戻って 1-3-5-3 とする。
2. ★ **そのままアルペジオにするとコードの切り替えで大きく跳躍する**（オクターブと5度を足した幅など）。**配置を変え**、前のコードの最後の音に近い位置から次を始める。ルートを最高音に置き、第三音へ下がり、第五音へ上がってルートに戻るといった動きでつなぎ目を滑らかにする。厳密なルールはなく、通常は滑らかにつなぐが、大きな跳躍も意図して使えば面白さが出る。
3. **転回形のアルペジオ**（21.3）。同じコードの転回形を一小節内で素早く切り替える（基本形 → 転回形 → 別の転回形 → 1オクターブ上の基本形）。コードがいくつか変わったように聴こえるが、和声は同じまま。大きな跳躍がある拍は二音だけにする。

シンセのアルペジエーターでは二つの主なパラメーターで自動化できる。Rate（1/8、1/16）は §5.2 の音価、Style（Up、Down、Up then Down、Random）は方向に対応する（21.2）。アルペジエーターは転回形を選ばないため、§5.3 の手順 2 は自分で配置する必要がある。

### 5.4 二つの伴奏楽器が同時に鳴るとき（图解编曲 p0166–0167）

★ **一方がフレーズを弾くとき、もう一方は単純な伴奏に徹する**。ユニゾンやハーモニーを付ける場合は例外（p0166）。
ギターのハーモニーは下に付ける。上に付けると目立ちすぎる（p0166）。ギターのフレーズを前に出すには、ピアノの音を伸ばす（p0167）。
§5.1 の手順 1 と同じ考え方に基づく。まず楽器ごとの音域を決め、次にこのセクションでどちらがフレーズを担うかを決める。


## 6. ドラムの打ち込み（タイミングの揺れ、リニアドラミング、ゴーストノート、上下の帯域）（DeSantis）

### 6.1 スタイルに合わせてタイミングの揺れを決める

リアルタイム入力のドラムはばらつきやすく、マウス入力やクオンタイズ済みのドラムは正確すぎる。どちらも極端だと生演奏らしく聴こえない（p0154）。
**打ち込む前にスタイルを判断する**。Techno、House、Electro、EDM では**完全クオンタイズが適しており**、
打音の強さを均一にしてもよい。大半の Hip-hop は生のドラマーを直接サンプリングすることが多いため、自然な揺れを少し残す（p0154）。

揺れを残す方法は四つ（p0154–0156）。

| 方法 | 使い方 |
|---|---|
| **パーセント指定のクオンタイズ** | 強度 50% では、正しい位置までの距離の半分だけ音符が移動する。**人の演奏のずれを適度に残す**ことで、自然さを保ちながらタイミングを補正できる |
| **一部の楽器だけクオンタイズする** | 通常はキット全体をそろえる。ハイハットだけをそろえてキックとスネアはそのままにするか、逆にハイハットの揺れを残してキックとスネアをそろえる。二つの聴こえ方は大きく異なる |
| **自然に叩けるテンポを探す** | 人それぞれ最も正確に演奏できるテンポ範囲があり、速すぎても遅すぎても正確さは落ちる。そのテンポで打ち込み、クオンタイズせずに狙ったフィールが出るかを確かめる |
| **ヒューマナイズ** | タイミングとベロシティに細かなばらつきを加える |

★ **見落としやすい聴覚上の特性**。再生が遅いとタイミングのずれが目立ち、速いと目立ちにくい（p0156）。
遅いテンポで打ち込んだドラムは、速く再生すると実際より正確に聴こえる。

### 6.2 リニアドラミングでは拍を刻む役とアクセントの役を分けない

リニアパターンでは**各楽器を等しく扱い**、特定の打点を強調するために声部を重ねることを避ける（p0163）。

- テンポによって性格が変わる。速いテンポ（例 170 bpm）では転がるように聴こえ、**個々の音符より各声部が合わさったラインのほうが明瞭に聴こえる**（p0163）
- drum and bass の groove でよく使われる（p0163）
- すべて16分音符で書き、16分音符の位置すべてに音を置くといった制約を加えてもよい
- ★ **キット内の各楽器を対等に扱える**。拍を刻む役とアクセントを付ける役の従来の分担がなくなり、どの楽器も支配的にならない（p0164）
- 同じ音符の組み合わせでも、一部のベロシティを変えるだけで性格が大きく変わる（p0164）
- **常に一声部に限定する必要はない**。同時に鳴らしたほうがよい箇所では音を重ねる（p0164）

### 6.3 ゴーストノートが成立する音源

目立つ音の間を埋めるごく弱い音で、通常はスネアで叩く（p0166）。
純粋な電子音楽では各楽器のベロシティが一定のことが多く、生のドラマーの叩き方とは大きく異なる（p0166）。

**二つの使い方**（p0167–0168）

1. **前進感を出す**。裏拍の間に弱いスネアを加える。たとえば第1拍と第3拍で、16分音符の2つ目と3つ目の位置に入れる
2. **構成上の節目を予告する**。ごく速い連打で次の頭拍へ導く。32分音符の連打から頭拍のキックまでが、一続きの動きとして聴こえる。
   効果を誇張するには、これらの音を拍より明らかに遅らせる（§6.1 のタイミングの揺れと併用する）

★ **ゴーストノートにはベロシティに反応する音源が必須**（p0168–0169）。
マルチサンプリングのアコースティックドラム音源には弱打のサンプルがあり、実際のドラムのように反応する。**打音が強弱で変わらないドラムマシンも多く、ゴーストノートを足しても別のパターンになるだけ**。
打ち込む前に、音源がベロシティに反応するか確かめる。

通常はスネアに入れるが、ほかの楽器で試してもよい（p0169）。

### 6.4 上半分と下半分

実物のドラムキットの配置を理解しておくと、実際の演奏を想定してビートを組める（p0171）。

| 位置 | 楽器 | その位置に入る理由 |
|---|---|---|
| **上半分** | ハイハット、ライド、クラッシュのほか、スプラッシュ、チャイナシンバル、ゴング | 実物の位置は太鼓類より上にあり、周波数帯域も高い |
| **下半分** | キック、スネア、タム | 位置も周波数帯域も低い |

**スネアはどちらにも分類できる**。周波数では両者の中間にあり、ここでは下半分に入れる（p0171）。

**使い方**　この区分を帯域配分の出発点にする。全体として上半分は高域、下半分は低中域を占め、
スネアの帯域が両者の境界に当たる。ここは他の音と最も競合しやすい。

ランダマイズと責任（p0273–0274）は本文 §2.4 を参照。

## 9. groove の分類とフィール（Groove Essentials）

### 9.1 本書の分類

- 全六章は Rock、Funk、R&B/Hip-Hop、Jazz、World/Specialty、Global Tours（p0008）。各 groove に SLOW と FAST の二段階のテンポがある（p0003）。
- **細分と拍位置による分類**。Rock は8分音符の groove、16分音符の groove、half-time groove に分かれる（p0019）。Funk は分類名というより概念で、アクセントの位置をずらすのが特徴（p0041）。
- **feel による分類**。Jazz は swing（easy / lazy / relaxed / bright / bouncy / driving / up）、shuffle、2-feel、Jazz Waltz in 3 と in 1 に分かれる（p0064–0078）。R&B/Hip-Hop には swing feel の loop 型、アクセントで8分音符に焦点を移す16分音符の型、half-time shuffle がある（p0052–0056）。
- **地域別の分類**。World の章では Disco、classic 2-beat、2nd line、Reggae、Calypso、Soca、Bossa、Samba（遅い／中くらい／速い）、Baião、Batucada、Merengue、Cha-Cha、Bolero、Mambo、Songo、Nañigo、Mozambique、Salsa、Tango、Beguine を地域別に掲載する（p0082–0111）。2nd Line は複数のジャンルにまたがる groove で、Zydeco / Cajun / Swamp / Funk / Gospel / Brass Band のいずれにも現れる（p0112）。
- **テンポ**。プロ向けの譜面にはテンポの数値があまり記されないため、本書も意図的に bpm を**記載しない**。「fast」でも、ある晩には遅すぎ、別の晩には速すぎることがある。メトロノームで自分で測って記録する（p0116）。スタイル別に範囲を示す Drummer's Bible と併せて読むと、**範囲を出発点にし、最終的には「feels good」でテンポを決める。**

### 9.2 フィールの主要用語

| 概念 | 内容 | ページ |
|---|---|---|
| Time center | 共通のパルスに対して groove がどこに乗るかを示す。pushing ahead / laying back / dead center。rushing（テンポが速まること）や dragging（テンポが遅くなること）とは区別する | p0028 |
| Tight / loose | tight = バンド全体で歯切れのよいリズムを演奏すること。緊張することとは別で、loose = sloppy | p0028 |
| 声部ごとの time center | 同じ曲の中で、パーカッションは spot on でかなり前寄り、ベースはやや太め（少し後ろだがテンポは落とさない）、ドラムは両者の間を探る（p0035）。ベースはギターより後ろ、ギターは鍵盤より前に出る。こうした層の違いが人間らしさを生む（p0042） | p0035、p0042 |
| 電子ドラムと共演する | 電子ドラムの打点とぴったり合わせ、flam が生じないようにする | p0035 |
| 重ねた groove の flam を避ける | four-on-the-floor では各楽器の打点を完全にそろえる | p0022 |
| Half-time feel | backbeat は 2&4 から第 3 拍に移り、音楽の流れは速く感じられる。自然に開放感が生まれ、間も広がる。遅いテンポではその間を詰めて走りやすいため、頭の中ですべての細分を鳴らし続ける | p0036、p0038 |
| Swing の強さ | はっきり（タイトに）出すことも、ほのかに（ゆったりと）出すこともできる。ride beat がバンド全体の swing の強さを決めるため、一貫させる | p0052、p0056 |
| Shuffle | 「特定の backbeat を持つ swing」と考える（Drummer's Bible では各拍の3連符の 1、3 番目と定義する。p0013。両方を参照） | p0072 |
| 2-feel | 演奏の強さと音量を抑えて間を広げる。タイムの正確さは保つ | p0074 |
| Open hi-hat | 開いたハイハットは groove の中で閉じる。閉じる位置が適当だと groove-killer になる | p0030 |
| Hi-hat の音量 | 速い hi-hat の三つのコツは、どれも「強く叩きすぎない」こと | p0033 |
| リズムのずれによる緊張感 | キックをベースラインと意図的にずらして緊張感を作る。小節の前半で打点をそろえ、後半でずらす = 同じ groove の中で緊張と解放を生む | p0021、p0034 |
| 変奏の頻度 | ときどき使う。曲中ずっと変奏すると、せわしないドラムマシンのように聴こえる | p0025、p0027 |
| 音数の多い groove の三つの確認項目 | キット内の強弱のバランス / 細分の正確さ / アンサンブルへの意識 | p0043 |
| Ghost のベロシティ | 主な打点の間の音を強く叩きすぎると、リズムが濁る | p0057 |
| click がないときのドラマーの役割 | 全体のテンポ、time center、16分音符の細分、backbeat の位置、swing の強さ、Samba のうねり、clave、Merengue の推進力を示す | p0015 |
| Groove はケーキの本体 | 変わった技はアイシングで、groove がケーキ本体に当たる | p0124 |

### 9.3 このスキルの他の節との対応

- time center → `SKILL.md` §3 push/pull。Groove Essentials が述べる各声部の共通パルスに対する**一貫した**位置は、§3 の「声部ごとにグリッドから一定の傾向でずれる」ことと同じ。ずれの量は引き続きミリ秒で記す。§3 の例ではベースが前、ギターが後ろで、Groove Essentials の例ではパーカッションが前、ベースがやや後ろ。方向はさまざまだが、**声部ごとに位置が異なる**点は共通する。
- 重ねた groove の flam を避ける → `SKILL.md` §2.0。four-on-the-floor 系のスタイルではドラムキットの完全クオンタイズが適している。他の声部には独自の time center を持たせてもよい。
- リズムのずれによる緊張感 → `SKILL.md` §7.1 交織型。Groove Essentials の「前半で打点をそろえ、後半でずらす」は、小節単位で重ねる箇所と分ける箇所を決める方法に当たる。
- half-time → ARR-SPEC `groove.feel: halftime`。backbeat が第 3 拍に来ることが判断基準。
